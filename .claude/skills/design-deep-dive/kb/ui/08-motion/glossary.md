# Глоссарий: движение в интерфейсе

Сводный глоссарий проекта собирается в `../00-glossary/`. Смежные глоссарии: `../04-shape-elevation/glossary.md` (тени, слои, фокус), `../07-iconography-imagery/glossary.md`, `../09-design-tokens/glossary.md`.

## Базовые понятия

**Движение** (motion) — визуальное изменение состояния интерфейса во времени. В отличие от «анимации» как жанра, движение в UI служебно: объясняет, что изменилось и откуда взялось. Пример: поповер вырастает из кнопки за 150 ms.

**Переход** (transition) — изменение свойства от одного значения к другому за заданное время по заданной кривой. В CSS прерываем: при смене цели плавно уходит к новому значению. Пример: `transition: opacity 150ms cubic-bezier(0,0,0.2,1)`.

**Анимация по ключевым кадрам** (keyframe animation) — движение, заданное набором состояний в процентах от длительности. В CSS не прерывается. Пример: `@keyframes spin { to { transform: rotate(360deg) } }`.

**Длительность** (duration) — время перехода. Основная единица — миллисекунда. Пример: 150 ms (дефолт Tailwind, Carbon, Atlassian).

**Задержка** (delay) — пауза перед началом перехода. Отдельное свойство `transition-delay`. Пример: 300 ms на выходе меню, чтобы оно не гасло при случайном уводе курсора.

**Кривая, функция плавности** (easing function, timing function) — зависимость прогресса от времени. Задаётся `cubic-bezier()`, `linear()` или ключевыми словами. Пример: `cubic-bezier(0.4, 0, 0.2, 1)`.

**Кубическая кривая Безье** (cubic-bezier) — кривая по четырём числам `[P1x, P1y, P2x, P2y]`; x в диапазоне [0, 1], y произвольный. Пример: `cubic-bezier(0, 0, 0.2, 1)` — ease-out Material 2.

**Перелёт** (overshoot) — проскок цели с последующим возвратом. В кривой Безье это y > 1, в пружине — ζ < 1. Пример: `cubic-bezier(0.12, 0.4, 0.29, 1.46)` у Ant Design, перелёт до 146 %.

**Подсед** (undershoot, anticipation) — отступ в противоположную сторону перед движением. В кривой это y < 0. Пример: `cubic-bezier(0.71, −0.46, 0.88, 0.6)` у Ant Design.

## Роли кривых

**Замедление, вход** (decelerate, entrance, ease-out) — резкий старт, мягкое торможение. Для появляющихся элементов. Пример: `cubic-bezier(0, 0, 0.2, 1)`.

**Ускорение, выход** (accelerate, exit, ease-in) — мягкий старт, уход «в стену». Для исчезающих насовсем элементов. Пример: `cubic-bezier(0.4, 0, 1, 1)`.

**Стандартная** (standard, ease-in-out) — симметричная; для элементов, которые видны от начала до конца и перемещаются внутри экрана. Пример: `cubic-bezier(0.4, 0, 0.2, 1)`.

**Линейная** (linear) — постоянная скорость; только для циклов: спиннер, прогресс, шиммер. Пример: `linear` у `animate-spin`.

**Emphasized** — усиленная кривая Material 3 для крупных акцентных переходов. На Android это составной путь из двух кривых, в CSS не переводится: документация M3 честно пишет «N/A (Use Standard as a fallback)».

**Productive против expressive** (Carbon) — две «личности» движения: рабочая (незаметная, для задач) и выразительная (для смены контекста, уведомлений). Пример: productive standard `cubic-bezier(0.2, 0, 0.38, 0.9)`, expressive standard `cubic-bezier(0.4, 0.14, 0.3, 1)`.

**Bold против practical** (Atlassian) — драматичная и повседневная кривые. Пример: ease-out bold `cubic-bezier(0, 0.4, 0, 1)` для входа панели, ease-out practical `cubic-bezier(0.4, 1, 0.6, 1)` для hover.

## Пружины

**Пружина** (spring) — модель движения через физику, а не через время: параметры задают силу, а длительность получается сама. Пример: `{mass: 1, stiffness: 380, damping ratio: 0.8}`.

**Жёсткость** (stiffness, tension) — сила возврата пружины. Чем выше, тем быстрее и резче. Пример: 1400 у M3 standard fast spatial.

**Демпфирование** (damping, friction) — сила торможения. Пример: коэффициент затухания ζ = 0.9 у standard-схемы M3.

**Коэффициент затухания** (damping ratio, ζ) — безразмерная мера демпфирования. ζ = 1 — критическое затухание без перелёта; ζ < 1 — колебания с перелётом; ζ > 1 — вялый подход без перелёта. Пример: ζ = 0.6 у M3 expressive fast spatial даёт перелёт 9.5 %.

**Масса** (mass) — инерция объекта. Обычно 1. Пример: `{mass: 1.75, tension: 200, friction: 12}` у Comeau.

**Собственная частота** (natural frequency, ω_n) — `√(k/m)`, определяет темп. Пример: k = 380, m = 1 → ω_n = 19.5 рад/с.

**Воспринимаемая длительность** (perceptual duration) — параметр пружины у Apple: «approximately equal to the settling duration, but for very bouncy springs, will be the duration of the period of oscillation»; численно равна `response`. Пример: 0.5 s у всех трёх системных пружин SwiftUI.

**Bounce** — параметр Apple от −1 до 1: `1 − ζ` при ζ ≤ 1, `1/ζ − 1` у передемпфированной пружины (меньше нуля), 0 — критическое демпфирование. Пример: `smooth` 0, `snappy` 0.15, `bouncy` 0.3.

**Response** — параметр пружины SwiftUI: период колебания без трения `2π/ω_n`, с; он же `duration` в `Spring(duration:bounce:)`. Пример: ζ 0.7, k 380 → `response` 0.3223.

**Время успокоения** (settle time) — момент, после которого кривая пружины навсегда остаётся в полосе 1 % пути вокруг цели; время CSS-перехода пружины ДС — оно, вверх до 10 ms. Не путать с оценкой по огибающей t₉₉ и с `settlingDuration` SwiftUI (полоса 0,1 %). Пример: ζ 0.7, k 380 → 337 ms, в CSS 340 ms.

**Расширение пружины** (`org.design-deep-dive.spring`) — `dampingRatio` и `stiffness` при массе 1 в `$extensions` токена `transition`: из него сборка ДС выводит `linear()` и время успокоения. Пример: `{"dampingRatio": 0.7, "stiffness": 380}`.

**Допуск приближения** — на сколько ломаная точек `linear()` может отойти от кривой пружины: 0,25 % пути вместе с округлением записи. Пример: 23 точки у пружины ζ 0.7, k 380.

**Spatial и effects** (M3 Expressive) — две категории пружин: пространственные (меняют форму или положение) и эффекты (цвет, прозрачность). Effects всегда ζ = 1.0, то есть не пружинят. Пример: default spatial ζ 0.8 / k 380, default effects ζ 1.0 / k 1600.

**`linear()`** — CSS-функция кусочно-линейной интерполяции, позволяющая записать пружину без JS. Baseline Newly available с декабря 2023, Widely available с июня 2026. Пример: `linear(0, 0.007 1.85%, 0.028 3.8%, …, 1)` — 21–28 точек с процентами у пружины ДС (`04-spring-tokens-transitions-platforms.md` §1.2).

**Reversing shortening factor** — правило спецификации CSS Transitions, пропорционально сокращающее длительность прерванного перехода. Причина, по которой `linear()`-пружина плохо ведёт себя на прерываниях: пружина на 1600 ms может перезапуститься за 400 ms.

## Приёмы и хореография

**Прерываемость** (interruptibility) — возможность прервать движение новым действием без ожидания конца. Свойство `transition` и JS-пружин; у `@keyframes` отсутствует.

**Origin-aware появление** — рост элемента из точки привязки, а не из центра. Реализуется через `transform-origin`. Пример: `--radix-popover-content-transform-origin`.

**Стаггер** (stagger) — последовательные задержки у элементов серии. Пример: 20 ms на элемент, суммарно не более 500 ms (Carbon).

**Хореография** (choreography) — согласование нескольких одновременных движений: порядок, пути, задержки. Пример: порядок появления контента у Carbon из пяти категорий.

**Движение от действия** (action-driven motion) — разные настройки перехода на вход и на выход состояния. Пример: hover кнопки 125 ms на приход курсора, 450 ms на уход (Comeau).

**FLIP** (First, Last, Invert, Play) — приём анимации перестановки: измерить позиции до и после, применить обратный `transform`, снять его с переходом. Даёт анимацию раскладки без анимации layout-свойств.

**Морфинг формы** (shape morphing) — переход между двумя контурами. В M3 Expressive относится к spatial-пружинам. В веб-сервисах применяется редко.

**Шиммер** (shimmer) — бегущая или пульсирующая подсветка скелетона. Пример: `pulse 2s cubic-bezier(0.4,0,0.6,1) infinite`, keyframes `50% { opacity: 0.5 }`.

**Подсветка изменившегося** (flash, highlight-on-change) — короткая заливка элемента после внешнего обновления. Пример: затухание 1000–2000 ms.

**Скрим, подложка** (scrim, blanket, backdrop) — затемняющий слой под модальным окном. Имеет собственные токены движения. Пример: `motion.blanket.enter` = 250 ms fade (Atlassian).

## Производительность

**Композитный слой** (compositing layer) — слой, который GPU двигает без перерисовки. Свойства, не выходящие за пределы композитинга: `transform`, `opacity`.

**Layout, paint, composite** — три шага рендера. `width`/`height`/`top` задевают все три, `background-color` — два, `transform`/`opacity` — один.

**Бюджет кадра** (frame budget) — 16.6 ms при 60 fps.

**`will-change`** — подсказка браузеру, что элемент будет анимироваться; удерживает его на GPU и включает субпиксельный рендер. Цена — память GPU на каждый слой.

**Субпиксельный рендер** (sub-pixel rendering) — плавное смещение между пикселями. Доступен `transform`, недоступен `margin`/`top`.

**Сдвиг раскладки** (layout shift) — скачок контента из-за изменения размеров. `clip-path` и `transform` его не вызывают, `height` вызывает.

## Механизмы CSS и API

**`@starting-style`** — блок начальных стилей для элементов, появляющихся из `display: none` или в top layer. Baseline 2024.

**`transition-behavior: allow-discrete`** — разрешает переход дискретных свойств (`display`, `overlay`), чтобы выход элемента был виден.

**`overlay`** — свойство, отвечающее за присутствие элемента в top layer; включается в список переходов, чтобы удаление отложилось до конца анимации.

**View Transitions API** — браузерный механизм переходов между состояниями документа или между документами. `document.startViewTransition()` (SPA) и `@view-transition { navigation: auto }` (MPA).

**Scroll-driven animations** — привязка прогресса анимации к прокрутке (`animation-timeline: scroll()` / `view()`). В веб-сервисах почти не применимо.

## Шаблоны переходов и платформы

**Push и pop** — смена экрана вперёд по иерархии и возврат назад. В кабинете — смена области содержимого, в мобильном приложении — системный переход навигации. Пример: `NavigationStack` в SwiftUI, `NavHost` в Compose.

**Нижняя панель** (sheet, bottom sheet) — слой, выезжающий снизу поверх экрана; закрывается свайпом вниз. Пример: `.sheet` + `.presentationDetents` в SwiftUI, `ModalBottomSheet` в Compose.

**Выдвижная панель** (drawer) — слой сбоку, который остаётся «рядом» и уходит с торможением. Пример: `ModalNavigationDrawer` в Compose.

**Общий элемент** (shared element) — элемент, который переходит из одного состояния или экрана в другое, не исчезая. Пример: `view-transition-name` на вебе, `Modifier.sharedElement` в Compose, `matchedGeometryEffect` в SwiftUI.

**Масштаб длительности аниматоров** (animator duration scale) — настройка Android, которой «Убрать анимацию» ставит 0; Compose следует ей через `MotionDurationScale`, и движение кончается в следующем кадре.

**Уменьшение движения** (Reduce Motion) — настройка iOS: системные переходы идут растворением, приложение читает `accessibilityReduceMotion`.

**`clip-path`** — обрезка элемента геометрической фигурой. Аппаратно ускоряется, не влияет на раскладку. Пример: `inset(0 0 100% 0) → inset(0)` для раскрытия изображения.

## Доступность движения

**`prefers-reduced-motion`** — медиа-фича, сообщающая о настройке ОС «сократить анимацию». Значения `no-preference` и `reduce`. Baseline с января 2020.

**`prefers-reduced-transparency`** — то же для прозрачности; при `reduce` снимается `backdrop-filter`.

**Reduce, not remove** — принцип: пространственное движение заменяется непространственным (затухание, цвет), а не отключается полностью.

**Вестибулярный триггер** (vestibular trigger) — движение, вызывающее головокружение и тошноту. Три фактора: доля экрана, рассогласование направления и скорости, пройденная дистанция.

**Change blindness** — неспособность заметить изменение, произошедшее мгновенно. Одна из причин, по которой движение полностью убирать нельзя.

**WCAG 2.3.3 Animation from Interactions** — уровень AAA: анимацию, запущенную действием пользователя, можно отключить.

**WCAG 2.2.2 Pause, Stop, Hide** — уровень A: у движения, запущенного автоматически и идущего дольше 5 секунд параллельно с другим контентом, должен быть контрол паузы.

**WCAG 2.3.1 Three Flashes** — уровень A: не более трёх вспышек в секунду.

## Токены

**Токен длительности** (duration token) — в DTCG объект `{value: number, unit: "ms" | "s"}`. Пример: `{"value": 150, "unit": "ms"}`.

**Токен кривой** (cubicBezier token) — массив из четырёх чисел. Пример: `[0, 0, 0.2, 1]`.

**Составной токен перехода** (transition token) — `{duration, delay, timingFunction}`. Пример: `motion.transition.popupEnter`.

**Семантический токен движения** — токен, названный по назначению, а не по значению. Пример: `motion.popup.enter.top` (Atlassian).

**Токен-keyframe** — именованный набор ключевых кадров, вынесенный в систему токенов. Пример: `motion.keyframe.scale.in.small` = 95 → 100 % (Atlassian), `--p-keyframes-bounce` (Polaris).

**`motionUnit`** — множитель скорости всего продукта. Пример: 0.1 s у Ant Design, от него считаются Fast/Mid/Slow.
