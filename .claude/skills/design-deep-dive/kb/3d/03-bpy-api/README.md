## Выжимка папки

1. Код «по памяти» написан для 3.x–4.x: из 95 типичных фрагментов в 5.2.2 падают 87 — сверять с таблицей `03 §4` и `bpy_probe.py`.
2. Треть ошибок нейросетей тихие (14 из 41): заканчивать каждый скрипт отчётом и `assert` (`04 §4.5`).
3. data API вместо операторов (в 50–700 раз быстрее, не зависит от выделения); операторы — через `temp_override` и проверку `{'FINISHED'}` (`01 §4`).
4. Каждый объект — в коллекцию сцены; объекты в MCP искать по тегу, не по имени (имена переводятся, «Cube» → «Cube.001») (`01 §3`, `04 §4.3`).
5. Ноды — по `type`/`bl_idname`; режим ноды до поиска сокета; сокет — по имени среди доступных; `link.is_valid` (`02 §2`).
6. Principled BSDF v2: 32 входа, новые имена (Specular IOR Level, Transmission/Coat/Sheen Weight, Emission Color + Strength) (`02 §3.2`).
7. Входы GN-модификатора 5.2 — `mod.properties.inputs.<id>.value` + `ob.update_tag()`; `mod["Socket_N"]` сломан (`02 §5.2`).
8. EEVEE 5.x: `BLENDER_EEVEE`; bloom — Glare в `scene.compositing_node_group`; `use_auto_smooth`, `Action.fcurves`, `scene.node_tree` удалены (`03 §5`).
9. Габариты — после `view_layer.update()` и по `bound_box` оригинала (у вычисленных текста/кривых он неверен) (`01 §5.4`).
10. Помощники bpyx (25/25 тестов в `blender -b` и PyPI-bpy) закрывают все эти ловушки — подключение в `snippets/README.md`.
