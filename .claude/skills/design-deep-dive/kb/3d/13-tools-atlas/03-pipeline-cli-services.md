## Выжимка для агента

1. **CLI-конвейер уже в `../../scripts/3d/node` и `99-raw/tools/bin`** — не переустанавливать: gltf-transform 4.5.0,
   gltfpack 1.2 (npm-версия без BasisU/WebP + нативный бинарник с ними), toktx 4.4.2, gltf-validator
   2.0.0-dev.3.10 → §1.
2. **`gltf-transform prune` в 4.5 по умолчанию `keepLeaves: false, keepExtras: false`** — удаляет пустышки-метки и
   `userData`; если метки/extras нужны для JS — явно `--keep-leaves --keep-extras` или отдельный шаг без `prune`
   → §1 (`../08-export-gltf/03-compression-textures-budgets.md §1.2, §4`).
3. **`gltfpack -ke` не сохраняет extras мешей** (только `-kn`/`-km` для имён/материалов); без `-ke` теряются любые
   свои данные на меше (например, `_WAVE`-атрибут или JSON-паспорт в extras) → §1 [I §4, E/28].
4. **mcp-for-blender 2.0.3 — 3 неисправленные CVE, не 2**: CVE-2026-10661 (CVSS v3.1 4.3), **CVE-2026-10662** —
   SSRF issue #203, опубликован NVD 02.06.2026 — до волны 1, C1 его пропустил («CVE нет»), CVSS v3.1 6.3, и
   CVE-2026-10688 (exec через необязательный safe mode, CVSS v3.1 5.5). Ни одна не исправлена на 23.09.2026;
   `pip-audit`/OSV/Dependabot их не покажут (OSV знает только форк-диапазон) → §3 [проверено: O-notes.md, NVD].
5. **Официальный Blender Lab MCP 1.0.3 (GPL-3.0-or-later, Forgejo `lab/blender_mcp`)** — работает в фоне
   (`--command blender_mcp`), документированный путь для постоянного агента; mcp-for-blender — только с окном →
   §3.
6. **GitHub API без токена = 60 запросов/час** — сначала ungh.cc (звёзды/дата пуша, без лимита) и собственный кэш
   → §3, метод сбора.
7. **Poly Haven — единственная библиотека без ключа и с однозначной CC0**: «use for any purpose, including
   commercial work», можно редистрибутировать даже внутри продаваемого продукта → §6.
8. **Hunyuan3D-2/2.1 лицензия не действует в ЕС, Великобритании, Южной Корее** — проверять регион заказчика перед
   любым использованием (не только техническая CVE-осторожность, но и юридическая) → §7 [консенсус C1/C2/G].
9. **Free-тарифы генераторов не дают чистых коммерческих прав**: Meshy Free — CC BY с атрибуцией, Tripo Free —

выключать её нужно вручную независимо от изменения (1) [O, §4; проверено вторично].

**Изоляция фонового Blender** (для O, но пограничная зона с атласом — версии те же, что видит агент-оператор):
bubblewrap (`bwrap`) 0.12.0 (LGPL-2.0-or-later, user namespaces, без sudo) и `systemd-run --user` 257
(LGPL-2.1-or-later, cgroup v2; `MemoryMax`+`MemorySwapMax=0` обязательны вместе — одно без другого не ограничивает
своп) — оба уже в системе, не требуют установки. `../../scripts/3d/blender_supervisor.py` (агент O, 298 строк) —
супервизор поверх них: `start/exec/status/stop/replay` через Unix-сокет, шаг-транзакция с откатом на контрольную
точку `.blend` при падении; строка в `../../scripts/3d/README.md` добавлена оркестратором (раздел «Эксплуатация»), сюда
занесено как запись `atlas.tsv` (`base-utility`) для полноты машиночитаемой таблицы.

## Частые ошибки

- **Ставить `bpy` из PyPI там, где уже есть `blender_run.py`** — лишний 401 МБ пакет и версия Python 3.13 отдельным
  venv ради того, что уже работает через `blender -b`.
- **Считать «2 CVE» у mcp-for-blender устаревшей цифрой волны 1** — актуально **3** на 23.09.2026 (п.4 выжимки);
  не копировать старое число в новые файлы.
- **Включать Hunyuan3D-путь без проверки юрисдикции заказчика** — лицензия прямо запрещает три конкретных региона.
- **Загружать закрытый ассет заказчика в gltf.report/glTF Compressor** без проверки политики хранения — данные уходят
  на чужой сервер.
- **Путать `gltfpack -kn/-km/-ke`**: `-ke` не спасает extras мешей полностью в некоторых конфигурациях — проверять
  результат `gltf_web_inspect.py`, не полагаться на факт передачи флага.
- **Опираться на PulseMCP/mcp.so/Glama как на полный список MCP-серверов** — официальный Blender Lab MCP туда не
  попадает (Forgejo, не GitHub).
- **Бить GitHub REST API напрямую вместо ungh.cc/кэша** при первой попытке — сжигает лимит 60/час, который общий на
  все параллельные эксперименты машины.

## Открытые вопросы и противоречия

1. **CVE-счёт mcp-for-blender**: волна 1 (C1, `04-ai-agents-mcp/01 §6.2`) — «2 CVE»; O (волна 3, свежий запрос к
   NVD 23.09.2026) — 3 CVE, включая CVE-2026-10662 (SSRF). **В реестр
   аудита X**: пропуск C1: CVE-2026-10662 опубликован NVD 02.06.2026, до волны 1; но файл `04-ai-agents-mcp/01` нуждается в обновлении даты
   актуальности.

   или беглый просмотр) — честно помечены `[не проверено]`, кандидаты на точечную проверку, если понадобятся в
   рецептах K или конвейере J.
3. **Лицензия `fake-bpy-module-5.2`** не указана на PyPI напрямую (взял с GitHub-репозитория nutti — MIT), сама
   страница PyPI поля `license` не заполняет — расхождение источников, не критично (заглушки без исполнения).

   или точечного дополнения, если понадобятся в рецептах K.
