## Выжимка папки

1. **Не стирай сцену**: в сцене человека `select_all`+`delete`, удаление всех объектов файла и `bpyx.clear_scene()` уничтожили 4, 9 и 22 из 31 его ID; «тег + своя коллекция + своя сцена превью» — 0 (`01 §1`, I/01).
2. **Своё — по тегу, не по имени**: поиск по имени перекрасил материал человека и удалил его камеру; чужое в своей коллекции — выселить; уборка — только своих ID (`01 §2`).
3. **Правка поверх**: ручные трансформации и цвета человека переносятся в `overrides` и переживают пересборку (`01 §2.5`, I/01).
4. **Камера, свет, мир и настройки рендера — в своей сцене превью**; рендер `render.render(scene=…)` не меняет сцену человека (`01 §3`).
5. **Имена для JS — `[a-z0-9_]`, уникальные после санитизации three**; смысл — в custom property объекта; постобработка `gltfpack -cc -kn -ke`; узел искать по `userData.name` (`01 §8`, I/03).
6. **Масштаб применять без переноса origin**: `transform_apply(scale=True)` переносит и location (флаги по умолчанию True) (`01 §7`).
7. **Модификаторы — идемпотентно**, стек Mirror → Boolean → Weld → Bevel → SubD → (Triangulate) → WN; резак булевых — в `glTF_not_exported` (`02 §1`).
8. **Дописывающий агент за 20 шагов**: `.blend` ×2,9, GLB 16 512 треуг. вместо 632 и габарит 1000 м; чистка своего файла возвращает 1,32 МБ и 632 треуг. (`02 §5`, I/02).
9. **Осмотри до правки, верни выделение и режим человека, обнови depsgraph, проверь `{'FINISHED'}` и размер GLB** (`04`).
10. **Объём, а не идеальность; критика — конкретная; самопроверка кода** до отправки — ловит стирание сцены, выход, узлы по имени (`03`).
