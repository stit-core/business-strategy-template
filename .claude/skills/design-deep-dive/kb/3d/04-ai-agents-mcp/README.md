## Выжимка папки

1. **Инструмент по умолчанию для агента без окна — не mcp-for-blender**: его аддон в `blender -b` не стартует; штатный
   фон есть у официального MCP Blender Lab (`--online-mode --command blender_mcp`) и у `blender -b --python`; мост C1
   даёт все инструменты mcp-for-blender без окна. → 01 §8, §10; 02 §2 `[проверено]`
2. **mcp-for-blender — для работы с окном и Poly Haven**: аддон протокола 9, `DISABLE_TELEMETRY=true`, версия закреплена,
   Hunyuan3D/Hyper3D выключены (CVE-2026-10661/10662/10688 в 2.0.3 не исправлены); оба сервера по умолчанию на порту 9876. → 01 §6, §10
3. **`execute_blender_code`**: новое пространство имён на вызов, вывод только `print`, `sys.exit()` закрывает Blender
   пользователя без сохранения, «Communication error» — это исключение в коде. → 01 §3.4, §2.4 `[проверено]`
4. **Ошибки API чинятся 1–2 повторами с traceback** (0,70 → 0,97 исполнимости на Blender 5.0), но форма от повторов не
   улучшается: главные дефекты — парящие/оторванные части; их ловит код, а не VLM. → 03 §2, §7; 05 §13
5. **«Исполнилось» ≠ «годится»**: у sonnet 8 из 8 скриптов без исключений и 1 годный; масштаб ×10–25, кадр, стыки,
   экспортируемость — главные ошибки сильных моделей. → 05 §1, §11 `[проверено]`
6. **Протокол**: паспорт стиля и ассета в метрах → один идемпотентный `build(P)` → аудит + утверждения → рендер
   камеры и 4 ракурсов → рубрика, ≤2–3 итерации с откатом → GLB → `gltf-transform` → браузер. → 04 §1 `[проверено]`
7. **Координаты — кодом, отношения — моделью; камера — по габаритам**, не углами Эйлера. → 04 §3.3, §5.4; 03 §6
8. **VLM-судья: попарно и по вопросам брифа** — попарно 0,66–0,77 согласия с людьми (пара экспертов ≈ 0,79), вопросы да/нет 88,7–91,5 %; судья — только среди прошедших проверки кодом (J `../11-evaluation-qa/02-render-critique.md` §4.2); баллы «геометрия 1–10» — почти шум;
   проверки кодом согласуются с людьми лучше (F1 0,962 против 0,549). → 03 §7; 04 §6–7
9. **Официальный MCP Blender Lab** работает без окна в 5.2.2 (`--command blender_mcp`, нужен `--online-mode`), порт 9876
   совпадает с mcp-for-blender; справка API 5.2 встроена. → 02 §2 `[проверено]`
10. **Изоляция — на том, кто запускает агента**: отдельный процесс Blender, рабочая папка, копии .blend; сотрудники Blender
    советуют отдельную машину или ВМ. → 01 §6.4; 02 §10
11. **Ни сервер, ни Blender не переживают краш сами** — надзор снаружи: супервизор `blender_supervisor.py` держит процесс живым,
    делает контрольные точки, ловит зависание/segfault/OOM по таймауту и коду выхода, восстанавливает сцену. → 06 §2 `[проверено]`
12. **Реальная граница без sudo — `bwrap`**: Blender рендерит EEVEE и экспортирует GLB, не видя `~/.ssh`, сети и чужих процессов;
    автозапуск Python из `.blend` держи выключенным (`-Y`); телеметрия в 2.0.3 выключена по коду; CVE mcp-for-blender (10661/10662/
    10688) не исправлены и не видны pip-audit. → 07 §4–5 `[проверено: O/02–03]`
