## 1. Где и как запускать

| где | как | вывод |
|---|---|---|
| MCP (`execute_blender_code`) | отправить текст `scene_check.py` целиком; паспорт — в свойстве коллекции или заменой строки `PASSPORT = None` | последняя строка `SCENE_CHECK {json}` |
| фон, один или много `.blend` | `python3 ../../scripts/3d/qa_pipeline.py scene a.blend b.blend --passports map.json` | сводка в stdout, полный JSON `--out`; код выхода 0 — замер выполнен (вердикт в JSON), 2 — сбой; с `--strict` — 0 pass / 3 review / 1 fail |
| внутри своего скрипта в фоне | `exec(code, {"bpy": bpy})` с перехватом stdout (как делает MCP) | то же |

`qa_pipeline.py scene` в том же процессе прогоняет `preflight()` агента E (`../08-export-gltf/04 §5`): потери экспорта (процедуры,
shape keys при apply, цветовые пространства, UV > 4). Замечания preflight по объектам вне ассета (свет студии, камера) понижаются до INFO.

```bash
# Python 3 + Blender 5.2.2 — [проверено] два ноутбука: протокол C1/12 и «первая попытка» sonnet
python3 ../../scripts/3d/qa_pipeline.py scene 99-raw/experiments/C1/12-protocol-objects/out/laptop.blend \
  99-raw/experiments/C1/11-naive-first-try/out/sonnet/sonnet_laptop.blend \
  --passports 99-raw/experiments/J/01-calibration/passports.json   # код 0 — замер выполнен, вердикт — в JSON; 2 — сбой
```

Вывод (сокращён): `laptop.blend` — `pass`; `sonnet_laptop.blend` — `fail`: `dims_mismatch` (0,70 × 0,96 × 0,59 м против
0,304 × 0,284 × 0,213), `floating_part` (экран 0,451 м, дисплей 0,053 м, плита клавиатуры 0,0105 м), `not_on_ground`,
`raw_sharp_edges`, `unapplied_scale`, `double_verts` [проверено].

```python
# Blender 5.2.2 — [проверено] проверка так, как её исполнит MCP: текст утилиты + паспорт
import bpy, io, json, math
from contextlib import redirect_stdout

def box(name, size, loc):
    bpy.ops.mesh.primitive_cube_add(size=1.0, location=loc)
    ob = bpy.context.object
    ob.name = name
    ob.scale = size
    bpy.ops.object.transform_apply(location=False, rotation=False, scale=True)
    return ob

base = box("Box_Base", (0.30, 0.20, 0.10), (0, 0, 0.05))
lid = box("Box_Lid", (0.30, 0.20, 0.02), (0, 0, 0.115))          # зазор 5 мм — «парит»
bolt = box("Box_Bolt", (0.02, 0.02, 0.02), (0, 0, 0.05))         # целиком внутри корпуса
cam = bpy.data.objects.new("Cam", bpy.data.cameras.new("Cam"))
bpy.context.scene.collection.objects.link(cam)
cam.location = (0.6, -0.9, 0.5)
cam.rotation_euler = (math.radians(65), 0, math.radians(33))
bpy.context.scene.camera = cam
P = {"dims_m": [0.30, 0.20, 0.125], "touch": [["Box_Lid", "Box_Base"]], "on_ground": True}
code = open("../../scripts/3d/scene_check.py", encoding="utf-8").read()
code = code.replace("\nPASSPORT = None\n", "\nPASSPORT = " + repr(P) + "\n", 1)
buf = io.StringIO()
with redirect_stdout(buf):
    exec(code, {"bpy": bpy})
res = json.loads(buf.getvalue().strip().splitlines()[-1][len("SCENE_CHECK "):])
print(res["verdict"], res["codes"])
assert res["verdict"] == "fail"
assert {"floating_part", "not_touching", "hidden_inside", "no_material"} <= set(res["codes"])
```

### 2.1. Подложка и область ассета

Правило C1 (`../04-ai-agents-mcp/04 §6.2`): при коллекциях `ASSET_*` проверяются только они. Если коллекций нет (код «первой
попытки», чужая сцена), `scene_check` сам отделяет подложку: объект с `is_shadow_catcher` или плоский меш (толщина < 1 %
размера), который шире остального ассета в ≥ 3 раза. Ловец теней opus 60 × 60 м давал `huge_scale`, `cropped`, `off_center`,
`no_material` в 7 из 8 сцен; после отделения — ни одного. Опорой для `on_ground` становится верх подложки под ассетом, иначе
z = 0 мира [проверено].

### 2.2. Парение и касание

Граф частей: ребро между A и B, если меш-зазор ≤ `touch` (BVH `overlap`; иначе минимум `find_nearest` от выборки ≤ 3 000 вершин
A к поверхности B и обратно); компоненты связности (union-find); всё, кроме крупнейшей по треугольникам, — `floating_part` с
зазором до основной группы. Старый аудит мерил зазор габаритных коробок с порогом max(2 мм, 1 % диагонали): у сцены с ловцом
теней (диагональ 85 м) порог 0,85 м — парение не ловилось вообще; у мелких деталей внутри коробки соседа — тоже.

| сцена | что нашлось | зазор | оценка |
|---|---|---|---|
| sonnet laptop | экран, дисплей, плита клавиатуры | 0,451 / 0,053 / 0,0105 м | дефект (C1) |
| sonnet phone | блок камеры с линзой, кнопка | 0,077 / 0,195 м | дефект (C1) |
| sonnet room | полка | — | дефект (C1) |
| sonnet mug | кофе внутри кружки | 0,0307 м от стенок | дефект, нет в матрице C1 |
| opus room | листья над горшком | 0,030 м | похоже на дефект |
| протокол room | абажур не касается стойки (стойка до 1,48 м, абажур 1,40–1,70 м) | 0,184 м | мелкий дефект: «логика деталей» W4 [V:whPWKecazgM 13:39] |
| opus rocket, sculpture, logo | дым, шар в узле, текст отдельно от орбиты | 0,026 / 0,050 / 1,28 м | задумано → `allow_floating` |

Порог: законные зазоры протокольного ноутбука 0,2 и 0,49 мм (C1/16), ближайший настоящий отрыв 10,5 мм → любое значение из
0,5–10 мм разделяет; принят max(1 мм, 0,2 % диагонали) — для комнаты 3 м это 9,9 мм [проверено].

### 2.3. Пересечения деталей

Старый флаг `interpenetration` (есть ли пересечение BVH) сработал в 20 сценах из 32, настоящих прорастаний (M2.3 по C1) — 2.
Попытка отделить «стык» от «прорастания» долей вершин внутри провалилась: у вставленной детали из двух колец вершин (линза,
плавник, ножка, стойка) внутри **ровно 50 %** — у законных стыков протокола и у дефектов одинаково. Проверка «внутри» по нормали
ближайшей грани ломается на вывернутом меше: кольцо ракеты с нормалями внутрь «проглотило» весь корпус (99,7 %). Итог:

- «внутри» — чётностью пересечений луча (не зависит от нормалей), доля — минимум из доли площади (центры граней) и доли вершин
  (плоскость из одной грани: центр внутри буквы, углы — нет; так `Backing` логотипа sonnet ложно «прятался»);
- пары проверяются, если пересекаются поверхности **или** коробка одной части целиком внутри коробки другой (болт внутри
  корпуса не касается его поверхности — `overlap` пуст);
- WARN только `hidden_inside` (≥ 98 %) и только в непрозрачном контейнере — невидимая деталь тратит треугольники (скрытая и
  внутренняя геометрия, AlexJJ [V:wfrAqPvbJk0 04:54, 07:11]); спрятанная деталь считается соединённой (не «парит»); ядро внутри
  прозрачного пламени (opus rocket) — INFO; остальные пересечения — INFO с долей и глубиной, решение — по рендеру (`02 §2`)
  [проверено].

### 2.4. Рёбра и сглаживание

«Сырое» ребро — двугранный угол > 85° на объекте без Bevel/Subsurf (фаска 1 сегментом превращает 90° в два по 45°). Ложные
срабатывания C1 (7 из 8 протокольных): торцы ручки, утопленные в стенку кружки; мелкие линзы и стёкла окон; low-poly дерево.
Правила: считать долю **длины** видимых сырых рёбер (порог 10 %); ребро скрыто, если точка на 0,1 мм снаружи от его середины
лежит внутри соседней детали или внутри своего замкнутого меша (ручка, сваренная с кружкой в один объект); пропускать части
< 15 % крупнейшей (третичные детали D1), листы (толщина < 2 %) и паспорт `style: lowpoly`. Сглаживание через острое ребро —
> 80° (не 60°: скругление кромки 4 сегментами даёт рёбра по 45°) [проверено].

## 3. Паспорт: поля и утверждения

Паспорт — словарь `P` из `build(P)` (C1 `../04-ai-agents-mcp/04 §3.2`); `scene_check` читает поля:

| поле | тип | проверка | уровень |
|---|---|---|---|
| `collection` | str | область ассета (иначе все `ASSET_*` или вся сцена минус подложка) | — |
| `dims_m`, `dims_tol` | [x, y, z] м, доля | габарит вычисленных мешей ±5 % по каждой оси | ERROR `dims_mismatch` |
| `touch`, `max_gap_m` | [[A, B], …], м | меш-зазор пары ≤ `max_gap_m` (по умолчанию `touch`) | ERROR `not_touching` |
| `on_ground` | bool | низ ассета на опоре (верх подложки или z = 0) в пределах `touch` | ERROR `not_on_ground` |
| `max_tris`, `max_materials` | int | бюджет | ERROR / WARN |
| `allow_floating` | [имена] | эти компоненты могут парить | INFO |
| `style` | `"lowpoly"` | не проверять сырые рёбра, гранёность, сглаживание | — |
| `framing` | `"center"` | смещение от центра → WARN (иначе INFO) | WARN |

Калибровка ±5 %: у протокольных объектов отклонение ≤ 1,5 % (телефон по глубине), у «первых попыток» — от десятков процентов до
×25 (кружка opus 2,22 м против 0,095 м) → ±5 % разделяет с большим запасом; для тонких пропорций (толщина корпуса 7,8 мм) ±5 %
= 0,4 мм — строже точности фасок, задавайте `dims_tol` 0,1 для осей тоньше 1 см [проверено: J/01; спорно для тонких осей].

```python
# Blender 5.2.2 — [проверено] паспорт в свойстве коллекции: проверка найдёт его сама
import bpy, io, json, math
from contextlib import redirect_stdout

coll = bpy.data.collections.new("ASSET_box")
bpy.context.scene.collection.children.link(coll)
mat = bpy.data.materials.new("Box_Mat")
bsdf = next(n for n in mat.node_tree.nodes if n.type == "BSDF_PRINCIPLED")
bsdf.inputs["Base Color"].default_value = (0.55, 0.12, 0.05, 1.0)
for name, size, z in (("Box_Base", (0.30, 0.20, 0.10), 0.05), ("Box_Lid", (0.30, 0.20, 0.02), 0.11)):
    bpy.ops.mesh.primitive_cube_add(size=1.0, location=(0, 0, z))
    ob = bpy.context.object
    ob.name = name
    ob.scale = size
    bpy.ops.object.transform_apply(location=False, rotation=False, scale=True)
    bpy.ops.object.modifier_add(type="BEVEL")
    ob.modifiers[-1].width = 0.004
    ob.data.materials.append(mat)
    for c in list(ob.users_collection):
        c.objects.unlink(ob)
    coll.objects.link(ob)
coll["passport"] = json.dumps({"dims_m": [0.30, 0.20, 0.12], "touch": [["Box_Lid", "Box_Base"]], "on_ground": True})
cam = bpy.data.objects.new("Cam", bpy.data.cameras.new("Cam"))
bpy.context.scene.collection.objects.link(cam)
cam.location = (0.6, -0.9, 0.5)
cam.rotation_euler = (math.radians(65), 0, math.radians(33))
bpy.context.scene.camera = cam
sun = bpy.data.objects.new("Key", bpy.data.lights.new("Key", "AREA"))
bpy.context.scene.collection.objects.link(sun)
buf = io.StringIO()
with redirect_stdout(buf):
    exec(open("../../scripts/3d/scene_check.py", encoding="utf-8").read(), {"bpy": bpy})
res = json.loads(buf.getvalue().strip().splitlines()[-1][len("SCENE_CHECK "):])
print(res["verdict"], res["codes"], res["metrics"]["passport"])
assert res["verdict"] == "pass", res["codes"]
```
