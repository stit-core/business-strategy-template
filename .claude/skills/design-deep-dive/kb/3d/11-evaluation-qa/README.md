## Выжимка папки

1. Порядок: `qa_pipeline.py scene` (≈ 2 с на 32 сцены) → рендер и рубрика → `qa_pipeline.py glb` (2–10 с) → `page` (12–16 с на режим).
2. Числа кодом раньше VLM: кадр, парение, масштаб, материалы, экспортируемость — код; прорастание на виду, суп из примитивов, вкус — рендер.
3. Без паспорта (`dims_m` ±5 %) масштаб не проверяется: кружка 2,22 м проходит все общие проверки, с паспортом ловятся 24/24 «первых попыток».
4. Калибровка J/01: ложные срабатывания аудита C1 на годных объектах 7/8 → 0 блокирующих; кадр 10/10 при 0 ложных; «прорастание» — не флаг, а INFO.
5. Подложку (ловец теней, пол) — вне ассета; `gltf_diff` — по копии `.blend` только с `ASSET_*` (иначе IoU 0,002 вместо 0,997).
6. Попарный судья меряет «богаче», код — «правильнее»: в J/02 судья выбрал бы три ассета с `fail`; судья — только среди прошедших код, два порядка в чистых вызовах;
   «вау» между дорогами (код / Blender / гибрид) — слепые пары людей в двух порядках, ИИ-судья — только отсев, решение — доля побед гибрида над кодом (`06`).
7. Рубрика делит «ошибку» (блокирует) и «вкус» (выбор среди годных); критик не переписывает замысел брифа.
8. Анимация — числом: клипы, длительности, начало в 0, углы турнтейбла в четвертях (`three_probe.py`); без сэмплов турнтейбл крутится назад.
9. Страница — ворота F1 (`gate_check`) + статика import map; TBT 150 мс десктопа на hero-lazy не проходится (172–175 мс) — `[спорно]`.
10. Регрессионный набор проверяет и агента, и сами проверки: 4 отрицательных контроля должны падать всегда.
