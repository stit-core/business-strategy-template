## 3. Решения и почему

- **KTX2 на C — не включать по умолчанию**: на GLB Z (один атлас 2048²) +301 КБ br сети (транскодер 213 КБ br), первый кадр +18…25 мс;
  выигрыш — память GPU −74 % и нет длинной задачи 53–68 мс. Включать при ≥ 2 атласов 2048² или упоре в память. Телефону — WebP.
- **Начинка — отдельным GLB**: −119 / −62 КБ br первого экрана, начинка через ≈ 51 мс после первого кадра; заглушка — начинка кода; если
  страница открыта сразу на «скане» — начинка ждётся до первого кадра; ошибка — начинка кода, `console.info`.
- **Поиск начинки**: корень сцены glTF не узел; приоритет extras `zveno_inner` → `j3_inner` → `inner` (ловушка: сцена «inner»).
- **Приём 8 через pmndrs GodRays**, а не свой raymarch по карте теней: на WebGL готового объёма с тенью нет; GodRays дал студийный фон B за
  +0,37 мс. Параметры p3: эллипс R 1,9 × 0,65 в 2,5 м за целью камеры, плотность 0,5 (0,8 поднимала весь фон), экспозиция 0,12.
- **ΔE медианы фона 3,0–3,2 (> 3) принят**: свечение намеренное; край кадра и колонка текста — как у p2 (у Cycles-кадра B с дымкой — 6,15).
- **Умолчание сцены — p2**: страница C (Z3) не меняется без явного `look: 'p3'`; A — `look: 'p3'` в `main.js`.
- **Бенч — пропускная после простоя** (медиана интервалов rAF непригодна); стенды AO/TSL CD2 считали медиану — пересчитано.
