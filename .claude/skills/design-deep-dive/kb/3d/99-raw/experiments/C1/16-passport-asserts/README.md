# C1/16 — утверждения по паспорту ассета (габариты, контакты, бюджет)

Цель: проверяемая кодом замена вопроса «детали касаются?» и «размер верный?» (по C2 проверки кодом согласуются с людьми
лучше VLM-судьи: F1 0,962 против 0,549). `passport_asserts.py` — самодостаточный код для `execute_blender_code`
(проходит безопасный режим), печатает одну строку `ASSERT {json}`: габариты ассета по оценённым мешам в мировых
координатах против паспорта (±5 %), зазор между парами частей (BVH: пересечение = 0, иначе минимальное расстояние от
вершин A до поверхности B), треугольники, материалы.
```bash
python3 ../../scripts/3d/blender_run.py 99-raw/experiments/C1/16-passport-asserts/run_on_blend.py --blend <file.blend> [-- '<JSON с полями PASSPORT>']
```
Результат (23.09.2026, Blender 5.2.2):
- ноутбук по протоколу (C1/12): `ok: true`, габариты 0,304 × 0,2842 × 0,2129 м, зазоры клавиши–основание 0,
  крышка–основание 0,49 мм, экран–крышка 0,2 мм, 14 390 треугольников, 5 материалов;
- ноутбук «первой попытки» sonnet (C1/11): `ok: false` — габариты 0,70 × 0,96 × 0,59 м (×2–4), экран висит в 0,451 м
  от основания, дисплей в 0,502 м от крышки, клавиатура в 10,5 мм от основания. Те же дефекты видны на рендере
  (`../11-naive-first-try/out/sonnet/views_laptop/sheet.png`) — проверка ловит их числом, без картинки.
