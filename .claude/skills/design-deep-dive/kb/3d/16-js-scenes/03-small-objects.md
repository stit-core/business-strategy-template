# 03 · Маленькие 3D: объект и символ в блоке — SDF в студийном свете, серия моделей, своя жизнь и отклик

Малое 3D — один предмет, символ или знак в карточке, полосе раздела или блоке рядом с текстом: не мир, а вещь, которую
хочется рассмотреть. Кодом его делают полем расстояний (SDF) в студийном свете — одним шейдером, без ассетов, в полном
разрешении. Нормы — из серии 10 студийных моделей разделов и знака проекта сайта-портрета (замеры и раунды правок
заказчика) и из набора `examples/`. Контракт движка — `01`, место на странице — `02`, длинная сцена-мир — `04`.

## Выжимка для агента

1. **Одна модель на секцию**, во всю ширину полосы или карточки; на плитке сетки — только постер. `[проверено]` → §1
2. **Форма — поле расстояний в осях предмета** из простых тел (`min`, `smin`, полярный повтор складыванием); коробка
   `BMIN..BMAX` — по всем состояниям модели. `[проверено]` → §2
3. **Марш только внутри коробки**: ≤ 140 шагов, шаг 0,92·d, стоп при d < 0,00022·t; промах ближе 1,25 px смешивается с
   фоном — край без лесенки. `[проверено]` → §2
4. **Полное разрешение при DPR ≤ 2 под бюджетом пикселей**: 4,7–13 мс при 3,7 МП на Iris Xe, 1,3–3,2 мс при 0,56 МП;
   полноэкранный SDF без объёма — 12–14 мс при 4,6 МП, ему — ½ разрешения. `[проверено]` ПК, `[кейс]` телефон → §2
5. **Студия — три мягких софтбокса и пол** с отражением (≤ 64 шагов), контактной тенью (AO 4 пробы) и мягкой тенью ключа
   (≤ 28–32 шагов); пятно студии привязано к модели, а не к кадру. `[проверено]` → §3
6. **Стекло** — Френель, преломление 1/1,5, внутренний проход ≤ 40 шагов с поглощением; печать и гравировка — ящичным
   фильтром по следу пикселя. `[проверено]` → §3
7. **Серия — одно ядро**: свет, тон, парение, отклик на курсор и пауза — общие; модель держит форму, материал, свою жизнь
   и действие по касанию. «Тут двигается, а там не двигается» — отзыв на серию без общего ядра. `[проверено]` → §4, §5
8. **Парение одно на сайт**: подъём ≤ 1,2 % размера сцены (синусы 11,3 и 17,9 с), рыскание 3,5°, наклон 1,2°; к
   курсору — 10° и 5° с поворотом студии. `[проверено]` → §4, §9
9. **Сцена без рамки**: ни карточки, ни маски — края кадра уходят в фон места (0,24 высоты по бокам, 0,17 сверху и снизу).
   «Нативно, не как вставка» — слово заказчика. `[проверено]` → §6
10. **Тихие зоны текста**: сцена знает, где лежит HTML-текст места, и гасит там яркое, импульсы и мерцание.
    `[проверено]` → §7
11. **Герой — сдвигом объектива** на ≈ 2/3 ширины на ПК, в средней полосе на телефоне; камеру ради композиции не
    поворачивают. `[проверено]` → §8
12. **Колебания крупных форм** — период ≥ 10 с или шум без ведущей частоты; полоса 2,5–6 с запрещена; вспышки ≤ 3 в
    секунду. `[проверено]` → §9
13. **У каждой модели — действие по касанию**: предмет открывается, поворачивается, шлёт волну; курсор — наклон и
    подсветка. «Больше деталей и жизни» — отзыв на модели без них. `[проверено]` → §9
14. **Постер — кадр покоя той же камеры**, широкий постер — `object-position` по сдвигу героя. `[проверено]` → §10
15. **Рецепт — 10 шагов** от смысла места до проверки в Play. `[проверено]` → §11

## 2. SDF-объект в коробке

- **Форма** — поле расстояний в осях предмета: шары, кольца, листы, плиты; объединение `min`, сглаженное `smin`, полярный
  повтор складыванием — n одинаковых частей за одну выборку поля `[проверено]`.
- **Коробка** `BMIN..BMAX` — в осях модели по всем её состояниям (раскрытие, веер, крышка); поза модели — поворот луча
  в оси модели, коробка её не учитывает. Узкая коробка режет часть формы, широкая — тратит шаги `[проверено]`.
- **Марш** — только внутри коробки (код — `01` §12): ≤ 140 шагов, шаг 0,92·d, попадание при d < 0,00022·t; промах ближе
  1,25 px смешивается с фоном по минимуму d/(t·px) — край без лесенки и без суперсэмплинга `[проверено]`.
- **Нормаль** — градиент поля по 4 выборкам «тетраэдром»; мягкая тень и AO — из самого поля, без трассировки сцены
  `[проверено]`.
- **Разрешение** — полное, DPR ≤ 2 под бюджетом пикселей (`01` §6): 4,7–13 мс при 3,7 МП. Полноэкранный SDF без
  ограничивающего объёма (рельеф во всю сцену, метаболы) — 12–14 мс при 4,6 МП: ему ½ разрешения или фон без мелкой детали
  `[проверено]`.

```glsl
float sdBox(vec3 p, vec3 b){ vec3 q = abs(p) - b; return length(max(q, 0.0)) + min(max(q.x, max(q.y, q.z)), 0.0); }
float sdCyl(vec3 p, float r, float h){ vec2 d = abs(vec2(length(p.xz), p.y)) - vec2(r, h); return min(max(d.x, d.y), 0.0) + length(max(d, 0.0)); }
float sdTorus(vec3 p, vec2 t){ vec2 q = vec2(length(p.xz) - t.x, p.y); return length(q) - t.y; }
float smin(float a, float b, float k){ float h = max(k - abs(a - b), 0.0)/k; return min(a, b) - h*h*h*k/6.0; }
vec3 polar(vec3 p, float n){                      // полярный повтор складыванием: n копий вокруг оси y
  float a = 6.2831853/n, f = atan(p.z, p.x);
  f = mod(f + 0.5*a, a) - 0.5*a;
  return vec3(cos(f)*length(p.xz), p.y, sin(f)*length(p.xz));
}
const vec3 BMIN = vec3(-1.0, -0.2, -1.0), BMAX = vec3(1.0, 0.2, 1.0);   // коробка в осях модели
float map(vec3 p){                                // втулка, 8 лопастей и обод — одна выборка поля
  float hub = sdCyl(p, 0.18, 0.12) - 0.02;
  float blade = sdBox(polar(p, 8.0) - vec3(0.58, 0.0, 0.0), vec3(0.34, 0.012, 0.09)) - 0.015;
  float rim = sdTorus(p, vec2(0.95, 0.035));
  return min(smin(hub, blade, 0.06), rim);
}
vec3 nrm(vec3 p){                                 // нормаль «тетраэдром»: 4 выборки поля
  const vec2 e = vec2(1.0, -1.0)*0.0006;
  return normalize(e.xyy*map(p + e.xyy) + e.yyx*map(p + e.yyx) + e.yxy*map(p + e.yxy) + e.xxx*map(p + e.xxx));
}
```

## 3. Студийный свет и материалы

- **Окружение** — три мягких софтбокса в гномонической проекции (прямые края остаются прямыми) и градиент; оно же светит
  модель и отражается в ней. Студия поворачивается к курсору — матрица окружения и направление ключа следуют указателю
  `[проверено]`.
- **Пол** — отражение модели облегчённым маршем ≤ 64 шагов, контактная тень AO 4 пробы, мягкая тень ключа ≤ 28–32 шагов,
  тёплая полоса света `[проверено]`.
- **Пятно студии привязано к модели** и гаснет до края кадра: свет «квадратом» и засвет у края — отзыв заказчика на
  пятно, привязанное к кадру `[проверено]`.
- **Стекло** — Френель (Шлик), преломление 1/1,5, внутренний проход по `mapIn` ≤ 40 шагов с поглощением Бера — Ламберта
  `[проверено]`.
- **Печать и гравировка** — линии и знаки на гранях ящичным фильтром по настоящему следу пикселя (`04` §7): густой узор вдали
  уходит в среднюю долю, а не мерцает; фольга — рельеф из альфы текстуры `[проверено]`.
- Тон — Neutral, фон места — `preTone`, дизеринг (`01` §5).
- **Дешёвые материалы**, когда студийный марш не нужен: matcap — освещение из одной картинки-шара, без света и окружения
  (09/04 §8) `[проверено]`; палитра всей серии одной текстурой — смена настроения или времени суток одной заменой
  (Messenger, Abeto) `[кейс]`.

```glsl
const vec3 KEY = vec3(1.0, 0.86, 0.68), COOL = vec3(0.45, 0.55, 0.7);
float softRect(vec3 d, vec2 c, vec2 hs, float soft){   // софтбокс на плоскости z = 1 в осях студии
  if (d.z <= 0.0) { return 0.0; }
  vec2 e = abs(d.xy/d.z - c) - hs;                       // гномоническая проекция направления
  return 1.0 - smoothstep(-soft, soft, max(e.x, e.y));
}
vec3 studio(vec3 d){                                     // d — направление в осях студии (повёрнутых к курсору)
  vec3 c = mix(vec3(0.012), vec3(0.03), 0.5 + 0.5*d.y);
  c += KEY*2.2*softRect(d, vec2(-0.7, 0.55), vec2(0.38, 0.24), 0.10);            // ключ сверху-слева
  c += COOL*0.6*softRect(vec3(-d.x, d.y, -d.z), vec2(-0.5, 0.25), vec2(0.3, 0.5), 0.14);   // отсвет сзади
  c += vec3(0.8)*softRect(vec3(d.x, d.z, d.y), vec2(0.0, 0.1), vec2(0.7, 0.05), 0.05);     // верхняя полоса
  return c;
}
float fresnel(vec3 n, vec3 v){ return 0.04 + 0.96*pow(1.0 - max(dot(n, -v), 0.0), 5.0); }   // Шлик, стекло 1,5
```

## 4. Серия моделей: один свет, одна жизнь

- **Одно ядро на серию**: студия, камера, тон, парение, отклик на курсор, окна автодвижения и пауза живут в ядре; модель
  — форма, материал, своя жизнь и действие по касанию. Модели разных разделов сайта двигаются одинаково: «тут двигается, а
  там не двигается» — отзыв на серию, где каждая модель жила по-своему `[проверено]`.
- **Парение ядра**: подъём 1,2 % размера сцены (сумма синусов 11,3 и 17,9 с), рыскание 3,5° (14,7 и 23,3 с), наклон 1,2°
  (12,1 с); к курсору — 10° по рысканию и 5° по наклону, студия поворачивается вместе с ним `[проверено]`.
- **Окна автодвижения**: появление 18 с, пробуждение 9–11 с; дальше модель живёт парением ≈ 30 кадров/с (`01` §7)
  `[проверено]`.
- **Детали и жизнь**: рельефная фольга, торцы листов, гравировка схем с фильтром по следу, бусины суши; своя жизнь —
  пакеты по дорожкам, кометы по дугам, блик раз в 6,5 с; действие по касанию у каждой модели. «Больше деталей и жизни»,
  «вау-эффект» — отзыв на серию без них `[проверено]`.

## 5. Модель — плагин ядра

- Ядро серии и части модели — `01` §12: GLSL (`map`, `mapIn`, `matAt`, `decal`, `extraGlow`, коробка) и JS-хуки (`frame`,
  `pose`, `step`, `tap`, `anchors`, `idle`). Модель регистрируется одной строкой в реестре моделей ядра; один файл модели
  служит и странице концепта, и месту на сайте (`opts.variant`) `[проверено]`.
- Ядра серии в наборе нет. Одна модель на месте собирается на `examples/scene-template.js`: форма и студия — в его
  фрагментном шейдере (§2, §3), поза и парение — в JS (§9), сдвиг объектива и тихие зоны — уже в шаблоне (§7, §8)
  `[практика]`. Вторая модель того же сайта — повод вынести общее в ядро: иначе парение и свет разойдутся.
- Вес: ядро 8,8 КБ + модель 2,4–9,5 КБ min+gz; знак — 13 КБ `[проверено]`.

## 6. Сцена без рамки

- Сцена — во всю ширину секции, без карточки, маски и скруглённой рамки; края кадра уходят в фон места: студия — спад
  0,24 высоты по бокам и 0,17 сверху и снизу, мир — 7 % по высоте `[проверено]`. Край кадра — ровно фон места: `preTone`
  (`01` §5) и `edgeK` дают стык без шва.
- На плитке — модель по центру на чуть поднятом фоне плитки `[проверено]`.
- Основание — «нативно, не как вставка»; «свет квадратом, засвет слева» (§3) — отзывы заказчика `[проверено]`.

```glsl
// края кадра — в фон места; ширина спада — в высотах кадра (examples/scene-template.js)
float edgeK(vec2 uv){ vec2 m = min(uv, 1.0 - uv)*uRes/uRes.y; return smoothstep(0.0, 0.24, m.x)*smoothstep(0.0, 0.17, m.y); }
// в main(): col = mix(uBg, col, edgeK(uv));
```

## 7. Тихие зоны текста

- **Где текст места** `[проверено]`: ПК — заставка 0…46 % ширины во всю высоту, подписи 0…42 % ширины × нижние 34 %;
  телефон — верхние 42 % на заставке, нижние 32 % под подписями; RTL — зеркально, геометрия не зеркалится.
- **Что в зоне** `[проверено]`: яркость не выше средней по кадру — сжатие `L / (1 + 4…6·L)` с сохранением оттенка;
  импульсы ×0,05, ореол ×0,4, мерцание мелочи — 0. Сцена под текстом становится фоном, а не соперником.
- **Набор**: `opts.layout.quiet = [x0, x1, k]` — колонка у начала строки, полная сила до x0 и спад до x1 (по умолчанию
  на месте ПК — 0,34 → 0,6); `quietY = [низ, верх, k низа, k верха]` — полосы телефона (0,32 и 0,42) `[практика]`.
- Совпадает с правилом «ни одного движения под читаемым текстом» (creative 05/01 §5.3).

```glsl
// uQuiet = (x0, x1, k, rtl), uQuietY = (низ, верх, k низа, k верха) — examples/scene-template.js
float quietK(vec2 uv){
  float x = mix(uv.x, 1.0 - uv.x, uQuiet.w);
  float q = uQuiet.z*(1.0 - smoothstep(uQuiet.x, uQuiet.y, x));
  q = max(q, uQuietY.z*(1.0 - smoothstep(uQuietY.x - 0.12, uQuietY.x, uv.y)));
  q = max(q, uQuietY.w*smoothstep(1.0 - uQuietY.y, 1.0 - uQuietY.y + 0.12, uv.y));
  return q;
}
// в main(): float L = dot(col, vec3(0.2126, 0.7152, 0.0722)); col = mix(col, uBg + (col - uBg)/(1.0 + 6.0*L), quietK(uv));
```

## 8. Сдвиг объектива

- **Внеосевая проекция**: центр кадра сдвигается в проекционной матрице (`Pm[8] = −sx`, `Pm[9] = −sy`), камера смотрит
  на героя прямо. Герой — на ≈ 2/3 ширины на ПК (sx 0,26–0,4 полукадра), в средней полосе на телефоне — между заголовком
  заставки сверху и подписями снизу (у мира sy −0,06…−0,14, чуть ниже центра); колонка текста остаётся у начала строки
  `[проверено]`.
- **Камеру ради композиции не поворачивают**: поворот показывает героя сбоку и наклоняет вертикали, сдвиг сохраняет
  анфас `[проверено]`.
- **RTL** — сдвиг с другой стороны, мир и модель не зеркалятся (`01` §1, `rtl`).
- В сцене «один шейдер» сдвиг — `uShift` в долях полукадра (`examples/scene-template.js`); по умолчанию на месте ПК —
  (0,33; 0), на телефоне — (0; 0,06) `[практика]`.

```js
// перспектива со сдвигом центра кадра (по столбцам); sx, sy — сдвиг в долях полукадра: 0,33 — герой на 2/3 ширины
function perspectiveShift(fovDeg, asp, near, far, sx, sy) {
  var f = 1 / Math.tan(fovDeg * Math.PI / 360);
  return new Float32Array([f / asp, 0, 0, 0, 0, f, 0, 0, -sx, -sy, (far + near) / (near - far), -1,
    0, 0, 2 * far * near / (near - far), 0]);
}
```

## 9. Своя жизнь, курсор и касание

- **Колебания**: крупные формы — период ≥ 10 с или шум (суммы синусов 11–41 с без общих долей); полоса 2,5–6 с
  запрещена (creative 05/01 §6.3); парение ≤ 1,2 % размера сцены, рыскание 3,5°, наклон 1,2° `[проверено]`.
- **Курсор** — наклон модели 10° и 5° с поворотом студии, подсветка ближней части; сглаживание τ 0,35–0,45 с,
  присутствие τ 0,5–0,6 с; только `pointerType !== 'touch'` `[проверено]`.
- **Касание** — действие предмета: крышка открывается, кольца делают оборот, стопка раздвигается, волна идёт по дугам;
  отпускание со сдвигом < 6 px, не чаще раза в 0,34 с; вспышки ≤ 3 в секунду `[проверено]`.
- **Части-кнопки** — выбор проекцией центров частей в CSS px (`01` §8), каждую часть дублирует кнопка HTML `[проверено]`.
- **Пороги по прокрутке** (включить свет части, открыть лист) — с гистерезисом 0,012 по p: включается выше порога,
  выключается ниже порога − 0,012, без дрожи на границе `[проверено]`.
- **Пауза** останавливает и парение, и свою жизнь (`02` §12) `[проверено]`.

```js
// парение ядра, одинаковое у всех моделей: s — размер сцены, t — время своей жизни, (hx, hy) — курсор −1..1, h — присутствие
function floatPose(t, s, hx, hy, h) {
  var TAU = Math.PI * 2, DEG = Math.PI / 180;
  var lift = 0.012 * s * 0.5 * (Math.sin(TAU * t / 11.3) + Math.sin(TAU * t / 17.9 + 1.7));
  var yaw = 3.5 * DEG * 0.5 * (Math.sin(TAU * t / 14.7) + Math.sin(TAU * t / 23.3 + 0.9)) + 10 * DEG * hx * h;
  var tilt = 1.2 * DEG * Math.sin(TAU * t / 12.1 + 0.4) + 5 * DEG * hy * h;
  return { lift: lift, yaw: yaw, tilt: tilt };
}
```

## 11. Рецепт «предмет в блоке»

1. **Смысл и место**: предмет — из существительных бизнеса и фактов места (`05` §1); место — полоса раздела или карточка,
   одна модель в секции; на плитке сетки — постер.
2. **Форма** — поле расстояний в осях предмета из простых тел; повторы — складыванием; коробка — по всем состояниям (§2).
3. **Студия** — три софтбокса, пол с отражением, AO и мягкой тенью; пятно света привязано к модели; края кадра — в фон
   места (§3, §6).
4. **Материал** — стекло или свой; печать и гравировка — ящичным фильтром по следу пикселя (§3).
5. **Поза и жизнь** — парение ядра, наклон к курсору 10° и 5°, своя жизнь с периодами ≥ 10 с, действие по касанию (§9).
6. **Раскладка места** — сдвиг объектива, тихие зоны под текстом, подписи частей — HTML по якорям (§7, §8).
7. **Цвет и чёткость** — линейный расчёт, Neutral, `preTone`, дизеринг; DPR ≤ 2 под бюджетом пикселей, множитель
   0,7…1 (`01` §5, §6).
8. **Прокрутка** — `scrub` по проходу полосы (ω 6,5) или окно появления 18 с; своя жизнь ≈ 30 кадров/с, вне экрана — 0
   (`02` §6, `01` §7).
9. **Стенд** — постер и кадры состояний (§10); цена — `bench` при 1440×640 DPR 2 и 390×360 DPR 3, в бюджете кадра
   `01` §6.3.
10. **Play** — модель чёткая, свет без «квадрата», края в фон, парение как у соседних моделей, касание делает действие,
    пауза останавливает всё (`06` §5).

## Частые ошибки

- **Полноэкранный SDF в полном разрешении без коробки** — 12–14 мс на сцену, которую можно ограничить объёмом.
- **SDF-предмет в ½ разрешения** — «модели нечёткие» (`01` §6).
- **Пятно студии привязано к кадру** — свет «квадратом» и засвет у края.
- **Карточка или маска вокруг сцены** — «как вставка»; края — в фон места.
- **Парение с периодом 3–5 с** — вестибулярная полоса и клише «вечного качания» (`cliche:floating-bob-loop`).
- **Своё парение у каждой модели** — «тут двигается, а там не двигается».
- **Касание — случайная вспышка** вместо действия предмета; вспышки чаще 3 в секунду.
- **Наведение по касанию** — подсветка «залипает» на телефоне.
- **Композиция поворотом камеры** — герой сбоку, вертикали падают; сдвиг объектива.
- **Яркое и мерцающее под колонкой текста** — нет тихих зон.
- **Текст и подписи частей в холсте** — не читаются диктором; HTML по якорям.
- **Нет постера** — пустой прямоугольник в обзоре холста, в статичной копии и при reduce.

## Открытые вопросы и противоречия

- **SDF ½ разрешения** — 09/04 (выжимка п.7, §2.5, §10); норма этой папки — §2 и `01` § Открытые вопросы.
- **Амплитуда парения.** creative 05/01 §6.3: «амплитуда ≤ 2–4 % высоты объекта, наклон ≤ 3°». Парение папки — 1,2 %
  размера сцены и наклон 1,2°; рыскание 3,5° — поворот вокруг вертикали, а не наклон. Если creative считает наклоном и
  рыскание, норма папки шире на 0,5°.
- **«Уменьшить движение» у малой модели.** Набор снимает сцену целиком и оставляет постер; 09/05 (выжимка п.17) и
  creative 05/01 §4 — «уменьшить, а не убрать»: ручное действие остаётся. Вариант — модель без своей жизни и без скраба,
  касание — мгновенной сменой состояния; в наборе не сделан `[не проверено]`.
- **Ядро серии** в набор не входит: модель на месте — шаблон «один шейдер» (§5); ядро серии собирается по `01` §12.
- **Студия кодом и студия three.** 14/02 строит студию PMREM из излучающих панелей — та же идея мягких панелей; числа
  цены у двух реализаций сравнивать нельзя: разные машины, разное число проходов.
- **Числа телефона** — `[кейс]`: реальные телефоны не мерились.
