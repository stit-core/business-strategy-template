# 05 · Приёмы вау для сцен на JS: двенадцать семейств, приёмы студий, выбор по смыслу места

Каталог приёмов, которые делают сцену на своём движке эффектной: двенадцать семейств из 25 сцен проекта сайта-портрета (у
каждого — что, когда, рецепт, цена, риски, клише), остальные приёмы каталога, общие модули, приёмы студий из разборов и
клише. Цена — медиана кадра на Intel Iris Xe по методу `01` §9. Как сцена живёт на странице — `02`, малое 3D —
`03`, длинная сцена-мир — `04`.

## Выжимка для агента

1. **Сцену выбирают по смыслу места**: предмет и факты бизнеса внутри сцены, естественные станции сюжета, подпись-факт
   на каждой; зрелище вокруг одного знака без фактов и «игрушечный» мир деловому сайту не нужны. `[кейс]` → §1
2. **«Вау» — режиссура одной механики**: мир отвечает на ввод, у частиц есть повод, камера срежиссирована, переход —
   событие; набор эффектов без механики «вау» не даёт. `[кейс]` → §1, §7
3. **Эффект места → семейство** — таблица выбора по тому, что место должно сказать. → §2
4. **SDF-объект в студии** — предмет раздела крупно: 4,7–13 мс при 3,7 МП. `[проверено]` → §3.1
5. **Свет в пыли** — аналитическая сцена без марша, пыль видна только в конусах света: 7,1–8,4 мс при 4,4 МП.
   `[проверено]` → §3.2
6. **Линии света с ореолом** — инстанс-квады, ядро не тоньше 0,55·DPR px по энергии: 4,9–5,6 мс при 4,6 МП.
   `[проверено]` → §3.3
7. **Частицы собирают знак** — только с поводом: «логотип из частиц» — насыщенное клише; 3 600 точек — 4,4–5,1 мс.
   `[проверено]` → §3.4
8. **Обратимая адвекция** — форма рождается из капель и уходит обратно ровно по прокрутке; один проход, 3,5–6,2 мс полосой.
   `[проверено]` → §3.5
9. **Типографика из поля расстояний** — буквы в объёме, смысл — всегда HTML: 5,2–7,4 мс. `[проверено]` → §3.6
10. **Фото в 2,5D** — глубина правилами из самого кадра; лучи к солнцу — дорогая часть (32 шага на пиксель).
    `[проверено]` → §3.7
11. **Бесконечный зум** — слои порядков масштаба с весами в сумме 1, станции — PCHIP: 3,8–9,6 мс. `[проверено]` → §3.8
12. **Один дубль** — миры-плоскости одного шейдера, путь монотонными кубиками: 7,7–11 мс. `[проверено]` → §3.9
13. **Каустики стекла** — самое дорогое семейство (10,9–18,6 мс); дешёвая замена — анимированный тайл каустики.
    `[проверено]`, замена — `[практика]` → §3.11
14. **Приёмы студий, которые повторяет свой движок**: форма в вершинном шейдере у тысяч инстансов, трава одним мешем,
    палитра мира одной текстурой, мир под курсором, второстепенное реже, кадр по требованию с пробуждением. `[кейс]`
    `[исходник]` → §7
15. **Клише разборов**: жидкость за курсором, «liquid glass», тоннель огней, CA + зерно + виньетка на весь экран, логотип из
    частиц без повода, 3D-«центр» без задачи. `[мнение]` → §8
16. **Концепт на «Креативе» — сцена по тому же контракту**: выбранный концепт уходит в место без переписывания; у
    карточки — смысл, место, семейство, цена в мс и КБ. `[проверено]` → §6

## 1. Выбор по смыслу места

Из 24 показанных заказчику концептов взяты 10: листание страниц, город-плата, рост сети, лента маршрута, зал витрин, туннель
карточек, форма из капель, один дубль, зум по порядкам, созвездие. Общее у взятых — вывод из выбора, заказчик причин не
называл `[кейс]`:

1. **Сцена рассказывает смысл места через предмет и факты самого бизнеса** — настоящие фото на оси времени, сканы
   документов в витринах, точки направлений на карте, развороты с фото. Зрелища вокруг одного знака без фактов (знак из
   светил, огни строем, живой знак, свет-кисть, физика знака, плоское в объём, узор, надпись из зёрен, буквы в объёме) и
   опыты с тоном (каустики галереи, бумажный театр, мир-миниатюра) не взяты.
2. **У сюжета естественные станции** — даты, уровни, порядки масштаба, витрины, точки маршрута: они ложатся на такты `beats`,
   у каждой станции — подпись-факт. «Один раз крутнул — произвело действие» работает, когда станция осмысленна.
3. **Камера движется сквозь мир** — 4 из 10 взятых — длинные сцены на всю ширину (`04`).
4. **Цена посильная** — взятые стоят 3–11 мс при 4,4 МП; самые тяжёлые (15–19 мс) не взяты — совпадение, но удобное: две
   живые сцены помещаются в кадр.

- **Правило**: предмет сцены — из существительных бизнеса и фактов места; станции — из его истории; подпись — факт, а не
  описание эффекта (`02` §13); новый блок ради сцены допустим `[кейс]`. Концепт растёт из концепции и фактов продукта, а не
  из каталога приёмов (`../../../references/phases.md`, этап `art-direction`).
- **Студии говорят о том же**: «never creating "3D for the sake of 3D"» — Immersive Garden о GQ × AP; 3D-«центр» без задачи
  — насыщенное клише (`cliche:webgl-centerpiece`) `[кейс]`.

## 3. Двенадцать семейств

### 3.1. SDF-объект в студии

- **Что.** Предмет из простых тел — шары, кольца, листы, плиты — в студийном свете, одна модель в секции (`03`).
- **Когда.** Предмет раздела, знак, символ услуги: «рассмотреть», наклонить курсором, открыть касанием.
- **Рецепт** `[проверено]`:
  1. Форма — поле расстояний в осях предмета: `min`, `smin`, полярный повтор; коробка — по всем состояниям.
  2. Марш только в коробке: ≤ 140 шагов, шаг 0,92·d, стоп 0,00022·t; промах ближе 1,25 px — в фон.
  3. Студия: 3 софтбокса + пол (отражение ≤ 64, AO 4 пробы, тень ≤ 28–32); пятно привязано к модели; края в фон.
  4. Стекло: Френель, преломление 1/1,5, внутренний проход ≤ 40 шагов; печать — ящичный фильтр по следу пикселя.
  5. Поза в JS: парение ядра ≤ 1,2 %, наклон к курсору 10° и 5°; касание — действие предмета.
  6. Прокрутка → `scrub`; подписи — HTML по якорям.
  7. Neutral, `preTone`, дизеринг; DPR ≤ 2 под бюджетом пикселей.
- **Цена.** 4,7–13 мс при 3,7 МП, 1,3–3,2 мс при 0,56 МП; ядро 8,8 КБ + модель 2,4–9,5 КБ `[проверено]`.
- **Риски.** Полноэкранный SDF без коробки — 12–14 мс; узкая коробка режет форму; ½ разрешения — «нечётко».
- **Клише.** Хромированный блоб (`cliche:chrome-liquid-metal`), стеклянный тор на пастели (`cliche:glass-object-pastel`),
  вечное качание (`cliche:floating-bob-loop`) — предмет должен быть предметом бизнеса и отвечать прокрутке и касанию.

### 3.2. Аналитическая сцена со светом в пыли

- **Что.** Зал с витринами: помещение — пересечения луча с плоскостями и коробками без марша, лучи прожекторов в пыльном
  воздухе, пыль видна только в конусах.
- **Когда.** Экспонаты: документы, образцы, предметы истории; проход вдоль витрин тактами.
- **Рецепт** `[проверено]`:
  1. Помещение — аналитические пересечения в полноэкранном шейдере; пол с отражением.
  2. Конус прожектора: свет в воздухе — хорда луча зрения через конус в точке ближайшего подхода к оси, × 1/(s² + 0,08),
     мягкий край.
  3. Пыль — облако `GL_POINTS`, повторяемое вокруг камеры: `p += 4·floor((cam − p)/4 + 0,5)`; дрейф — суммы синусов 13–40 с.
  4. Яркость пылинки = конус × 1/r² × (0,5 + 0,9·рассеяние вперёд); тёмные отбрасываются в вершинном шейдере (размер 0).
  5. Тень витрин — аналитический тест коробок вдоль отрезка «источник → пылинка».
  6. Субпиксель: размер < 1,2 px → 1,2 px, яркость × размер/1,2.
  7. Курсор — второй конус от зрителя; в тихих зонах пыль гаснет.
- **Цена.** 7,1–8,4 мс при 4,4 МП; 1,8–2,1 мс телефонный кадр `[проверено]`.
- **Риски.** Мерцание пыли без субпиксельной поправки; пыль под текстом — тихие зоны (`03` §7).
- **Клише.** «Лучи сквозь окно» без предмета; спасает экспонат с фактом в каждой витрине.

### 3.3. Линии света с ореолом

- **Что.** Светящиеся отрезки и ленты: мосты, сети, маршруты, связи, дорожки города.
- **Когда.** Связи, потоки, маршруты, рост сети; строится по прокрутке или проигрывается полосой.
- **Рецепт** `[проверено]`:
  1. Отрезок — инстанс-квад: экранные концы, расширение на ядро + 2,6 ореола, колпачки у огней.
  2. Фрагмент: расстояние до отрезка в px; ядро — `smoothstep(w ± 0,8 px)`; ореол — гаусс + экспоненциальный хвост.
  3. Сложение `ONE, ONE` (в HDR-цель, если есть свечение).
  4. Тонкие и далёкие линии: полуширина ядра ≥ 0,55·DPR px, яркость × настоящая/нарисованная ширина.
  5. Построение по прокрутке: у инстанса окно готовности [t0, t1], конец — `mix(A, B, fr)`.
  6. Касание: фронт по координате вдоль линии + затухающая синусоида «струны».
  7. Отражение — та же геометрия, отражённая в плоскости, в текстуру ½.
- **Варианты** `[проверено]`: рост сети колонизацией пространства (Runions) к «точкам спроса» внутри контура знака,
  трубчатая толщина ветвей, обрезка вне знака с кончиков — 5,3–5,6 мс; лента маршрута — центростремительный Катмулл — Ром
  с равным шагом, голова ленты ведёт камеру (`04` §2).
- **Цена.** 4,9–5,6 мс при 4,6 МП `[проверено]`; геометрия ≈ 0, платим заливкой ореола.
- **Риски.** Ширина зависит от DPR; муар тонких линий вдали — LOD по следу (`04` §7); мигание чаще 3 раз в секунду —
  WCAG 2.3.1.
- **Клише.** Тоннель огней «hyperspeed» (`[мнение]`) — линии должны быть данными бизнеса: заказы, маршруты, связи.

### 3.4. Частицы собирают знак или слово

- **Что.** Тысячи огней или зёрен перестраиваются из россыпи в знак, слово, объём.
- **Когда.** Только с поводом: частицы — материал предмета или данные (заказы, участники, точки), сборка — итог сюжета.
- **Рецепт** `[проверено]`:
  1. Цели строя — один раз в JS: точки из масок (Canvas 2D → альфа), из поля расстояний (толщина и нормаль зерна), из
     оболочек 3D.
  2. Одна вершина на частицу; цели — атрибуты (xyz + код цвета); прогресс выбирает пару целей.
  3. Перестановка по рангам (порядок чтения ↔ колонка) или сортировка по кривой Мортона — пути не перекрещиваются кашей.
  4. Перестроение волной: задержка 0,62 · id / N, подъём по дуге `sin(π·e)`.
  5. Дрожь — суммы синусов без общей доли; мерцание строя — бегущая волна с периодом ≥ 12 с.
  6. Ветер курсора и волна касания — в вершинном шейдере по экранному расстоянию.
  7. Отражение — второй проход тех же точек.
- **Цена.** 3 600 точек — 4,4–5,1 мс; зерно с нормалями — 9,3–9,6 мс при 4,6 МП `[проверено]`; в three 40 тыс. точек с
  морфингом — ≈ 1 мс (09/04 §4).
- **Риски.** Обратная прокрутка бесплатна, но reduce — сразу финальная форма; знак из частиц заказчик проекта не взял.
- **Клише.** «Шар, галактика или логотип из частиц» — насыщенное (`cliche:particle-swarm`); поворот — частицы как материал
  предмета или морфинг в схему продукта; частицы, которые собираются в модель под каждую ссылку, — у студий (§7).

### 3.5. Обратимая адвекция

- **Что.** Капли краски в воде собираются в знак, потом в слово — и ровно обратно при прокрутке назад.
- **Когда.** Тихая светлая полоса, рождение формы, переход от хаоса к смыслу; `play` 9–10 с.
- **Рецепт** `[проверено]`:
  1. Форма = маска(x + warp(x)·s), s — псевдовремя от прогресса; s → 0 — форма собрана, назад — ровно обратно.
  2. `warp` — бездивергентный поток: ротор двух октав плиточного шума 256² + опускание.
  3. Маска — поле расстояний из текстуры; уровень мипа растёт с s — рассеивание мягчеет.
  4. Клубы — вложенный изгиб шума; капля — сечение вихревого кольца с турбулентным краем.
  5. Цвет — поглощение Бера — Ламберта на светлом фоне: две краски гасят разные каналы, грязи нет; кромка — по градиенту
     плотности; свет сверху — `dFdy`.
  6. Курсор — поворот координат вокруг точки; касание — новая капля.
- **Цена.** 3,5–6,2 мс полосой 2,8 МП, 8,2–8,4 мс полным кадром; один проход `[проверено]`.
- **Риски.** Светлый фон места — вне `preTone` (`01` § Открытые вопросы); 8-битные маски — полосы.
- **Клише.** Жидкость за курсором (§8) — здесь движение ведёт сюжет, а не мышь.

### 3.6. Кинетическая типографика из поля расстояний

- **Что.** Буквы в объёме: строки собираются, свет идёт по граням, буквы разлетаются.
- **Когда.** Имя, слово, лозунг на первом экране или в полосе — когда текст и есть предмет.
- **Рецепт** `[проверено]`:
  1. Глифы — контуры, вшитые в сцену, или Canvas 2D после загрузки шрифта (пересборка поля, когда шрифт пришёл).
  2. EDT Фельценшвальба — Хуттенлохера → `R16F`; градиент сглажен 5×5.
  3. Буква — инстанс-коробка, луч идёт по полю внутри: выдавливание, грань-призма, другой цвет боков.
  4. Сюжет строк на точках 0 / 0,33 / 0,66 / 1; камера проходит сквозь «вихрь».
  5. HDR → свечение 2 ступени → Neutral.
  6. Смысл — HTML: поисковики и экранный диктор.
- **Цена.** 5,2–7,4 мс при 4,6 МП, подготовка 0,23 с `[проверено]`.
- **Риски.** Кириллица и другие письма — в атласе или контурах; текст в холсте без HTML-дубля не читается.
- **Клише.** Гигантский вордмарк без задачи (`cliche:giant-display-type`) — поворот: текст как предмет сцены.

### 3.7. Фото в 2,5D

- **Что.** Кадр места оживает: глубина, вода, лучи, пыль, предмет в отражении.
- **Когда.** У заказчика есть сильное фото места; первый экран полосой.
- **Рецепт** `[проверено]`:
  1. Слои глубины из кадра правилами: небо далеко, здания — середина, вода — пол; без карты глубины.
  2. Параллакс от курсора и прокрутки пропорционально близости.
  3. Вода — сдвиг выборки рябью, дорожка бликов к источнику.
  4. Лучи — радиальное накопление ярких мест к солнцу.
  5. Пыль 3 слоя с параллаксом.
  6. Предмет из отражения — SDF-линза, преломляющая кадр.
- **Вариант** `[практика]`: карта глубины офлайн нейросетью — сверять лицензию модели: у части моделей глубины она
  некоммерческая.
- **Цена.** 12,7–13,8 мс при 3,2 МП: 32 шага лучей на пиксель, на 16 шагов — вдвое дешевле (расчёт) `[проверено]`.
- **Риски.** Дыры по краям слоёв при большом сдвиге; волосы и стекло; бюджет пикселей снижен до 3,2 / 1,6 МП.
- **Клише.** Параллакс всего подряд (`cliche:parallax-everything`).

### 3.8. Бесконечный зум

- **Что.** Камера ныряет на ≈ 16 порядков масштаба — от планеты до молекул, у каждого порядка свой стиль.
- **Когда.** «От общего к частному», масштаб дела, история уровнями.
- **Рецепт** `[проверено]`:
  1. Переменная — lg(высота кадра в метрах); у проекта 7,2 → −8,6.
  2. Порядок — свой стиль-слой; веса соседей в сумме 1 (смесь по `fract(s)`): яркость не пульсирует при быстром проходе.
  3. Станции — PCHIP по [p, lg h, фокус x, фокус y]; последний наклон × 0,4 — мягкая посадка.
  4. Точка зума — герой (≈ 2/3 ширины на ПК), виньетка вокруг неё.
  5. Рамка следующего порядка; линейка масштаба — HTML.
  6. Курсор смещает точку зума, касание — шаг назад.
  7. Длинный переход (5,6 порядка) — с необязательной точкой покоя посередине (`04` §6).
- **Цена.** 3,8–9,6 мс при 4,4 МП; 1,3–2,7 мс телефонный кадр `[проверено]`.
- **Риски.** Укачивание — зум на весь экран только на L2, в reduce — раскадровка (creative 05/01 §6.2); точность float
  на больших масштабах — считать в логарифме и в осях текущего порядка.
- **Клише.** Зум ради зума без станций — у каждого порядка должен быть факт.

### 3.9. Один дубль камеры

- **Что.** Непрерывный пролёт через несколько миров без склеек: город → полоса печати → портал в точке растра → плата →
  море → берег.
- **Когда.** Путь бизнеса через несколько сред; главная после первого экрана.
- **Рецепт** `[проверено]`:
  1. Миры — плоскости с процедурными материалами в одном полноэкранном шейдере.
  2. Путь — монотонные кубики по 18–19 ключам [p, x, y, z, курс, наклон, поле зрения]; высота в asinh (`04` §4).
  3. Честная фильтрация по следу пикселя: полосы и решётки — ящичным фильтром, ряды огней — боке (`04` §7).
  4. Портал — нырок в точку растра: нижний мир повёрнут по курсу подлёта, кадр не вращается (`04` §5).
  5. Герой — сдвигом объектива; тихая колонка — увеличенный след фильтра, мир уходит в расфокус под текстом.
  6. Курсор — поворот головы ≤ 6°; касание — рывок со вспышкой.
  7. `beats` ω 2,4, точки покоя 0 · 0,17 · 0,35 · 0,58 · 0,78 · 1.
- **Цена.** 5,4–8,5 мс страница концепта, 7,7–11 мс место, 1,8–2,2 мс телефон; 933 строки, 15,6 КБ `[проверено]`.
- **Риски.** Полноэкранное движение камеры — вестибулярный риск: только L2, станции в reduce; один шейдер на шесть миров
  трудно отлаживать — миры-функции с общим интерфейсом.
- **Клише.** «Полёт сквозь облака к логотипу» — путь должен проходить через среды самого бизнеса.

### 3.10. Бумажные слои

- **Что.** Бумажный театр: вырезанные слои, кулисы, задники, прожектор; смена актов — театральными перестановками.
- **Когда.** История актами, ремесло, тёплая ручная подача.
- **Рецепт** `[проверено]`:
  1. Бумажки — Canvas 2D, по 3 маски в каналах R, G, B одного среза массива текстур.
  2. Сборка срезов спереди назад: цвет бумаги, волокно 512², кромка среза ловит свет, мягкие тени (смещённая выборка маски).
  3. Свет: рампа, лампы, циклорама, прожектор.
  4. Смена актов — перестановки: кулисы в стороны, задники вверх, ряды в трюм.
  5. Курсор — параллакс и блик фольги; касание — прожектор.
- **Цена.** 7,6–9,6 мс при 4,6 МП; подготовка 0,5 с `[проверено]`.
- **Риски.** Подготовка масок — за постером (`01` §2); тон бумаги на тёмном фоне места.
- **Клише.** Бумажный «крафт» как стиль без сюжета; заказчик проекта опыт с тоном не взял.

### 3.11. Каустики стекла

- **Что.** Свет через стеклянные скульптуры рисует каустики на полу и стенах белой галереи.
- **Когда.** Стекло — материал продукта; музейная тишина; первый экран, одна живая сцена.
- **Рецепт** `[проверено]`:
  1. Проход 1: сетка 160² лучей солнца через SDF-стекло скульптуры → MRT 3×RGBA32F.
  2. Проход 2: проекция сетки на пол и стену; яркость = отношение площадей ячейки; тень стекла → атлас RGBA16F.
  3. Проход 3: аналитическая архитектура, SDF-стекло до 2 внутренних отражений с поглощением; лучи в воздухе — длина пути
     в пучке.
  4. Каустику считают только две ближние скульптуры.
  5. Курсор — солнце; касание — поворот скульптуры.
- **Дешёвая замена** `[практика]`: анимированный тайл каустики в свете пола — ≈ 0 мс, без настоящего преломления.
- **Цена.** 10,9–18,6 мс при 3,4 МП, p90 ритма 33 мс — самая дорогая; бюджет телефона 1,2 МП `[проверено]`.
- **Риски.** Цели RGBA32F читать без линейной фильтрации (`OES_texture_float_linear` есть не везде) или держать в RGBA16F;
  вторая живая сцена рядом не помещается.
- **Клише.** «Liquid glass» (§8) — стекло только у продукта из стекла.

### 3.12. Тилт-шифт мир

- **Что.** Мир-миниатюра: диорама с машинами, людьми, птицами, кораблём; узкая полоса резкости делает мир «игрушечным».
- **Когда.** Кампания L2 с игровым тоном; для делового сайта заказчик проекта сцену не взял («наверное, не надо»)
  `[кейс]`.
- **Рецепт** `[проверено]`:
  1. Растр: ≈ 2 500 статичных инстансов + динамика (46 машин, 70 людей, 30 птиц) — JS-буфер за кадр.
  2. Карта теней 2048 (телефон 1536).
  3. Сцена в MRT с глубиной → кружок нерезкости в альфе.
  4. Копии ½ и ¼, сборка по кружку нерезкости.
  5. Камера вдоль диорамы — 8 ключей, Катмулл — Ром; фокус — под курсором.
  6. Касание — оживает деталь.
- **Вариант** `[документация]`: тилт-шифт без глубины одним проходом в ½ — `TiltShiftEffect` pmndrs (`focusArea` 0,4,
  `feather` 0,3) у сцен на three.
- **Цена.** 13,5–19,0 мс при 4,4 МП; 1 004 строки, 17,4 КБ `[проверено]`.
- **Риски.** Дороже 13 мс — вторая живая не помещается; «игрушечный» тон спорит с деловым смыслом.
- **Клише.** Боке на всём — размытие должно вести взгляд к станции.

## 6. Как показать концепт

- **Страница «Креатив» холста** — по концепту на артборд: живая сцена на своём движке по контракту `01`, постер под
  холстом, у каждого — карточка; заказчик отмечает «беру / не беру / ещё в эту сторону» (`../../../references/phases.md`,
  этап `art-direction`). На L2 — 12–20 концептов не меньше чем из трёх семейств.
- **Концепт — та же сцена**, что пойдёт на сайт: без `opts.variant` она стоит по центру, как на странице концепта, с
  `variant` — встаёт в место; выбранный концепт уходит в место без переписывания `[проверено]`.
- **Карточка концепта** `[практика]`: что сцена говорит о продукте одной фразой; место на странице и режим прокрутки;
  семейство и движок; ввод — прокрутка, курсор, касание; цена — `bench` при 4,4 МП и на телефонном кадре, вес min+gz; что
  нужно от заказчика — факты, фото, сканы.
- **Широта**: вариации тем сайта и новые форматы — свет, миниатюры, кино одним дублем, типографика, физика, генеративный
  знак; «кардинально новое» — повод показать семейства, которых заказчик не ждал `[проверено]`.
- **Постер концепта** — кадр `poster_p` стендом; у `play` — ещё кадр финала: в обзоре холста заказчик видит, о чём сцена,
  до Play (`02` §9).

| каустики подделкой | анимированный тайл каустики в свете пола | ≈ 0 мс, тайл 50–200 КБ | нет настоящего преломления | §3.11 |

**Вау на рубль** — лучшее отношение эффекта к цене по сводке разборов `[мнение]`: точки собираются в знак по прокрутке
(§3.4); мир из инстансов с движением в шейдере и потоками по кривым (`04` §3); мир отвечает на ввод через uniform или FBO
(≤ 0,5 мс); переход маской или выборкой следующей сцены (`04` §5); палитра мира одной текстурой; световые трассы с
выборочным свечением (§3.3); фото в 2,5D (§3.7); «один дубль» со станциями (§3.9). **Дорого на рубль**: жидкость за курсором
(клише и 7–30 МБ памяти), стекло с отдельным рендером сцены на каждый объект, физика тяжёлой библиотекой до действия
пользователя (≈ 1,1–1,6 МБ).

| клише | почему | метка | замена |

| тоннель огней «hyperspeed» | клоны готовых компонентов | `[мнение]` | трассы как данные бизнеса (§3.3) |
| CA + зерно + виньетка на весь экран всегда | шаблон пост-обработки | `[мнение]` | аберрация — только в переходах (Igloo Inc) |
| «ИИ-вид»: фиолетовый градиент, светящиеся орбы | почерк генераторов | `[мнение]` | реестр: `cliche:ai-saas-2024`, `cliche:floating-orbs` |

| зрелище вокруг одного знака без фактов | заказчик проекта из 9 таких концептов не взял ни одного | `[кейс]` | предмет и факты места (§1) |
| слабая доступность наградных 3D | жюри: Bruno Simon — доступность 6,6 против 8,6 за анимации; GQ × AP — 6,0 против 8,6; Immersive Garden — 6,8–7,2 против 9,0–9,4 | `[награда]` | текст в HTML, пауза, reduce — раскадровка, кнопки вместо жестов (`02` §11–13) |

Реестр клише подачи — `../../creative/08-uniqueness-anti-slop/cliche-registry.yaml`; приём в статусе `saturated` или `dated`
идёт только с поворотом из его `twists`.

## Частые ошибки

- **Приём из каталога вместо смысла места** — сцена-зрелище без фактов; заказчик выбирает сцены со станциями и фактами.
- **Частицы, жидкость, стекло «потому что вау»** — клише без поворота.
- **Десять эффектов в одной сцене** — одна механика, доведённая до деталей, сильнее.
- **Семейство дороже 13 мс рядом со второй живой сценой** — множитель мылит обе.
- **Полноэкранный SDF без коробки и лучи 32 шага на пиксель «как есть»** — цена ×2–3 к нужной.
- **Мигание линий и импульсов чаще 3 раз в секунду** — WCAG 2.3.1.
- **Текст сцены только в холсте** — не индексируется и не читается.
- **Концепт и сцена сайта — разный код** — выбранное приходится переписывать; концепт — по контракту `01`.
- **Факты студий из пересказов без источника** — в норму идёт то, что видно в исходнике, документации или открытом кейсе.

## Чек-лист

- [ ] Сцена выбрана по смыслу места: предмет и факты бизнеса, станции сюжета, подпись-факт на каждой?
- [ ] Одна механика сцены названа одной фразой; ввод меняет мир, а не только камеру?
- [ ] Семейство взято по таблице §2; цена по семейству — в бюджете кадра `01` §6.3?
- [ ] Приём из реестра клише — с поворотом из `twists`?
- [ ] Вспышки ≤ 3 в секунду, колебания ≥ 10 с, текст — HTML?
- [ ] Концепт на «Креативе» — сцена по контракту `01` с карточкой: смысл, место, семейство, цена, что нужно от заказчика?

## Открытые вопросы и противоречия

- **Частицы.** `cliche:particle-swarm` насыщен — семейство 3.4 живёт только с поворотом; заказчик проекта знак из частиц не
  взял. Годится ли семейство для кампании L2 без данных — `[кейс]`.
- **SDF-объекты в ½.** Разборы студий рендерят SDF в ½ с апскейлом по глубине; норма этой папки — полное разрешение в
  коробке (`01` § Открытые вопросы): разные условия — полноэкранный SDF против объекта в объёме.
- **Звук.** Студии делают звук функцией сцены (по умолчанию выключен, по действию; WCAG 2.2, 1.4.2 — пауза дольше 3 с);
  в рантайме набора звука нет, норма звука — вне этой папки.
- **Один холст на страницу** у студий против холста на место в наборе — `02` § Открытые вопросы.
- **Разборы в пересказах** без открытого первоисточника в папку не взяты: в норму идёт то, что видно в исходнике,
  инженерном блоге, документации или открытом кейсе.
- **Цена приёмов студий** в мс на эталонной встроенной графике не мерилась — числа студий своей выборки.
