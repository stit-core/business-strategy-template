# 04 · Длинная сцена-мир на всю страницу: много объектов, путь камеры по тактам, смена миров, LOD по следу пикселя

Длинная сцена-мир — второй масштаб папки: не предмет в блоке (`03`), а закреплённая сцена во всю ширину страницы, где
одновременно движутся сотни и тысячи объектов, камера летит сквозь мир, и на каждом такте «что-то происходит». Дорого она
выглядит потому, что мир большой и живой, а стоит дёшево потому, что весь мир — инстансы и шейдер от одного-двух чисел.
Эталон проекта сайта-портрета — город-плата с потоками данных; рядом — пролёт одним дублем через несколько миров,
бесконечный зум по порядкам масштаба, мир-миниатюра, огни строем, лента маршрута по точечной карте. Черновик набора —
`examples/world-template.js`: квартал из ≈ 800 домов одним вызовом, улицы с импульсами, мир в мире 1 : 16, 5 точек покоя.
Контракт движка — `01`, место и режим `beats` — `02`, приёмы — `05`.

## 3. Как движется много объектов

- **Объекты — инстансы, движение — шейдер.** У дома атрибуты экземпляра: центр и полуширины `[cx, cz, hx, hz]`, высота,
  зерно, задержка. Высота считается в вершинном шейдере: один uniform подъёма поднимает все дома волной от центра —
  задержка до 0,62 по расстоянию плюс шум до 0,1, окно подъёма 0,28–0,3 прогресса. Ни одного объекта в JS за кадр
  `[проверено]`.
- **Импульсы по дорожкам** — во фрагментном шейдере линии: у вершины ленты — дуговая координата s и параметры (скорость,
  период 3–7 с, фаза, направление). Голова — гаусс не уже 1,3 px вдоль и 1,15 px поперёк, хвост — экспонента 0,6–1,1 по
  самой линии; у тихих лент период 0 — без импульсов. Скорости и фазы у лент свои — общей частоты нет, кадр не «пульсирует»
  `[проверено]`.
- **Волна касания** — массив из 3 волн в uniform (x, z, возраст): фронт идёт 4–4,6 ед/с и живёт 3,5–3,6 с; у города-платы
  фронт восьмиугольный, как трассировка под 45°, — `max(max(|dx|, |dz|), (|dx| + |dz|)·0,7071)`, окна вспыхивают снизу
  вверх `[проверено]`.
- **Строй точек** — 5 целей в атрибутах вершины, прогресс выбирает пару, задержка по номеру вершины — тоже ноль JS за
  кадр (`05` §3.4) `[проверено]`.
- **JS двигает только единицы** со своим поведением — машины, люди, корабль миниатюры, голова ленты маршрута, физика знака:
  динамический буфер (`bufferSubData`) или массив uniform `[проверено]`.
- **Сортировка спереди назад** — дома пересортировываются, только когда камера сдвинулась на 0,25 ед. (ключ — округлённые
  координаты): ранний тест глубины экономит заливку, а сортировка не идёт каждый кадр `[проверено]`.
- **У студий то же правило** (`05` §7): глобус Shopify BFCM 2023 — десятки тысяч дуг одним вызовом, кривая Безье строится в
  вершинном шейдере, завершённые дуги переиспользуются `[кейс]`; folio 2025 Bruno Simon — 78 400 травинок одним мешем, форма
  по индексу вершины, сетка зациклена вокруг камеры `[исходник]`; Unseen — 125 000 импостеров до горизонта `[кейс]`; Active
  Theory — второстепенная бегущая текстура 12 кадров/с при 60 у сцены `[кейс]`.
- **Свыше ≈ 100 тыс. экземпляров со своей логикой** — отсечение, LOD и жизненный цикл на GPU — это compute и непрямое
  рисование WebGPU (14/08); своему движку на WebGL2 — инстансы, узоры в шейдере и импостеры `[практика]`.

```glsl
float h1(float n){ return fract(sin(n*127.1 + 311.7)*43758.5453); }
// импульсы линии id: along — вдоль линии, across — поперёк от её оси, w — ширина линии; fa, fc — след пикселя вдоль и поперёк
float pulse(float id, float along, float across, float w, float fa, float fc){
  float v = 0.5 + 0.7*h1(id), T = 3.0 + 4.0*h1(id + 7.0), dir = h1(id + 3.0) < 0.5 ? -1.0 : 1.0;   // своя скорость и период
  float b = mod(uTime*v - along*dir + h1(id + 11.0)*T, T), db = min(b, T - b);
  float hr = max(0.05, 1.3*fa), ha = max(w, 1.2*fc);                       // голова не тоньше пикселя
  float head = exp(-db*db/(hr*hr))*exp(-across*across/(ha*ha))*(0.05/hr);  // энергия головы сохраняется вдали
  return head*6.0 + exp(-b/0.8)*0.35*band(across, w, fc);                  // голова + хвост по самой линии (§7)
}
```

## 4. Путь камеры и такты

- **Ключи — по прогрессу**: [p, глаз xyz, цель xyz, поле зрения, сдвиг x y] или [p, x, y, z, курс, наклон, поле зрения];
  такт — подмножество ключей, на которых камера стоит `[проверено]`.
- **Без перелёта**: монотонный кубик Фриче — Карлсона по каждому каналу (ограничитель 3/√(α² + β²)) или PCHIP —
  быстрый жест проходит такты насквозь, скорость не ломается, камера не выезжает за ключ `[проверено]`. Катмулл — Ром по
  глазу и цели — для плавного пути с редкими ключами (город-плата) `[проверено]`.
- **Высота глаза — в asinh(y / y₀)**: ниже y₀ спуск линейный, выше — логарифмический; у мира набора y₀ = 0,5 ед.
  **Радиус нырка в мир в мире — в логарифме**: `exp(mix(log ra, log rb, u))` — постоянная скорость масштаба `[проверено]`.
- **Пружина рантайма** ведёт прогресс к точке покоя такта (ω 2,4–3,6 → 1,3–2,0 с), сцена добавляет дотяг τ 0,12 с
  (`02` §4) `[проверено]`.
- **Сдвиг объектива — на всех ключах**: герой на 2/3 ширины на ПК (sx 0,24–0,4), на телефоне — средняя полоса (sy
  −0,06…−0,14); RTL — путь отражён z → −z, сдвиг — с другой стороны, мир не зеркалится (`03` §8) `[проверено]`.
- **Ближняя плоскость — по высоте глаза**: near = 0,05 высоты с пределами (у набора 0,0015…0,5 ед.), far = near × 12 000
  `[проверено]`. Обратная глубина через `EXT_clip_control`, где расширение есть, точнее логарифмической и не выключает ранний
  тест глубины `[практика]`.
- **Редактор пути** — студии собирают путь камеры и такты в браузерном редакторе таймлайнов (Unseen, Immersive Garden)
  `[кейс]`; у своего движка ключи — таблица по p в файле сцены: её правят числами и снимают стендом.
- **Экспозиция и детали — тоже по ключам p**: таблица экспозиции, подъём `rise(p)`, пороги загорания с гистерезисом 0,012
  `[проверено]`.

```js
// канал ch пути по ключам [[p, …], …]; tf и itf — пространство канала (высота глаза — asinh); examples/world-template.js
function monotone(keys, ch, tf, itf) {
  var n = keys.length, d = [], m = [], q;
  for (q = 0; q < n - 1; q += 1) { d.push((tf(keys[q + 1][ch]) - tf(keys[q][ch])) / (keys[q + 1][0] - keys[q][0])); }
  m.push(d[0]);
  for (q = 1; q < n - 1; q += 1) { m.push(d[q - 1] * d[q] <= 0 ? 0 : (d[q - 1] + d[q]) / 2); }
  m.push(d[n - 2]);
  for (q = 0; q < n - 1; q += 1) {                                     // Фриче — Карлсон: без перелёта за ключ
    if (d[q] === 0) { m[q] = 0; m[q + 1] = 0; continue; }
    var a = m[q] / d[q], b = m[q + 1] / d[q], s = a * a + b * b;
    if (s > 9) { var k = 3 / Math.sqrt(s); m[q] = k * a * d[q]; m[q + 1] = k * b * d[q]; }
  }
  return function (p) {
    var i = 0; while (i < n - 2 && p > keys[i + 1][0]) { i += 1; }
    var x0 = keys[i][0], h = keys[i + 1][0] - x0, t = Math.min(1, Math.max(0, (p - x0) / h)), t2 = t * t, t3 = t2 * t;
    var y0 = tf(keys[i][ch]), y1 = tf(keys[i + 1][ch]);
    return itf((2 * t3 - 3 * t2 + 1) * y0 + (t3 - 2 * t2 + t) * m[i] * h + (-2 * t3 + 3 * t2) * y1 + (t3 - t2) * m[i + 1] * h);
  };
}
// высота: monotone(KEYS, 2, function (v) { return Math.asinh(v / 0.5); }, function (v) { return Math.sinh(v) * 0.5; })
```

## 5. Смена миров внутри сцены

Четыре способа, все без склеек `[проверено]`:

1. **Мир в мире** — те же буферы и программы, другой uniform уровня (смещение и масштаб) и квадрат обрезки: город в окне
   ядра 1 : 28, квартал в площади 1 : 16. Малый мир рисуется, когда камера близко (p > 0,45–0,5 или ближе 6 ед.); большой
   гаснет к финалу. Последний кадр повторяет первый — постер и финал совпадают. Дымка считается в единицах уровня: малый мир
   в дымке так же, как большой.
2. **Плоскости-миры одного шейдера** — каждый мир — плоскость с процедурным материалом; порог по p или по высоте камеры
   переключает мир; нижний мир повёрнут по курсу подлёта, и нырок в портал идёт прямо, без вращения кадра.
3. **Порядки масштаба** — слои стиля по `fract(lg h)`, веса соседних слоёв в сумме 1: при быстром проходе яркость не
   пульсирует (`05` §3.8).
4. **Строи** — пары целей в атрибутах вершин; переход — волной по номеру (`05` §3.4).

Единство миров и шов (`05` §7): палитра всего мира — одна текстура 16×16 (Messenger, Abeto), настроение меняется одной
заменой `[кейс]`; цвет тумана равен фону — на стыке оба мира сходятся к общему цвету, и мир подменяется под туманом
`[практика]`; маска-порог — чёрно-белая текстура задаёт каждому пикселю свой порог прогресса перехода `[практика]`; переход
— событие в самих материалах (аберрация и иней у Igloo Inc), а не проход поверх кадра `[кейс]`.

## 6. Сюжет на 4–6 тактов

- **5–7 точек покоя**: заставка (p 0 — собранный кадр-постер) → 3–5 событий → финал; последние ≈ 8 % — покой, кадр
  держится `[проверено]`.
- **Каждый такт — станция** со смыслом и подписью-фактом; между тактами — пролёт 1,3–2 с; на такте камера живёт сама
  (дыхание камеры 17–37 с, свет по дорожкам) `[проверено]`.
- **Первый такт — самый «широкий» кадр** (видно всё поле), **финал — самый «глубокий»** (внутри, ближе всего); рифма
  «конец = начало» делает раскадровку цельной `[проверено]`.
- **Необязательная точка покоя** делит длинный переход пополам: зум на 5,6 порядка — точка 0,9 `[проверено]`.
- **Что выбирает заказчик** — из 24 показанных концептов взяты 10; общее у взятых (вывод из выбора, заказчик причин не
  называл) `[кейс]`: сцена рассказывает смысл места через предмет и факты самого бизнеса; у сюжета естественные станции
  (даты, уровни, порядки, витрины, точки маршрута) — они ложатся на такты; камера движется сквозь мир — 4 из 10 взятых
  длинные сцены; цена посильная — 3–11 мс при 4,4 МП. Зрелища вокруг одного знака без фактов и «игрушечный» мир для
  делового сайта не взяты (`05` §1).

## 7. LOD и честная фильтрация по следу пикселя

- **Ящичный фильтр по следу пикселя**: покрытие полосы ширины w пикселем ширины fw — `(min(d + w/2, fw/2) −
  max(d − w/2, −fw/2)) / fw`; для периодической решётки — разность первообразной. Вдали узор сам уходит к средней доле
  w/T: ни муара, ни дрожи `[проверено]`.
- **Линии не тоньше пикселя по энергии**: полуширина ядра не меньше 0,65 px (дорожки) или 0,55·DPR px (линии света),
  яркость × настоящая / нарисованная ширина `[проверено]`.
- **Огни в расфокусе** — гауссовы пятна трёх ближайших огней ряда; при большом следе — к среднему `[проверено]`.
- **Точечная карта** — ближайший узел решётки считается в шейдере; уровень детализации — по экранному шагу: узлы крупного
  уровня остаются, мелкие гаснут, вдали — ровная заливка `[проверено]`.
- **Малый мир гасит мелкий свет пропорционально размеру пикселя**: множитель импульсов 0,3…1 по
  `0,03 / (размер пикселя в единицах уровня)` — город читается городом, а не белым комом `[проверено]`.
- **Тихая колонка** — тот же фильтр с увеличенным следом: мир сам уходит в мягкий расфокус под текстом `[проверено]`.

```glsl
// точный ящичный фильтр полосы ширины w пикселем шириной fw и решётки таких полос с периодом T (examples/world-template.js)
float band(float d, float w, float fw){ fw = max(fw, 1e-5); return max(0.0, min(d + 0.5*w, 0.5*fw) - max(d - 0.5*w, -0.5*fw))/fw; }
float pI(float x, float T, float w){ float k = floor(x/T + 0.5); return k*w + clamp(x - k*T + 0.5*w, 0.0, w); }
float pulses(float x, float T, float w, float fw){ fw = max(fw, 1e-5); return (pI(x + 0.5*fw, T, w) - pI(x - 0.5*fw, T, w))/fw; }
// улица: покрытие по fwidth координаты; когда пиксель шире линии в разы — к средней доле
// float lx = mix(band(d.x, w.x, fw.x), w.x, smoothstep(0.25, 0.6, fw.x));
// окна фасада: pulses(u, 0.06, 0.03, fwidth(u))*pulses(v, 0.08, 0.04, fwidth(v)); вдали доля горящих окон — 0,42
```

## 12. Рецепт «длинная сцена-мир»

1. **Сюжет — 5–7 точек покоя** от «широкого» кадра к «глубокому»; каждая станция — факт места и подпись; финал повторяет
   заставку или держит итог; последние 8 % — покой (§6).
2. **Мир — детерминированный план** (mulberry32 с постоянным зерном): квартал, решётка, строй; один и тот же при каждом
   запуске — постеры и раскадровка совпадают с живой сценой (`01` §9).
3. **Объекты — инстансами** (сотни и тысячи одним вызовом), повторяющееся — узором в шейдере; JS двигает только единицы
   (§3).
4. **Движение — в шейдере** от p и t: волна подъёма по задержке (окно 0,28–0,3 прогресса), импульсы по дуговой координате с
   разными скоростями и периодами 3–7 с, волна касания — массив из 3 фронтов (§3).
5. **Камера — ключи по p**: [глаз, цель, поле зрения, сдвиг]; монотонный кубик по каналу, высота в asinh, нырок — радиус в
   логарифме; ближняя плоскость 0,05 высоты глаза, дальняя × 12 000 (§4).
6. **Герой — сдвигом объектива** на 2/3 ширины (ПК) или в средней полосе (телефон); RTL — отражение пути, мир не
   зеркалится (§4, `03` §8).
7. **Смена миров** — мир в мире (те же буферы, масштаб, обрезка) или плоскости-миры одного шейдера; переходы — порталы
   внутри кадра (§5).
8. **LOD по следу пикселя** — ящичный фильтр полос и решёток, линии ≥ 1 px по энергии, головы импульсов ≥ 1,3 px, малый
   мир гасит мелкий свет 0,3…1 (§7).
9. **Кадр** — HDR RGBA16F (запас RGBA8) → свечение 1/4…1/64 (порог 0,75, вес 0,45) → Neutral → тихие зоны → края в фон
   места (7 % высоты) → sRGB → дизеринг (§8).
10. **Бюджет** — пиксели, множитель, кадр и порядок деградации — по `01` §6.1–6.4; своя жизнь — 30 кадров/с, вне
    экрана — 0 (`01` §7).
11. **Место на странице** — режим `beats`: поле = заставка 0,78 H + 480 px на такт + хвост 0,45 H + выход 0,45 H; пружина
    ω 2,4–3,6; подписи тактов в окне сцены; рельс, «Пропустить», пауза (`02` §5, §7, §12).
12. **Постер и раскадровка** — стендом: p 0 для постера, точки покоя для раскадровки; телефон — своя раскладка ключей;
    живая проверка — колесо по 120 px переключает такты по одному, reduce и программный рендер — раскадровка без поля
    (§10, `02` §16).

## Частые ошибки

- **Объекты в JS за кадр** (матрицы сотен домов) — длинные кадры прокрутки; движение — в шейдере от одного числа.
- **Одна частота у всех импульсов** — кадр «пульсирует» целиком; у каждой линии своя скорость и фаза.
- **Ключи камеры по времени** — сцена не стоит на такте и не отвечает прокрутке; ключи — по p.
- **Катмулл — Ром по ключам с остановками** — камера проскакивает станцию на быстром жесте; монотонный кубик или PCHIP.
- **Высота глаза линейно** — спуск с орбиты «падает» в конце; asinh.
- **Постоянная ближняя плоскость** — конфликты глубины на улице или срезанный горизонт на орбите.
- **Склейка двух сцен** вместо мира в мире — шов и вторая сборка; те же буферы в другом масштабе.
- **Мелкий свет без LOD** — муар вдали и «белый ком» малого мира.
- **Линии тоньше пикселя без поправки энергии** — дорожки мерцают и пропадают при движении камеры.
- **Свечение без порога и предела** — «светлячки» и засвет под текстом.
- **Сцена дороже 13 мс** — вторая живая не помещается, множитель мылит кадр; дорогие сцены проекта заказчик не выбрал.
- **Телефону — меньше объектов вместо меньшего кадра** — мир беднеет, а цена почти та же: дорога заливка.
- **Финал не рифмуется с заставкой** — раскадровка и обзор читаются обрывком.
