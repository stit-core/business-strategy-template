# Набор сцен на JS: шаблоны движка, рантайм страницы, демо и стенд

Рабочие шаблоны своего движка на WebGL2 без библиотек и рантайм, который ведёт сцены по прокрутке. Нормы, по которым они
написаны, — `../01-engine.md` (движок) и `../02-stage-runtime.md` (место на странице); малое 3D — `../03-small-objects.md`,
длинная сцена-мир — `../04-long-scenes.md`, где сцена живёт — `../06-where-it-runs.md`. Палитра шаблонов нейтральная:
графит `#16181D`, тёплый ключ, холодный отсвет.

## Файлы

## Как взять шаблон

1. **Копия.** Малое 3D, символ, фон с мелкой деталью — `scene-template.js` → `scenes/<имя>.js`; длинная сцена-мир —
   `world-template.js` → `scenes/<имя>.js`.
2. **Имя.** В строке регистрации `['template']` (у мира — `['world']`) → `['<имя>']`; то же имя — в `data-stage` места и
   в `m=` стенда.
3. **Картинка.** Шаблон «один шейдер» — тело `main()` до тихой зоны; хвост — тихая зона → края в фон → тон → sRGB →
   дизеринг — остаётся как есть. Мир — план (`rng(<зерно>)`, генерация `BLD`), шейдеры земли и домов, ключи камеры `KEYS`
   отдельно для ПК и телефона.
4. **Палитра** — `opts.palette` (hex) или таблица `PAL`; цвета бренда приходят опциями места, а не правкой кода.
5. **Время и ввод.** Своя жизнь — от `uTime`, периоды крупных форм ≥ 10 с или шум без ведущей частоты; прогресс — `uP`
   (уже сглажен рантаймом); курсор — `uPointer` (x, y в −1..1, присутствие); касание — `uTap` (1 → 0) и `uTapAt`.
6. **Точки покоя мира** — в `info().beats` и в `data-beats` места; последние ≈ 8 % прогресса — покой.
7. **Стенд** — кадр, лист кадров, `perf`, `bench` (§ Параметры стенда); вес — `esbuild --minify` и gzip.
8. **Место** — разметка по `demo.html`, рантайм — `new StageRuntime(window.STAGE_SCENES, {…}).mount(document)`; живая
   проверка — `stage_smoke.py` (`../02-stage-runtime.md` §16).

## Регистрация и контракт

```js
(window.STAGE_SCENES = window.STAGE_SCENES || {})['<имя>'] = function (canvas, opts) {
  // нет WebGL2 — onStatus('no-webgl') и null; есть opts.onReady и KHR_parallel_shader_compile — {pending: true, destroy}
  // готово — ручка: setVisible, wake, scrub, setIdle, setPlaying, isPlaying, setTexture, destroy (рантайм)
  //                 setTime, setHover, tap, pulse, redraw, info (стенд)
};
```

В `window` сцена пишет только эту строку; читает — `devicePixelRatio`, `innerWidth`, `innerHeight`, `matchMedia`,
`performance`. Методы, опции и статусы — `../01-engine.md` §1.

## Подключение рантайма

```html
<script src="scenes/<имя>.js"></script>
<script src="stage-runtime.js"></script>
<script>new StageRuntime(window.STAGE_SCENES, { header: 72, headerPhone: 64 }).mount(document);</script>
```

## Разметка места

| атрибут места | значение |
|---|---|
| `data-stage` | имя сцены в `STAGE_SCENES` |
| `data-mode` | `scrub` (по умолчанию) · `beats` · `glide` · `play` |
| `data-beats` | точки покоя через запятую, `0,0.25,0.5,0.75,1`; без них `beats` работает как `scrub` |
| `data-tempo` | ω пружины; по умолчанию `beats` 3, `glide` 2, `scrub` 6,5 |
| `data-pin`, `data-exit` | поле закрепления и длина выхода, px |
| `data-dur` | длительность `play`, с; по умолчанию 9 |
| `data-range` | отрезок прохода полосы `a,b`, который становится прогрессом 0..1 |
| `data-variant` | место для сцены (`opts.variant`): сдвиг объектива и тихие зоны места |
| `data-bg` | hex фона места (`opts.background`) |
| `data-tex` | картинки слотов 0..3 через запятую |
| `data-rtl` | зеркальная композиция |

| элемент внутри места | что |
|---|---|
| `[data-window]` | окно сцены; у `beats` и `glide` — `position: sticky` под шапкой |
| `[data-poster]` | постер `<img>` под холстом — кадр покоя той же камеры |
| `[data-canvas]` | `<canvas hidden aria-hidden="true">`; рантайм заменяет его свежим на каждую жизнь сцены |
| `[data-caps] > [data-cap][data-k]` с `[data-fill]` | подписи тактов (`aria-live="polite"`), полоска пути до следующего такта |
| `[data-from][data-to]` | надпись на отрезке прогресса |
| `[data-rail] > [data-dot]` | рельс тактов (ПК) |
| `[data-skip]`, `[data-pause]` | «Пропустить» и пауза (`aria-pressed`) |
| `[data-veil]` | затемнение выхода в фон места |
| `[data-steps] > [data-beat]` | блоки шагов `beats`; у `[data-steps]` — `margin-top: −H` |
| `[data-story]` | раскадровка: обзор холста, reduce, программный рендер |

Состояния, которые ставит рантайм: `[data-live]` у места — сцена ожила; `[data-stage-story]` — раскадровка вместо
закрепления; `[data-on]` у подписи и надписи; `--fill` у текущей подписи; `aria-current="step"` у точки рельса;
`aria-pressed` у паузы. Облик состояний — CSS страницы (образец — `<style>` в `demo.html`).

**Высоты блоков шагов** при окне H: заставка — 0,78 H (телефон 0,7 H); каждый следующий такт — 480 px (телефон 420);
последний — шаг + хвост 0,45 H + выход 0,45 H (`data-exit`). В `demo.html` при H = 760: 593 · 480 · 480 · 1164 px — 4 точки
покоя; у длинной сцены — 593 · 480 · 480 · 480 · 1164 px — 5 точек покоя.

## Опции рантайма

`new StageRuntime(scenes, o)`; `info()` — состояние мест, `destroy()` — снять всё; `StageRuntime.spring`,
`StageRuntime.isSoftware` — статические.

| опция | по умолчанию | что |
|---|---|---|
| `maxLive`, `maxLivePhone` | 2, 1 | живых сцен одновременно: ПК, телефон |
| `wakeAhead` | 0,5 | оживить, когда до окна ≤ 0,5 его высоты |
| `dropFar` | 1,5 | уничтожить сцену дальше 1,5 высоты окна |
| `line` | 0,6 | линия такта — доля высоты окна |
| `header`, `headerPhone` | 72, 64 | высота липкой шапки, px |
| `tempo`, `tempoBeats`, `tempoGlide` | 6,5, 3, 2 | ω пружины по режимам |
| `eps` | 4·10⁻⁴ | порог остановки пружины |
| `dur`, `playAt` | 9, 0,4 | длительность `play`, доля видимости полосы для старта |
| `exitK` | 0,94 | предел затемнения выхода |
| `phone` | `(max-width: 40rem), (pointer: coarse)` | признак телефона |
| `force3d` | false | живые сцены и на программном рендере (стенд) |
| `isLive` | — | функция «показан ли документ вживую»; на холсте Claude Design — эвристика Play (`../02-stage-runtime.md` §10) |
| `retryLost` | 1 | сколько раз оживлять сцену после потери контекста |

## Параметры стенда

Адрес `stand.html?…` — кадр одной сцены на всё окно; при одинаковых `p` и `t` кадр одинаков.

| параметр | что |
|---|---|
| `m`, `src` | имя регистрации и путь файла сцены |
| `p`, `t` | прогресс 0..1 и время своей жизни, с |
| `hx`, `hy` | курсор в −1..1 от центра |
| `tap=x,y`, `pulse` | касание в точке и фаза импульса 0..1 |
| `mobile`, `rtl`, `variant`, `bg`, `tex` | телефон, зеркальная композиция, место, фон, картинки слотов |
| `live` | своя жизнь идёт; ритм кадров за 3 с → `window.__perf` (медиана, p90) |
| `bench=N`, `ps` | цена кадра: N перерисовок с `readPixels` в точках `ps` (по умолчанию 0,15 / 0,5 / 0,85) → `window.__bench` |

Готовность — `window.__ready`, ошибка — `window.__err`. Утилита `../../../../scripts/3d/stage_stand.py` поднимает стенд в
Chromium с GPU и берёт размер окна (`w`, `h`) и плотность (`dsf`) из ключей:

```bash
PY=~/.cache/design-deep-dive/venv/bin/python; O=~/.cache/design-deep-dive/out/3d/stand   # из папки скилла
$PY scripts/3d/stage_stand.py shot  $O/t.png m=template src=scene-template.js w=1440 h=760 dsf=2 p=0.5 variant=hero
$PY scripts/3d/stage_stand.py perf  m=world src=world-template.js w=1440 h=760 dsf=2 variant=hero
$PY scripts/3d/stage_stand.py bench m=world src=world-template.js w=390 h=600 dsf=3 mobile variant=hero
$PY scripts/3d/stage_smoke.py --json ~/.cache/design-deep-dive/out/3d/stage-smoke.json   # demo.html: gpu, reduced, soft
```
