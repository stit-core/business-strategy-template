## Выжимка для агента

1. Выбирай эффект по задаче страницы, а не по моде: продуктовый лендинг — hero-объект, орбитальная витрина, предрендер или видео; кампания и портфолио — миры, частицы, игры → §1.2, `02-when-3d-budgets-loading.md` §6. [консенсус]
2. Для каждого эффекта сначала проверь, **нужен ли Blender**: 25 из 70 эффектов — шейдеры, CSS или чужие рантаймы (градиенты, блобы, волны, жидкость, метаболы, облако частиц, SDF-текст, эффекты над картинками, пост-луки, глобус, сплаты, Spline) → Blender не открывать → §1.3, матрица §23. [практика]
3. Предрендер в картинку (PNG → WebP/AVIF с альфой) дешевле реалтайма в 8–27 раз только по JS (hero 1024² — 4–14 КБ AVIF/WebP против ≥ 110 КБ br за three.js, без GLB); для детальной формы без текстур видео сопоставимо с GLB (VP9 1 с 124 КБ против GLB 117 КБ, `../12-recipes/08-sequence-video-alpha.md`) → если интерактив не нужен, рендерь в Blender → §13. [проверено: 99-raw/experiments/A/06-deliverable-sizes, 03-bundle-sizes]
4. Вращение продукта без интерактива: видео 2 с — 40–60 КБ, секвенция 48 кадров WebP — 0,2–0,4 МБ, GLB + three — 0,2–0,3 МБ + рантайм; для перемотки прокруткой — секвенция в canvas или all-intra видео → §13.4, §14, §15. [проверено]
5. Прозрачное видео поверх контента: VP9-alpha WebM (Chrome/Firefox/Edge) + HEVC-alpha (Safari) или один **stacked-alpha** файл (RGB сверху, альфа снизу) + 20 строк WebGL; анимированный AVIF — нельзя (Safari ломает, Chrome тормозит) → §15.2. [проверено: A/06; практика: Archibald 2024, Shopify 2026]
6. Hero-объект: GLB ≤ 1–2 МБ (Draco/Meshopt + KTX2/WebP), 1 объект, окружение HDR 1k или RoomEnvironment, `setPixelRatio(min(dpr, 2))`, рендер по требованию → §2. [практика; проверено на выборке: медиана 3D наградных сайтов 2,6 МБ]
7. Свет у реалтайм-героя — **запечённый в Blender** (lightmap/AO в текстуры, KTX2) там, где сцена статична: так сделаны Unseen, Igloo, Steven → §2.4. [проверено: сайты; практика]
8. Орбитальная витрина без своего кода — `<model-viewer>` 4 (poster, `loading="lazy"`, `camera-orbit` с `env(window-scroll-y)`, AR-кнопка); тон по умолчанию — Khronos PBR Neutral → §3.1. [документация: model-viewer 4.x]
9. Варианты цвета — `KHR_materials_variants` из Blender (glTF-экспортёр пишет варианты) или подмена `material.color` в JS; не грузить отдельный GLB на каждый цвет → §3.2. [документация three: webgl_loader_gltf_variants; экспорт — `../08-export-gltf/`]
10. «Посмотреть в AR»: Android Scene Viewer — ≤ 100 тыс. треугольников (идеал 30–50 тыс.), текстуры ≤ 2048², ≤ 10 МБ, **без Draco/KTX2/морфов/вершинных цветов**, 1 анимация; iOS — USDZ (model-viewer генерирует на лету, без анимаций) → отдельный лёгкий GLB для AR → §3.3. [документация Google ARCore]
11. Путь камеры на прокрутке рисуй кривой в Blender и отдавай JSON точек (Z-up → Y-up: `[x, z, -y]`) → `CatmullRomCurve3` → прокрутка двигает параметр `t` с затуханием → §4.1. [практика: Codrops 2026-07-07]
12. Анимацию, которую играет прокрутка, делай в Blender (действие/NLA → glTF animation) и в JS один раз `action.play()`, затем на каждый кадр `action.time = progress * clip.duration; mixer.update(0)` (рецепт `action.paused = true` + `mixer.setTime` в r186 даёт кадр 0), а не проигрывай по времени → §4.5, `../07-animation/03-gltf-to-web-playback.md` §3.3. [проверено]
13. Прокрутку привязывай к uniforms/`setTime` в цикле рендера, **не к React-состоянию**; монтируй только активную и соседние сцены → §4.3–4.4. [практика: Shopify Editions 2026]
14. Шейдерный градиент (Stripe-лента, mesh gradient) — 1–6 draw calls, 5–25 КБ JS (`@paper-design/shaders` 6 КБ br), без ассетов; самый дешёвый «вау» для SaaS → §5.1. [проверено: stripe.com, A/03]
15. Частицы на поверхности логотипа/модели: из Blender — меш-донор или готовый массив точек (Float32 бинарь), в вебе — `Points`/GPGPU; 10–100 тыс. точек на телефоне, до ~1 млн на десктопе с WebGPU-compute → §6. [практика; числа — `../09-web-runtime/`]
16. Стекло: `MeshPhysicalMaterial.transmission` (из glTF `KHR_materials_transmission`) или drei `MeshTransmissionMaterial` — каждый такой объект = дополнительный проход рендера сцены; на телефоне 1 объект и низкое разрешение буфера → §7. [документация three; практика]
17. Текст — в DOM всегда; WebGL-текст (troika/MSDF) только дублирует скрытый, но доступный HTML-текст (прозрачный, выделяемый) → §8.2. [практика: Codrops 2025-06-05; проверено: LCP не видит текст в canvas — A/04]
18. Эффекты над картинками (искажение при наведении, переходы) — шейдер на плоскости поверх `<img>`; `<img alt>` остаётся в DOM как запасной вариант и LCP → §9. [практика; проверено: A/04]
19. Маленькие миры и игры (Messenger, Bruno Simon) — жанр портфолио/кампании: 5–20 МБ, ворота «Click to start», весь контент в canvas; для продуктового лендинга не выбирать → §11. [проверено: сайты]
20. Маскот со скелетной анимацией — GLB 250–400 КБ на персонажа (GitHub), 1–3 клипа, ленивая загрузка ниже первого экрана → §12.1. [проверено: github.com/home]
21. Гауссовы сплаты — для места/продукта «как на фото»: 1,4–3 МБ на сцену, 1 draw call, форматы SPZ/SOG/`KHR_gaussian_splatting`; Blender их не делает (съёмка → обучение) — нужен постер-фолбэк → §16.1. [проверено: oryzo, worldlabs; документация three r186]
22. Глобус с точками — `cobe` (5 КБ br, 6 draw calls) вместо GLB Земли; данные — JSON координат → §17.1. [проверено: cobe.vercel.app, A/03]
23. Пост-эффекты (bloom, зерно, аберрация, пикселизация, ASCII, дизеринг) — каждый проход = полноэкранный рендер; объединяй в один `EffectPass`, на телефоне оставляй 1–2 → §18. [практика; документация pmndrs/postprocessing]
24. Spline — быстрый путь для дизайнера, но рантайм ≈ 0,83 МБ br (+ физика 0,42 МБ) и 192 draw calls в покое на spline.design; агенту на Linux Spline MCP недоступен (только десктоп macOS/Windows) → §20. [проверено: A/03, spline.design; документация Spline]
25. Запечённые симуляции (ткань, бумага, разрушение) переносятся в веб как shape keys (морфы) или VAT-текстуры; не пытайся симулировать это в браузере → §21.1. [практика: Codrops 2025-08-20, 2026-09-19]
26. Клише 2024–2026, которые снижают оценку: стеклянный тор/капля на градиенте, шар или галактика из частиц, хромированный блоб, «ворота Enter with sound», прелоадер с процентами, жидкое искажение картинок при наведении на каждой карточке → §22. [мнение: практики и жюри; см. `../../ui/11-styles-trends/`]
27. Любой эффект с фоновой анимацией обязан останавливаться при `prefers-reduced-motion: reduce` (≈13 из 16 проверенных наградных сайтов этого не делают) и вне экрана → §1.4, `04-reference-sites-measured.md` §6. [проверено]
28. Для каждого эффекта держи **запасной вариант без WebGL**: постер (картинка того же ракурса из Blender), видео или CSS; tier 0 detect-gpu/нет WebGL → запас → §1.4. [практика; проверено: A/05]
29. Сложность для агента: легко — предрендер, видео, model-viewer, шейдерный фон, cobe; средне — hero-GLB, путь камеры, частицы, стекло; трудно — миры с физикой, GPGPU, сплаты, конфигураторы, переходы сцен → поле «Агенту» в карточках. [мнение: оценка A]

## 1. Как читать каталог

### 1.1. Поля карточки
- **Вид** — что видит пользователь (1–2 строки). **Примеры** — живые URL (проверены curl/браузером 2026-09-22/23; «[замер]»
  — есть в `04-reference-sites-measured.md`).
- **Класс** техники: `реалтайм-меш` (GLB в WebGL/WebGPU), `шейдер` (без 3D-ассетов), `предрендер` (картинка), `секвенция`
  (кадры), `видео`, `сплат`, `CSS 3D`, `рантайм` (Spline, model-viewer, Unicorn как готовый плеер).
- **Blender**: `нет` / `моделирование` / `моделирование + запекание` / `рендер кадров` / `анимация` / `точки или пути`.
- **Цена**: вес поставки, нагрузка GPU (draw calls, проходы, overdraw) и CPU (JS, декодирование).
- **Телефон / запас**, **A11y** (reduced motion, текст вне canvas, клавиатура), **Агенту** (легко/средне/трудно и почему),
  **Клише** (что уже заезжено), **Разборы** (статьи с кодом), метки доказательности.

### 1.3. Роль Blender по классам
- `шейдер`, `CSS 3D` — Blender не нужен (иногда — только текстура шума или матcap).
- `реалтайм-меш` — моделирование, UV, запекание света/AO/процедурных материалов в текстуры, экспорт GLB
  (`../08-export-gltf/`); процедурные ноды без запекания в glTF не переживают экспорт [проверено: A/06 — белая банка].
- `предрендер`, `секвенция`, `видео` — полная сцена, свет, рендер EEVEE/Cycles; вывод PNG RGBA → кодирование в
  WebP/AVIF/WebM вне Blender (ffmpeg, Pillow) — `05-blender-deliverables-map.md`.
- `точки/пути` — Blender как редактор данных: кривая → JSON, выборка точек поверхности → бинарный Float32.
- `сплат` — не Blender (съёмка/обучение); Blender — для масок, привязки и сопутствующих мешей.

### 1.4. Общие правила для всех карточек
- **Запас без WebGL**: `canvas.getContext('webgl2')` = null или tier 0 → постер/видео того же ракурса (рендер Blender).
- **Reduced motion**: при `matchMedia('(prefers-reduced-motion: reduce)').matches` — показать статичный кадр
  (`renderer.render` один раз, `setAnimationLoop(null)`); прокрутка не должна запускать самопроизвольные движения камеры
  (переходы — мгновенные или кросс-фейд). Токены движения — `../../ui/08-motion/`.
- **Вне экрана** — `IntersectionObserver` → стоп цикла; **вкладка скрыта** — `document.hidden` → стоп.
- **Текст и CTA** — HTML поверх canvas; canvas `aria-hidden="true"`, если он декоративный; интерактивный просмотрщик —
  фокусируемый, с подписью (`alt` у model-viewer) — `../../ux/08-accessibility/`.

## 2. Hero-объект

**2.1. Статичный 3D-герой из предрендера (pre-rendered hero still)** — фотореальный продукт/иллюстрация как картинка
в первом экране.
- Примеры: apple.com/airpods-pro (LCP — картинка героя) [замер], apple.com/iphone-air (фото-рендер телефона с рукой) [замер], sleep-well-creatives.com (иллюстративные кадры-постеры) [замер].
- Класс: предрендер · Blender: моделирование + свет + рендер кадра RGBA · Рантайм: `<img>`/`<picture>` (AVIF → WebP → PNG).
- Цена: 4–14 КБ AVIF/WebP с альфой на 1024² для простой сцены, фотореализм — 50–200 КБ [проверено: A/06 — простая сцена]; ноль JS.
- Телефон/запас: это и есть запас; отдать 2 размера через `srcset`. A11y: `alt`, без движения.
- Агенту: **легко** — детерминированный рендер; риск — AgX высветляет брендовый цвет (красный → розовый) [проверено] → выбирать view transform (Standard / Khronos PBR Neutral) — `../06-materials-lighting-render/`.
- Клише: «плавающий продукт на пастельном градиенте с мягкой тенью».
- Разборы: `05-blender-deliverables-map.md` §2. Метки: [проверено], [практика].

**2.2. Вращающийся или парящий hero-объект (floating / auto-rotating hero)** — продукт медленно вращается или «дышит»
в реальном времени.
- Примеры: oryzo.ai (пробковая подставка, инерция, глубина) [замер], landonorris.com (шлем) [замер], github.com/home (маскоты «плавают») [замер], spline.design (глянцевые фигуры) [замер].
- Класс: реалтайм-меш · Blender: моделирование + запекание (AO/свет) + экспорт GLB · Рантайм: three (`Float` из drei или синус в цикле), model-viewer `auto-rotate`.
- Цена: GLB 0,2–1,5 МБ (GitHub — 250–360 КБ на маскота); 5–40 draw calls; JS three ≥ 110 КБ br, R3F+drei ≈ 290 КБ br [проверено].
- Телефон/запас: DPR ≤ 1,5; постер того же ракурса; при reduce — без вращения. A11y: декоративный canvas → `aria-hidden`.
- Агенту: **средне** — нужен чистый GLB (масштаб, origin, нормали) и свет, совпадающий с Blender (`../09-web-runtime/`).
- Клише: «медленно крутящийся продукт по центру без смысла»; Utsubo советует «одна вещь с весом и инерцией» [мнение вендора].
- Разборы: Codrops «Building Efficient Three.js Scenes» 2025-02-11 (бюджет 2,1 МБ). Метки: [проверено], [практика].

**2.3. Hero, реагирующий на курсор (cursor-reactive hero)** — объект поворачивается к курсору, расталкивается, раскрывает
детали под мышью.
- Примеры: lusion.co (куча «крестов» реагирует на курсор, физика) [замер], hubtown.co.in (раскрытие монолита мышью) [замер], activetheory.net (логотип) [замер].
- Класс: реалтайм-меш (+ физика/шейдер) · Blender: моделирование + запекание; для «раскрытия» — вторая текстура/маска · Рантайм: three + Rapier/cannon-es или шейдерная маска по позиции курсора.
- Цена: Lusion — 85 draw calls в покое, 2 МБ геометрии; физика — wasm 0,5–2,4 МБ (Rapier) [проверено: сайты].
- Телефон/запас: нет курсора → гироскоп или автопрогон; без hover-зависимого контента. A11y: эффект не должен нести смысл.
- Агенту: **средне/трудно** — инерция и затухание (`MathUtils.damp` есть в r186 — отчёт V), физика — трудно.
- Клише: «объект следит за мышью» на каждой студийной витрине.
- Разборы: Codrops «Creating an Interactive Mouse Effect with Instancing» 2023-12-13; «Building an Interactive 3D Cluster with TSL» 2026-08-12. Метки: [проверено], [практика].

**2.4. Герой в запечённой комнате или ландшафте (baked-lighting hero scene)** — объект в интерьере/на рельефе с мягким
глобальным освещением, которое в реальном времени не посчитать.
- Примеры: unseen.co (пастельная комната с арками и водой, KTX2 со светом ≈ 0,9 МБ на текстуру) [замер], igloo.inc (снежный рельеф и иглу, KTX2 12,7 МБ) [замер], tympanus.net/Tutorials/CodropsFanMuseum/ (весь свет запечён).
- Класс: реалтайм-меш · Blender: моделирование + UV2 + **запекание** (Cycles bake: Combined/Diffuse/AO) + денойз · Рантайм: three, `MeshBasicMaterial`/`lightMap` или unlit с запечённой картой.
- Цена: текстуры 1–13 МБ KTX2 (4K атласы), геометрия 0,3–1 МБ; draw calls 40–60 [проверено: сайты]. Память GPU ≈ 5,3 МБ на 2048² RGBA8 с мипами (сжатый KTX2 в 4–8 раз меньше) — `02 §3`.
- Телефон/запас: атласы 1024–2048 вместо 4K; статичный кадр рендера той же камеры.
- Агенту: **средне** — запекание скриптом повторяемо, но нужен контроль UV и шумов (`../06-materials-lighting-render/`, `../08-export-gltf/`).
- Клише: «пастельная сюрреалистичная комната с арками» (Unseen-стиль, 2024–2026).
- Разборы: Codrops «Building a Fully-Featured 3D World in the Browser with Blender and Three.js» 2025-04-08; «One Shot Baking» (Codrops 2026-08-24). Метки: [проверено], [практика].

## 3. Витрина и конфигуратор продукта

**3.1. Орбитальный просмотрщик (orbit product viewer)** — продукт можно крутить, приближать, есть постер до загрузки.
- Примеры: modelviewer.dev (скафандр 8,7 МБ GLB) [замер], apple.com/iphone-air (3D-вьюер ниже героя, three r165, KTX v1 ×87) [замер], threejs.org/examples/webgl_loader_gltf.
- Класс: реалтайм-меш / рантайм model-viewer · Blender: моделирование + PBR-текстуры (запечённые) + экспорт GLB · Рантайм: `<model-viewer camera-controls poster loading="lazy">` или three + `OrbitControls`.
- Цена: model-viewer ≈ 240 КБ br (со своей three 0.183) [проверено]; GLB 1–5 МБ; model-viewer сам снижает разрешение до 0,5 при падении FPS (держит 38–60 fps) [документация].
- Телефон/запас: `poster` = рендер Blender того же ракурса; `interaction-prompt`. A11y: `alt`, управление стрелками (встроено), `a11y`-переводы ракурсов.
- Агенту: **легко** с model-viewer (атрибуты), **средне** с three (свет, тонмаппинг, кадрирование по Box3).
- Клише: нет (утилитарный приём); ошибка — вьюер вместо фото в первом экране e-commerce.
- Разборы: modelviewer.dev/examples/loading/. Метки: [документация], [проверено].

**3.2. Варианты цвета и материала (material variants)** — переключение расцветок без перезагрузки модели.
- Примеры: threejs.org/examples/webgl_loader_gltf_variants, modelviewer.dev/examples/scenegraph/ (варианты, смена материалов).
- Класс: реалтайм-меш · Blender: материалы вариантов → `KHR_materials_variants` (экспортёр glTF поддерживает варианты — проверка `../08-export-gltf/`) · Рантайм: three `GLTFLoader` (userData variants) или model-viewer `variant-name`.
- Цена: +1 текстурный набор на вариант (1–4 МБ) или 0 при смене только `baseColorFactor`; DV360 для рекламы советует обесцвеченную базовую текстуру × цвет [документация].
- Телефон/запас: грузить текстуры варианта по требованию. A11y: переключатели — HTML-кнопки с подписями.
- Агенту: **средне** — нейминг материалов и вариантов должен совпадать между Blender и JS.
- Клише: нет. Метки: [документация].

**3.3. «Посмотреть в AR» (view in your space)** — кнопка открывает продукт в комнате пользователя.
- Примеры: modelviewer.dev/examples/augmentedreality/, developer.apple.com/augmented-reality/quick-look/ (галерея USDZ, Apple Pay-баннер).
- Класс: рантайм ОС (Scene Viewer / AR Quick Look / WebXR) · Blender: лёгкая AR-версия модели: ≤ 100 тыс. треугольников (идеал 30–50 тыс.), 1 UV, ≤ 10 материалов, текстуры ≤ 2048², без Draco/KTX2/морфов/вершинных цветов, 1 анимация, 1 ед. = 1 м, фронт +Z [документация: Scene Viewer]; USDZ для iOS (model-viewer генерирует сам, но без анимаций).
- Цена: GLB ≤ 10 МБ (15 МБ — ошибка валидатора); Merchant: рекомендация 10 МБ, максимум 15 МБ [документация].
- Телефон/запас: кнопка только при поддержке (`ar-status`). A11y: подпись «View in your space» (NN/g: иконки AR непонятны).
- Агенту: **средне** — две поставки (веб-GLB со сжатием и AR-GLB без него), проверка валидатором.
- Клише: AR «ради AR» — NN/g: плохое AR вредит восприятию товара [исследование, n = 11]. Метки: [документация], [исследование].

**3.4. Конфигуратор из частей (part configurator)** — выбор деталей, размеров, материалов; модель пересобирается.
- Примеры: tympanus.net/codrops/2025/07/29/exploring-the-process-of-building-a-procedural-3d-kitchen-designer-with-three-js/ (процедурная кухня), needle.tools (конфигураторы — продукт Needle) [замер].
- Класс: реалтайм-меш · Blender: библиотека частей с общими origin/осями и нейминг, запечённые материалы · Рантайм: three/R3F, Needle Engine, Babylon.
- Цена: 2–10 МБ частей, грузить по требованию; draw calls растут с числом частей → инстансинг/слияние.
- Телефон/запас: 2D-превью вариантов (рендеры Blender). A11y: все опции — HTML-формы.
- Агенту: **трудно** — логика совместимости, привязка частей, состояние. Клише: нет. Метки: [практика].

**3.5. Взрыв-схема и сборка (exploded view / assembly)** — продукт разлетается на детали и собирается по прокрутке.
- Примеры: igloo.inc (иглу распадается на блоки при прокрутке) [замер], hubtown.co.in (монолит распадается на кубы) [замер].
- Класс: реалтайм-меш + анимация · Blender: детали отдельными объектами с origin в центре детали; анимация разлёта (ключи) или только конечные позиции в `extras` · Рантайм: three, интерполяция позиций по прогрессу прокрутки или `AnimationMixer.setTime`.
- Цена: +0 к геометрии (те же детали), draw calls = число деталей (инстансинг, если детали одинаковые).
- Телефон/запас: видео/секвенция разлёта. A11y: при reduce — сразу собранное или сразу разобранное состояние.
- Агенту: **средне** — главное — корректные origin и имена деталей в Blender. Клише: слабое. Метки: [проверено], [практика].

**3.6. Горячие точки и аннотации (hotspots / annotations)** — метки на модели с подписями, следуют за поворотом.
- Примеры: modelviewer.dev/examples/annotations/, threejs.org/examples/css2d_label.
- Класс: реалтайм-меш + DOM · Blender: пустышки (Empty) в точках меток → узлы glTF с именами · Рантайм: model-viewer `slot="hotspot-…" data-position`, three `CSS2DRenderer` или проекция `Vector3.project`.
- Цена: ≈ 0. Телефон/запас: список характеристик в HTML. A11y: метки — кнопки в DOM, фокусируемые.
- Агенту: **легко** — пустышки из Blender дают точные координаты (совет Woan, Codrops 2026-08-24). Метки: [документация], [практика].

## 4. Сторителлинг на прокрутке

**4.1. Камера по пути на прокрутке (scroll-driven camera path)** — прокрутка ведёт камеру через сцену, как пролёт
дрона/долли.
- Примеры: tympanus.net/Tutorials/CurveGallery/ (путь из Blender, 500 плоскостей), oryzo.ai (камера по глубине Z) [замер], explore.ownprimland.com (пролёт над рельефом) [замер].
- Класс: реалтайм-меш + данные пути · Blender: кривая Безье → точки (`evaluated_get(depsgraph).to_mesh()`, `matrix_world @ v.co`) → JSON `[x, z, -y]`; либо анимированная камера → glTF · Рантайм: `CatmullRomCurve3(points, closed, 'catmullrom', 0.5)`, `getPoint(t)`/`getTangent(t)`, прокрутка → `t` через `gsap.quickTo` (1 с, power3.out) или Lenis.
- Цена: JSON пути 1–30 КБ; сцена — по наполнению. GSAP + Observer ≈ 40 КБ br [проверено].
- Телефон/запас: короче путь, меньше объектов; при reduce — шаги-«слайды» без пролёта. A11y: весь текст истории — HTML-секции.
- Агенту: **средне** — надёжно, если экспорт пути скриптом и проверка оси; скрипт Codrops зависит от `active_object` → брать объект по имени. Клише: «полёт через туннель из картинок».
- Разборы: Codrops 2026-07-07 (код github.com/gaspoorf/curve-gallery); Codrops 2023-02-14 (Theatre.js + R3F — Theatre не развивается, `03-runtime-landscape.md` §6). Метки: [практика].

**4.2. Трансформации объекта на прокрутке (scroll-scrubbed object transforms)** — продукт поворачивается, приближается,
меняет материал по мере прокрутки.
- Примеры: oryzo.ai [замер], landonorris.com [замер], apple.com/iphone-air (3D-вьюер ниже героя) [замер].
- Класс: реалтайм-меш · Blender: модель + (опц.) ключевые позы · Рантайм: GSAP ScrollTrigger `scrub` → свойства объекта; Lenis для плавности.
- Цена: GLB 1–7 МБ; прокрутка 13–40 draw calls [проверено: выборка].
- Телефон/запас: секвенция кадров того же движения (§14). A11y: reduce → ключевые позы без интерполяции.
- Агенту: **средне**. Клише: «телефон крутится, пока читаешь характеристики». Метки: [проверено], [практика].

**4.3. Закреплённые секции с 3D (pinned 3D sections)** — секция «прилипает», пока 3D проигрывает сюжет, затем уходит.
- Примеры: shopify.com/editions/spring2026 (секции-сцены) [замер], sleep-well-creatives.com [замер].
- Класс: реалтайм-меш + DOM · Blender: сцены по секциям · Рантайм: ScrollTrigger `pin`, один полноэкранный canvas за DOM.
- Цена: Shopify — 45–108 draw calls, p95 кадра 33 мс [проверено]; держать смонтированными только активную и соседние сцены.
- Телефон/запас: без pin, обычный поток с картинками. A11y: pin не должен ломать клавиатурную прокрутку.
- Агенту: **средне**. Клише: слабое. Разборы: Codrops Shopify Spring '26 (2026-06-26). Метки: [проверено], [практика].

**4.4. Переходы между сценами (scene transitions)** — одна 3D-сцена перетекает в другую (маска, шум, растворение).
- Примеры: shopify.com/editions/spring2026 (композит нескольких FBO) [замер], hubtown.co.in (куб → световые трассы) [замер].
- Класс: шейдер + реалтайм-меш · Blender: сцены; для масок — текстура шума/вихря · Рантайм: render targets, полноэкранный композит-шейдер с `uProgress`.
- Цена: +1 полный рендер на кадр перехода (две сцены) — на телефоне заметно.
- Агенту: **трудно** — управление FBO, памятью, dispose. Разборы: Codrops «Composite Rendering: The Brilliance Behind Inspiring WebGL Transitions» 2026-02-23; «Building Persistent Page Transitions with WebGPU» 2026-06-30; The Sleepers (переход по ч/б текстуре-порогу) 2026-07-10. Метки: [практика].

**4.5. Анимация из Blender, которую «проигрывает» прокрутка (baked animation scrubbing)** — разлёт, сборка, раскрытие,
смена формы, отснятые в Blender ключами.
- Примеры: igloo.inc (блоки) [замер], threejs.org/examples/webgl_animation_keyframes (эталон: LittlestTokyo) [замер], tympanus.net/Tutorials/BalloonButton/ (ткань → shape keys, по клику).
- Класс: реалтайм-меш + анимация · Blender: действие (Action, в 5.x — слои и слоты), NLA, shape keys; экспорт animations в glTF · Рантайм: `AnimationMixer`, `action.play()` один раз, затем `action.time = progress * clip.duration; mixer.update(0)` (не `paused = true` + `setTime` — кадр 0 в r186; `../07-animation/03-gltf-to-web-playback.md` §3.3).
- Цена: анимация трансформаций — единицы КБ; морфы — ×(число ключевых форм) размер вершин.
- Агенту: **средне** — экспорт анимаций в 5.x (слоты) — `../07-animation/`. Метки: [практика], [проверено: сайт].

**4.6. Пролёт над ландшафтом и картой (landscape flythrough)** — рельеф местности, облака, камера над ним.
- Примеры: explore.ownprimland.com (elevation.glb + KTX2 10 МБ ×2 на сезоны; drag и zoom) [замер], hubtown.co.in [замер], tympanus.net/codrops/2026/04/21/false-earth-from-webgl-limits-to-a-webgpu-driven-world/.
- Класс: реалтайм-меш + шейдер · Blender: рельеф (Displace по карте высот) или только карта высот + текстура; облака — плоскости с альфой · Рантайм: плоскость с displacement в вершинном шейдере, туман.
- Цена: Primland — 27 МБ, текстуры рельефа 20 МБ, кнопка входа на 168-й с на «домашней» сети [проверено] → бюджет: 1 атлас 2048–4096 KTX2.
- Телефон/запас: статичная аэрофотография с метками. Агенту: **средне** (рельеф — просто, «красиво» — трудно). Метки: [проверено].

## 5. Абстрактные и генеративные фоны (Blender не нужен)

**5.1. Mesh gradient и градиентная лента (mesh gradient / gradient ribbon)** — мягкие перетекающие цвета, волнистая
лента в герое.
- Примеры: stripe.com (лента, three r178, 1–6 draw calls, при reduce останавливается) [замер], shaders.paper.design (mesh gradient и др.), shadergradient.co.
- Класс: шейдер · Blender: нет · Рантайм: полноэкранный квад + фрагментный шейдер; `@paper-design/shaders` (≈ 6 КБ br), ShaderGradient (R3F), своя 1 плоскость с шумом.
- Цена: JS 6–25 КБ, GPU — 1 полноэкранный проход; реальную цену делает страница вокруг (Stripe: TBT 7,1 с при CPU×4 — Next.js и аналитика) [проверено: A/03, stripe].
- Телефон/запас: CSS `linear/radial-gradient` или статичный кадр; DPR 1 для фона (размытое не требует чёткости). A11y: фон — `aria-hidden`, reduce → стоп.
- Агенту: **легко**. Клише: «пастельный фиолетово-розовый mesh gradient» (2021–2026, повсеместно).
- Разборы: каталог V — «градиенты Stripe» `LW9d2cqIHb4`; Codrops «How to Code a Subtle Shader Background Effect with R3F» 2024-10-31. Метки: [проверено], [практика].

**5.2. Шумовой «блоб» (noise-displaced blob)** — сфера/капля, поверхность которой медленно «дышит» шумом.
- Примеры: tympanus.net/codrops/2024/07/09/creating-an-animated-displaced-sphere-with-a-custom-three-js-material/, zentry.com (проволочный радужный «цветок», Spline) [замер], урок «Wobbly Sphere» в threejs-journey.com.
- Класс: шейдер (вершинное смещение) · Blender: нет (иногда матcap-текстура) · Рантайм: `IcosahedronGeometry(1, 64–128)` + шум в вершинном шейдере / TSL `positionNode`, `MeshPhysicalMaterial` с `onBeforeCompile`.
- Цена: 20–80 тыс. вершин, 1–2 draw calls; шум в вершинах дешевле, чем во фрагментах (MDN).
- Агенту: **легко/средне** (нормали после смещения — пересчитывать в шейдере). Клише: **высокое** — «хромированный/радужный блоб».
- Метки: [практика], [документация MDN].

**5.3. Волны и поверхность воды (waves / water surface)** — сетка точек или поверхность колышется волнами.
- Примеры: threejs.org/examples/webgl_points_waves, threejs.org/examples/webgpu_tsl_raging_sea, threejs.org/examples/webgpu_ocean, unseen.co (вода в комнате) [замер].

- Цена: 1–3 draw calls; отражения (`Reflector`) = ещё один рендер сцены.
- Агенту: **легко**. Клише: «точечные волны» (2019–2022). Разборы: Codrops «Dissecting a Wavy Shader» 2025-10-25; урок «Raging sea» (threejs-journey). Метки: [документация], [практика].

**5.4. Жидкость и курсор-жидкость (fluid simulation)** — цвет/дым течёт за курсором, растекается.
- Примеры: shopify.com/editions/spring2026 (общее поле жидкости, искажает точки и свет) [замер], tympanus.net/codrops/2026/03/23/building-a-dual-scene-fluid-x-ray-reveal-effect-in-three-js/, tympanus.net/codrops/2025/02/26/webgpu-fluid-simulations-high-performance-real-time-rendering/.
- Класс: шейдер (FBO-симуляция) · Blender: нет · Рантайм: пинг-понг render targets (адвекция, дивергенция, давление) или WebGPU compute.
- Цена: 5–20 полноэкранных проходов симуляции за кадр при низком разрешении (¼–⅛ экрана); на телефоне — снизить сетку.

**5.5. Метаболы (metaballs)** — капли сливаются и разделяются, как ртуть или воск.
- Примеры: threejs.org/examples/webgl_marchingcubes, tympanus.net/codrops/2025/06/09/how-to-create-interactive-droplet-like-metaballs-with-three-js-and-glsl/, drei `MarchingCubes`.

- Агенту: **средне**. Клише: «лава-лампа на тёмном фоне». Метки: [документация], [практика].

**5.6. SDF raymarching (стекло, формы из формул)** — идеально гладкие формы, морфинг, мягкие тени без полигонов.
- Примеры: tympanus.net/codrops/2024/07/15/how-to-create-a-liquid-raymarching-scene-using-three-js-shading-language/, tympanus.net/codrops/2024/06/12/shape-lens-blur-effect-with-sdfs-and-webgl/, threejs.org/examples/webgpu_shadertoy.

- Цена: GPU-ёмко (цикл на пиксель); на телефоне — ½ разрешения, ≤ 64 шагов.
- Агенту: **средне/трудно** (отладка формул). Клише: низкое. Метки: [практика], [документация three r186 release notes].

**5.7. Шейдерная «туманность», аврора, свет (shader aurora / nebula, no-code)** — светящиеся облака, лучи, переливы.

- Класс: шейдер / рантайм Unicorn Studio · Blender: нет · Рантайм: Unicorn Studio embed (заявлено ≈ 50 КБ gzip [мнение вендора]), свой шейдер, Paper Shaders.
- Цена: 2–3 draw calls; Unicorn на главной — TBT 254–1158 мс (разные прогоны) [проверено].
- Агенту: **легко** (готовые пресеты) — но пресеты no-code узнаваемы. Клише: **высокое** — «фиолетовая аврора в тёмном герое» (стиль ИИ-стартапов 2024–2026). Метки: [проверено], [мнение].

## 6. Частицы и точки

**6.2. Морфинг частиц между формами (particle morphing)** — облако точек перетекает из логотипа в продукт, в текст.

**6.4. GPGPU-частицы с полем течения и курсором (GPGPU particles / flow field)** — сотни тысяч частиц текут по полю,

**6.5. Облака точек из сканов и видео (point clouds)** — пространство из цветных точек, «проявляющееся» при прокрутке.

## 7. Стекло, преломление, металл

**7.1. Стекло с transmission (transmissive glass)** — прозрачный объект искажает то, что за ним; толстое стекло, лёд,
пластик.
- Примеры: threejs.org/examples/webgl_materials_physical_transmission, threejs.org/examples/webgpu_materials_transmission, tympanus.net/codrops/2025/03/13/warping-3d-text-inside-a-glass-torus/, tympanus.net/codrops/2026/09/08/building-an-infinite-liquid-glass-grid-with-three-js-webgpu-and-tsl/.
- Класс: реалтайм-меш · Blender: Principled BSDF `Transmission Weight`, `IOR`, `Thickness` (Volume) → `KHR_materials_transmission`/`volume`/`ior` (проверка переноса — `../08-export-gltf/`) · Рантайм: `MeshPhysicalMaterial` (transmission, thickness, ior), drei `MeshTransmissionMaterial` (samples, chromaticAberration).
- Цена: каждый кадр сцена за стеклом рендерится в отдельный буфер (1 доп. проход на все transmission-объекты в three; `MeshTransmissionMaterial` — свой FBO на объект) → на телефоне 1 объект, `resolution` 256–512.
- Телефон/запас: предрендер стекла (Cycles) картинкой — выглядит лучше реалтайма. A11y: декоративно.
- Агенту: **средне**. Клише: **очень высокое** — «стеклянный тор/капля/кубик на градиенте» (2022–2026). Метки: [документация], [практика].

**7.2. Дисперсия и хроматическая рефракция (dispersion)** — радужная кайма на гранях стекла, как у призмы.
- Примеры: threejs.org/examples/webgl_loader_gltf_dispersion (`KHR_materials_dispersion`), blog.maximeheckel.com/posts/refraction-dispersion-and-other-shader-light-effects/ (2023, R3F), tympanus.net/codrops/2026/08/31/volatile-nexus-tinkering-with-glass-caustics-cubes-and-sound-in-three-js/.
- Класс: реалтайм-меш + шейдер · Blender: Principled `Dispersion` (Cycles) — перенос в `KHR_materials_dispersion` не проверен [не проверено → E] · Рантайм: FBO сцены + `refract()` с разным IOR для R, G, B и циклом сэмплов (Heckel).
- Цена: как 7.1 × число сэмплов (8–16 выборок на пиксель). Агенту: **средне/трудно**. Клише: высокое (Vercel-стиль призм 2022–2023). Метки: [практика], [документация three].

**7.3. Каустики (caustics)** — световые узоры от стекла/воды на поверхности.
- Примеры: threejs.org/examples/webgpu_caustics, threejs.org/examples/webgpu_volume_caustics, drei `Caustics`.
- Класс: шейдер + реалтайм-меш · Blender: для статичной сцены — **запечь каустики** в текстуру пола (Cycles) · Рантайм: drei Caustics (доп. проходы), WebGPU-примеры r186.
- Цена: высокая в реалтайме (несколько проходов); запечённая текстура — 0 проходов. Агенту: **средне** (запечь), **трудно** (реалтайм). Метки: [документация], [практика].

**7.4. Иридесценция, хром, жидкий металл (iridescent / chrome)** — радужная плёнка, зеркальный металл с отражением
окружения.
- Примеры: activetheory.net (радужно-хромовый логотип) [замер], steven.com (металлические кольца с гравировкой) [замер], threejs.org/examples/webgl_loader_gltf_iridescence.
- Класс: реалтайм-меш · Blender: Principled `Thin Film` (5.x) / Metallic 1 + низкая шероховатость → `KHR_materials_iridescence` (перенос — E); главное — **HDRI окружения**, без него металл чёрный · Рантайм: `MeshPhysicalMaterial` (iridescence, metalness), `scene.environment` = PMREM из HDR 1k.
- Цена: HDR 1k ≈ 0,4–0,6 МБ (Lando 378 КБ, Mana 425 КБ) [проверено]; `RoomEnvironment` — 0 КБ.
- Агенту: **средне**. Клише: высокое («хромированная типографика/логотип» 2021–2025). Метки: [проверено], [документация].

- Агенту: **средне**. Запас: скриншот-текстура (§13.2). Метки: [документация three], [практика].

**21.3. Стилизация: тун, контур, «иллюстрация в 3D» (NPR: toon, outline, painterly)** — 3D, похожее на рисунок: плоские
заливки, контур, штрих.
- Примеры: sleep-well-creatives.com (иллюстративный NPR-мир) [замер], messenger.abeto.co [замер], projects.thibautfoussard.com/the-sleepers/ (контур inverted hull), tympanus.net/codrops/2026/04/24/susurrus-crafting-a-cozy-watercolor-world-with-three-js-and-shaders/.
- Класс: реалтайм-меш + шейдер · Blender: **контур inverted hull**: чёрный материал в последнем слоте + backface culling + модификатор Solidify (отрицательная толщина, flip normals, material offset) → glTF с «apply modifiers»; в three заменить материал контура на `MeshBasicMaterial` · Рантайм: `MeshToonMaterial` + gradientMap, `OutlinePass`/`webgpu_postprocessing_outline`.
- Цена: контур-оболочка удваивает треугольники объекта; пост-контур — 1–2 прохода. Агенту: **средне**. Клише: низкое (NPR в 2025–2026 — отход от «пластика»). Метки: [практика].

## Частые ошибки

- **Реалтайм там, где хватило бы картинки**: крутящийся GLB без интерактива стоит ≥ 110 КБ br JS + GLB + декодеры и
  GPU каждый кадр; картинка/видео — 5–60 КБ [проверено].
- **Процедурный материал Blender «как есть» в GLB**: glTF переносит только факторы и картинки → банка белая
  [проверено]; запекать в текстуры (`../08-export-gltf/`).
- **AgX по умолчанию для брендового продукта**: насыщенный красный становится розовым [проверено]; в 5.2.2 есть
  Standard и Khronos PBR Neutral (отчёт V), в three — `NeutralToneMapping`.
- **Один GLB для веба и для AR**: Scene Viewer не принимает Draco/KTX2/морфы — отдельный AR-файл [документация].
- **Текст в canvas** (3D-заголовок, текст из частиц без HTML-дубля): LCP нет, поиска нет, скринридера нет
  [проверено: A/04; Messenger, Bruno Simon без записей LCP].
- **Нейросеть по памяти пишет старый three**: `RGBELoader` (с r180 — `HDRLoader`), `Clock` (с r183 — `Timer`),
  `PostProcessing` (r183 — `RenderPipeline`), `outputEncoding`/`sRGBEncoding` (r152 — `outputColorSpace`),
  `BoxBufferGeometry`, `physicallyCorrectLights`, `PCFSoftShadowMap` (с r182 устарел) → см. `03-runtime-landscape.md` §2.
- **Экспорт кривой пути без смены осей**: Blender Z-up, three Y-up → `[x, z, -y]` (или экспортёр glTF с +Y up).
- **Бесконечный цикл рендера без движения и при reduce** (25 из 33 сайтов) — батарея и нагрев.
- **Анимированный AVIF как «видео с альфой»** — Safari ломает, Chrome/Android тормозят [практика: Archibald].
- **Секвенция без окна памяти**: 200 кадров 1080² в памяти ≈ 900 МБ декодированных пикселей → держать ±N кадров.
- **Копирование «наградных» бюджетов** (12,6 МБ медиана) на продуктовый лендинг → `02-when-3d-budgets-loading.md`.

## Открытые вопросы и противоречия

- Перенос `Dispersion`, `Thin Film` (иридесценция), `Transmission` + `Volume` из Principled BSDF 5.2 в glTF-расширения
  не проверялся здесь → агент E (`../08-export-gltf/`).
- Клише-таблица — оценка по наблюдениям и мнениям практиков, не исследование; нет количественных данных о том, как
  клише влияют на восприятие бренда.
- Число точек/частиц «на телефоне» (10–100 тыс.) — практика без замера на реальных устройствах → волна 2 (F).
- 3D-иконки (§13.1): живые примеры в замер не попали; каталог опирается на базу `ui`.
- Сплаты: единый формат ещё не устоялся (SOG, SPZ, `KHR_gaussian_splatting` — статус ратификации Khronos не проверен;
  каталог V ссылается на доклад Khronos 04.2026) → G.
- «Шаблонность» Spline-сцен и no-code-эффектов (Unicorn) — мнение; зато они быстрее для дизайнера.
