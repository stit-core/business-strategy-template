## Выжимка папки

1. Код анимации 5.x — только через слот и channelbag (`action.fcurves` удалён в 5.0); `keyframe_insert` — только именованные аргументы;
   чужое действие без слота не анимирует (`01 §1`).
2. Экспорт — с сэмплированием и `export_anim_slide_to_zero=True`: без сэмплов поворот ≥ 180° между ключами ломается (турнтейбл стоит или
   крутится назад), изинги и сдвиг к нулю теряются (`01 §3–4`, `03 §1.4`).
3. Несколько частей одного эффекта — одно действие со слотами = один клип; отдельные действия разъезжаются по времени; второй клип — NLA-дорожка
   ровно с одной полосой (`01 §5`).
4. Морфы: относительные shape keys, модификаторы применять до ключей (иначе `export_apply` удаляет морфы молча), Meshopt сжимает морфы ×4 (`02 §1`).
5. Констрейнты, драйверы, симуляции в glTF не уходят — запекать (`bake_action_objects`, shape key на кадр); Follow Path требует `update_tag()` (`02 §3–4`).
6. Анимация материалов/света (`KHR_animation_pointer`) в three r186 не играется — JS-треки на свойства материала (`03 §1.6, §3.5`).
7. Скраб прокруткой: `action.time = p·duration; mixer.update(0)`; рецепт `paused + setTime` даёт кадр 0; сглаживание — `damp`, время — `Timer` (`03 §3`).
8. Клипы весят 1–5 КБ (после `optimize` — втрое меньше); тяжелы морфы и геометрия (`03 §2`).
9. Простое движение одного объекта — JS; хореография частей и деформации — клип Blender; петли без взаимодействия — предрендер-видео (`04 §1–2`).
10. Камера на прокрутке — JSON-кривая (1,4 КБ, 8 мм от запечённой камеры); логотип — JS-таймлайн/клип при three на странице, иначе видео с альфой (`04 §3–4`).
