Генератор даёт **один плотный треугольный меш с UV-атласом и запечёнными картами** за секунды–минуты. Для сайта это сырьё:
его доводят (`02-cleanup-to-web.md`), проверяют лицензию и стиль. Интеграции «генератор ↔ Blender» в целом — C2
`../04-ai-agents-mcp/02-integrations-landscape.md` §5; исследования генерации кодом и судей — C2 `03`.

## Выжимка для агента

1. **Живой тест Rodin через пробный ключ MCP провалился**: `generate_hyper3d_model_via_text` → `{"error": "API_INSUFFICIENT_FUNDS"}`
   дважды (13:07 МСК, разные промты); ключ `vibecoding` зашит в аддон и общий для всех установок. Для системы заказчика пробный
   ключ — не источник генераций. → §5 `[проверено]`
2. **Генератор — для органики и «как на фото», не для героя-продукта и серии**: маскот, растение, еда, декор; продукт заказчика,
   иконки серии, абстракции — код, фактуры и HDRI — библиотека (таблица §1). → §1 `[проверено: G/01–G/03; исследование C2; мнение]`
3. **На этой машине только облачные API**: открытые модели требуют NVIDIA — TRELLIS.2 ≥ 24 ГБ, Stable Fast 3D ≈ 6 ГБ (есть путь
   Apple MPS), Hunyuan3D-2 6–16 ГБ; CUDA здесь нет. → §2 `[документация: README; C2]`
4. **Бесплатные тарифы и коммерция**: Meshy Free — CC BY 4.0, коммерция с обязательной строкой «Model created with Meshy»;
   Tripo Free — «Public Models · Non-Commercial Use»; Rodin Free — публичная галерея, «неограниченный экспорт и любое
   использование» только в платных. Для сайта заказчика — платный тариф. → §3 `[документация]`
5. **API Rodin — только тариф Business** ($120/мес., $1 152/год, 120–240 RPM); прямой кредит $1,5; базовая генерация Gen-2.5 —
   0,5 кредита (≈ $0,75), надбавки складываются. Альтернатива — fal.ai (второй режим аддона). → §2, §4 `[документация: цены и API Rodin]`
6. **Tripo — самый дешёвый на модель** в платных планах: $20/мес. ≈ 200 моделей ($0,16), $90/мес. ≈ 1 660 ($0,09). → §2 `[документация]`
7. **MCP Rodin шлёт только `tier=Sketch`, `mesh_mode=Raw`, `texture_mode=high`** (треугольный суп низшего уровня) и ходит на старый
   адрес `hyperhuman.deemos.com`; уровни Gen-2.5, квады, форматы кроме GLB — только прямой API. → §4 `[исходник аддона]`
8. **Не включать Rodin по картинкам и Hunyuan3D в mcp-for-blender 2.0.3**: CVE-2026-10661 (чтение любого файла по пути от модели и
   отправка наружу), CVE-2026-10662 (SSRF #203) — обе не исправлены в 2.0.3; `…_via_images` на сервере тоже читает любой путь. → §4 `[проверено C1/13; исходник]`
9. **Не нажимать «Set Free Trial API Key» в Blender пользователя**: оператор пишет ключ в настройки аддона, а автосохранение
   настроек включено; для теста хватает свойства сцены. Аддон не проверяет `bpy.app.online_access`. → §4 `[проверено]`
10. **Ждите от генератора сотни тысяч треугольников**: Rodin Raw — 500–1 000 000 граней (по умолчанию 500 000), Quad —
    1 000–200 000 (18 000) `[поиск]`; TRELLIS.2 экспортирует с `decimation_target=1 000 000` и текстурой 4096 `[документация]` —
    всегда доводка до 50/100 тыс. (A `02 §3.1`). → §6
11. **PBR-режим, а не «shaded»**: запечённый свет в альбедо спорит со светом страницы; SF3D отделяет освещение, TRELLIS.2 даёт
    base color/roughness/metallic/opacity, Rodin и Meshy — PBR в API. → §6 `[документация]`
12. **Доводка проверена на ассете той же структуры** (скан-атлас 90 тыс. треуг.): Decimate + перепечка нормали → 12 тыс. треуг.,
    0,28 МБ телефон / 0,58 МБ десктоп, ошибка P95 2,6 мм; на выходе генератора — `[не проверено]`. → §6, `02` `[проверено]`
13. **Масштаб генератора условный** («normalized size» — описание инструмента MCP) — реальные размеры из паспорта ассета. → §6 `[исходник]`
14. **Судить генератор попарно, по рендерам и в двух порядках**: абсолютные баллы VLM — шум; перевороты вердикта ~26 % между
    разными генераторами и 94 % между двумя выборками одной модели (C2 `03 §7`). Делай 2–4 кандидата и выбирай. → §7 `[исследование C2]`
15. **Промт `asset_creation_strategy` MCP ставит генераторы и библиотеки впереди кода** — для героя и серии неверно (C1 `04 §4`). → §1 `[исходник; мнение C1]`
16. **Лицензия открытых весов ≠ лицензия результата**: TRELLIS/TRELLIS.2 — код MIT (веса — по карточке модели); Hunyuan3D-2 — лицензия Tencent не действует в
    ЕС, Великобритании и Южной Корее (C2); Stable Fast 3D — «NOASSERTION» на GitHub, условия — на странице модели `[не проверено]`. → §3 `[документация]`

## 4. Как генератор вызывается из Blender через MCP (mcp-for-blender 2.0.3, аддон протокола 9)

- Включение: `scene.blendermcp_use_hyper3d = True`, `scene.blendermcp_hyper3d_mode = 'MAIN_SITE'|'FAL_AI'`, ключ — свойство сцены
  `blendermcp_hyper3d_api_key`, настройки аддона или `BLENDERMCP_HYPER3D_API_KEY`; `_get_hyper3d_api_key()` сначала смотрит
  сцену [исходник; проверено: G/01].
- Поток: `generate_hyper3d_model_via_text(text_prompt, bbox_condition)` → `create_rodin_job` (`POST hyperhuman.deemos.com/api/v2/rodin`,
  multipart: `tier=Sketch`, `mesh_mode=Raw`, `texture_mode=high`, `prompt`, `bbox_condition` — пропорции, нормированные к 100) →
  `{task_uuid, subscription_key}` → `poll_rodin_job_status(subscription_key)` (все статусы «Done») → `import_generated_asset(name,
  task_uuid)` (`/api/v2/download` → первый `*.glb` → временный файл без удаления → импорт, ожидается один меш) [исходник].
  Текущий адрес API в документации Rodin — `https://api.hyper3d.com/api/v2` [документация].
- Отказ пробного ключа: ответ приходит сразу (≈ 1 с), генерация не расходуется; промт `asset_creation_strategy` велит при
  «insufficient balance» сказать пользователю ждать следующего дня или завести ключ hyper3d.ai / fal.ai [проверено: G/01; исходник].
- Безопасность: запросы к Rodin без таймаутов в главном потоке Blender; `…_via_images` читает любой локальный путь на сервере и
  отправляет в Rodin; Hunyuan3D — CVE-2026-10661 и CVE-2026-10662 (SSRF #203) не исправлены в 2.0.3 (C1 `01 §6`, C1/13) — не включать; телеметрия
  выключена (`telemetry_consent: false`, `DISABLE_TELEMETRY=true`) [проверено: G/01; C1].
- Настройки пользователя: оператор `blendermcp.set_hyper3d_free_trial_api_key` пишет ключ в `prefs.hyper3d_api_key`; у пользователя
  `use_preferences_save=True` — ключ сохранится при выходе. Безопасный путь теста — только свойства сцены, закрытие окна сигналом
  TERM; `userpref.blend` после сеанса не изменился [проверено].

## 7. Сравнения и судьи (из C2, без пересказа)

- 3DGen-Bench: 68 400 экспертных голосов, 5 критериев; согласие GPTEval3D с людьми 0,677, CLIP 0,661, обученный судья 0,725
  (C2 `03 §7.1`).
- Judging to Improve (судья для генерации по одной картинке): перегрузка картинками → ответ «по позиции»; сплаты прячут дыры; без
  эталона судья награждает «чистое, но неверное»; перевороты вердикта ~26 % между генераторами и 94 % между двумя выборками
  одной модели — разброс внутри генератора сравним с разницей между генераторами (C2 `03 §7.2`).
- Готовность «для движка» (манифолд, UV без перекрытий, PBR без запечённого света, LOD) почти никто не измеряет — обзор
  production-ready (C2 `03 §1`). Собственного сравнения генераторов в этой сессии нет (нет ключей, решение заказчика).
- Ролики-ориентиры для проверки заявлений (Andrew Price «Testing Viral AI 3D Products», VideoSmile «GPT-6 Astra») — в каталоге V;
  транскрипты не читались (режим экономии).

## Частые ошибки

1. **Считать пробный ключ источником генераций** — общий, исчерпывается (G/01) [проверено].
2. **Генератор для героя-продукта** — неточная форма, искажённые надписи и лого [мнение; исследование C2 о пропорциях].
3. **Бесплатный тариф для коммерческого сайта** — Tripo Free некоммерческий, Rodin Free без «любого использования», Meshy Free
   требует кредит [документация].
4. **Выход генератора прямо на страницу** — сотни тысяч граней и 4K-текстуры (`02`) [документация; проверено на скане G/03].
5. **Включить Hunyuan3D или Rodin по картинкам в MCP 2.0.3** — утечка локальных файлов (CVE-2026-10661) [проверено C1/13].
6. **Нажать «Set Free Trial API Key» в Blender пользователя** — ключ остаётся в его настройках [проверено].
7. **Судить по одной генерации** — разброс внутри генератора ≈ разнице между генераторами (C2) [исследование].
8. **Модель по памяти**: «Rodin API на hyperhuman.deemos.com» (сейчас `api.hyper3d.com`), «TRELLIS работает на ноутбуке» (нужна
   NVIDIA ≥ 24 ГБ для TRELLIS.2), «Tripo Free можно в коммерцию», «Luma Genie/CSM — стандарт» (не проверено в 2026) [документация].

## Чек-лист

- [ ] Задача из §1 действительно для генератора (органика, «как на фото»), а не для кода или библиотеки?
- [ ] Тариф заказчика платный и допускает коммерцию; на бесплатном — атрибуция и её место на странице?
- [ ] Вход (картинка-референс) принадлежит заказчику?
- [ ] Сгенерировано 2–4 кандидата, выбран лучший попарно по рендерам?
- [ ] Выход доведён по `02`: треугольники, масштаб, PBR без света, текстуры, вес в бюджете?
- [ ] В MCP включён только Rodin по тексту (или прямой API), Hunyuan и «по картинкам» выключены?
