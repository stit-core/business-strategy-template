## Выжимка папки

1. Без вопроса заказчику — только CC0 (Poly Haven, ambientCG, Essentials Blender); CC BY — с атрибуцией TASL на странице;
   NC/ND/editorial/«Non-Commercial» бесплатных генераторов — нельзя; магазинные «royalty free» — спросить (GLB на странице
   скачивается как файл). → `03 §1`
2. Poly Haven — без ключа: 997 HDRI, 862 текстуры, 521 модель; брать glTF, не .blend; сырой ассет 4,7–11,4 МБ → одна команда
   сжатия → 0,15–1,2 МБ; HDRI для окружения — 512×256 (0,42 МБ). → `03 §2`
3. Выбор источника: продукт заказчика, иконки серии, абстракции — код; реквизит «как на фото», HDRI, фактуры — библиотека;
   органика и маскоты — генератор + доводка; место «как на фото» целиком — сплат. → `01 §1`
4. Пробный ключ Rodin в аддоне MCP общий и был исчерпан (`API_INSUFFICIENT_FUNDS`); API Rodin — тариф Business $120/мес.;
   бесплатные тарифы генераторов не дают чистых коммерческих прав (Meshy — CC BY с кредитом, Tripo — некоммерческий). → `01 §2–5`
5. MCP: только Rodin по тексту; Hunyuan3D и Rodin по картинкам не включать (CVE-2026-10661, 10662); оператор пробного ключа пишет в
   настройки пользователя; аддон не смотрит на `online_access`. → `01 §4`
6. Доводка: `asset_intake` → Decimate COLLAPSE (UV сохраняется, 1,7 с) → ошибка в мм (P95 ≤ 0,5 % габарита) → перепечка нормали
   (`cage_extrusion` 1–2 %) → сжатие; Remesh/QuadriFlow работают в фоне, но стирают UV. → `02 §3–4`
7. Скан 90 тыс. треуг. после доводки: 12 тыс., 0,28 МБ телефон / 0,58 МБ десктоп — гипотеза A (≤ 0,8 МБ) подтверждена на
   ассете структуры «выход генератора». → `02 §8`
8. Генераторы по умолчанию дают сотни тысяч граней и 4K+ текстуры, масштаб условный — всегда доводка и реальные размеры. → `01 §6`
9. Сплаты: `KHR_gaussian_splatting` ратифицирован; three r186 рисует их только `WebGPURenderer`; SOG/SPZ ≈ 12–17 байт на сплат
   против 248 у PLY; герой ≤ ~200 тыс. сплатов (≤ 3 МБ) + постер. → `04 §1–3`
10. Непроверенное (режим экономии): живой выход Rodin/Meshy/Tripo, лицензии Fab/Kenney/Quaternius/SF3D, конвертация и
    рендер сплатов на этой машине, аддоны сплатов для Blender. → разделы «Открытые вопросы» файлов.
