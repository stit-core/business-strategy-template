## Выжимка папки

1. Цвет бренда на сайте: Blender «Khronos PBR Neutral» ↔ three `NeutralToneMapping` — между рендерами ≤ 1,1 ΔE2000, к hex под ровным светом ≈ 1,9; unlit в three — `toneMapped = false`.
2. AgX (умолчание 5.x) выцветает бренд (ΔE 7–15, белый → #C1C1C1, «розовеет» красный на свету); Punchy темнит; AgX three светлее Blender на +3,5 L* (степень 2,2 против 2,4).
3. «EEVEE светлее three на 13 L*» — извлечение солнца из HDRI (`world.sun_threshold` 10): для сравнений с вебом — Cycles или порог 0; three ближе к Cycles (≤ 5,8 L*).
4. Hex → линейный всегда; свет витрины серый; цвет правят светом и экспозицией, не base color.
5. Доезжают до three (ΔE 1,7–3,7): пластик с coat, глина, хром, керамика, ткань с обходом Sheen (вес 1, Tint = вес × цвет), неон, палитра-текстура; не доезжают: анизотропия (12–16), иридесценция (4,5–8), стекло на прозрачном canvas (≈ 10).
6. Свет от габарита: d = 4r, `P = π·d²·E`; E_key 2–3 Вт/м² под Neutral, 5–8 под AgX; светлый фон — отдельной лампой, не усилением key.
7. Паспорт серии (нормировка, одна камера 85 мм, один свет, Neutral, прозрачный фон + ловец теней) даёт ровную серию и живой бренд (C* 84–93 против 38–44 у «наивной»).
8. Сначала разрешение, потом `frame_camera` (кадр зависит от аспекта); продукт 70–100 мм, трети для hero, full frame для иконки.
9. Превью EEVEE 16 сэмплов (2,6 с на 1024²), финал 64 (7,5 с), трассировка +60 % для металла; Cycles CPU только с явными сэмплами (умолчание 4096): 64 + OIDN — 40 с на 1024².
10. Поставки: рендер с альфой — AVIF q60–75 (в 2–6 раз легче WebP; альфа с потерями), фото-текстуры — WebP/KTX2; видео с альфой — stacked-alpha + VP9 (HEVC-alpha на Linux не кодируется); bloom — Glare, виньетка и зерно — CSS.
