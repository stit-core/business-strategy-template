## Выжимка для агента

1. **HDRI не нужен: студия для отражений — сцена из излучающих панелей → `PMREMGenerator.fromScene(st, 0.02)`**: тёмная сфера-градиент
   + 8–9 ламп-прямоугольников (`MeshLambertMaterial`, `emissive`). Две студии по сценам: «сборка» (длинные горизонтальные полосы — линия
   блика вдоль корпусов суставов, контровые ±135°) и «скан» (холоднее, контрастнее для меди и стали). Смена — присваиванием
   `scene.environment` без перекомпиляции. Цена ≈ 0 мс кадра (+0,06–0,1 мс в тишине), 0,3 КБ br. `[проверено]`
2. **Лампы — белые или холодные; тёплый (фирменный) отражатель красит металл**: отражатель `#ff6d2e` ×0,9 давал точёным крышкам бронзовый
   отлив (a* 4,7, оттенок 287°); нейтральный низкий отражатель `#e9edf2` ×0,55 — a* 1,1, оттенок 276° (графит 269°), провал крышек в
   чёрное 7,1 → 4,6 % объекта. Тёплый свет делает белый лак бежевым (R−B 14,9 → 2,8 после правки J2). `[проверено]`
3. **`scene.environment = rt.texture`, а не `rt`**: с целью рендера вместо текстуры металл чёрный, белый серый — без ошибок в консоли. `[проверено]`
4. **Тон — `NeutralToneMapping`, экспозиция 1,22** для бренда и товара: AgX гасит фирменный оранжевый, ACES его краснит. С постом тон —
   эффектом в конце цепочки, у рендерера `NoToneMapping`. `[проверено]`
5. **Neutral давит тёмные тона в 5–10 раз** («носок» x − 6,25x² при x < 0,08): фон/туман/горизонт цвета страницы задаются **обратной функцией**
   (`preTone(hex, exposure)`) и проходят тот же тон, что сцена — иначе шов на горизонте или чёрный фон; фон кадра к странице ΔE 2,5. `[проверено]`
6. **Свет по сюжету — точечный, над лаком, не на нём**: вспышка фиксации в 1,5 см от лака выжигала свой корпус (пятно 4,5 % кадра);
   0,7 м к камере от центра модуля, дальность 2,6 м — 0,84 %. `[проверено]`

## 2. Частые ошибки

| Симптом | Причина | Правка |
|---|---|---|
| металл чёрный, белый серый | `scene.environment = rt` | `rt.texture` |
| крышки бронзовые | тёплый отражатель в студии | лампы белые/холодные; фирменный цвет — только у кольца |
| шов на горизонте, фон чёрный | фон в hex мимо тон-маппинга | `preTone` + тот же тон |
| серая вуаль под текстом | пол отражает студию и блик ключа на скользящих углах | `envMapIntensity` 0,06, `specularIntensity` 0,18 |
| тёмные крышки сливаются с фоном | нечему отражаться | низкий нейтральный отражатель + контровые ±135° |
| свой корпус выжжен вспышкой | точечный свет у самой поверхности | свет над лаком, 0,5–0,7 м |

## 3. Чек-лист

- [ ] студия PMREM из панелей (по сцене — своя), без HDRI; лампы белые; `rt.texture`;
- [ ] Neutral 1,22; фон/туман через `preTone`; фон кадра к странице ΔE ≤ 3 (`img_metrics.py`);
- [ ] ключ с тенью только на десктопе; тень — раз в кадр; контактное пятно;
- [ ] свет по сюжету — над поверхностью, с дальностью; в покое 0.

## 4. Не проверено (кандидаты)

`SunLight` с каскадными тенями (r186, #34221), `LightProbeGrid.bake()` (r184; WebGPU — r186), `ProgressiveLightMapGPU` (лайтмап в браузере),
PCSS (`webgl_shadowmap_pcss`), контактные тени глубиной снизу (`webgpu_shadow_contact`) — `[документация: дайджест 04 §B.3, B.6; S1, S3, S4]`.
