## Выжимка для агента

1. **v3 = v2 + 7 приёмов под флагами** (студия по сценам, IK, мир, AO, свет по сюжету + пост, микродеталь, процедурная фактура крышек); все флаги выключены —
   кадр равен v2 (те же 49/17 вызовов и 31 037 треугольников), каждый приём включается один — цена и вклад видны по отдельности:
   лист `CD/sheet-techniques.jpg`. `[проверено: CD/02–07]`
2. **Цена приёмов на Iris Xe (десктоп 1440×900, DPR 1,5, медиана 3 чередованных прогонов)**: v2 3,4 мс → v3 5,9 мс; студия ≈ 0,
   IK +0,3 (CPU), деталь +0,1–0,6, AO +0,7–1,1, мир +1,0–1,5, свет по сюжету + пост +1,3–1,7. Телефон-режим (412×915, DPR 1,25, low):
   1,9 → 2,1 мс. `[проверено]`
3. **Вес**: v2 123,2 КБ br → v3 132,0 КБ br на телефоне (без чанка поста) и 227,3 КБ br на десктопе; из них пост 96,8 КБ
   (N8AO ≈ 77, база pmndrs 13,4, bloom/LUT/зерно/виньетка/FXAA ≈ 6), мир 1,3, деталь 0,7, IK 0,5, студия 0,2. 3D-ассетов — 0 КБ. `[проверено]`
4. **Кадр hero по числам** (`img_metrics.py`, маска объекта той же сценой): фон к странице ΔE 2,50 (v2 2,80), блик ≥ 97 L* — 0,67 %
   объекта (цель 0,1–1 %; v2 2,4 %), пересвет белого 0,01 % (v2 0,13 %), объект−фон 33,5 L* (v2 34,8), вес в зоне текста 0,26 (v2 0,16 — хуже).
   «Пересвет» 1,1 % по любому каналу — это R = 255 у горящего кольца (сам hex бренда `#ff5a1f` имеет R = 255). `[проверено]`
5. **Слои после v3** (мнение CD, один судья — автор; решают люди вслепую): свет ≈ ⅚ (v2 ⅔), материал ≈ ⅗ (½), атмосфера ≈ ⅗ (¼),
   деталь ≈ ½ (—), движение и отклик ≈ ⅚ (⅔). Не закрыто кодом: запечённый GI/AO уровня Cycles, фактура поверхности
   (карты, износ), уникальная форма начинки, фотореализм неподвижного кадра — это ассет и предрендер Blender (гибрид). `[мнение]`
6. **Слабые места v3 для глаз**: IK у границы текста складывает руку «к зрителю» (поза тесная), вспышка фиксации с bloom — крупное
   пятно света, горящее кольцо розовеет (ΔE 17 к hex у v3 при ярком свечении, 12 у v2 — Neutral обесцвечивает яркое), в зоне текста
   больше «веса» (пол и горизонт). `[проверено]`
