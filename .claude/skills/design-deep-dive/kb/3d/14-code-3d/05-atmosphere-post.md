## Выжимка для агента

1. **«Предмет в мире» кодом стоит полмиллисекунды**: пол с отражением предметов (свой Reflector: ½ разрешения + размытие ¼ по «высоте над
   полом» из альфы зеркального прохода), туман по высоте во **всех** материалах одним патчем `onBeforeCompile` с общими uniform, горизонт и
   ореол одной формулой в фоне и в тумане пола (шва нет), фон «до тона» (`preTone`). Цена +0,48 мс кадра (1440×900, DPR 1,5), 1,3 КБ br. `[проверено]`
2. **Контровой свет в дымке (приём 8)** — самый дешёвый способ получить «студийный» фон Blender: светящийся эллипс в 2,5 м за рукой →
   `GodRaysEffect` pmndrs (заслонение глубиной сцены + радиальная свёртка в ½) складывается в линейный HDR до тона. Рука режет свет, силуэт
   отделяется от фона (объект − фон +1,5 L*), при IK тени-лучи двигаются вместе с рукой. Вес 1,8 КБ br (сборка без приёма), цена — §3. Три
   ловушки: «солнце» (яркий малый диск), граница свечения по горизонту (пол заслоняет диск), подъём тёмного фона дальними отсчётами (плотность ≤ 0,5). `[проверено]`
3. **AO кодом — тонкий эффект за заметную цену** (одна сцена, одна поза, четыре реализации): N8AO в цепочке pmndrs **+1,04 мс** и **77,6 КБ br**;
   `N8AOPass` в `EffectComposer` three +1,76 мс; `SSAOPass` +1,90 мс / 4,7 КБ; `GTAOPass` +3,26 мс / 7,1 КБ (+2,4 КБ база композитора).
   Глазом различимы только стыки основания и под крышками. Для статичных стыков — AO в GLB (запекание Blender, гибрид): 0 мс кадра. `[проверено]`
4. **Цепочка поста, которая не ломает бренд**: RenderPass (HalfFloat, **MSAA 0**) → N8AO (½, `accumulate: false`, `transparencyAware: false`) →
   EffectPass [bloom по порогу **3,4 HDR** → Neutral (тон — здесь, у рендерера `NoToneMapping`) → LUT 32³ → зерно SOFT_LIGHT 0,05 → виньетка] →
   **FXAA отдельным EffectPass**. Эффекты fx — +0,82 мс, ≈ 6 КБ br (+13,4 КБ база pmndrs), чанк поста 97 КБ br качает только десктоп. `[проверено]`
5. **Две MSAA-ловушки композитора** (обе молчаливые): N8AO + MSAA — первый кадр 0,5–1,35 с (без MSAA 65–150 мс); HalfFloat + MSAA 4 +
   анизотропный `MeshPhysicalMaterial` — Inf/NaN на сэмплах краёв → «искры»-квадраты bloom. Правило: MSAA композитора 0 всегда, сглаживание —
   FXAA; попутно пост подешевел на 1,8 мс (fx 3,95 → 2,17). `[проверено]`
6. **Порядок эффектов решает**: свёрточный эффект (FXAA/SMAA) в общем EffectPass читает сырой вход и выбрасывает bloom, тон и LUT (пересвет
   11,5 %); bloom с порогом 1 зажигает блики лака (HDR 2–3) раньше фирменного оранжевого (яркость 0,21·R); зерно OVERLAY выбивает блики в 255
   (пересвет 3,9 %), SOFT_LIGHT 0,12 — «крапинка» в тёмных. `[проверено]`
7. **Настоящий объём с тенями, SSR, SSGI, VXGI в r186 — только WebGPU/TSL**: `GodraysNode` (raymarch по карте теней), `SSRNode`, `SSGINode`,
   `lighting/vxgi`; на WebGL остаются `SSRPass`, `SAOPass`, `GTAOPass`, `SSAOPass` и лучи pmndrs (маска + радиальная свёртка). Вход в WebGPU —
   +107 КБ br и свой откат (`08`). `[документация: исходники three 0.186.0 examples/jsm/tsl/display, lighting/vxgi]`

## 3. Контровой свет в дымке — приём 8 (CD/21, фаза 3)

**Что делает.** За рукой (2,5 м за целью камеры, эллипс 1,9 × 1,2 м, повёрнут к камере) — светящийся диск с мягким краем (canvas-градиент).
`GodRaysEffect` pmndrs копирует глубину сцены в цель источника (рука и пол заслоняют диск), размывает (Кавазе SMALL), считает радиальную свёртку
в ½ разрешения и складывает результат ADD в линейный HDR до тона Neutral. Свет не входит в основную сцену и зеркало. Сила 0 — тяжёлая часть
эффекта не считается (свой `update` пропускает). Десктоп, только с постом.

**Как подбирали** (кадры `99-raw/experiments/CD/out/cd3/sweep/`, листы `sheet1–3.jpg`, итог — `out/cd3/pairs-p2-p3b.jpg`):

| Шаг | Параметры | Итог глазами и числами |
|---|---|---|
| s0 | диск R 1 м, `#aebcdc`, экспозиция 0,6 | «солнце» за рукой, на разносе — ослепительный шар; лучей не видно — **отвергнуто** |
| s1–s4 | тусклее, R 1,7–2,6 м, 4,5–6 м за рукой | мягкий фон за силуэтом; у s4 — тёмный клин от J2 через колонку текста |
| s5–s8 | эллипс 0,6–0,7, короткие лучи (спад 0,9) | колонка текста тёмная; **граница свечения по горизонту** — пол заслоняет нижнюю половину диска |
| t1–t3 | источник ближе: 1,6–2,5 м за рукой | границы нет — «колонна» света гаснет к основанию; выбран t2 |
| u, v | экспозиция 0,09–0,12; **плотность 0,8 → 0,5** | ΔE медианы фона к странице 3,4 → 3,0: при 0,8 каждый пиксель «дотягивался» до диска (+0,7 L* у фона L* 5); сила на это почти не влияет |

## 4. Частые ошибки

| Симптом | Причина | Правка |
|---|---|---|
| серая вуаль под текстом, фон L* 13 | пол отражает PMREM-студию и блик ключа на скользящих углах | `envMapIntensity` 0,06, `specularIntensity` 0,18 |
| шов на горизонте, ореол «в воздухе» | ореол фона в экранных координатах, туман пола его не знает | одна формула ореола по мировому направлению в фоне и тумане |
| первый кадр 0,5–1,35 с | N8AO + MSAA композитора | `multisampling: 0`, FXAA |
| «искры»-квадраты на краях | HalfFloat + MSAA 4 + анизотропный Physical (Inf/NaN) | MSAA композитора 0 |
| кадр без тона, пересвет 11,5 % | FXAA в общем EffectPass | FXAA отдельным проходом |
| светится лак | порог bloom 1 (блики лака HDR 2–3) | порог 3,4, вспышка/кромка — выше 3,4 |
| пересвет 3,9 % / «крапинка» | зерно OVERLAY / SOFT_LIGHT 0,12 | SOFT_LIGHT 0,05 |
| кадры после остановки | накопление N8AO по кадрам, `transparencyAware` (+2 прохода) | `accumulate: false`, `transparencyAware: false` |
| «солнце» за объектом | яркий малый источник лучей | тусклый большой эллипс, экспозиция ≈ 0,12 |
| граница свечения по горизонту | диск лучей частично под полом — пол заслоняет | источник ближе к объекту (≤ 2,5 м), нижний край над полом |
| фон кадра светлеет целиком | плотность свёртки 0,8+ — дальние пиксели дотягиваются до источника | плотность ≤ 0,5 |

## 5. Чек-лист

- [ ] мир: пол отражает только предметы, туман в каждом материале (один патч), фон и туман через `preTone`; фон кадра к странице по краям ΔE ≤ 3;
- [ ] пост — отдельный чанк, телефон его не качает; MSAA композитора 0; FXAA отдельным проходом; bloom по порогу HDR выше бликов;
- [ ] AO — только если стыки двигаются; иначе запечь в GLB; N8AO без накопления и без прозрачности;
- [ ] лучи: источник тусклый и крупный, не под полом, плотность ≤ 0,5; колонка текста и края кадра как без лучей (`img_metrics`, кольцо 5 %);
- [ ] цена каждого приёма — в тишине, парой «с/без» в одном чередовании.

## 6. Не проверено (кандидаты)

- Настоящий объём с тенью от ключа на WebGL (свой raymarch по карте теней в ¼ + билатеральное размытие) — оценка ≈ 1 мс; в r186 готовое
  решение есть только для WebGPU (`GodraysNode`). `[документация: three 0.186.0 examples/jsm/tsl/display/GodraysNode.js]`
- `SSRPass` для лака на полу (сейчас — плоское зеркало): точнее на изогнутых корпусах, но +полный проход нормалей. `[документация]`
- `SMAAEffect` вместо FXAA (резче на тонких рисках колец). `[документация: pmndrs]`
