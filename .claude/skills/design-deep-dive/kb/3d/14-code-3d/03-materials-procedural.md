## Выжимка для агента

1. **Набор «промышленный продукт» — 0 байт карт**: белый лак `MeshPhysicalMaterial` (clearcoat 1 / 0,08, шерох. 0,36), сатиновый алюминий
   (металл, шерох. 0,4, **анизотропия 0,35 вдоль трубы**, `anisotropyRotation` π/2), точёный графит крышек (металл 0,9, шерох. 0,3,
   **анизотропия 0,8 по окружности** — UV токарного профиля идут по кругу, `anisotropyRotation` 0 даёт радиальную полосу-блик), резина
   (0,72), матовая сталь винтов (0,5). Телефон — Standard без лака и анизотропии. `[проверено: J/04, CD/02–07]`
2. **Ловушки материала видны только числами**: алюминий при шерох. 0,3 и 0,55 читается хромом (v2); тёплый свет делает белый бежевым
   (R−B 14,9 → 2,8); тёплый отражатель студии даёт металлу бронзу (a* 4,7 → 1,1 без него); зеркальная головка винта (0,32) — «искра». `[проверено]`
3. **Анизотропный Physical + MSAA 4 в HalfFloat-буфере композитора = «искры»-квадраты bloom** (Inf/NaN на сэмплах краёв): MSAA композитора
   выключать, сглаживать FXAA отдельным проходом. `[проверено]`
4. **Излучение бренда держать ниже сжатия Khronos Neutral**: пик канала × экспозиция < 0,76 — цвет без сжатия; при пике 19,5 (вспышка ×16)
   доля белого g ≈ 0,74 — оранжевый розовеет. Яркость отдавать **узкой LED-полосе** (атрибут `band` = uv.y открытого цилиндра, маска
   0,36–0,64 поперёк пояска, `#ff6a2a` × до 30) — «розовых» пикселей кольца в hero 12,8 → 2,5 %. `[проверено]`
5. **Процедурная фактура**: круговая анизотропия — через UV (0 байт); шум шероховатости — патч `onBeforeCompile` (GLSL) на WebGLRenderer
   или `roughnessNode` на TSL (`mx_noise_float`) — TSL требует `WebGPURenderer` (+107 КБ br к сцене): числа и откат — `08` §2. `[проверено]`
6. **Материалы GLB (гибрид) кодом не переписываются**: клон на ключ (исходник не мутировать), Physical → Standard на телефоне, туман
   патчем `withHF`, FrontSide вместо doubleSided Blender (кроме наклеек), кольцо и светодиод — экземпляр на модуль; анизотропия из Blender в three
   не доезжает (ΔE 12–16, дорожка Z) — для точёных крышек нужна UV по окружности или `materials: 'code'`. `[проверено: CD/11; Z фаза 1]`

## 2. Частые ошибки

| Симптом | Причина | Правка |
|---|---|---|
| алюминий — хром | шерох. 0,3 / 0,55 без анизотропии | 0,4 + анизотропия 0,35 вдоль оси |
| белый бежевый | тёплый ключ/отражатель | лампы белые, R−B белой точки ≤ 5 (`white_check.py`) |
| крышки бронзовые | тёплый отражатель в PMREM | нейтральный низкий отражатель |
| кольцо розовое при свечении | излучение выше сжатия Neutral | лак ≤ 1 × exp, яркость — LED-полоса |
| «искры» на краях металла | MSAA композитора + анизотропия | `multisampling 0` + FXAA |
| материал GLB без тумана или тумана дважды | клон материала «помнит» флаг без патча | клонировать чистый исходник и патчить копию |
| программа пересобирается на первом кадре | патч материала без `customProgramCacheKey` / компиляция не в том буфере | ключ кэша на патч; `compileAsync` с тем же целевым буфером (`01` §4, ловушка 6) |

## 3. Чек-лист

- [ ] белая точка (L95, R−B), блик ≥ 97 L* 0,1–1 % объекта, пересвет ≤ 1 % (`img_metrics.py`);
- [ ] излучение бренда ниже сжатия Neutral, вспышка — полосой/ядром; ΔE цвета бренда в покое — по маске роли (`p2_metrics.py role`);
- [ ] телефон — Standard; анизотропия только десктоп; MSAA композитора выключен;
- [ ] у каждого патча `onBeforeCompile` — свой `customProgramCacheKey`.

## 4. Не проверено (кандидаты)

«Апельсиновая корка» лака шумом в нормали лака (`clearcoatNormal` процедурно), износ по кривизне, `MeshSSSNodeMaterial` для полупрозрачных
накладок, `retroreflectivity` (r186), sheen для резины, iridescence/dispersion (риск клише) — `[документация: дайджест 04 §B.1–B.2, S1, S6]`.
