## Выжимка для агента

1. **Код закрывает продуктовую L2-сцену до уровня «предмет в студии и в мире» без единого байта ассетов**: студия PMREM из излучающих
   панелей по сценам, контровой свет в дымке, пол с отражением и туманом, свет по сюжету с выборочным bloom, промышленные материалы без карт
   (лак, сатин-анизотропия, точёный графит), крепёж/кабель/маркировка правилами. Страница A: 3D-ассеты **0 КБ**, JS 3D **234,1 КБ br десктоп /
   135,7 телефон** (бюджет L2 ≤ 350 / 250), кадр **4,72 мс** на Iris Xe (1440×900, DPR 1,5; все приёмы), телефон-режим 0,53 мс. `[проверено]` → `01` §10
2. **Чего код не даёт** (и где Blender или гибрид сильнее — кадры судьи A·B·C, `CD/out/cd3/abc_judge.jpg`): уникальная форма (начинка «как
   CAD»: подшипники, обмотка, плата; фланцы с крепежом), фактура поверхности (износ, «апельсиновая корка», карты шероховатости), запечённый
   свет (AO стыков, цветной отскок), неподвижный фотореализм (Cycles 64–128 спп + OIDN, рентген). Это — геометрия и запекание Blender. `[проверено: CD/17, D Z]` → `01` §10
3. **Сильнейший ход кода — продукт отвечает вводу**: рука указывает на курсор (аналитическая IK, 0,5 КБ, ≈ 0,2 мс CPU), на телефоне — на
   касание; путь инструмента остаётся пунктиром 0,4 с (приём 10, ≈ 0 мс); свет отвечает сюжету (вспышка фиксации, скан светит на начинку).
   В покое 0 кадров. У кадров и видео Blender этого слоя нет. `[проверено]` → `07`
4. **Гибрид C — лучшее из двух для продукта с CAD**: крюк `_shared/code3d` берёт модули из GLB по именам (пустышка = шарнир, оси three,
   роли материалов по имени), всё живое остаётся кодом. Крюк v2: начинка отдельным GLB (−119 КБ br первого экрана, приходит через ≈ 51 мс
   после первого кадра), KTX2 по требованию (на одном атласе 2048² — +301 КБ br сети при −74 % памяти GPU: брать WebP). `[проверено]` → `04` §2
5. **Цена приёмов в тишине** (Δ мс кадра к «всё выключено» 1,32 мс; вес — сборкой без приёма): студия +0,06 / 0,2 КБ; IK ≈ 0,2 CPU / 0,5;
   мир +0,48 / 1,3; деталь +0,10 / 0,7; фактура +0,10 / 0; свет по сюжету и пост +0,82 / ≈ 6 (+13,4 база pmndrs); **контровой свет в дымке
   +0,37 / 1,8**; след ≈ 0 / 0,9; **AO +1,04…3,26 / 4,7…77,6** — самый дорогой и самый тонкий. `[проверено]`
6. **AO кодом не окупается на статичных стыках**: N8AO +1,04 мс и 77,6 КБ br, SSAO +1,90 / 4,7, GTAO +3,26 / 7,1 — все «тонкий эффект»;
   запечённый AO в GLB — 0 мс. `[проверено]` → `05` §2
7. **Молчаливые ловушки — ловить числами, не глазами** (ни ошибки, ни предупреждения): `scene.environment = rt` вместо `rt.texture` (металл
   чёрный); пол, отражающий студию (серая вуаль под текстом); MSAA композитора + N8AO (первый кадр 0,5–1,35 с) и + анизотропный Physical
   («искры» bloom); FXAA в общем EffectPass (кадр без тона); компиляция программ не в том целевом буфере (длинная задача 2,2 с); ранний
   `return` под define не вырезает `import()` (страница без крюка получила +47 КБ br). `[проверено]` → `01` §4, `05`
8. **Тёмные тона и бренд под Khronos Neutral**: «носок» x − 6,25x² давит тёмные в 5–10 раз — фон/туман/горизонт задавать обратной функцией
   (`preTone`); излучение бренда держать ниже сжатия (пик × экспозиция < 0,76), яркость отдавать узкой LED-полосе — иначе оранжевый розовеет. `[проверено]` → `02`, `03`
9. **Интерактив не заходит в текст**: цель IK ограничивается колонкой текста по содержимому (Range строк), у текста рука указывает, а не
   тянется; контраст H1 над живым 3D 15,1:1 (телефон 10,4:1). `[проверено]` → `07`
10. **Ворота в тишине — чисто**: motion_check L2 (5 режимов) **B 0, S 0, D 0**, marketing_audit блокеров/серьёзных 0, site_probe — см.
    `a-code/README.md`. Под нагрузкой соседей (load 24–30) TBT той же v2 рос с 76–137 до 634–827 мс: судить TBT и первый кадр только в тишине
    и парой с эталоном в одном прогоне. `[проверено]`
11. **WebGPU для такого лендинга не нужен**: TSL-материал на `WebGPURenderer` — +107 КБ br, откат на WebGL2 — первый кадр ×1,5; переходить,
    когда нужен compute, объём с тенью (`GodraysNode`), SSGI/SSR/TRAA или VXGI — в r186 они только на WebGPU. `[проверено]` → `08`
12. **Метод замера**: вес — только сборкой с `--define` (флаг в рантайме бандлер не видит); кадр — пропускная «окно / число кадров» после
    ожидания простоя (медиана интервалов rAF при `--disable-gpu-vsync` двугорбая и непригодна); вид — `img_metrics.py` с маской той же сценой
    (край кадра и зона текста — отдельно от медианы фона). `[проверено]`

## Дерево решения: код / Blender / гибрид / сплат / видео

| Задача страницы | Бери | Почему (числа) |
|---|---|---|
| продукт отвечает на ввод (курсор, касание, клавиши, прокрутка ведёт механику) | **код** (+ геометрия из Blender, если есть CAD) | IK, след, свет по сюжету — 0–1 КБ и ≤ 0,3 мс; кадры/видео отвечают только времени `[проверено]` |
| сборка/разборка, скан «внутрь», сюжет по прокрутке | **код** на процедурной геометрии или на GLB-модулях | 0 КБ ассетов, 0 кадров в покое, ворота K 0/0/0 `[проверено]` |
| студийный свет, дымка за объектом, пол-отражение | **код** | студия ≈ 0 мс, мир +0,48, контровой свет в дымке +0,37 `[проверено]` |
| микродеталь по правилу (< 30 уникальных элементов: винты по окружности, кабель, маркировка) | **код** | 86 винтов одним InstancedMesh, кабель, наклейки — +0,7 КБ br `[проверено]` |
| уникальная форма (≥ 30 разных деталей), начинка «как CAD», износ, фактура | **Blender → GLB** (гибрид C) | код держит правило, а не форму: сравнение `a-code__scan-half` ↔ `c-hybrid__scan-half` `[проверено: CD/11, Z]` |
| статичный AO/GI на стыках, запечённая тень | **Blender (запекание) в GLB** + код | AO кодом +1,04…3,26 мс и 4,7…77,6 КБ за тонкий эффект, запекание — 0 мс `[проверено]` |
| неподвижный премиальный кадр (постер, станции, рентген) | **Cycles** (или свой рендер той же сцены кода, 9–22 КБ WebP) | Cycles сильнее в неподвижном кадре — кадры судьи B `[проверено: Z]` |
| продукт с CAD и живой страницей | **гибрид C**: GLB модулями (+ начинка отдельным файлом) + весь код | крюк: 20 КБ br чанк + GLB 679 КБ br без начинки `[проверено]` |
| «реальное место», съёмка | сплат (Spark / `GaussianSplat` r186) | нужен захват; Spark 744 КБ br — вне бюджета L1 |
| кинематографичный пролёт без ввода на слабом телефоне | видео/секвенция | 0 WebGL, но не отвечает на ввод; 0,5–2 МБ |
| compute (≥ 200 тыс. частиц, поля), объём с тенью, SSGI/SSR, VXGI | **WebGPU + TSL** с откатом | в r186 — только там; +107 КБ br, откат ×1,5 первого кадра `[проверено]` |

Правило в одной строке: **чем больше страница отвечает на ввод и сюжет — тем больше код; чем больше нужна уникальная форма, фактура и
неподвижный фотореализм — тем больше Blender; продукт с CAD — гибрид (меш и запекание из Blender, всё живое — кодом)**.

## Как запустить пример

```bash
R=/home/mm/Документы/app-design/blender-research; CD=$R/99-raw/experiments/CD; Q="python3 $R/99-raw/tools/slot_run.py"
$CD/build.sh                              # страница A (= _shared/code3d/build.sh a-code/js), 1–2 с; $CD/build.sh kb — вес по приёмам
$R/15-showcase/_shared/code3d/build.sh zveno/c-hybrid/js --glb    # гибрид C (крюк); --ktx2 — ещё KTX2Loader и транскодер basis
$Q --kind browser --label CD-frames -- python3 $CD/lp.py frames --b v3 --out $CD/out/f --extra look=p3        # кадры состояний (+ --masks all)
$Q --kind browser --heavy --label CD-bench -- python3 $CD/lp.py bench --out b.json --modes desk,mob --repeat 3 --sets "c3:all:p2;c3:all:p3"
$Q --kind browser --heavy --label CD-hook -- python3 $CD/hook2/hook2_run.py run $CD/out/hook2/q   # крюк v2: KTX2 / WebP / начинка отдельно
```
Стенды: `CD/preview.html?b=v3&phase=story&t=0&look=p3&lk=beamExp:0.12` (кадр, маска `&mask=1`, IK `&px=&py=`, след `&demo=ik&path=x0,y0,x1,y1`),
`CD/bench.html` (цена кадра), `CD/hook2/hook2.html` (GLB: сеть, память GPU, первый кадр), `CD/ao/ao.html`, `CD/tsl/{gl,tsl}.html`.
