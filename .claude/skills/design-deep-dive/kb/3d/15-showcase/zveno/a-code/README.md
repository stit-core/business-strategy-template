## Паспорт A — что делает код (флаги, вид `p3`: `main.js` → `createScene(…, { look: 'p3' })`)

| Флаг | Приём | Телефон (low) |
|---|---|---|
| `studio` | студия PMREM по сценам: «сборка» (длинные полосы-блики, контровые ±135°, нейтральный низкий отражатель) и «скан» (холодная) | да |
| `ik` | рука тянется к указателю; у текста — **указывает** на курсор (цель поднята, схват нацелен), граница — колонка текста по содержимому; телефон — касание | да (касание) |
| `world` | тёмный пол с отражением предметов, туман по высоте во всех материалах, горизонт и ореол в дымке | туман и горизонт, без зеркала |
| `ao` | N8AO на стыках (½) | нет |
| `fx` | свет по сюжету (вспышка фиксации над лаком, скан светит на начинку), bloom выше порога 3,4 (LED-полоса кольца, ядро кромки скана), LUT, зерно, виньетка, FXAA | нет |
| `detail` | 86 винтов одним InstancedMesh, кабель к напольному разъёму, маркировка шрифтом страницы, риски колец, швы | да, без винтов |
| `texture` | точёный графит крышек: круговая анизотропия по UV токарного профиля | нет |
| `beam` (фаза 3) | **контровой свет в дымке**: светящийся эллипс за рукой, лучи pmndrs — рука режет свет, силуэт отделён от фона; на разносе — «колонна» света за модулями, в «скане» — свечение за разрезом | вместо лучей — ореол фона ×5, ширина 22, только в «модулях» (итерация №2, 0 мс) |
| `trail` (фаза 3) | **след инструмента**: пунктир путевых точек 0,4 с за точкой захвата, когда руку ведёт курсор (IK) или идёт «первое движение» | да |

API для `main.js` — как у v2 (`createScene(canvas, {context, dprMax, quality})` → `ready, resize, set, pointer, intro, renderNow, stop, dispose, stats`;
добавлены `tap`, `ikBounds`, `flags`, `mask(role?)`, `look`). В `main.js` фазы 2 граница IK считается **по содержимому** (Range строк и кнопок):
в фазе 1 край флекс-строки кнопок (1312 из 1440 px) давал `minX = 0,6` — рука на странице к тексту не тянулась вовсе.
