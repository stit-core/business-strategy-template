# Испытание «3D для сайта до вау-уровня»: Blender + 3D кодом — план (утверждён заказчиком «делай», 25.09.2026 ~18:20)

## Контекст

Ты просишь по-настоящему проверить, что дают сайту Blender и 3D чистым кодом, довести **обе дороги до вау**, понять, как делать
вау воспроизводимо, где сильнее Blender, где код, где они дополняют друг друга, и получить вердикт: на что мы способны сейчас,
какие правила ресерча помогли, какие нет. Недостающее про «3D кодом» — досследовать и записать в `blender`.

Исходная точка: `blender` даёт «правильно и чисто», но не «красиво» — помощник нашёл причины прямо в коде (свет,
фон, отражения, кадр). `creative` довёл 3D кодом («Звено», L2) до «уверенного предметного рендера» и записал, что
следующий шаг — ассет Blender и мир вокруг продукта. Нейросетевое видео (`ai-media`) кинематографично, а 3D генераторов ты
забраковал. Планка — «чётенько», красиво, разнообразно.

## Как мерим «вау»

1. **Годность** — ворота без провалов: бюджеты, LCP постером, 0 вызовов в покое, reduce, телефон в эмуляции, контраст.
2. **Вау** — рубрика creative-research (`effectiveness.rubric.json`): попарно, критерии concept / craft / motion / clarity;
   правило L2 — победа или ничья в ≥ 2 из 3 (concept, craft, motion) против якорей класса (Illoca, hubtown + референсы ниже).
3. **Судьи**: решающий голос — **твой, вслепую** (страница голосования: 20–30 пар по 10–15 минут, каждая пара в двух порядках;
   по желанию — ещё 1–2 дизайнера по ссылке). ИИ-судья в чистом контексте — только предварительный отсев брака (он узнаёт
   известные сайты и не оценивает движение). Движение — по записям 10 с.
4. **Цели**: в каждом предмете лучший вариант делит или выигрывает craft у якоря своего класса и вслепую бьёт базовую линию;
   по дорогам — решение «Blender обязателен / по бюджету / не нужен» по доле побед гибрида над кодом (≥ 0,75 / 0,4–0,75 / < 0,4).

## Что берём из ресерча — и что чиним

**Надёжно** (берём как есть): паспорт в метрах до кода, идемпотентный `build(P)` на `bpyx`, фаски 1–3 % (3 сегмента + harden +
Weighted Normal для глянца), врастание деталей 30–40 %, пара цвета Khronos PBR Neutral ↔ `NeutralToneMapping`, экспорт пресетом +
Meshopt, «постер → 3D после LCP», рендер по требованию, reduce → 0 вызовов, проверки кодом (`scene_check`, `qa_pipeline`).

**Почему не вау в Blender — чиним первым делом:**

| Дефект | Причина (найдено в коде базы) | Правка | Цель-число |
|---|---|---|---|
| белый товар серый (L* 68 вместо ~96) | ключ `d1lib.stage`/`rk.studio` светит главную грань под ≈ 83° | ключ 30–45° от оси камеры, подъём 30–45°, софтбокс для полосы-блика, контровые ±135° × 1,2–2, белые лампы, мир 0–0,15 | главная грань ≥ 85 L*, блик ≥ 97 L* на 0,1–1 %, клиппинг товара ≤ 1 % |
| тёмная стена (L* 55–59 при странице 91–95) | стена на 9,5r, лампы на 4r | своя лампа на фон или прозрачный фон + ловец теней | фон = страница ± 3 L*, объект–фон ≥ 10–15 L* |
| точечные блики, оливковое золото | нечего отражать | HDRI CC0 (есть на диске) для отражений | попарно лучше исходника |
| всё по центру | у кадра нет `shift_x` | 16:9, `shift_x` −0,17, поля 8–12 % | треть под заголовок |
| шум EEVEE | 48 спп | финал героя — Cycles 64–128 + OIDN | шум ≤ 2,5·10⁻³ |
| стекло — «серый брусок» | нет контровых полос | тёмный фон, лампы-полосы, просвет, bounces 16–32 | кромки светлыми линиями |

**Код на максимуме — топ приёмов** (по «вау на рубль»): студия PMREM по сценам; интерактив как показ механики (IK за курсором);
мир вокруг продукта; AO на стыках; свет по сюжету + выборочный bloom, зерно, LUT; процедурная микродеталь; процедурная фактура;
объёмный луч; составной переход между сценами; частицы, которые объясняют. WebGL — по умолчанию; одна ветка WebGPU/TSL с
замером отката — чтобы обновить правило базы.

**Гипотезы, которые вердикт подтвердит или опровергнет**: код сильнее во всём, что отвечает на ввод, в весе и в параметрике;
Blender — в статичном GI, AO, микродетали, фактуре и неподвижном кадре; гибрид (меш и запекание из Blender + живое кодом) —
лучший для продукта; бренду без продукта код не уступает, а Blender нужен для иллюстративных миров; на телефоне запечённая
сцена дешевле кода с AO и туманом.

## Проверка — применимо ли в реальности

- Числа кодом до картинки: `qa_pipeline.py scene|glb|page`, валидатор Khronos, `gltf_diff.py` (ΔE ≤ 3,5, IoU ≥ 0,99), `three_probe.py`.
- Страница: `site_probe.py` + `gate_check()` (десктоп; Pixel 7 CPU ×4 на медленном 4G; reduce), своя метка первого кадра модели;
  ворота creative-research `motion_check.py --level L0|L1|L2` и `marketing_audit.py` — вывод в наши папки.
- Бюджеты героя телефон/десктоп: ≤ 0,8/1,5 МБ, ≤ 50/100 тыс. треуг., ≤ 30/60 вызовов в покое, DPR ≤ 1,5/2, JS 3D ≤ 250/350 КБ br.
- Картинка: одинаковые кадры A/B/C листами, записи 10 с; ИИ-судья — отсев; **ты — слепое голосование**.
- WebKit (Playwright) — как ближайшее к Safari, с пометкой «не iOS»; реальный телефон — в конце, по твоему согласию, через
  приватную страницу.

## Как работаю

**Метод вау (один на все предметы — его и проверяем):** референсы → паспорт арт-дирекшна → этюд света (4 схемы на одной модели:
студия с софтбоксом и полосами; низкий ключ с контровыми; атмосфера с дымкой и лучом; светлая пастельная циклорама) → 2–4
варианта hero → лучший → проход деталей → кадр → движение → пост → веб → критика (код → я → отсев судьёй), ≤ 2–3 итерации с
откатом к лучшему.

**Техника и порядок на машине:** Blender — `blender -b` через `../../scripts/3d/blender_run.py` с помощниками базы (официальный MCP в
песочнице базу не видит); страницы — свой бандл three 0.186.0 + esbuild из офлайн-кэша npm, декодеры со своего домена,
`serve_br.py` для замеров; тяжёлый рендер — один одновременно под замком `app-design/.locks/render.lock`; браузер — под
существующими `.locks/browser.lock`; перед рендером свободной памяти ≥ 3 ГБ; Cycles — только с явными сэмплами; свои фоновые
процессы закрываю сам. Мелкие правила: кнопка паузы у каждой петли > 5 с, `--tone neutral` у проверок, `--palette false`, если
JS меняет материалы по имени.

**Не делаю:** платные API и регистрации, генераторы 3D, правки в соседних базах (creative-research и ai-media — только читаю
и копирую к себе), ничего не публикую без твоего согласия.

**Где лежит:** `3d/15-showcase/` (страницы, галерея, голосование, вердикт), `3d/14-code-3d/`,
опыты — `99-raw/experiments/{Z,CD,KB,SD,VD}/`.
