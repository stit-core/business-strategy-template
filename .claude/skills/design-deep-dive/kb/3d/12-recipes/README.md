## Выжимка папки (10 строк)

1. Выбор — по задаче страницы (`00 §1`): товар — постер/видео/hero-GLB/model-viewer; бренд — шейдер/скульптура/логотип; кампания — прокрутка, диорама;
   товар, который отвечает вводу, — код (14), CAD-деталь + всё живое — гибрид (15), кадр, который светит за курсором, — проходы (16), расцветки — variants (17).
2. Интерактив не нужен — предрендер: иконка 2,4–2,8 КБ AVIF, петля VP9 с альфой 124 КБ — без three (02, 08).
3. Каркас один: паспорт → идемпотентный `build(P)` → `rk.asserts` + `rk.audit` → `rk.studio/camera/neutral` → `rk.render` → `rk.ship` → эталонная страница → ворота;
   свет героя — по рецепту 13, не `rk.studio` (ключ под ≈ 83° к грани: белое L* 68 — реестр T1 корневого README).
4. Пара цвета — Khronos PBR Neutral ↔ `NeutralToneMapping`; E_key 2–3 Вт/м²; 85–90 мм; сначала разрешение, потом кадр.
5. Утверждения кодом ловят реальные ошибки композиции (галька свисает с подставки на 13 мм — 09); писать их от опорной детали.
6. Экспорт — пресет E по коллекции `ASSET_*`, `optimize` без склейки для адресуемых частей; AR — отдельный несжатый GLB + USDZ (12).
7. Страницы не с нуля: hero-lazy (`window.HERO_CFG`), H/21 (скраб), F2 shader-background, model-viewer; ворота `gate_check()` 24/24 (01), 15/15 (06).
8. Повторы — GN-инстансы без Realize: 900 объектов 22 КБ и 1 вызов (10), остров 14,5 КБ (07).
9. Стекло в three преломляет только canvas: фон и предметы — в сцене; на прозрачном canvas — «белая плита» (09).
10. Честно слабое: телефоны и AR на устройствах не проверены, маскот не собран; свет hero «аккуратный, не Awwwards» у 01–12 закрыт рецептом 13
    (белое 68 → 92–95 L*); «вау» по слепым парам (заказчик, 26.09): главный кадр Blender «Звена» > код > гибрид, «Сдано» B > A,
    Velmora — ничья с нейросетью, доля гибрида над кодом 0,40 — «по бюджету» (`../15-showcase/vote/results.md`, блок VOTE `../15-showcase/VERDICT.md`);
    вживую тот же судья выбрал гибрид во всех трёх предметах (`../15-showcase/vote/live-assessment.md`) — кадры мерят ремесло, не живую страницу.
