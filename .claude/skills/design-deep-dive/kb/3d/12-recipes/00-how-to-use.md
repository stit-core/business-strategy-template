Волна 3 · агент K · 23.09.2026 · Blender 5.2.2 LTS, glTF-IO 5.2.40, three r186, Chromium (Playwright, Iris Xe) · 17 рецептов: 01–12 (K) —

## Выжимка для агента

1. **Сначала задача страницы, потом техника**: продукт — постер/видео/model-viewer/hero-GLB; бренд без предмета — шейдер или
   скульптура; кампания — прокрутка и сцены. Дерево — §1, первоисточник A `../01-web-3d-landscape/02-when-3d-budgets-loading.md §7` [консенсус: A, F1, H].
2. **Предрендер, если интерактив не нужен**: иконка AVIF 2,4–2,8 КБ, петля VP9 с альфой 124 КБ против 174 КБ JS three + GLB
   (рецепты 02, 08) [проверено].
3. **Каркас рецепта один**: бриф → паспорт стиля (1 раз на серию) + паспорт ассета `P` в метрах → идемпотентный `build(P)` →
   `rk.asserts` + `rk.audit` → студия и кадр → рендер → `rk.ship` (пресет E + постобработка) → страница-эталон → ворота (§2) [проверено].
4. **Паспорт по умолчанию — Khronos PBR Neutral ↔ `NeutralToneMapping`**, E_key 2–3 Вт/м², 85–90 мм, мир цвета страницы (§3);
   AgX — только для атмосферного hero без бренд-hex (ΔE 7–9) [проверено].
5. **Код писать на помощниках**: `rk` (обёртка), `d1lib` (формы), `bpyx` (API 5.2), `d2lib` (свет), `presets` (экспорт E) — ни одного
   имени API по памяти; каждый блок рецепта исполнен в напечатанном виде (§4) [проверено: K/01 — 11 из 11 рецептов].
6. **Проверки кодом ловят реальные ошибки композиции**: `rk.asserts` поймал гальку, свисающую с подставки на 13 мм (рецепт 09), и
   ложный габарит ленты шире цоколя (рецепт 04) — утверждения писать по опорной детали [проверено].
7. **Сначала разрешение, потом кадр**; кадр — по габариту (`rk.camera`), у объекта с одними GN-инстансами габарит пуст — прокси
   (рецепт 10) [проверено].
8. **Экспорт — только пресетом E по коллекции `ASSET_*`**; `optimize --flatten false --join false`, если части адресуются из JS;
   для AR — отдельный несжатый GLB (рецепт 12) [проверено].
9. **Страница — не с нуля**: hero-lazy F1 (`window.HERO_CFG` — подмена ассета без пересборки), H/21 (скраб клипа), F2 shader-background,
   model-viewer; рецепты 06 и 09 — свои страницы по образцам F2 [проверено: K/02, K/04, K/05, K/07–K/10].
10. **Ворота** — `site_probe.py` + `gate_check()` F1 (копия — `99-raw/experiments/K/02-hero-page/gates.py`): LCP-элемент не canvas,
    TBT, вес, вызовы, DPR, reduce → 0 вызовов в покое; рецепты 01 и 06 прошли 24/24 и 15/15 [проверено].
11. **Смотреть глазами одну картинку на прогон** (постер/лист) и честно писать слабое место — оно есть почти в каждом рецепте (§5).
12. **Время агента**: рецепт исполняется за 0,3–18 с Blender (+ 12–56 с кодирования у 02 и 08), правок кода — 0–2 на рецепт (§5).

## 4. Как запускать

```bash
# bash — [проверено] все рецепты: блоки python → examples/<slug>/build.py → Blender → валидатор + three
python3 ../../scripts/3d/run_recipes.py 12-recipes/0[1-9]-*.md 12-recipes/1[0-2]-*.md
python3 ../../scripts/3d/blender_run.py 12-recipes/examples/01-hero-product/build.py      # один рецепт вручную
python3 ../../scripts/3d/web_view.py --page 12-recipes/examples/06-logo-3d-particles/index.html out/ --scroll 0,0.5,1
```

- Блоки ```python рецепта исполняются **в напечатанном виде, по порядку** в одном процессе Blender; блок с первой строкой
  `# run: system` — Python окружения скилла (Pillow, ffmpeg) после Blender; блок с `[не проверено]` в первой строке пропускается.
- Прогонщик пишет `examples/<slug>/build.py` (и `post.py`), `numbers.json`, `web/<name>/web_sheet.png`, итог — `$DDD_HOME/out/3d/run_recipes/result.json`.
- Через MCP (окно Blender): тот же код одним `execute_blender_code` (идемпотентный `build(P)` надёжнее кода частями, C1 `04 §5`);
  `sys.path` на `scripts/3d` — абсолютный. **`rk.reset()` в сцене человека не вызывать**: `bpyx.clear_scene()` удаляет все объекты сцены
  и сирот (I `../02-blender-workflow/` §3 п. 1) — там только своя коллекция (`D.fresh_collection`), своя сцена превью для камеры и
  рендера, `inspect_scene()` до и `keep_user_state()` после (I `02-blender-workflow/01 §2`, `04 §2`).
- Метки для JS (пустышки `hotspot_*`, extras) — имена по таблице I `02-blender-workflow/01 §8.1`, постобработка только
  `gltfpack -cc -kn -ke` (`rk.ship(optimize="gltfpack")`); у мешей рецептов 01/05 имена и extras пережили `optimize --flatten false
  --join false` (проверено по JSON GLB), пустышки этим прогоном не проверялись.

## Частые ошибки (сквозные, из прогонов)

| ошибка | где поймано | правило |
|---|---|---|
| аудит до камеры и вида | 01 | `rk.audit()` после `rk.camera` и `rk.neutral` |
| цикл серии затирает числа | 02 | `rk.reset(keep_numbers=i > 0)` |
| утверждение габарита по «не той» детали | 04, 09 | габарит опорной детали + отдельные правила (высота, касания) |
