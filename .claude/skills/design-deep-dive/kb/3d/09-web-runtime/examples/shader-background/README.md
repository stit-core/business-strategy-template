# shader-background — шейдерный фон героя без Blender (three r186, @paper-design/shaders 0.0.81)

Агент F2, волна 2, 23.09.2026. Эксперимент: `../../../99-raw/experiments/F2/04-shader-bg/` (`shots/fx_*.json`, `swatch_result.json`).
Одна страница, варианты `?v=`: `gradient` (по умолчанию: полноэкранный фрагментный шейдер, fbm-шум с деформацией домена,
4 цвета бренда, дизеринг), `ribbon` (как у Stripe: деформация и цвет в вершинном шейдере сетки 128×128), `paper`
(`ShaderMount` + `meshGradientFragmentShader` из библиотеки), `sdf` (raymarching 5 метаболов, smooth-min, 64 шага, по умолчанию
½ разрешения; `&res=1` — полное), `swatch` (проверка цвета uniform; `&cs=off` — без `#include <colorspace_fragment>`).
Общее: `NoToneMapping` (hex бренда = пиксель), DPR фона ≤ 1, `Timer` (r183+), цикл только при видимости героя, активной
вкладке и без reduce (иначе один кадр), CSS-градиент под canvas — запас без WebGL; текст и кнопка — HTML.

## Замеры (Chromium 153 headless, Iris Xe; bench — 120 кадров с `readPixels`, режим без vsync)

| Вариант | Холст | Вызовов/кадр | Мс/кадр (bench) | FPS без vsync | JS по сети | Заметки |
|---|---|---|---|---|---|---|

| `ribbon` (вершинный, MSAA) | 1440×900 | 1 | 2,34 | 533 | 361 КБ | 16,6 тыс. вершин × 4 fbm; на десктопном GPU не дешевле фрагментного |
| `paper` | **2880×1800** при CSS 1440×900 | 1 | — (свой контекст) | 1 073 | **119 КБ** | библиотека рендерит минимум при DPR 2 (`minPixelRatio = 2`, параметр конструктора); reduce (`speed` 0) → 0 вызовов |

Замеры на общей машине (6–9 агентов) шумят: bench одного варианта в разных прогонах 1,45–4,3 мс; сравнивать варианты
внутри одного прогона. Первая версия градиента (пороги масок выше медианы fbm ≈ 0,44, кубическое сглаживание value-noise)
дала «оранжевую кашу» с квадратными пятнами решётки: фиолетовый и голубой не проявлялись → пороги у медианы и квинтика.
