# hero-lazy — эталон hero-блока с 3D (three r186): постер → 3D после LCP

Собран из `99-raw/experiments/F1/02-hero-variants` (варианты и замеры) и A/07. Что показывает: постер из того же GLB (одинаковые
кадр и тонмаппинг) — LCP; three грузится после `load`, когда блок рядом с экраном и браузер простаивает; GLB одним запросом,
декодеры по `extensionsUsed`; телефону — лёгкий набор (WebP 512², без транскодера KTX2), десктопу — KTX2 ETC1S 1024²; кадр по
проекции вершин; `compileAsync`; кроссфейд на CSS; покачивание ±20° с периодом ≈ 16 с; кнопка паузы (WCAG 2.2.2); стоп цикла вне
экрана, в скрытой вкладке и при `prefers-reduced-motion: reduce` (0 вызовов в покое); прозрачный canvas — фон рисует CSS.

Файлы: `index.html` (разметка, CSS), `hero.js` (исходник модуля), `dist/` (бандл esbuild, чанки: three 153 КБ br), `assets/`:
`camera_512.glb` (WebP 512², meshopt, 564 КБ — телефон), `camera_1k.glb` (KTX2 ETC1S 1024², meshopt, 1,18 МБ — десктоп),
`decoders/basis/` (транскодер three@0.186.0 — только для KTX2), `poster.avif` (19,8 КБ) / `poster.webp` (25,4 КБ) 1024² с альфой;
`make_poster.py` — снимок постера из страницы (`index.html?poster`). Модель: Camera_01, Poly Haven, CC0. Всего без `.br` ≈ 3,3 МБ.

Сборка и проверка:
```bash
# esbuild 0.28 + three 0.186.0 (npm в своей папке) — [проверено: этот README]
NODE_PATH=$DDD_HOME/node/node_modules npx esbuild hero.js --bundle --format=esm --splitting --minify --outdir=dist --legal-comments=none
python3 make_poster.py                      # постер из того же GLB и той же пары тонмаппинга
# замер: сервер с brotli (../../scripts/3d/serve_br.py) + ../../scripts/3d/site_probe.py URL OUT [--mobile --throttle | --reduced-motion] --quick
```

Выводы: (1) LCP — постер, 3D его не трогает (52 / 460 мс); (2) TBT на эмуляции телефона 255–290 мс — в пороге «≤ 300 мс от 3D»
(A `02 §3.1`); (3) первый 3D-кадр на медленном 4G 5,2 с — на границе бюджета A «≤ 5 с»; KTX2 для телефона при текстурах 512²
не окупается (транскодер 204 КБ br на медленной сети — +1,9 с), выигрыш KTX2 — память и CPU при 1k+ (`06` §3); (4) reduce — ноль
вызовов и ноль движения в покое; (5) 0 ошибок консоли во всех режимах. [проверено]

Ворота `gate_check()` (`05` §7.2, прогон `99-raw/experiments/F1/06-doc-snippets`): 23 из 24 проверок OK; **не прошла одна — TBT
десктопа 175 мс при пороге 150** (вклад KTX2 и транскодера, не three: тот же бандл с ассетом без текстур — 79 мс, K/02; телефон 280 мс ≤ 300 — прошёл). Кандидаты на снижение: без
`compileAsync`-синхронной части не обойтись (F1/02), остаются разбиение загрузки на кадры и меньший чанк three (именованные импорты).
Стекло объектива (transmission) при прозрачном canvas не видит CSS-фон — у тёмной линзы незаметно, у прозрачного стекла нужен фон в
canvas (`01` §6.3).

Не проверено: реальные телефоны (Safari iOS без `requestIdleCallback` — работает запасной `setTimeout`), потеря контекста WebGL,
клавиатурный проход (кнопка паузы — нативный `<button>`, фокус виден: `outline 3px` + белый ореол).
