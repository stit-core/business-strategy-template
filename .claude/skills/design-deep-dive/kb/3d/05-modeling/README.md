## Выжимка папки

1. Паспорт до кода: метры реального предмета, опорная деталь, отношения, бюджет; координаты деталей — от габаритов опоры, зазоры ≤ 1 мм утверждением, мелкие детали врастают на 30–40 % (01 §1).
2. Три уровня формы и зоны отдыха; деталь ≥ 4 px в целевом размере (01 §2).
3. Каждое видимое ребро — фаска 1–3 %; дёшево — 1 сегмент + острые рёбра данными (×2 треуг.), качество — 3 сегм. + harden + WN (×4); фаска без harden/WN даёт полосы (01 §3, D1/01).
4. Мягкие формы — кольца контура по профилю кромки (`rounded_slab`, `power` 2,4–2,6, суперэллипс), профили — гладкими кривыми (01 §4, 02 §3).
5. Выразительность абстракции — лента с закрутом/сужением (`sweep`), блоб — SDF с fillet и Mean (01 §5, 03 §4).
6. Модификаторы — с явными значениями через `bpyx.add_modifier`; для веба применять (`export_apply`); `bmesh.ops.bevel` по умолчанию скашивает вершины (02).
7. Булевы — EXACT + очистка для статичного hard-surface; плоские вырезы — контуром с отверстиями + сварка; деформируемое — без булевых (05 §3).
8. Повторы — GN-инстансы без Realize → `EXT_mesh_gpu_instancing`; точки для частиц — ровно N своей выборкой, Float32 (x, z, −y) (03).
9. Двигающаяся часть — отдельный объект с pivot на оси; экран мокапа — отдельный меш с UV 0–1 (04 §1–2).
10. Проверять кодом (габарит, зазоры, иерархия, сырые рёбра, неманифолд, вершины glTF, `preflight()` E) и одной картинкой (глянец/глина 3/4); архетипы D1 — 0,2–27 тыс. треуг., 19–600 КБ (05 §7–8).
