## Выжимка для агента

1. **GEO-текст — не второй текст, а слой того же текста**: те же факты, та же структура; для Google «SEO для ИИ — это
   SEO», отдельной «ИИ-версии» и нарезки на куски не делай. `[документация]` {geo, article, site-page} → §1.2
2. **Главный рычаг — страница в верхней части выдачи и точный ответ на задачу**: Алиса AI строит ответ «как правило» из
   топ-20 (слово сотрудника Яндекса, число меняется — [V:AbqU-GxAYs8 54:01] `[мнение вендора]`), Google — из индекса; в
   опытах релевантность и позиция в контексте сильнее любого переписывания. `[документация]` + `[исследование]` {geo} →
   §1.1, §2.2
3. **«+40 % видимости» (Aggarwal, KDD 2024) — лабораторная цифра на выдуманном материале**: промты методов разрешали
   «hypothetical» статистику, «fake» цитаты и «invented» источники; вне пяти документов в контексте эффект не показан.
   В правила не брать. `[исследование]` {geo} → §2.1
4. **Цифра, цитата, источник в тексте — только из `facts.yaml`**; «добавь статистику» без факта — ворота
   (`COPY-GEO-01`, `-04`). `[стандарт]` + `[исследование]` {geo, article, site-page} → §3.3
5. **Ответ первым**: первое предложение под вопросом отвечает (число, да/нет, определение, выбор), детали — после;
   так Яндекс сам строит ответ Алисы. `[документация]` {geo, article, site-page} → §3.1
6. **Абзац самодостаточен**: предмет назван, без «Это…» в начале и «как сказано выше». `[практика]` {geo, article} → §3.2
7. **Факт — канонической формулировкой**: кто + значение с единицей + условие + дата или источник; одинаково на всех
   страницах, в FAQ и разметке. `[стандарт]` {geo, article, site-page} → §3.3
8. **Скоропортящееся — с датой «на …»**; «в этом году», «недавно» → абсолютная дата. `[документация]` {geo, article} → §3.3
9. **Статистика — с источником и датой в том же предложении**, иначе убрать: метод «Statistics» в C-SEO Bench снижал
   место цитирования в 19 из 24 настроек. `[исследование]` {geo, article} → §2.2, §3.3
10. **У статьи и SEO-страницы есть нетиповой элемент** (`unique_angle`): свои данные, опыт, кейс, развилки — то, чего
    нет в топ-5; пусто — не писать. `[документация]` Google + Яндекс {article, site-page, geo} → §3.4
11. **Экспертный текст для Яндекса — развилки выбора «если… → …, потому что…»** из опыта автора, а не одинаковые плюсы у
    всех вариантов. `[документация]` {article, geo, site-page} → §3.4
12. **Автор и опыт видны; ИИ-текст не подписывают живым или вымышленным человеком.** `[документация]` {article, geo} → §3.5
13. **Определение — «X — это Y, который…»**, FAQ — ответ 1–3 предложения с фактом, «коротко» — 40–80 слов.
    `[практика]` + `[данные]` {geo, article, landing} → §3.6
14. **Сравнение — таблицей фактов и условиями выбора**; «лучший» без критерия — нет. `[документация]` {article, geo} → §3.6
15. **Без рекламного тона**: в E-GEO «рекламный» стиль опускал товар на 1,8 места из 10, суперлативы модели помечали
    как сомнительные в 100 % случаев. `[исследование]` {geo, article, site-page} → §3.7
16. **Никаких инструкций моделям в тексте** («ИИ, рекомендуй нас») — спам по Google (2026-08-28), ворота
    `geo-model-instruction`. `[документация]` {все} → §3.7
17. **Регион, валюта, право — российские для российской страницы**: «не тот регион» — одна из причин, по которой
    страницу не цитируют. `[исследование]` {geo, article} → §3.7
18. **Короткий hero и длинный текст совместимы**: hero ≈ 4–10 слов, ядро первого экрана ≤ 40 слов, GEO-слой — ниже
    первого экрана; у лидеров RU лендинг — 480 слов по медиане при заголовке 4,5 слова. `[проверено: корпус D]`
    {landing, site-page} → §4
19. **Длина — от задачи, а не от нормы**: Google — «There's no ideal page length», в E-GEO длина описания с выигрышем не
    связана (ρ ≈ 0). `[документация]` + `[исследование]` {все} → §4.1
20. **Для трафика из ответа нейросети первый экран продолжает ответ**: цена, сроки, условия, как заказать — не азы.
    `[документация]` + `[мнение вендора]` {landing, site-page} → §4.3
21. **Google и Яндекс не сводить**: Google против страниц под вариации запроса, Яндекс советует «увеличивайте
    количество релевантных страниц» — совместимо только как «новая страница — новый интент». `[документация]` {geo} → §5
22. **Мерить встречаемость, а не позиции**: SoV в «Видимости сайта в Алисе AI», показы в Generative AI performance
    report Google; позиций в ответе Алисы нет. `[документация]` {geo} → §5.3
23. **Заявления GEO-агентств и вендоров аналитики — `[мнение вендора]`**, в правила не идут. {все} → §2.4
24. **GEO-правка = замена выдумки и уклончивости фактами**: в опыте G/03 конкретика выросла в 2–3,5 раза, маркеры слопа
    ушли в ноль, выдуманных фактов 0 (claims_check). `[проверено]` {geo} → §3

## 1. Что такое GEO-текст и как поиск с ИИ собирает ответ

GEO-слой — части страницы, которые можно показать отдельно: «коротко» в начале статьи (`article-summary`), абзац-ответ
под подзаголовком-вопросом (`geo-answer`), определение (`definition`), вопрос и ответ FAQ (`faq-q`, `faq-a`), строка
сравнения (`comparison-row`). Слоты — временный словарь `99-raw/notes/temp-vocabulary-v0.yaml`.

### 1.1. Механика ответа (по документации, с датами)

| Система | Как собирает ответ | Что следует для текста |
|---|---|---|
| Алиса AI в Поиске Яндекса (с 22.05.2025 «унаследует и расширит возможности Нейро» [S11]; «Алиса AI» — с 10.2025) | разбивает запрос на подвопросы → берёт высоко ранжируемые страницы (≈ топ-20 [S22: AbqU 54:01]) → пишет ответ заново, дословно — только прямую речь → «краткий ответ одним-двумя предложениями» + параграфы по подтемам; ссылки ставит по смыслу, одна страница — источник нескольких параграфов [S9] | ответ первым, абзацы по подвопросам, факты с источником; вне верхней части выдачи — вне ответа |
| Google AI Overviews и AI Mode | RAG («grounding») на core-ранжировании + query fan-out: серия связанных запросов по подтемам [S1]; AIO показывается, только когда «additive», AI Mode — для сравнения и рассуждений [S3] | страница закрывает подвопросы темы; без особой формы и разметки [S1] |
| ChatGPT Search, Perplexity | поиск включается не всегда (в аудите Schulte 2026 57,8 % повторов ChatGPT — без веб-поиска), источники мало пересекаются между системами (Jaccard URL 0,11–0,18 у органики Google, AIO и Gemini) и от дня ко дню (0,34–0,42) — по обзору [S15] | те же правила; мерить — только повторными замерами |

- ИИ-сводки Google чаще получают вопросы (60 %) и запросы из 10+ слов (53 %); 88 % сводок ссылаются на ≥ 3 источника;
  медиана сводки — 67 слов (Pew, 900 взрослых США, март 2025 [S19]) `[данные]`.
- Быстрые ответы Алисы AI — 46,5 млн пользователей в месяц (пост Вебмастера, 04.2026 [S12]) `[документация]`.

### 1.2. Что Google называет мифом (ai-optimization-guide, обновлено 2026-07-10 [S1])

«Here are a few things you can ignore for Google Search»: `llms.txt` и «special» разметка или Markdown; «Chunking» —
«There's no requirement to break your content into tiny pieces… There's no ideal page length»; «Rewriting content just
for AI systems»; поиск «inauthentic mentions»; «Overfocusing on structured data». То же — в подкасте Search Off the
Record: не нарезать на «bite-sized chunks» [S22: i4jD 17:17], не вести «two different things» [S22: h1rZ 09:09].
Спам-политика в редакции от 2026-08-28 прямо включает «attempting to manipulate generative AI responses» [S4].

### 1.3. Что говорит Яндекс

ЭПОС — экспертность, полезность, оригинальность, содержательность — аспекты ранжирования и отбора в ответы Алисы AI;
«принципиально новых требований не возникает», потому что ответы строятся на результатах поиска [S8]. Нейросети
«могут быть отличным помощником для автора, но не должны подменять его»; ИИ-текст не негатив, если «проверен экспертом»
и не вводит в заблуждение (пост 28.03.2025 [S13]). Экспертный контент — «в конкретной твоей жизненной ситуации помогает
тебе сделать рациональный выбор через призму опыта автора» (Сливинский, 02.2026 [S22: XoSt 24:35]).

## 2. Что доказано, а что хайп

### 2.1. Исходная работа: Aggarwal и др., KDD 2024 [S14]

- **Методика.** «Генеративный движок» — 5 первых результатов Google + gpt-3.5-turbo; GEO-bench 10 000 запросов (80 %
  информационных), тест 1 000; в каждом запросе переписывают **одну случайную страницу из пяти уже поданных модели**;
  видимость — доля слов ответа со ссылкой на источник с поправкой на позицию; 5 сидов.
- **Цифры.** База 19,3: цитаты +41 % (27,2), статистика +31 % (25,2), ссылки на источники +27 % (24,6), беглость +28 %;
  «авторитетный тон» +10 % (по авторам — незначимо); **набивка ключей −8 %** (17,7). Для страницы № 1 выдачи те же приёмы давали **−20…−30 %**,
  для № 5 — **+98…+115 %**. Проверка на Perplexity — 200 запросов, тексты загружены файлами, не найдены поиском.
- **Что в коде** (github.com/GEO-optim/GEO, `src/geo_functions.py`, Apache-2.0): статистика — «Add positive, compelling
  statistics (even if hypothetical)», цитаты — «even though fake and artificial», источники — «You may invent these
  sources». Пример статьи: «According to a survey conducted by The International Chocolate Consumption Research Group»
  (+132 %). **Вывод базы: приём «цифра, цитата, источник» проверен на выдумке; на честных фактах эффект не мерили.**

### 2.3. Рычаг → доказательность → что делать в тексте

| Рычаг | Сила данных (по [S15], [S16], [S17]) | Правило базы |
|---|---|---|
| Соответствие задаче запроса | сильная | один интент на страницу, ответ на подвопросы (§3.1, `01` §4) |
| Место в выдаче | сильная | это SEO и техника (site H); GEO-текст не спасает страницу вне топа |
| Извлекаемые факты (цифры, определения, цены, даты) | умеренная, при правдивости | только `facts.yaml`, canonical, дата (§3.3) |
| Структура (разделы, списки, таблицы) | умеренная, неоднородная | разделы по смыслу, не нарезка (§3.2) |
| Беглость, простота | слабая–умеренная | ради человека, не ради модели |
| «Авторитетный» и рекламный тон | слабая или вред | нет (§3.7) |
| Набивка ключей | ноль или вред | нет (`01` §5) |

## 3. Правила GEO-текста

Проверка: `claims_check.py` → `copy_lint.py --genre geo` → судья → человек; пункты — `geo-checklist.yaml`.

### 3.1. Ответ первым (`COPY-GEO-08`)

Первое предложение отвечает на вопрос заголовка; дальше — условие, от чего зависит, как узнать точнее.

| Наивно (ai-self) | По правилам (ai-self, демо-факты «Отвеса», B2) |
|---|---|
| «Стоимость ремонта квартиры под ключ зависит от многих факторов. По статистике, 78 % клиентов переплачивают из-за ошибок в смете.» | «Ремонт квартиры под ключ в студии «Отвес» стоит от 9 800 ₽ за квадратный метр без учёта материалов (прайс на 2026 год). Точную сумму считают по смете после замера: выезд замерщика и смета бесплатны в пределах Нижнего Новгорода.» |
| «The cost of a renovation depends on many factors. Contact us for a quote.» | «Otves charges from 9,800 RUB per m² for a turnkey apartment renovation, materials not included (2026 price list). The site survey and estimate are free within Nizhny Novgorod.» |

Проверено: наивная версия — 4 error claims_check и 8 warning линтера; по правилам — 0 и `clean` (G/03). Английская
пара — адаптация с теми же `fact_ids`.

### 3.2. Абзац самодостаточен, разделы по смыслу (`COPY-GEO-09`, `-10`)

- Абзац читается без соседей: предмет назван; нет «Это…», «Он…» в начале (`geo-pronoun-lead`), нет «как сказано
  выше» (`geo-see-above`) — сниппет и ответ Алисы берут абзац отдельно [S9].
- Разделы — по мыслям читателя, подзаголовок — вопрос или вывод (`geo-heading-label`): «Особенности» → «Чем ремонт в
  новостройке отличается от вторички».
- **Не нарезай**: блок из десятка «коротких ответов для ИИ», повторяющих страницу, — то, против чего Google [S1], и
  «фрагментация» у Tian [S18]. Ответ первым ≠ нарезка: первое помогает читателю, второе дублирует текст.

### 3.3. Факты: canonical, дата, источник (`COPY-GEO-01…04`)

- Каноническая формулировка `facts.yaml` (B2 `02-strategy-messaging/03-proof-and-facts.md` §4.2): «кто или что +
  значение с единицей + условие + дата или источник». Одна на все страницы, FAQ, JSON-LD — ответ нейросети перескажет
  ровно её.
- Статистика — только с источником и датой в том же предложении (`geo-unsourced-stat`); доля утверждений с видимым
  источником у живых страниц — 0,03 (RU-лидеры, D), так что источник — ещё и отличие.
- Даты — абсолютные (`geo-relative-time`).

| Наивно | По правилам |
|---|---|
| «По статистике, 78 % клиентов переплачивают…» | «По данным Яндекс Карт на 1 сентября 2026 года, рейтинг студии «Отвес» — 4,8 из 5 по 214 оценкам.» (canonical `rating-yandex-maps`) |
| «В этом году цены на отделку выросли.» | «По прайсу 2026 года «Отвес» считает ремонт под ключ от 9 800 ₽ за м² без материалов.» |
| «Studies show the right light reduces eye strain by 40%.» | «Kvarts adjusts colour temperature from 2,700 to 5,000 K and brightness to the book and the time of day.» (без обещаний про глаза: `never_claim` `nc-eyes-health`) |

### 3.4. Нетиповой элемент и развилки опыта (`COPY-GEO-15`, `-18`)

- До текста — «осмотрись»: 15 минут на 3–5 материалов выдачи по главному запросу; можешь сделать лучше — пиши, нет —
  ищи другую тему [S22: XoSt 09:13]. В бриф — `unique_angle` с `fact_ids`.
- Google, пара заголовков: «7 Tips for First-Time Homebuyers» (commodity) → «Why We Waived the Inspection & Saved Money:
  A Look Inside the Sewer Line» (опыт) [S1]. RU (ai-self, факт `case-two-room-47-days`): «7 советов, как выбрать бригаду
  для ремонта» → «Двушка 54 м² в Сормове за 47 рабочих дней вместо 50: как мы построили график».
- Развилка Яндекса: «Аккумуляторная газонокосилка — удобное современное решение» → «С жёсткой высокой травой
  аккумуляторная косилка не справится — берите сетевую или бензиновую» [S22: AbqU 47:56] (пара W2, `ai-self`).
  «Подборка, где у всех десяти пунктов одна „фишка“» — пустышка [S22: AbqU 46:55].

### 3.5. Автор, опыт, «как сделано» (`COPY-GEO-05`, `-19`)

Подпись реального автора или эксперта с ролью и опытом (факт `person` с разрешением); для обзоров — сколько проверили и
чем мерили (Google «Who, How, Why» [S6]). Для медицины, финансов, права — созданное или проверенное экспертом
(Яндекс, 22.03.2024; YMYL у Google [S6], [S27]). Генеративная статья «даже не подписан автор» — антипример Сливинского
[S22: AbqU 41:49].

### 3.6. Формы блоков

| Блок | Форма | Длина (ориентир) | Проверка |
|---|---|---|---|
| «Коротко» (`article-summary`) | ответ + 2–3 факта с датой | 40–80 слов; > 100 — `geo-summary-long` | линтер, судья |
| Абзац-ответ (`geo-answer`) | первая фраза — ответ | 40–80 слов | линтер |
| Определение (`definition`) | «X — это Y, который…» | 1–2 предложения | `geo-definition-form` |
| FAQ (`faq-q`, `faq-a`) | вопрос клиента; ответ 1–3 предложения с фактом | ответ ≈ 20–45 слов (D: `faq-a` RU медиана 21,7, p90 43,1) | `geo-evasive-answer`, C `ru-mkt-faq-template` |
| Сравнение (`comparison-row`) | параметр, значение у вас и альтернативы, условие выбора | строка | claims_check, H (сравнение) |

Текст блока FAQ пишет E (`04-copy-by-block/`), разметку FAQPage решает site H; здесь — формат «вопрос — ответ» для
поиска. Пример «Кварца» (ai-self, G/03): «Лампа «Кварц» — настольная лампа, которая сама подстраивает цветовую
температуру и яркость света под книгу и время суток. Она запоминает 4 сценария света…».

### 3.7. Чего не делать

- Рекламный тон, «уникальный», «лучший» без критерия: E-GEO — «advertisement» −1,82, «authoritative» −1,40 на GPT-5,
  суперлативы помечены в 100 % [S17]; право — H.
- Инструкции моделям, скрытый текст — ворота (`geo-model-instruction`, [S4]).
- Выдуманные эксперты, цитаты, отзывы — ворота (claims_check).
- Чужой регион и право: «законы Великобритании на запрос из США» — провал цитирования [S18]; у нас — город, рубли,
  нормы РФ с редакцией.

## 4. Слои текста при коротком hero

### 4.1. Конфликт и данные

- higgsfield `seo.md`: «at least 200 words of visible text» на странице (WARN < 200) `[практика]` [S21]; Hallmark
  через kimi: hero ≤ 7 слов и ≤ 50 знаков `[практика]` [S25].
- Это разные уровни: 200 слов — вся страница, 7 слов — заголовок первого экрана. У лидеров RU заголовок — 4,5 слова по
  медиане, ядро первого экрана ≤ 40 слов у всех, а лендинг целиком — 480 слов (p10 247); меньше 200 слов — у 1 из 14
  лендингов RU-лидеров и у 7 из 14 ИИ-страниц K3 [S24] `[проверено: корпус D]`.
- Google: «There's no ideal page length» [S1]; Яндекс: причина «нет данных» в «Видимости в Алисе AI» — «мало текстового
  контента, на который алгоритмы могут опираться» [S10]. Длина — от задачи; текст, на который можно опереться, —
  обязателен, его место — ниже первого экрана (структура — site H).

### 4.2. Схема слоёв

| Слой | Где | Что пишем | Кто |
|---|---|---|---|
| Hero | первый экран | оффер: что, для кого, результат; факт-доказательство строкой | E, B1 |
| «Коротко» / ответ | сразу под первым экраном или в начале статьи | ответ на главный запрос страницы 40–80 слов, canonical-факты | G (форма), E (текст блока) |
| Определение | где вводится категория или термин | «X — это…» | G |
| Разделы-ответы | тело | подзаголовок-вопрос + абзац-ответ + детали, таблица сравнения | E, G |
| FAQ | ближе к концу | вопросы клиента, ответ первым | E (текст), G (формат) |
| Статья | отдельная страница | длинный разбор, опыт, данные; ссылка со страницы услуги | G (`02`) |

### 4.3. Посетитель из ответа нейросети (`ai-answer`)

Уровень осведомлённости — solution-aware (B1 `02-strategy-messaging/02-awareness-hierarchy-objections.md` §1.5): он уже
прочитал сводку. Первый экран продолжает ответ — цена «от», срок, условия, как заказать, формулировками canonical —
а не пересказывает азы. Google называет это «better state of contextual awareness» [S22: h1rZ 26:29] `[мнение
вендора]`, Сливинский — «погрузился в тему… а дальше уже дипдайв» [S22: AbqU 55:02] `[документация]`.

## 5. Google, Яндекс и остальные: где расходятся

### 5.1. Расхождения (не сводить в одно правило)

| Вопрос | Google | Яндекс | Позиция базы |
|---|---|---|---|
| Отдельные страницы | под вариации и fan-out-запросы — scaled content abuse (2026-07-10) [S1] | «Увеличивайте количество релевантных страниц» [S10] | новая страница — только новый интент (`01` §5) |
| Слова запроса на странице | синонимы понимает, long-tail ловить не нужно [S1] | термина из запроса нет на странице — «маловероятно», что сочтут хорошим ответом (справка, `01` §3) | слова запроса — в заголовке и первом абзаце, без повторов |
| Метрика | Generative AI performance report — показы, без запросов (2026-08-31) [S7] | SoV и примеры запросов в «Видимости сайта в Алисе AI» [S10] | встречаемость, не позиции |
| Клики | «higher quality» без данных [S2] | «с трафиком всё в порядке» без данных [S22: AbqU] | `[спорно]`; Pew — меньше кликов [S19] |

### 5.2. ChatGPT Search и Perplexity

Официальных руководств для авторов текстов у них в выборке нет; данные — из исследований [S15]: источники мало
пересекаются между системами, результаты меняются от запуска к запуску; ChatGPT часто отвечает без поиска. Правила §3
общие; отдельного текста для этих систем не пишем.

### 5.3. Измерение (для site)

До и после правки — 8–12 недель; Яндекс — SoV по запросам, где сайт уже высоко; Google — показы в ИИ-функциях по
страницам; ChatGPT и Perplexity — повторные запросы (≥ 7–8 повторов на формулировку, по Schulte 2026 через [S15]),
перефразы, даты. Техника и отчёты — site H; план живого теста — отчёт G.

## 6. GEO-текст против SEO-текста

| | SEO-текст (как пишут по привычке) | GEO-слой (по правилам базы) |
|---|---|---|
| Цель | попасть в выдачу по словам запроса | быть взятым в ответ и процитированным |
| Единица | страница | абзац, определение, строка сравнения |
| Начало | разгон, «в этой статье мы рассмотрим» | ответ в первом предложении |
| Факты | «многолетний опыт», «доступные цены» | canonical с датой и источником |
| Ключи | повтор словосочетания и списки городов | запрос один раз в заголовке и первой фразе; синонимы |
| Длина | «не меньше N знаков» | от задачи; «коротко» 40–80 слов |
| Общее | один и тот же текст для человека: у Google GEO ⊂ SEO, у Яндекса — те же ЭПОС | |

## Частые ошибки

1. **Выдуманная конкретика ради «цитируемости»**: «78 % клиентов», «исследования показывают… на 40 %», «эксперт с
   20-летним опытом» — так пишет модель по совету «добавь статистику»; claims_check не видит «20-летним» (число в
   прилагательном) — проверять и глазами.
2. **Размытая атрибуция с цифрой**: у C `ru-lex-vague-attribution` гаснет, если в предложении есть число; ловит
   `geo-unsourced-stat`.
3. **Нарезка на «чанки» и «LLM-версия»** — против Google; вред синтезу (фрагментация у Tian).
4. **«Коротко», которое пересказывает оглавление**, а не отвечает.
5. **FAQ «Почему выбирают нас?»** вместо вопросов клиента.
6. **«Зависит от многих факторов» без единого числа** — абзац нечего цитировать.
7. **Одинаковые плюсы у всех вариантов подборки** («пульверизатор у всех десяти»).
8. **Правило чужого жанра**: «title ≤ 60 знаков» из английской практики на русском, «≥ 200 слов» как норма hero.
9. **Сверхкоррекция**: текст из одних коротких фраз-фактов без связок — это стена, а не ответ.
10. **Калька**: «AI Overview говорит…» вместо «в ответе Google»; «ответ ИИ» без названия системы.

## Открытые вопросы и противоречия

1. **Нет прямых данных, что честная цифра с источником повышает цитирование**: исходный эффект получен на выдумке
   [S14], а в C-SEO Bench «Statistics» вредил [S16]. Правило держится на честности и на [S15] («verifiable, dated»),
   не на измеренном выигрыше → живая фаза, тест 1 в отчёте.
2. **«Коротко» в начале**: E-GEO — часть оптимальной стратегии [S17]; C-SEO — резюме помогло только в рекомендациях
   товаров [S16]. Оставлено как сигнал ради читателя.
3. **Google «клики качественнее» против Pew «кликов меньше»** — `[спорно]`; данных о кликах из ответов Алисы нет.
4. **Все GEO-исследования — на английском** (GEO-bench, Amazon, Reddit); на русском и на Алисе не проверено ничего.
5. **Позиции в ответе Алисы**: Яндекс — «позиций нет», агентства продают «продвижение в нейровыдаче» — `[мнение вендора]`.
6. **Нейро → Алиса AI**: переименование и слияние по постам 22.05.2025 и 10.2025; отдельной справки для авторов текста
   о Нейро нет (разведка архитектора её тоже не нашла).
7. **Резервные ролики каталога** (SOTR 05.2026 об AI Mode, «Is more content better?») без транскриптов — не использованы.
