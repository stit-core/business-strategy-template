## Выжимка

1. План проверяй блоком SITE-PRE до сборки: непройденный B — не собирать.
2. Серьёзность — по маршруту «визит → действие»: B — действие не выполняется, закон, обман; S — трение и исход хуже профиля.
3. ux-чек-лист на сайте — только через `ux-marketing-profile.tsv`: как есть он даёт 87 % ложных срабатываний.
4. Шаблон генератора ловится порядком секций и связкой доказательств с `fact:`, а не словарём.
5. Ворота — своими замерами (`page_gates.py`), не по отчёту исполнителя; исходы — с троттлингом, вес — отдельно, CLS — прокруткой.
6. Контраст — B только у H1, лида, призыва и согласия (axe с адресами узлов); H1 первого экрана — без появления из `opacity: 0`.
7. Автопроверке структуры верь при уверенности ≥ 0,5; B из DOM и SCR подтверждай кадром или сырым HTML.
8. Судья — последним из автоматики, другой семьи, 11 прогонов для решения; профиль из 8 осей, без общего балла.
9. Быстрый набор (§7 файла 02) — для итераций; выдача и публикация — только полной проверкой.
10. Все три демо генераторов K/03 не прошли ворота: умолчания генератора — предмет проверки, а не образец.
