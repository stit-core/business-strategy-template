## Выжимка

1. Нормы движения приложений (ui, ux) на сайте — умолчание L0; подачу ведут классы `one-shot` / `scroll-linked` / `loop` / `pointer` / `transition`.
2. WCAG 2.2.2 — три условия сразу: разовое появление короче 5 с под него не попадает, петля — попадает; одна пауза на все петли.
3. Reduce, not remove: самопроизвольное и пространственное — убрать, смысл, прозрачность, цвет — оставить; проверять записью всей страницы.
4. Бюджет внимания: непрерывных движений в зоне L0 ≤ 1, L1 ≤ 2, L2 ≤ 3, ни одного под читаемым текстом; «дыхание» ≤ 2,5 % пикселей/с.
5. Колебания крупных объектов — период ≥ 10 с; 2,5–6 с (0,17–0,4 Гц) — пик укачивания (Diels 2013, Golding 2001, Apple).
6. Страница — ритм: пики через покой, «вау» ≤ 4 на 12 экранов, первый пик в первых 2–3 экранах, конверсия спокойна.
7. Появление — система из 2–3 примитивов, один раз, 8–24 px, 400–700 мс; контент видим без JS.
8. LCP-заголовок — без анимации или только `transform`: из `opacity: 0`, за маской строк или скриптом он выпадает из LCP в Chromium (E/01).
9. CSS scroll-driven — для DOM-эффектов под полной проверкой `@supports` (Chrome 115+, Safari 26+, Firefox 159+; старые версии — конечное
   состояние); GSAP — только для того, чего CSS не делает: закреплённая сцена со сложным сюжетом, синхрон с canvas и WebGL, Flip;
   Lenis — только L2.
10. Переходы страниц — прогрессивное улучшение (VT MPA: Chrome 126+, Safari 18.2+), 300–500 мс, навигация ≤ 4 с; прелоадер — только L2-кампания.
