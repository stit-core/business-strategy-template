## Выжимка для агента

1. **Раздел 0 читать первым**: станция, ворота, craft, роль, уровень, профиль, якорь, хвост имеют в базе по два-четыре смысла; в
   новых файлах — выбранное там определение. `[практика]` → §0
2. **Числа 1 / 2 / 3 — три разные величины**: петли в видимой зоне (бюджет внимания), насыщенные приёмы на страницу (доза клише),
   пики и акценты (счёт I); одно вместо другого не подставлять. `[практика]` → §0; X-19, X-20
3. **SDA — только CSS или WAAPI с `animation-timeline`**; сцена ScrollTrigger — «движение по прокрутке», не SDA. `[практика]` →
   §0; X-01
4. **Перехват прокрутки — любое изменение скорости или направления, включая виртуальную прокрутку**; pin со скрабом — не перехват.
   `[практика]` → §0; X-15
5. **Переход между страницами — `effect:page-transition`** (нативный — L1, библиотеки — L2); внутри страницы —
   `effect:view-transition`. `[практика]` → §0; X-21, X-62
6. **craft рубрики K — меньшая из двух подоценок**: типографика и композиция и — при 3D, видео или фото-hero — «ремесло медиа»
   (свет, материал, фактура, атмосфера); craft пар J и J2 — только второе. `[не проверено: калибровка]` → §0; X-63
7. **`effect_role` ≠ `visual_role` ≠ `section_role`**: роль эффекта, роль секции в ритме, вопрос посетителя (site). `[практика]` →
   §0; X-54
8. **Id не переводить**: `effect:<id>`, `cliche:<id>`, `block:<id>`, `EG-…`, `MKT-…` — латиницей, как в YAML; термин — по-русски с
   английским оригиналом при первом упоминании. `[практика]` → `README.md` «Как пользоваться»
9. **Число в определении — ориентир, канон — машиночитаемый файл** (`ambition-levels.yaml`, `marketing-tokens.json`,
   `effects.yaml`, `effect-gates.yaml`); при расхождении действует `CONTRADICTIONS.md`. `[практика]` → `README.md`

## Частые ошибки

- Бюджет внимания (петли в кадре) путают с дозой клише (насыщенные приёмы на страницу): у обоих L0 1, L1 2, L2 3 (§0).
- Сцену ScrollTrigger называют SDA и ставят ей `@supports`-фолбэк CSS, которого у неё нет (§0, группа 6).
- Кросс-документный переход пишут `effect:view-transition` — это переход внутри страницы; между страницами —
  `effect:page-transition` (§0).
- craft из попарного сравнения J и J2 (свет и материал 3D) выдают за итоговый craft рубрики K — там он меньшая из двух подоценок
  (§0).
- «Ворота» без уточнения: ворота эффектов K, ворота страницы site и экран «Enter» — разные вещи (§0).
- Id эффекта или клише переводят на русский (`effect:бегущая-строка`) — ссылки перестают находиться.
