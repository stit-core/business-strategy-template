## Выжимка на 10 строк

1. Клише — приём, который никто не выбирал; реестр задаёт условия, `art-direction` сайта записывает решение (`cliche:<id>`).
2. Пять проверок: концепция одной фразой без слов-пустышек, цвет и материал из бренда, исполнение числом, статус эпохи, один главный приём на сцену.
3. `use` — все проверки пройдены; `twist` — насыщенный приём с названным поворотом; `avoid` — хватает одного провала.
4. Диагноз по кластеру: ≥ 3 записей одного кластера на сцене без решения — провал; доза насыщенных на страницу L0 ≤ 1, L1 ≤ 2, L2 ≤ 3.
5. Приём стареет по дороге «урок → копипаст-кит → умолчание генераторов» за 6–18 месяцев (Wayback, npm: lenis ×11, Paper Shaders ×233 в 2026).
6. Маркеры соседей (IMG-M05/M06, R3, BR-02, MAT-07, ui 1, 3, 15, 28–34) на сайте — умолчания L0, снимаются решением с проверкой.
7. Типичность и новизна работают вместе (MAYA): конвенции взаимодействия и скелет — типичные, визуал, движение и композиция — свои.
8. Модели сходятся к типичному (typicality bias, гомогенизация идей) — направления брать из хвоста, вести журнал 8 осей, ≥ 4 отличий между проектами.
9. Почерк K3 — «редакционный люкс» (капс-хром, моно, WebGL-центр, анимация раскладки); хром общий для LLM-вёрстки 2026 — мерить кластер, не модель.
10. Детекторы impeccable и Gesso — вход, не вердикт: на наградных сайтах они тоже срабатывают; решает порог кластера реестра.
