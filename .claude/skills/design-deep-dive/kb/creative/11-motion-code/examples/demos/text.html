Движение

Семейства text и number

Текст движется там, где его читают

Разбиение — разметкой заранее, подсветка — по прокрутке, счёт — CSS-счётчиком поверх итога в HTML. Доступный текст цел во всех режимах.

01 — Разбиение · split-text-reveal

Куски — строки, слова или буквы — размечены заранее; вся сцена вместе со стаггером ≤ 1000 мс. Не на LCP-заголовке.

Слова поднимаются из своих коробок

По строкам — для длинной фразы:каждая строка — своя маска,шаг 60 мс, кривая out-expo.

Кадр

По буквам — только короткие слова до 12 знаков: длинное кириллическое слово растягивает каскад.

02 — Подсветка слов · scroll-text-highlight

Одна шкала на абзац, диапазон слова — по его месту: sibling-index() или --i. Непрочитанное — цвет с контрастом ≥ 3 : 1, а не прозрачность.

Читатель видит, где он сейчас: слова загораются по мере чтения, а весь текст остаётся в HTML и находится поиском.

03 — Честный счётчик · counter-up

Итог — текст в HTML (без JS, при reduce, для поисковиков); при счёте цифры рисует CSS-счётчик поверх прозрачного текста. Один раз, 1200 мс.
