Движение

Семейства scroll и mask

Появление — система, а не fade на всём

Вход первого экрана — CSS на загрузке; ниже — три приёма по ролям, шкалы прокрутки на CSS и маски.

01 — Полоса прогресса · scroll-driven-progress

Под шапкой: scaleX по шкале прокрутки документа, 0 КБ JS. Это индикатор — остаётся и в reduce; без поддержки шкал полосы нет.

02 — Система появления · scroll-reveal-system

Маска — заголовкам, подъём — тексту и карточкам (каскад ≤ 600 мс), проявление с масштабом — фигурам, рисование — схемам. Один раз.

Заголовок поднимается из маски

Лид — подъём на 16 px; прозрачность короче сдвига. Карточки ниже — каскадом по месту в группе.

03 — Раскрытие маской · mask-reveal

Разово (шторка снизу и обратный масштаб 1,06 → 1) и по шкале самого кадра (scroll-mask). Кадр под маской — без loading="lazy".

04 — Параллакс слоёв · parallax-layers

Разница скоростей ≤ 40 % (здесь 22 / 10 / −6 %), без масштаба; текст едет со страницей; на телефоне — половина.

05 — Линия по прокрутке · svg-line-draw

pathLength="1" и stroke-dasharray: 1 — длина пути не считается в JS; шкала — у коробки SVG.

06 — Текст-окно · text-mask-media

background-clip: text; положение кадра — зарегистрированная переменная по шкале слова. Настоящий текст: выделяется и читается.

Глубина

07 — Кадр до вылета · scroll-mask-expand

inset(22% 30%) → 0 за 70 % пути
