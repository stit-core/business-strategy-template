# 02 · Примитивы: появление, прокрутка на CSS, петли, указатель, микродвижение, переходы, переключатель

Примитив — значение `data-mk` с готовым поведением, опциями и тихой версией. У каждого здесь: зачем, разметка,
опции, токены, reduce, телефон, цена, эффекты каталога (`../06-effects-catalog/effects.yaml`), нормы. Машинный список
с опциями — `primitives.yaml`; контракт и переменные — `01`; DOM-сцены (`scene`) — `03`. Демо каждого — страница
`examples/demos/<семейство>.html` с якорем `#<id эффекта>`. Цена приёма — замер лаборатории каталога (06/01, таблицы
разделов) для той же техники и прогоны набора на `demo.html` (долгие кадры прокрутки 0,29 %, CLS 0,0035, TBT 0 мс —
`motion_check.py`, L1) `[проверено]`.

## Выжимка для агента

1. **Система появления — три приёма по ролям**: маска (`unmask`, `split`) — display-заголовкам, подъём (`rise`) — тексту
   и карточкам, шторка (`sweep`) — кадрам; проявление с масштабом (`scale-in`) — фигурам; спокойные секции, формы и цены
   — без `data-mk`. Одинаковое появление на всех секциях — маркер 28. `[проверено]` → §1
2. **Характер — от свойств и кривых, а не от одного fade**: маска — сдвиг и обрезка одной кривой `out-expo` 800 мс;
   подъём — 16 px 560 мс, прозрачность 336 мс `out-strong`; шторка — clip-path 800 мс с обратным масштабом 1,06 → 1;
   проявление — масштаб 0,96 → 1, размытие 6 px → 0. `[проверено: CSSTransition]` → §1
3. **Разбиение и счёт — разметкой и CSS**: куски текста размечены заранее, доступный текст цел; цифры счётчика рисует
   CSS-счётчик поверх прозрачного итога. `[проверено]` → §1.4, §1.7
4. **Прокрутка на CSS** — `@supports ((animation-timeline: scroll()) and (animation-range: 0% 100%))`, шкалы с
   `view-timeline-inset: 0px`; без поддержки — конечное состояние, полосы прогресса нет. `[проверено: Chromium]` → §2
5. **Петли — только при JS**, стоят вне экрана, при наведении и фокусе, по паузе; скорость строки — 30–60 px/с, период
   дыхания ≥ 10 с, вращение 24 с. `[проверено: 40,0 px/с]` → §4
6. **Указатель — только мышь и перо**: магнит ≤ 8 px и ≤ 25 % высоты, наклон ≤ 7°, прожектор под текстом; сглаживание
   по времени, кадры — только пока догоняет. `[проверено: магнит 8 px, наклон 5,6°]` → §5
7. **Отклик интерфейса — чистый CSS**: окно с `@starting-style`, аккордеон с `interpolate-size`, подпись кнопки
   `clip-path`, переворот, блик, колонки; в reduce — затухание вместо смещения. `[проверено: Chromium]` → §6
8. **Переходы — прогрессивное улучшение**: смена состояния — `startViewTransition` с типом `mk-state`, страницы —
   `@view-transition` с типом `mk-page`; без поддержки — обычная смена. `[проверено: Chromium]` → §7

## 1. Появление: один раз

Общее у всех: скрытое состояние — только под `[data-mk-on="full"]`; срабатывает, когда коробка элемента входит в окно
без нижних 4 %; один раз; что пролетели — сразу в конечном состоянии; у дна страницы — добор всех оставшихся; в reduce,
«Меньше», без JS и в обзоре холста — конечное состояние сразу. Группа `[data-mk-stagger]` — один триггер и каскад
(`01` §4.3). Время по дорожкам — `01` §4.2.

### 1.1. `entrance` — вход первого экрана

- **Зачем**: один вход первого экрана — заголовок, лид, призыв по порядку (`hero-entrance-once`, L0).
- **Разметка**: `<h1 data-mk="entrance" data-mk-lcp>…</h1> <p data-mk="entrance" style="--i: 1">…</p>`.
- **Опции**: `--i` — порядок (задержка `i × stagger.group`), `data-mk-lcp` — элемент LCP (только сдвиг), `--mk-dur`,
  `--mk-ease`, `--mk-wait`, `--mk-shift`, дорожки `--mk-o-*`, `--mk-t-*`.
- **Токены**: `duration.reveal` 560, `easing.out-expo`, `easing.out-strong`, `distance.shift-reveal` 16 px,
  `stagger.group` 60; до пяти элементов — 4 × 60 + 560 = 800 мс ≤ `hero-scene` 900.
- **Reduce**: длительности и сдвиг токенов в reduce — 0: конечный кадр с первой отрисовки. **Телефон**: так же.
- **Без JS** — идёт (CSS-анимация с `fill-mode: both` кончается видимой). Нормы: 05/02 §10, 06/01 §4.1. `[проверено]`

### 1.2. `rise` — подъём (`fade-up`)

- **Зачем**: лиды, абзацы, карточки групп (`scroll-reveal-system`, L1).
- **Разметка**: `<p data-mk="rise">…</p>`; группа — `<div data-mk-stagger><article data-mk="rise">…</article>…</div>`.
- **Опции**: `--mk-dur`, `--mk-ease`, `--mk-wait`, `--mk-shift`, дорожки `--mk-o-*` (умолчание 0,6 × длительности,
  `out-strong`) и `--mk-t-*`; в группе `--i`, `--n`.
- **Состояния**: `opacity: .01` и `translate3d(0, 16px, 0)` → 1 и `none`; прозрачность от 0,01, а не 0 — элемент остаётся
  кандидатом LCP (05/02 §10).
- **Цена**: 0,7 КБ JS у лаборатории, главный поток 19,9 / 79,3 мс/с (десктоп / телефон ×4), CLS 0 (06/01 §4).
- **Reduce**: видно сразу, без сдвига. **Телефон**: так же. Нормы: 05/02 §2, 06/01 §4.2. `[проверено]`

### 1.3. `unmask` — маска (`type-unmask`)

- **Зачем**: display-заголовки секций — строка поднимается из своей коробки (`scroll-reveal-system`).
- **Разметка**: `<h2 data-mk="unmask">…</h2>` — не на LCP-заголовке.
- **Механика**: сдвиг `translateY(100%)` и `clip-path: inset(-.3em -.2em calc(100% + .3em) -.2em)` идут одной кривой —
  видимая граница стоит на месте, как маска строки; запас 0,3 em открывает выносные элементы букв к концу. Обёртки для
  маски не нужны. `[проверено: глазом, кадры motion_smoke]`
- **Опции**: `--mk-dur` (800 мс, `duration.split-line`), `--mk-ease` (`out-expo`), дорожки `--mk-t-*`, `--mk-c-*`.
- **Reduce**: блок на месте без маски. Нормы: 05/02 §2.2, 05/03 §1.6.

### 1.4. `split` — разбиение текста (`type-unmask`)

- **Зачем**: заголовок по словам, фраза по строкам, короткий постер по буквам (`split-text-reveal`, L1).
- **Разметка — заранее**: куски — дочерние элементы.
  - Слова: `<h2 data-mk="split" data-mk-split="words"><span>Слова</span> <span>приходят</span> …</h2>` — пробелы между
    кусками, доступный текст цел.
  - Строки: `<p data-mk="split" data-mk-split="lines"><span>Первая строка</span><span>Вторая</span></p>` — куски
    блочные; на узком экране строка переносится внутри своей маски.
  - Буквы (≤ 12 знаков): `<h2 aria-label="Кадр" data-mk="split" data-mk-split="chars"><span aria-hidden="true">К</span>…</h2>`.
  На холсте куски пишет автор артборда, на сайте — компонент при сборке (`04`). Скрипт текст не режет.
- **Механика**: каждый кусок — маска §1.3 со своей задержкой; шаг `min(stagger.text, (split-total-max − длительность) /
  (n − 1))` — вся сцена ≤ 1000 мс; слова и буквы — 560 мс, строки — 800 мс. Замер: семь слов — задержки 0 … 360 мс
  с шагом 60, сцена 920 мс; три строки — 0, 60, 120 мс `[проверено]`.
- **Опции**: `data-mk-split`, `--mk-dur`, `--mk-ease`, `--mk-wait`, дорожки `--mk-t-*`, `--mk-c-*`, `--i`, `--n`.
- **Reduce**: текст целиком. **Телефон**: так же, длинные кириллические слова по буквам не делить.
- **Клише**: `cliche:split-text-reveal` — одна система на страницу, не на каждом H2. Нормы: 05/03 §1.6, 06/01 §2.1.

### 1.5. `sweep` — шторка (`sweep`)

- **Зачем**: кадры, полосы, разделители — кадр «въезжает» в рамку (`mask-reveal` L0, медиа в `scroll-reveal-system`).
- **Разметка**: `<div class="plate" data-mk="sweep" data-mk-from="left" style="--mk-r: 4px"><div data-mk-inner>…</div></div>`.
- **Механика**: `clip-path: inset(0 100% 0 0 round r)` → `inset(0 round r)` 800 мс `out-expo`; внутри — обратный масштаб
  `--mk-zoom` 1,06 → 1 той же длительностью. Стороны: `left`, `right`, `top`, `bottom`.
- **Цена**: 0,4 КБ JS, 27,7 / 39 мс/с (06/01 §10). Кадр под маской — без `loading="lazy"`.
- **Reduce**: кадр открыт. Нормы: 05/02 §2.2, 06/01 §10.

### 1.6. `scale-in` — проявление с масштабом

- **Зачем**: фигуры и иллюстрации «наводятся на резкость» (`scroll-reveal-system`); в словаре приёмов появления своего
  значения нет (`01` §7).
- **Разметка**: `<figure data-mk="scale-in" data-mk-blur>…</figure>`.
- **Механика**: масштаб `scale.reveal-in` 0,96 → 1 (800 мс `out-expo`), прозрачность 0,5 × (400 мс), размытие —
  только с `data-mk-blur`, `--mk-blur` 6 px ≤ 8 px (уровень L1), 0,7 × (560 мс `out-strong`).
- **Reduce**: фигура на месте, резкая. Нормы: 05/03 §2.2 (filter на L1 — ≤ 8 px на ≤ 2 слоях).

### 1.7. `count` — честный счётчик (`number-tick`)

- **Зачем**: цифра доказательства из фактов — момент внимания при входе в окно (`counter-up`, L0).
- **Разметка**: `<span data-mk="count">1 280</span>` — итог стоит в HTML; единица — снаружи элемента.
- **Механика**: набор разбирает итог (до 999 999, разделитель групп — узкий неразрывный пробел, до двух знаков после
  запятой) и ставит `--mk-to`, `--mk-dec`, `--mk-group`, `data-mk-fmt`. Зарегистрированное `--mk-num` (`<integer>`) идёт
  0 → итог за `duration.counter` 1200 мс; цифры рисует `::after`: `counter-reset` с `round()`, `mod()`, `pow()` и
  стилями `@counter-style` без ведущих нулей; текст итога в это время прозрачен (`-webkit-text-fill-color`), но остаётся в
  DOM — для поиска, копирования и экранного диктора; у `::after` пустой альтернативный текст (`content: … / ""`).
  После счёта (`data-mk-done`) виден сам текст. Набор текст не пишет. `[проверено: 35, 33, 12,9, 1 280, 4,8]`
- **Без поддержки** `mod()`, `round()`, `pow()` — итог без счёта. **Reduce, без JS** — итог.
- **Правила**: число — из фактов (`fact:<id>`), без «+» и округления вверх; не в ценах, тарифах и формах; один раз.
  Нормы: 05/01 §3.2, 06/01 §2.6.

### 1.8. `draw` — линия рисуется один раз (`line-draw`)

- **Зачем**: схемы, линии этапов, подчёркивания (`scroll-reveal-system`).
- **Разметка**: `<svg data-mk="draw"><path pathLength="1" d="…"/><path pathLength="1" d="…"/></svg>`.
- **Механика**: `stroke-dasharray: 1`, `stroke-dashoffset` 1 → 0, 800 мс `in-out`; пути — по очереди шагом
  `stagger.group`. Длина пути в JS не считается.
- **Reduce**: линия целиком. Нормы: 05/02 §2.2, 06/01 §4.5.

## 2. Прокрутка на CSS: прогресс равен положению прокрутки

Общее: шкала — коробка самого примитива (`view()` или именованная `view-timeline`) с `view-timeline-inset: 0px` —
`scroll-padding` страницы под липкую шапку прогресс не сдвигает и он совпадает с геометрией JS (`03` §5); `animation-timeline`
пишется после шортката `animation`; всё — под `@supports ((animation-timeline: scroll()) and (animation-range: 0% 100%))`
и `[data-mk-on="full"]`. Поддержка: Chrome 115+, Safari 26+, Firefox 159+ (по умолчанию) `[документация: MDN,
release notes Firefox 159]`; без поддержки — конечное состояние. Класс — `scroll-linked`: движение ведёт человек,
2.2.2 не относится, 2.3.3 — отключаемо (reduce).

### 2.1. `progress` — полоса прогресса

- **Разметка**: `<i class="bar" data-mk="progress" aria-hidden="true"></i>` (липко или фиксировано у верха).
- **Механика**: `scaleX` 0 → 1 по `scroll(nearest block)` — на холсте шкала внутреннего окна; 0 КБ JS.
- **Reduce и без JS — остаётся**: это индикатор положения. Без поддержки шкал — полосы нет (`display: none`), а не пустая
  полоса. Эффект `scroll-driven-progress` (L0). Нормы: 06/01 §4.3.

### 2.2. `parallax` — параллакс слоя

- **Разметка**: `<div class="plate" data-mk="parallax" style="--mk-depth: 0.18">…</div>` (или `data-mk-depth`).
- **Механика**: сдвиг `±depth × (½ окна + ½ высоты слоя)` по `view(block 0px)` на всём проходе `cover` — слой отстаёт от
  страницы ровно на `depth` пути; `|depth|` ограничен `scroll.parallax-ratio-max` 0,4; положительный — дальний слой,
  отрицательный — ближний навстречу. На холсте — по высоте внутреннего окна (`--mk-vh`).
- **Правила**: фон и периферия, текст едет со страницей, без масштаба крупных слоёв; один-два на страницу
  (`cliche:parallax-everything`). **Телефон**: половина амплитуды (`--mk-depth-k: .5`). **Reduce**: слой неподвижен.
  Эффект `parallax-layers` (L1). Нормы: 05/01 §6.2, 05/02 §6.

### 2.3. `scroll-draw` — линия по прокрутке

- **Разметка**: `<div data-mk="scroll-draw" style="--mk-from: cover 25%; --mk-to: cover 70%"><svg>…<path pathLength="1"/></svg></div>`.
- **Механика**: шкала `--mk-draw` — на элементе с `data-mk` (у пути своей коробки нет); `stroke-dashoffset` 1 → 0 в
  диапазоне `--mk-from` … `--mk-to`. **Reduce, без поддержки** — линия целиком. Эффект `svg-line-draw` (L1).
- Линия, чей конец «ведёт» окно (отвес, 09/02 §1.5), — свой CSS по той же шкале с диапазоном `cover 50vh … cover
  calc(100% − 50vh)`.

### 2.4. `highlight` — подсветка слов

- **Разметка**: слова — заранее, детьми абзаца: `<p data-mk="highlight"><span>Читатель</span> <span>видит</span> …</p>`;
  облик задаёт `--mk-dim` — цвет непрочитанного с контрастом ≥ 3 : 1 при кегле ≥ 24 px (не прозрачность).
- **Механика**: одна шкала `--mk-hl` на абзац; слово `k` из `n` загорается в диапазоне `cover (22 + 38·k/n) %` … `+2 %`;
  место — `sibling-index()` или `--i`. 0 КБ JS на движение.
- **Reduce, без поддержки** — абзац в цвете текста. Эффект `scroll-text-highlight` (L1, один-два на страницу). Нормы:
  06/01 §2.5 (у демо `#827a6e` на `#f3efe7` — 3,6 : 1).

### 2.5. `scroll-mask` — маска по прокрутке

- **Разметка**: `<div class="plate" data-mk="scroll-mask"><div data-mk-inner>…</div></div>`.
- **Механика**: `clip-path: inset(100% 0 0 0)` → `inset(0)` и обратный масштаб внутри — от входа кадра до 45 % прохода.
  Обратимо: при прокрутке назад кадр закрывается — для «появился и остался» берут `sweep`.
- **Reduce** — кадр открыт. Эффект `mask-reveal` (вариант `scroll-linked`, L0).

### 2.6. `frame-expand` — кадр до полного вылета

- **Разметка**: `<section data-mk="frame-expand"><div data-mk-stage><div data-mk-frame>…</div><div data-mk-caption>…</div></div></section>`.
- **Механика**: секция `100svh + --mk-len` (150vh, предел `scroll.pin-l1-max-vh`), окно липкое; кадр
  `inset(22% 30% round 28px)` → `inset(0)` за 70 % пути, подпись — 72–92 %. Только ≥ 48 rem.
- **Телефон, reduce, без поддержки** — кадр на всю ширину без сцены. Эффект `scroll-mask-expand` (L1). Нормы: 06/01 §10.

### 2.7. `text-mask` — текст-окно в картинку

- **Разметка**: `<p class="word" data-mk="text-mask" style="--mk-media: linear-gradient(…); --mk-media-size: 100% 240%">Глубина</p>`.
- **Механика**: `background-clip: text`; положение кадра — зарегистрированная `--mk-pan` 0 → 100 % по шкале слова
  (перерисовка на главном потоке — одно слово на экран). Без `background-clip: text` — сплошной цвет.
- **Правила**: настоящий текст, контраст — тёмная часть кадра и обводка 1 px (`cliche:giant-display-type` — по задаче).
  Эффект `text-mask-media` (L1). **Reduce** — кадр стоит.

### 2.8. `stack` — стопка липких карточек

- **Разметка**: `<div data-mk="stack"><article>…</article>…</div>` (до 8 карточек, все в одном контейнере).
- **Механика**: карточки липнут под шапкой со сдвигом `k × --mk-stack-step` (24 px, телефон 14); предыдущая уходит в
  `scale(--mk-sink)` 0,94 по шкале следующей (`timeline-scope`, имена `--mk-s1…8`); только `transform` — у Safari фильтр
  на липких слоях стоит кадров (06/01 §5.2).
- **Reduce и без JS** — липкость остаётся (это поведение прокрутки), масштаба нет. Эффект `sticky-stack` (L0).

### 2.9. `horizontal` — горизонтальная секция

- **Разметка**: `<section data-mk="horizontal" aria-label="…"><div data-mk-stage tabindex="0"><div data-mk-track>…панели…</div><div><i data-mk-bar></i></div></div></section>`.
- **Механика**: секция `--mk-panels × высота окна` (панелей ≤ 5, число ставит набор), окно липкое с
  `container-type: inline-size`; лента едет на `translateX(calc(-100% + 100cqw))` по шкале секции (`contain`);
  `[data-mk-bar]` — полоса прогресса ленты. Только ≥ 48 rem.
- **Телефон, reduce, без JS и поддержки** — родная лента `overflow-x: auto` со snap и клавиатурой `[проверено: phone]`.
  Эффект `horizontal-scroll` — **L2**. Нормы: 05/02 §5.

### 2.10. `header` — сжатие шапки

- **Разметка**: `<header data-mk="header"><div data-mk-plate></div><div data-mk-shadow></div><div data-mk-row><a data-mk-logo>…</a>…</div></header>`.
- **Механика**: зарегистрированное `--mk-shrink` 0 → 1 по первым 160 px `scroll(nearest block)`; части — только
  `transform` и `opacity`: плашка `scaleY(1 − shrink × --mk-plate-k)`, строка сдвигается на `--mk-row-shift`, логотип
  `scale(1 − 0,22 × shrink)`, тень и подписи — прозрачностью. Без шкал прокрутки — `data-mk-shrunk` по порогу 40 px и
  переход 320 мс.
- **Reduce** — сразу компактная шапка. Эффект `header-shrink-on-scroll` (L0). Нормы: 06/01 §12.5.

## 3. `text-path` — текст по кривой

- **Разметка**: `<svg aria-hidden="true"><path id="p" d="…"/><text><textPath href="#p" data-mk="text-path" data-mk-from="-2%" data-mk-to="38%" startOffset="18%">…</textPath></text></svg>`
  и тот же текст в скрытом заголовке.
- **Механика**: в кадре прокрутки, только пока SVG видна, набор пишет атрибут `startOffset` по проходу SVG через окно.
- **Reduce, без JS** — подпись на месте разметки (`startOffset` из HTML). Эффект `text-path` (L1). В дорожках спецификации
  атрибута SVG нет (`01` § Открытые вопросы).

## 4. Петли: только при JS, с паузой

Общее: петля идёт, только когда `data-mk-on="full"`, элемент в окне (вне окна — `data-mk-idle`) и нет `data-motion="paused"`;
без JS — кадр покоя (паузы без JS нет — нет и петли). Класс `loop`: механизм 2.2.2 — общая пауза; бюджет внимания —
`01` §5.4.

### 4.1. `marquee` — бегущая строка

- **Разметка**: `<div data-mk="marquee" data-mk-speed="40"><div data-mk-track>…</div><div data-mk-track aria-hidden="true">…тот же список…</div></div>`.
  Дубль пишет разметка (набор узлы не клонирует).
- **Механика**: обе дорожки едут на `translateX(-100%)` своей ширины; период = ширина / скорость — набор меряет дорожку
  после загрузки шрифтов и пишет `--mk-period`; скорость 30–60 px/с (`effects.yaml`, вне — предупреждение и предел).
  `data-mk-boost` — разгон от скорости прокрутки (вход ≤ 900 px/с, затухание λ 4) через `playbackRate` анимации.
  Стоит при наведении и фокусе (удобство, не механизм), вне окна и по паузе. `[проверено: 40,0 px/с; стоит при
  наведении, вне окна, по паузе]`
- **Reduce и без JS** — статичный ряд с переносом, дубль скрыт. **Телефон** — та же скорость.
- Эффекты `marquee-logos` (L0, знаки — только SVG из фактов) и `marquee-text` (L1, «заметная» петля 3,8–4,6 %/с — не под
  текстом). Клише `cliche:marquee-strip`. Нормы: 05/01 §5, 06/01 §3.

### 4.2. `drift` — дыхание и вращение

- **Разметка**: `<div data-mk="drift" data-mk-drift="float|orbit|spin|glow" style="--mk-period: 14s">…</div>`.
- **Варианты**: `float` — покачивание ±`--mk-amp` % высоты (умолчание `loop.float-amplitude-pct` 3) с периодом
  `--mk-period` (`duration.breathe-period` 12 с; `alternate`, кривая `easing.breathe`); `orbit` — путь по четырём точкам,
  `--mk-ox`, `--mk-oy`, некратные периоды у слоёв (29 / 37 / 43 с); `spin` — оборот 24 с, вращать обёртку `div`, а не
  `<svg>` (Chromium не композитит вращение `<svg>`); `glow` — прозрачность 0,55 ↔ 1 и масштаб 0,98 ↔ 1,02 размытого слоя
  за кнопкой.
- **Правила**: крупный объект — период ≥ 10 с, полоса 2,5–6 с запрещена (05/01 §6.3); под абзацем — нет; слои одной
  композиции (дети одного родителя) — одно движение в бюджете.
- **Reduce** — кадр покоя. Эффекты: `rotating-badge` (L0), `mesh-gradient-css` (вариант «пятна» на `transform`, L0),
  `glow-accent` (L1). Клише: `cliche:circular-rotating-text`, `cliche:mesh-gradient-bg`, `cliche:aurora-blobs`.

## 5. Указатель: только мышь и перо

Общее: только `(hover: hover) and (pointer: fine)` и `pointerType` мышь или перо; один слушатель `pointermove` на
документ, переменные — раз в кадр, цикл rAF — пока значения догоняют (в покое 0 кадров); сглаживание по времени
`damp(x, y, λ, dt)` — одинаково на 60 и 144 Гц (05/03 §4.5). Класс `pointer`.

### 5.1. `magnet` — магнит

- **Разметка**: `<a class="btn" data-mk="magnet"><span data-mk-label>Подпись</span></a>`.
- **Механика**: в радиусе 1,6 размера кнопки она тянется к указателю на ≤ `--mk-magnet` (8 px) и ≤ 25 % высоты, подпись —
  на 40 % дальше; λ 8 (возврат ≈ 0,37 с); свойство `translate` — не мешает своему `transform` кнопки. `[проверено: 8 px,
  возврат к 0]`
- **Reduce, тач** — кнопка не смещается. Одна главная кнопка на экран. Эффект `magnetic-cta` (L1), клише
  `cliche:magnetic-button`. Нормы: 05/03 §1.4.

### 5.2. `tilt` — наклон карточки

- **Разметка**: `<article data-mk="tilt" data-mk-deg="6"><i data-mk-glare></i>…</article>`.
- **Механика**: `perspective(900px) rotateX rotateY` ≤ 7°, λ 7; блик `soft-light` по положению указателя (`--mk-gx`,
  `--mk-gy`, `--mk-glare`). Один ключевой ряд. `[проверено: 5,6° у края]`
- **Reduce, тач** — плоская карточка. Эффект `tilt-card` (L1). Нормы: 05/03 §1.5.

### 5.3. `spotlight` — прожектор

- **Разметка**: слой под текстом внутри зоны: `<section data-mk-area><div data-mk="spotlight" aria-hidden="true"></div>…</section>`.
- **Механика**: `radial-gradient` по `--mk-x`, `--mk-y` (px от слоя), λ 10; покой — 70 % / 30 %. Облик — `--mk-spot`,
  `--mk-spot-r`.
- **Reduce**: свет идёт за курсором без хвоста — прямое управление (05/03 §1.5). **Тач**: пятно стоит в покое.
  Эффект `cursor-accent` (L1) — только внутри первого экрана и под текстом.

## 6. Микродвижение: чистый CSS

Общее: отклик интерфейса (05/03 §1), работает без JS; длительности и сдвиги — переменные с веткой reduce: в reduce
движение сменяется затуханием или мгновенной сменой.

| примитив | разметка | движение | reduce | телефон | эффект |
|---|---|---|---|---|---|
| `dialog` | `<dialog data-mk="dialog" closedby="any">`, кнопки `command="show-modal" commandfor="id"` | вход 320 мс `out-expo` из `translateY(24px) scale(.98)`, выход 250 мс `in`; `@starting-style`, `overlay` и `display` с `allow-discrete`; фон — с окном | проявление 180 мс без сдвига | так же | `dialog-entry-exit` (L0) |
| `accordion` | `<details data-mk="accordion" name="faq"><summary>… <span data-mk-marker>+</span></summary>…</details>` | `::details-content` 0 → `auto` за 200 мс (`interpolate-size`), значок поворачивается; без поддержки — мгновенно | мгновенно | так же | `details-accordion` (L0) |
| `button-label` | `<a data-mk="button-label">Подпись <svg>…</svg></a>` | `clip-path` по полной коробке: видна часть со значком (`--mk-icon`), при наведении и `:focus-visible` — вся | без анимации | подпись видна всегда | `button-expand-label` (L0) |
| `flip` | `<div data-mk="flip"><div data-mk-face>… <button data-mk-flip-toggle aria-expanded="false">Подробнее</button></div><div data-mk-back>…</div></div>` | `rotateY` 180° за 560 мс `in-out` при наведении и `:focus-within`; оборот скрыт обратной стороной, его текст и ссылка в DOM и в порядке Tab | без поворота: оборот стоит под лицом | кнопка «Подробнее» | `card-flip-3d` (L1) |
| `shine` | `<div data-mk="shine" tabindex="0">…</div>` | полоса света один раз проходит по кадру на наведение или фокус, 800 мс `in-out`; движется только полоса | блика нет | нет, фокус — да | `light-sweep` (L0) |
| `columns` | `<div data-mk="columns"><a data-mk-col><div data-mk-col-media>…</div>…</a>…</div>` | окно колонки `clip-path` раскрывается при наведении и фокусе, 320 мс; без указателя раскрыта первая | без перехода | все раскрыты | `expanding-columns` (L0) |

- Окно открывают команды кнопок (`command`, `commandfor`) — без JS; где их нет, то же действие делает набор; закрытие по
  клику мимо окна — `closedby="any"` или набор. Фокус в окне и возврат на кнопку — нативные (`showModal`).
- Переворот в reduce — не «проявление поверх лица»: оборот стоит под лицом, скрытого текста нет (motion_check
  EG-A11Y-10 считает скрытым текст под `opacity: 0`) `[проверено]`.
- Переворот на тач без JS — только фокус; кнопка `[data-mk-flip-toggle]` переворачивает и переводит фокус на ссылку оборота.

## 7. Переходы

### 7.1. `state` — смена состояния в View Transition

- **Разметка**: `<button data-mk="state" data-mk-target="#gallery" data-mk-attr="data-view" data-mk-value="list" aria-pressed="false">Список</button>`;
  у элементов, которые морфят, — `view-transition-name` в разметке.
- **Механика**: набор меняет атрибут цели внутри `document.startViewTransition({update, types: ['mk-state']})` и
  `aria-pressed` кнопок группы; группы — 320 мс `in-out`, перекрёстное затухание — 0,6 ×. Своё изменение —
  `mk.transition(fn)`.
- **Reduce, не full, нет поддержки** — та же смена без перехода (`fn()` сразу). Эффект `view-transition` (L1). Нормы:
  05/02 §8, 06/01 §6.1.

### 7.2. `page-transition` — переход между страницами

- **Разметка**: на обеих страницах `<style>@view-transition { navigation: auto; types: mk-page; }</style>` и общий
  элемент `<div data-mk="page-transition" style="view-transition-name: kit-cover">`.
- **Механика**: корень — «общая ось»: старая страница гаснет за 120 мс и уходит на 24 px влево (320 мс `in-out`), новая
  приходит справа и проявляется за 200 мс с задержкой 120; общий кадр — 400 мс `in-out` (`duration.page`). 0 КБ JS.
- **Поддержка**: Chrome 126+, Safari 18.2+; Firefox — обычная навигация `[документация]`; внутри документа View Transitions — Baseline (Chrome 111, Safari 18, Firefox 144). **Reduce** — затухание
  корня без сдвига. Набор проверяет, что у `[data-mk~="page-transition"]` есть `view-transition-name`. Эффект
  `page-transition` (L1, ≤ 400 мс на многостраничнике). Нормы: 05/02 §8.

## 8. Переключатель движения и пауза

- **`toggle`**: `<fieldset data-mk="toggle"><legend>Движение</legend><button data-motion-set="">Как в системе</button><button data-motion-set="reduced">Меньше</button><button data-motion-set="full">Полное</button></fieldset>` —
  контракт кода сайта; виден, только когда набор работает; цели ≥ 44 px на тач. Эффект `motion-toggle` (L0; на L2 —
  обязателен, на L1 — при петлях или ≥ 2 секциях прокрутки).
- **`pause`**: `<button data-mk="pause" aria-pressed="false"><span data-mk-when="run">Остановить движение</span><span data-mk-when="paused">Запустить движение</span></button>` —
  единая пауза всех петель (WCAG 2.2.2), видна, пока движение идёт; в липкой шапке.
- Поведение — `01` §5. `[проверено: «Меньше» — 0 бегущих петель, всё в конечном состоянии; «Полное» и «Как в системе» —
  обратно; пауза — 0 бегущих петель и возврат выбора]`

## Частые ошибки

- **Начальное состояние своим CSS без корня набора** — без JS, в reduce и в обзоре холста элемент скрыт навсегда.
- **Разбиение скриптом** — на холсте запрещено, на сайте — длинная задача до первого клика; куски — разметкой.
- **Счётчик, который пишет текст** — нарушает правило набора и ломает поиск по странице; итог — в HTML.
- **Вращение `<svg>` вместо обёртки** — 36 мс/с главного потока на десктопе и 127 на телефоне (06/01 §2.4).
- **Дыхание с периодом 3–5 с у крупного объекта** — пик укачивания (05/01 §6.3); ≥ 10 с.
- **Два слоя дыхания, разведённые по разным родителям**, — бюджет считает их двумя движениями.
- **Магнит на всех кнопках, наклон на всех карточках** — одна кнопка на экран, один ключевой ряд.
- **`scroll-mask` для «появился и остался»** — по прокрутке назад кадр закрывается; для одного раза — `sweep`.
