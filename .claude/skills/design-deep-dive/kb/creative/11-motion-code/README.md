# 11 · Движение страницы кодом: набор примитивов, DOM-сцены прокрутки, переключатель движения, проверка

Движение страницы проектируется, прототипируется и проверяется на этапе дизайна готовым кодом, а не пишется агентом по
памяти. Набор — один скрипт `examples/motion-kit.js` (одно глобальное имя `MotionKit`, без библиотек и сети) и один
файл стилей `examples/motion-kit.css`: 35 примитивов исполняют 33 эффекта каталога `../06-effects-catalog/effects.yaml`
по нормам `../05-motion/` и числам токенов `motion.marketing`. Момент спецификации движения
(`../09-ai-execution-evaluation/motion-spec.schema.json`) собирается примитивом — значением `data-mk` с опциями; тот же
код идёт на холст Claude Design файлом поддержки и в код сайта модулем острова. Набор не создаёт и не переносит узлы
DOM — только атрибуты, классы и CSS-переменные: без JS, при «уменьшить движение» и в обзоре холста страница полна.
3D и WebGL — `../../3d/16-js-scenes/` (общая пружина прогресса), отклик интерфейса — `../../ui/08-motion/`.

## Как пользоваться (для агента)

- **Этап движения** (`../../../references/phases.md`, `motion`): по моментам спецификации — примитив из
  `primitives.yaml` в поле `primitive`, опции — в `params` (имя без `data-mk-` и `--mk-`); поля момента переводятся в
  разметку по таблице `01` §6; чего набор не выражает, момент пишет своим кодом с `custom`. Проверка —
  `spec_check.py spec` (MS-25, MS-26).
- **Холст Claude Design**: `examples/motion-kit.js` → файл поддержки `motion-kit.js` в папке `lib` проекта холста
  строкой после строки поддержки (support.js); CSS набора — в `<helmet><style>`; адаптер в логике артборда — по
  `examples/artboard-adapter.dc.html` (`04` §1).
- **Код сайта**: CSS — в слой, модуль острова после `load` в простое, `toggle: false` рядом с островом предпочтений,
  куски разбиения и числа — компонент при сборке (`04` §2).
- **Лабораторная страница приёма**: копия файлов набора рядом со страницей; проверка — `motion_smoke.py --root <папка>
  --page index.html` и `motion_check.py` (`04` §3).
- **Посмотреть приём**: `examples/demo.html` — все примитивы на одной странице с DOM-контрактом, паузой и
  переключателем; `examples/demos/<семейство>.html#<id эффекта>` — по эффекту каталога.

## Выжимка папки

1. **Момент спецификации — примитив набора**: `primitive` = значение `data-mk`, `params` — опции; таблица «поле →
   разметка» и список того, чего набор не выражает. `[проверено: spec_check — 0 находок, motion_check — FAIL 0]` → `01` §6
2. **Только атрибуты, классы, переменные**: ни одного `innerHTML`, `appendChild`, `cloneNode`, записи текста и запроса
   сети; классический скрипт, одно глобальное имя. `[проверено: motion_smoke static]` → `01` §9
3. **Скрытое — только под `data-mk-on="full"`**: без JS, в reduce, при «Меньше» и в обзоре холста — конечные состояния;
   скрытого текста 0. `[проверено: nojs, rm, reduced]` → `01` §5.2
4. **Числа — переменные с именами токенов** `--motion-marketing-*` и запасными значениями; reduce — значения ветки
   reduce токенов; ДС проекта подменяет без правки набора. `[проверено: 29 имён]` → `01` §4
5. **Своё время у дорожки**: прозрачность короче сдвига (336 из 560 мс у подъёма); `tracks[].duration | easing |
   delay_ms` → `--mk-o-*`, `--mk-t-*`, `--mk-c-*`, `--mk-f-*`. `[проверено: CSSTransition]` → `01` §4.2
6. **Система появления — три приёма по ролям** и кривые с характером: маска 800 мс `out-expo`, подъём 16 px, шторка с
   обратным масштабом, проявление с размытием ≤ 8 px; стаггер 60 мс — `sibling-index()` с запасом `--i`.
   `[проверено]` → `02` §1
7. **Разбиение и счёт без записи текста**: куски — разметкой, цифры — CSS-счётчик поверх прозрачного итога.
   `[проверено]` → `02` §1.4, §1.7
8. **Прокрутка на CSS** — под `@supports` с `animation-range`, шкалы с `view-timeline-inset: 0px`; без поддержки —
   конечное состояние; Chrome 115+, Safari 26+, Firefox 159+. `[проверено: Chromium]`, `[документация]` → `02` §2
9. **DOM-сцены** `scrub` · `beats` · `glide` · `play` — прогресс в `--mk-p`, такт в `data-beat`, пружина дословно сцен
   3D: такт ω 3 — 95 % за 1,50–1,53 с без перелёта, такты по одному. `[проверено]` → `03`
10. **Петли — с паузой и в бюджете**: только при JS, стоят вне окна, при наведении и по общей паузе; строка 40 px/с;
    петель в окне на демо ≤ 1 из 2 (L1). `[проверено: motion_smoke desk; motion_check EG-A11Y-01…03, -17]` → `02` §4,
    `01` §5.4
11. **Указатель — мышь и перо, раз в кадр**: магнит 8 px и возврат, наклон 5,6° из 7. `[проверено]` → `02` §5
12. **Отклик и переходы — чистый CSS** с затуханием в reduce; переворот в reduce — оборот под лицом, без скрытого текста.
    `[проверено: EG-A11Y-10 — 0]` → `02` §6–7
13. **Переключатель — контракт кода сайта** (`data-motion`: нет, `reduced`, `full`) плюс `paused`; «Меньше» — 0 бегущих
    петель, «Полное» сильнее системы. `[проверено: EG-A11Y-24]` → `01` §5
14. **Вес**: 8,0 КБ JS + 4,9 КБ CSS brotli в сжатом виде (12,9 КБ) — в бюджете подачи L0 (20 КБ). `[проверено]` → `01` §8
15. **Холст**: файл поддержки, CSS в `<helmet>`, адаптер с `host: root` и `viewMode`; на claude.ai набор не проверялся.
    `[не проверено на холсте]` → `04` §1

## Как запустить

Команды — из папки скилла `.claude/skills/design-deep-dive/`; окружение — `../../../scripts/README.md`:

```bash
PY=~/.cache/design-deep-dive/venv/bin/python; K=kb/creative/11-motion-code/examples
$PY scripts/creative/motion_smoke.py --selftest
$PY scripts/creative/motion_smoke.py --shots --json ~/.cache/design-deep-dive/out/creative/motion-smoke.json   # 8 режимов, ≈ 2,5 мин
$PY scripts/creative/motion_smoke.py --modes static,desk,rm,nojs --root DIR --page index.html                   # своя страница
$PY scripts/creative/spec_check.py spec $K/demo.motion-spec.yaml
$PY scripts/creative/motion_check.py $K/demo.html --level L1 --modes desk,rm,nojs --spec $K/demo.motion-spec.yaml
python3 -m http.server 8011 -d $K        # demo.html и demos/ руками
```

Замок браузера утилиты берут сами; кадры `--shots` — в `$DDD_HOME/out/creative/motion-smoke/`.
