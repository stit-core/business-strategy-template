## Выжимка для агента

1. **Число хроматических цветов — по уровню**: L0 ≤ 2 (норма «≤ 2 хроматических, 1 смелый приём» — именно L0,
   `ai-media 01/03:423`), L1 ≤ 3, L2 ≤ 4 с долями; нейтрали и статусы не считаются. → §1.1 `[данные: C]` `[мнение вендора]`
2. **Эффектные сайты держат палитру первого экрана узкой**: ≤ 1 хроматического оттенка у 44 из 49, максимум 3, у 26 из 49 — ни
   одного (медиана 0–1 в зависимости от порога хромы); смелость — в тёмном фоне, кадре, типографике. → §1.1 `[данные: C sites.csv]`
   `[проверено]`
3. **Стратегия цвета направления → уровень**: restrained (нейтрали + 1 акцент) — L0–L2; committed (1 цвет на 30–60 %
   поверхности) — L1–L2; full-palette (3–4 роли) — L1–L2 по концепции; drenched (поверхность = цвет) — L2 или брендовая
   секция. → §1.2 `[мнение вендора: impeccable через A]`
4. **Правило «площадь ↔ хрома» ui (фон > 30 % — C ≤ 0,03) — умолчание L0**; на L1–L2 цветная поверхность законна при
   контрасте текста и концепции. Поправка к `ui 01/06 §1.7`, `ui 11/02 §4.4` для сайта. → §1.3
5. **Тёмный сайт — не чёрный**: фон L 0,14–0,20 OKLCH, поверхности +0,03…0,06, текст не чисто белый; тёмный первый экран — у
   половины эффектных сайтов (25 из 49, C, финал). → §2 `[данные: C]` `[практика: система: ui 11/01 §14]`
6. **Градиент — цвет, а не украшение**: `in oklab` с фолбэк-цветом; Δhue ≤ 40° или промежуточный стоп / `in oklch` с путём
   оттенка; комплементарная пара синий → оранжевый теряет хрому посередине (0,28 → 0,10). → §3.1 `[проверено]`
7. **Контраст — в худшей точке градиента**: белый текст на синем #2b3bff — 6,62, на оранжевом конце — 2,61 (провал даже
   для крупного). → §3.1 `[проверено]`
8. **`forced-colors` стирает градиенты и фоновые картинки**: текст обязан держаться на `background-color` под градиентом.
   → §3.2 `[документация: ui 01/06 §2.1]`
9. **Бандинг**: CSS-градиенты Chromium дизерит (0 байт, гладко); растровый градиент — AVIF 10 бит + зерно ≥ 10 %. → §3.3
   `[проверено]`
10. **Стекло — бюджет, а не стиль**: подложка ≥ 72 % при blur ≥ 12 px, ≤ 2 слоя в видимой зоне (над видео и WebGL — ≤ 1), сверх —
    не ставить, цена кадра — по замеру; ≤ 6 на странице — фильтр профиля, не норма (X-24); фолбэк без
    `backdrop-filter`, отключение при `prefers-reduced-transparency`; цену в FPS меряет F. → §4.1 `[практика: система: ui 11/01 §6]`
11. **Зерно — слоем под текстом, 5–9 % `soft-light`**; не на странице с бумажной фактурой. → §4.2 `[проверено]` `[спорно: impeccable]`
12. **Свечение CTA — только одной кнопке на тёмной или тонированной поверхности, со смещением и размытием**; на белом —
    нет. Поправка к `ui 13/01` Г5 для сайта. → §4.3
13. **Продукт показывать настоящим**: HTML-фрагмент UI > оптимизированный скриншот > рендер устройства; скриншот-hero —
    самый медленный тип LCP (7,5 с у лидеров). → §5.1 `[данные: ai-media 01/02]`
14. **Рамка браузера или устройства — не перерисовывать HTML/CSS** (Hallmark gate 47, taste «div fake screenshots banned»):
    скриншот в `<figure>` с волосяной рамкой или PNG-рамка вендора; живой фрагмент — настоящий компонент продукта. → §5.2 `[спорно]`
15. **Многостраничник — одна система**: общие токены, шапка, подвал, сетка, гарнитуры, акцент; по шаблонам меняются уровень,
    доля цвета, медиа и display-роль. → §6 `[практика]`

## 1. Палитра по уровню

### 1.1. Сколько цветов

| Уровень | Хроматических (C > 0,06) | Доли | Смелость |
|---|---|---|---|
| L0 | ≤ 2 (акцент + 1 вспомогательный ≤ 3 % площади) | фон и поверхности — нейтрали C ≤ 0,03 | одна: цвет, кадр или типографика |
| L1 | ≤ 3 | один цвет может занять секцию-пик или CTA-полосу | 1–2 фирменных приёма |
| L2 | ≤ 4 | committed/drenched секции, переливы по концепции | по пикам, между ними — спокойно |

Основания: «≤ 2 хроматических» — выборка NN/g 112 **минималистских** сайтов (ui 11/03 §4.2), то есть норма сдержанной подачи,
а не всех сайтов; Miniukovich — число доминирующих цветов снижает оценку, глубина цвета повышает (ui 13/02 §3.2)
`[исследование]`; C: у 41 эффектного сайта в 6 доминантах первого экрана медиана 1 оттенок, максимум 3 (aardvark, stripe-home),
0 — у 20 (мой расчёт: C > 0,06, доля ≥ 1 %, оттенки ближе 30° слиты) `[данные, предв.]`. Финал C, тот же метод (S1 2026-09-25): 49 страниц —
0 оттенков у 26, 1 — у 18, 2 — у 3, 3 — у 2 (те же aardvark, stripe-home); медиана 0 при C > 0,06 и 1 при C > 0,05; ≤ 1 оттенка — у 42–45 из 49
при любом пороге `[проверено]`. Акцентные мелочи (кнопка) в 6
доминант не попадают — счёт C занижает мелкие акценты. Проверка страницы: уникальные оттенки с C > 0,06 на скриншоте
секции; больше предела уровня — предупреждение (K).

### 1.2. Стратегия цвета и выражение бренда

Поле `art-direction.visual_language.color_strategy` (A, impeccable §4) и площадь цвета бренда — `../01-creative-direction/01-concept-and-directions.md`
§8 (ссылкой). Числа для вёрстки:

| Стратегия | Площадь хроматического | Где на странице | Уровень |
|---|---|---|---|
| restrained | акцент ≤ 5 % | кнопки, ссылки, одна деталь | L0–L2 |
| committed | один цвет 30–60 % | hero, пики, CTA-полоса, подвал | L1–L2 |
| full-palette | 3–4 роли с долями `share_max` | секции по темам, иллюстрации | L1–L2 при концепции |
| drenched | поверхность = цвет | вся страница или брендовая секция | L2; L1 — одна секция |

Бренд-цвет в «ИИ-полосе» 270–320° не меняют — полоса уходит в `exclusions.forbidden_hues` с `except_share_max` (A §8.3);
тёплая бумага бренда (`#F4EFE6` у «Лесной обжарки») ловится маркером LOOK-BG-WARM — граница «бренд или дефолт» за H.

### 1.3. Площадь и хрома: поправка к ui

ui: фон > 30 % экрана — C ≤ 0,03, плашка 5–30 % — ≤ 0,08, кнопка — 0,12–0,20 (ui 01/06 §1.7). Для сайта это умолчание L0.
На L1–L2 committed-секция с C 0,10–0,20 законна, если: текст на ней ≥ 4,5:1 во всех точках (§3.1), цвет из бренда или решения
`art-direction`, секция — событие ритма (`02-composition-rhythm-sections.md` §3.2), а не каждая вторая.

## 2. Тёмные сайты

- Фон L 0,14–0,20 OKLCH (Linear-подобные 14–18 %), поверхности светлее на 0,03–0,06, границы — белый 6–12 % (ui 11/01 §14)
  `[практика: система]`; разница фона и контейнера до 12 % (Hobday, ui 11/03 §4.4) `[мнение: с числом]`.
- Текст #f3f2ee-подобный (не #fff на #000 — ореолы у светлых букв на OLED `[практика]`), вторичный ≥ 4,5:1; акцент на тёмном
  — светлее ступенью (ui 09/04 §7.1: тёмная тема — сплошные заливки на светлой ступени).
- Тень на тёмном не видна — отделение поверхностей светлотой и обводкой (Hallmark «shadow-on-dark accidental glow»).
- Выбор светлого или тёмного — по сцене использования, не по категории (impeccable «Light or dark picked by category» — отказ)
  `[мнение вендора]`. Данные: тёмный первый экран — 25 из 49 эффектных сайтов; L1 13/27, L2 10/19 (C, финал; на 41 предв. — 21, L1 11/20, L2 8/17) `[данные]`.

## 3. Градиенты и переливы как цвет

### 3.1. Построение и контраст

```css
/* Chromium 153 · 2026-09-24 · [проверено: D/04 расчётом; интерполяция — ui 01/06 §2.2] */
.cta-band {
  background-color: #2b3bff;                                        /* фолбэк и forced-colors */
  background-image: linear-gradient(135deg, #2b3bff, #7a2bff);      /* браузеры без in oklab */
  background-image: linear-gradient(135deg in oklab, #2b3bff, #7a2bff);
}
/* комплементарная пара — через промежуточный стоп или путь оттенка, иначе середина сереет */
.hero-sheen { background-image: linear-gradient(120deg in oklch longer hue, #2b3bff, #ff7a1a); }
```

Опыт D/04 (контраст текста в концах и серединах):

| Градиент | Текст | Худший контраст | Середина sRGB → Oklab (L, C) |
|---|---|---|---|
| ультрамарин #2b3bff → фиолет #7a2bff | белый | 5,81 ✓ | 0,515/0,276 → 0,523/0,272 |
| синий #2b3bff → оранжевый #ff7a1a | белый | **2,61 ✗** (оранжевый конец) | 0,551/0,103 → 0,613/0,090 (хрома падает в обоих) |
| лес #12352a → изумруд #1f6b4f | #f1ede4 | 5,49 ✓ (светлый конец) | 0,389/0,068 → 0,386/0,066 |
| тинт #f4efe6 → #e3ebe4 | #1c1b18 | 14,16 ✓ | — |
| CTA-полоса шаблона ai-media J #0b1026 → #2e1e54 | белый | 14,69 ✓ | H 272–293° — «пурпурная полоса» без бренда |

Правила: контраст в самой светлой (для светлого текста — самой тёмной) точке зоны текста, у мелкого текста 4,5:1; Δhue ≤ 40°
(ui 01/06 §2.3) или `in oklch` с явным путём оттенка и проверкой середины; переливы на весь фон (mesh, аврора) — эффект F с
ценой; на L0 — статичный градиент малой площади.

### 3.2. Фолбэки

- `background-color` под любым градиентом — цвет, на котором текст проходит 4,5:1.
- `@media (forced-colors: active)` — градиенты и фоновые картинки исчезают (`background-image: none`), текст — `CanvasText`
  на `Canvas` (ui 01/06 §2.1) `[документация]`.
- Градиентный текст в заголовках — отказ по умолчанию (Hallmark, impeccable, ui 11/04 маркер); допускается только как главный
  приём L2 с `background-color`-фолбэком и проверкой контраста самой светлой буквы `[спорно]`.

### 3.3. Бандинг

CSS-градиент в Chromium гладкий (ступень 0,04 кода), растровые: AVIF 8 бит 0,55, AV1 10 бит 0,35 — полосы; SVG-шум 5 %
прячет ступень только поверх CSS; на растр — шум ≥ 10 % (ai-media 10/03 §4.3) `[данные: у соседа]`. Правило: фоны-переливы —
кодом (CSS, SVG, шейдер F), растровый градиент — только из 16-бит мастера в AVIF 10 бит с зерном.

## 4. Поверхности

### 4.1. Стекло

Токены `surface.glass-light/dark`: подложка 0,72, `blur(16px) saturate(180%)`, обводка 1 px белым 35 % (ui 11/01 §6: ≥ 72 %
при blur ≥ 12; NN/g 30 % + 25 px — края фона видны) `[практика: система]`. Контраст текста — по худшему участку подложки.
**Лимит — одна формулировка базы** (X-24, S1 2026-09-25; та же — `05-motion/03` §2.4 и `effects.yaml` `glass-panel.limits`): ≤ 2 слоя
`backdrop-filter` в видимой зоне (над прокручиваемым видео или WebGL — ≤ 1) — умолчание и граница клише `cliche:glassmorphism-panels`,
плюс цена кадра по замеру (`effect_bench.py`: главный поток ≤ контроль + 25 мс/с на телефоне CPU ×4 — порог-кандидат F `[не проверено]`);
≤ 6 элементов на странице — фильтр профиля `marketing_audit.py` (D3), а не норма. Основание ui «≤ 2 на экран» — бюджет
производительности (каждый `backdrop-filter` — слой, перерисовка при прокрутке), не стиль; у F над движущимся фоном 3 панели стоят
7,5 мс на кадр без vsync, 6 панелей с blur 48 — 7,6 мс: цена почти не растёт с числом панелей
`[проверено]`. Фолбэк `@supports not (backdrop-filter…)` — плотная подложка 0,92;
`prefers-reduced-transparency` — сплошной фон. Стекло на карточках сетки — маркер генерации (Lovable: стекло у 6 из 10 страниц,
до 37 элементов; ui 12/02 §5).

### 4.2. Зерно

`surface.grain-soft` 0,06 (0,05–0,09), `mix-blend-mode: soft-light`, SVG `feTurbulence` 280 Б, слой `z-index: -1` внутри
`isolation: isolate` — под текстом (ai-media 10/03 §4.3) `[данные: у соседа]`; Hallmark E7 — 0,06 multiply, только в hero.
Противоречие: impeccable (codex) — «feTurbulence grain reads as amateur» `[мнение вендора]`. Позиция: зерно — фактура мира
(плёнка, бумага, печать), а не «чтобы не было плоско»; на странице с бумажной фактурой не удваивать `[спорно]`.

### 4.3. Свечение CTA

`shadow.cta-glow`: смещение 8, размытие 24, −4 spread, цвет акцента 35 %. Условия: одна кнопка (hero или финал), тёмная или
тонированная поверхность, решение в `art-direction.decisions` (критерии H); ореол без смещения — декор (impeccable), на белом —
нет (Hallmark «Never a coloured glow on a light background»). `ui_audit.py` D4 «серьёзно» на сайте — ложное срабатывание
(аудит UI §4.3), профиль `marketing` — K.

## 5. Подача продукта

### 5.1. Что показывать и чем

| Способ | Когда | Цена | Правило |
|---|---|---|---|
| HTML-фрагмент UI (живой компонент, упрощённый) | SaaS, сервис, фичи | 0 картинок, текст индексируется | настоящие данные или помеченные примеры; не div-«муляж» |
| Скриншот (AVIF, `srcset`, `width/height`) | интерфейс сложный, важна точность | LCP скриншот-hero 7,5 с у лидеров — самый медленный тип (ai-media 01/02) | ≤ 150/80 КБ в первом экране; не `lazy` на LCP; телефону — вертикальный кадр |
| Рендер устройства со скриншотом (3d) | железо, приложение, премиальный продукт | вес и время рендера | рецепт 3d 03 (ссылкой); экран — композит настоящего скриншота (ai-media `IMG-MOCKUP`) |
| Петля UI 3–8 с (видео) | процесс в продукте | петля ≤ 600 КБ / 1,5 МБ (`ambition-levels.yaml` L1) | постер = LCP, пауза, reduce → постер |

Фичи: «HTML-фрагмент UI > скриншот > иллюстрация > короткая петля» (ai-media 01/01 §2.1) `[практика]`. Поправка к
`ui 07/02:702` («скриншоты не используются») для сайта: на SaaS-странице настоящий интерфейс — главный визуал.

### 5.2. Рамки браузера и устройства

- Hallmark E3 предлагает рамку браузера (Browserframe или «1 px + три точки»), а gate 47 того же Hallmark валит перерисованный
  хром (URL-строка, CSS-телефон, фейковое окно кода) — внутреннее противоречие вендора. taste: «div-based fake screenshots are
  banned», «real component preview» — можно `[мнение вендора]`.
- Позиция базы: рамка не нужна по умолчанию — скриншот в `<figure>` с волосяной рамкой 1 px и `radius.media`; рамка браузера —
  только когда продукт надо узнать как веб-приложение, и тогда как готовый PNG/SVG-ассет, не HTML; рамка телефона — PNG вендора
  или рендер 3d; у K3 рамка браузера вокруг дашборда в hero — колея SaaS (A §3.3, kimi 04/01 §5.2) `[спорно]`.
- Наклон 1–3°, выноски с номерами вместо стрелок (Hallmark E3); на < 60rem наклон и вылет снимаются, выноски — нумерованным
  списком под кадром (site `product-showcase`).

## 6. Единство системы многостраничника

| Общее на всех страницах | Меняется по шаблону страницы |
|---|---|
| `marketing-tokens.json` (display-шкала, отступы, радиусы, поверхности), гарнитуры, акцент и нейтрали | уровень страницы (L0 внутренние, L1 главная и продукт, L2 кампания — `ambition-levels.yaml`) |
| шапка, подвал, сетка, контейнер, стиль ссылок и кнопок, иконки | display-роль H1 (по длине), доля цвета (committed на главной, restrained в статьях) |
| система появления и reduce (E) | медиа первого экрана и число пиков |

Два мира (маркетинг и продукт) — два документа `art-direction` и два паспорта визуала (A §1; ai-media 06/01). Внутренние
страницы L0 — «сдержанная подача в той же системе, а не без дизайна» (решение 20 site) `[практика]`.

## Частые ошибки

1. «≤ 2 хроматических» как закон для всех уровней — или наоборот, 5–6 оттенков «для насыщенности» без долей.
2. Пурпурно-синий градиент без бренда (медиана генераторов, ui 01/06 §2.4); синий → оранжевый с белым текстом по всей длине.
3. Градиент без `background-color` — в forced-colors текст на пустом фоне.
4. Растровый градиент 8 бит на весь экран — полосы; попытка лечить их 3 % шума.
5. Стекло на каждой карточке; стекло поверх видео без плотной подложки.
6. Div-«скриншот» дашборда с фейковыми цифрами; HTML-рамка браузера с тремя точками.
7. Скриншот-hero `loading="lazy"` или 800 КБ PNG — LCP 7+ с.
8. Каждая внутренняя страница «своя» по цвету и шрифту — многостраничник распадается.
