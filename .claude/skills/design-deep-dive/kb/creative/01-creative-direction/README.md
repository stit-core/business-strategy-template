Выжимка:
1. Концепция — словами до эффектов: механизм, сцена аудитории, что доказывает первый экран, тезис ≤ 240 знаков, колея.
2. 3–5 направлений: пары различаются ≥ 2 осями из 4, тёплое или антиква ≤ 1, одна рекомендация; буквальное прочтение ≤ 1.
3. `art-direction` — один документ на мир сайта; `approved` — только с подписью заказчика; перед сдачей — `ad_check.py`.
4. Решения о приёмах — по пяти проверкам H (концепция, бренд, исполнение, эпоха, единственность); каждый `--allow` — с решением.
5. Уровень — вся подача, не только движение; L0 — сдержанно, но в той же визуальной системе, а не «без дизайна».
6. На всех уровнях: reduce-вариант, пауза петель > 5 с (2.2.2), ≤ 3 вспышек/с (2.3.1), смысл в HTML, фолбэк без WebGL и JS.
7. Бюджет в два слоя: подача (JS эффектов, 3D, WebGL, видео — наш) и страница (исходы и вес — site P, вес — предупреждение).
8. Умолчания: внутренние L0, лендинги L1, кампании L2; лидогенерация — L1 с конверсией L0, L0 при горячем мобильном ≥ 50 %.
9. Страница L2 — 2–4 пика с паузами, секции конверсии всегда L0; движение kimi: L0 `subtle`, L1 `expressive`, L2 `cinematic`.
10. Нормы соседей («1 смелый приём», 2,5 МБ, «один движущийся элемент», «только transform/opacity») — режим L0, а не закон.
