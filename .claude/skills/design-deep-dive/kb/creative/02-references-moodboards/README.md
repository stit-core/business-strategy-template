Выжимка:
1. В Dribbble, Behance, Dprofile входит только заказчик (`refs_client.py login`, окно Brave); агент — только через клиент.
2. Режимы — решения заказчика: Dribbble и Dprofile — «поиск», Behance — `off` (24.09.2026).
3. Без stealth и подмены UA; челлендж, капча, 403, 429 → стоп и пауза; ≥ 10 с + джиттер между страницами; 40–60 страниц в сутки.
4. Чужие работы — только в библиотеке заказчика `~/.local/share/creative-refs/`; в базе — ссылки, метаданные, «что взять».
5. Почти все площадки запрещают автоматический сбор (дословно — `01` §3); API — Are.na v3, Refero, Mobbin, Vimeo.
6. Галерея — список сайтов для C, не источник картинок: `search <галерея> latest` → `site-<домен>` с наградой и датой (Awwwards SOTD, CSSDA WOTD, FWA FOTD); превью — наш снимок сайта.
7. Мудборд — источник словесного описания: роль, `applies_to`, Take (объект + свойство + число), Do not take.
8. Лендинг: 1 композиция + 1 типографика + 1 блок-решение + 0–1 движение; из одного референса — одна секция.
9. K3: картинки ≤ 2000 px и ≤ 256 КиБ, сайт снимает Claude, видео — только `k3`; генераторам — слова и hex, не чужие работы.
10. Живые тесты 24.09: Dribbble — 170 кандидатов, Dprofile — 110, блокировок нет; галереи — офлайн на серверном HTML 222 записи (B/02), живой прогон — после замеров C.
