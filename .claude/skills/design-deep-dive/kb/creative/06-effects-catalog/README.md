Выжимка:
1. Эффект выбирается по `id` из `effects.yaml`; `level_min` и `limits` — по уровням A; реализация — `demo` (лаборатория) или `external_ref`/`stack_ref`.
2. В лаборатории все эффекты держат 60 кадров/с даже на CPU ×4 — цену различают главный поток (мс/с), CLS, движение в покое, задержка клика.
3. Библиотеки — только когда эффект включён: GSAP для закреплённой сцены 45,7 КБ на десктопе и 3,9 КБ на телефоне и при reduce.
4. Петля > 5 с — видимая пауза; на L2 — переключатель «Движение» (`effect:motion-toggle`): 3 состояния, помнится, побеждает ОС, останавливает WebGL, видео, GSAP и Lenis без перезагрузки.
5. Без JS контент виден, без поддержки `animation-timeline` — конечное состояние, без WebGL — CSS того же тона.
6. CLS: закрепление — `sticky`, а не `pin` через `position: fixed` (0,35–0,99 при прокрутке); раскрытия по наведению и прокрутке — `clip-path`/`transform` (наведение и прокрутка — не «ввод»).
7. Видео-фон: постер-кадр ≥ 0,05 бит/пиксель, видео после `load`, AV1 → H.264, теги BT.709 фильтром `setparams`, свой кадр 9:16.
8. Голо-шейдер (модель дифракционной решётки F2) закрывает висячую ссылку `3d 06/01 §3.5`; по умолчанию — окно тонов марки, текст на скриме.
9. Клише — по реестру H (53 id, ссылки сверены 2026-09-25): бегущая строка, свой курсор, магнит, аврора, стекло, split — насыщены; нужен поворот из концепции.
10. Лаборатория ≠ поле: Safari, Firefox, реальные телефоны и CSS-3D в WebKit — живая фаза; демо показывают эффект на пределе и не образец для исполнителя (`video-loop-hero` — громкая петля L2, `smooth-scroll` — без переключателя; X-26).
