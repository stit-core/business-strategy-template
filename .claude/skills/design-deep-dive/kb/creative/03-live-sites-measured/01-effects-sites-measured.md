## 1. Метод и ограничения

### 1.1. Что и как мерилось

- **Инструмент** — `effects_probe.py` (раздел в `../../scripts/creative/README.md`): один браузер, один режим; байты — по CDP
  (включая прерванные Range-запросы видео), библиотеки — по глобалам рантайма, DOM, баннерам и строкам в тексте JS
  (сигнатуры сверены с исходниками npm, опыт C/01), анимации — `document.getAnimations()` и перехват GSAP, стили — по
  тексту всех CSS-ответов, `<style>` и CSSOM. [проверено]
- **Сценарий**: `load` → 8 с → 2 с покоя (два скриншота через 1 с: доля меняющихся пикселей и связные движущиеся области) →
  снимок анимаций → разбор DOM и стилей → проверка бегущей строки (три замера за 0,7 с) → 24 шага колесом мыши (шаг =
  прокручиваемая высота / 24; 160 мс между шагами) → 1,5 с → фиксация веса сессии → тест своего курсора.
- **Режимы**: десктоп 1440×900, DPR 1; телефон — дескриптор Pixel 7 (412×839, DPR 2,625) + CPU ×4 + 150 мс RTT + 1,6 Мбит/с
  (как пресет Lighthouse и `site_probe.py` 3d); reduce — контекст `prefers-reduced-motion: reduce`, сравнение с обычным
  прогоном того же устройства (`rm_pair`).
- **Сеть и язык**: VPN с раздельной маршрутизацией — зарубежные серверы через выход в Литве, российские — напрямую.
  До и после каждой партии проверялись страна выхода (`ipinfo.io/country` = LT) и то, что `yandex.ru/internet/api/v0/ip`
  видит другой адрес (адреса не записывались); у страницы `net` = `ru-direct` (сервер в РФ по ipinfo) / `eu-vpn` /
  `unknown` (проверка до или после прогона не прошла). `locale` контекста — `en-US`, у русских сайтов `ru-RU`. Stripe
  отдаёт региональную версию по IP (`/en-lt/`) — язык при этом английский.
- **UA не подделывался**: десктоп — строка Playwright по умолчанию (`HeadlessChrome`), телефон — Pixel 7 с `HeadlessChrome`;
  флаг `AutomationControlled` не выключался. Сайт за челленджем — `blocked` и замена из запасного списка.

### 1.3. Ограничения

- **Лаборатория ≠ поле**: один прогон на режим, пустой кэш, домашняя сеть через VPN; INP не измеряется (нет
  взаимодействий) — только LoAF и TBT как косвенные признаки. CrUX по URL без ключа PSI закрыт (site M, 2026-09-24).
- **Headless на встроенной графике** (Iris Xe): FPS ≤ 60, WebGL реальный (ANGLE GL), но не телефонный GPU; телефон —
  эмуляция, не устройство (живая фаза).
- **Cookie-баннеры не закрывались** (правило: согласие не нажимаем) — признак `cmp`; баннер может стать LCP и попасть
  в палитру первого экрана.
- **Ворота** («Enter», «Start»): без клика мерится только заставка → признак `gate`; такие страницы перемерены с
  `--click` (LCP остаётся от экрана ворот — это и видит пользователь).
- **Перехват GSAP** (`Object.prototype.vars`) делает `'vars' in obj` истинным для всех объектов; на выборке сбоев не
  замечено, выключается `--no-gsap-hook`.
- **Детекторы эвристические**: свой курсор — элемент `pointer-events: none` ≤ 220 px, догоняющий мышь за 0,7 с; бегущая
  строка — дорожка шире контейнера, непрерывно сдвигающаяся в покое; горизонтальная прокрутка — широкая дорожка,
  сдвинутая вертикальной прокруткой > 0,5 экрана; split-текст — ≥ 6 коротких блоков в заголовке; появление — текст ниже
  первого экрана с `opacity < 0,05` до прокрутки и `> 0,5` после. Все проверены на известных случаях (C/02), ложные
  срабатывания на живых сайтах разобраны в §4.

### 1.4. Калибровка (опыт C/03)

Stripe, Linear, Vercel — те же главные, что у ai-media `01/02` и 3d `01/04`. Байты за одинаковое окно (load + 8 с):
`effects_probe.py` против `site_probe.py` −0,1 % / −0,0 % / +2,1 %; TBT 152/155, 120/118, 35/42 мс; three r178 и два
контекста WebGL у Stripe — как у 3d. Вес сессии и LCP расходятся по понятным причинам (длина сессии, префетч по
наведению, шум LCP) — поэтому для сравнения с соседями берётся `kb_first`. [проверено]

## 5. WebGL, canvas и видео

- **WebGL-контекст создают 31 из 49 (63 %)**; рисуют в покое (≥ 1 вызов за кадр без прокрутки) — 20 (41 %): непрерывный

## 9. Reduced motion: пары «обычный / reduce» (десктоп)

Итог пары (`rm_pair`, критерии): **yes** — в reduce исчезает всё, что двигалось в обычном режиме: движение первого экрана
≤ max(0,3 %, 10 % исходного), бесконечные анимации 0, видео не играет, WebGL не рисует в покое, бегущая строка стоит,
активных твинов GSAP ≤ 20 %; **partial** — хотя бы одно из этого снизилось вдвое; **no** — ничего; **n/a** — первый экран
неподвижен и в обычном режиме.

| Итог (22 пары) | Страниц | Какие |
|---|---|---|
| yes | 4 | Stripe (лента-градиент: 2 → 0 вызовов, строка логотипов стоит, движение 9,9 → 0,01 %), kobzon.city (видео и CSS-петля стоят), K3 Fluid Studio (33 → 0 %), K3 Woven Fashion (строка стоит) |

| no | 13 | Anime.js, Baikal, Lama Lama, Linear, Lisa, MTS Media, Paul Kalkbrenner, Shopify Editions, Squarespace Foundations, USAvionix, Why Zero, K3 Nexus Auto, K3 Seaview Resort |

- **Уважают reduce 4 из 21 страницы с движением (19 %), частично — ещё 4** [проверено; один прогон]. Совпадает с соседями:
  ai-media — 4 из 16, 3d — 1 из 16 полностью и 2 частично; Stripe уважает во всех трёх замерах.

## Частые ошибки

Замер (агенты, K, генератор с самопроверкой):
- **Искать GSAP по `window.gsap`.** Бандл (ESM) глобал не ставит; признаки — `window.gsapVersions`, свойство `_gsap` у
  анимированных элементов, `.pin-spacer`, баннер «GSAP 3.x» в JS. Иначе GSAP «нет» у большинства наградных сайтов (§3).
- **Складывать видео-поток в «вес первого экрана».** Opal за окно load + 8 с получил 144 МБ видео из 147 МБ; без видео —
  2,6 МБ. Видео — отдельной колонкой (`video_kb_first`), бюджет — по `kb_first_nv`.
- **Сравнивать вес сессии разных утилит без выравнивания окна.** Одни и те же страницы: +16–18 % из-за длины сессии и
  префетча; сравнимо только окно `load` + N с (C/03).
- **Наводить курсор до фиксации веса.** Наведение на ссылки запускает префетч Next.js (Vercel +0,9 МБ).
- **Верить одному прогону LCP.** Stripe Payments дал 17,6 с при TTFB 16,9 с (сеть), Linear — 2,2 и 7,0 с в соседних
  прогонах; флаг `ttfb-slow`, повтор.
- **Считать scroll-driven анимации «бегущими в покое».** У них `playState: running`, но без прокрутки они стоят —
  бегущие считаются только по DocumentTimeline.
- **Считать H1 дисплейным заголовком.** H1 бывает мелкой подписью (14,4 px у kobzon.city), крупный текст бывает в canvas
  (Lisa, Locomotive) — флаги `h1-small`, `text-in-canvas?`, кегли не усреднять.
- **Мерить заставку вместо сайта.** Ворота «Enter» (Miu Miu): без клика ни прокрутки, ни эффектов; LCP при этом — экран
  ворот (так и надо записывать).
- **Выводить плавную прокрутку из текста JS.** Модуль Lenis может быть загружен, но не создан (в reduce-ветке, на части
  брейкпоинтов); признак — класс `lenis` на `html` и хвост прокрутки ≥ 1 с после шага колеса.
- **Путать бегущую строку и автослайдер.** Строка движется непрерывно (3 замера за 0,7 с, одинаковый шаг), слайдер —
  скачком; обоим по WCAG 2.2.2 нужна пауза, если движение длится > 5 с.
- **Считать `.ru` признаком прямого маршрута.** theterminala.ru хостится в Эстонии и идёт через VPN; `net` — по стране
  сервера.
- **Подделывать UA и прятать безголовость ради обхода антибота.** Правило базы — `blocked` и замена (Cartier —
  «Access Denied», Hobro — «Just a moment…»).

## Открытые вопросы и противоречия

- **Лаборатория против поля.** Все числа — один прогон на режим, пустой кэш, VPN; INP не измерен; CrUX по URL без ключа
  PSI закрыт (site M, 2026-09-24). Нужен ключ PSI или CrUX API в живой фазе для 10–15 страниц выборки.
- **Уровни предварительные.** Правило по приёмам (§12) взято из черновика A v0; K3 получает L2 за курсор и плавную
  прокрутку — уровню нужна проверка рубрикой K (волна 3), а бюджеты L2 первого экрана (≤ 4,0 МБ у A) ниже медианы
  замера (5,6 МБ без видео).
- **Видео в «весе первого экрана».** Opal: 37 видеозапросов, 144 МБ за окно `load` + 8 с, а `<video>` в DOM не найдены
  (вероятно, shadow DOM или MSE) — детектор видео не видит теневой DOM; число байтов верно (CDP), разбор элементов — нет.
- **JS эффектов не отделён от JS фреймворка.** Бюджет A «JS подачи» (L1 100, L2 200 КБ br) по сессии не проверяется;
  нужен разбор по источникам (URL библиотек) — задача G (волна 2).
- **Детекторы-эвристики**: split-текст (51 % — завышение возможно: навигации и списки из коротких блоков), свой курсор (Apple
  MacBook Pro — вероятно ложное), ворота (уточнены до «Enter/Start/Begin/Play»). Проверка вручную по листам — 10–15 страниц
  волной 3 (K).
- **Противоречие с соседями по LCP**: у нас медиана 2,0 с и 57 % ≤ 2,5 с, у ai-media — 3,2 с и 37 %, у 3d — 5,8 с.
  Причины: состав (продукт и студии против главных e-com и 3D-миров), день и сеть, окно прокрутки; повтор 10 страниц
  через неделю даст разброс.
- **CSS scroll-driven 2 из 49 против позиции базы «scroll-driven — основной инструмент подачи»** (`PLAN.md`, поправки):
  практика 2026-09 — ScrollTrigger (23 из 49); scroll-driven — прогрессивное улучшение с `@supports` (решает E и G).
- **«Золотой сайт» и Tagline**: победители 2024–2026 не получены (страница результатов «Такой страницы не существует»,
  Tagline — архив 2020–2023); русская группа собрана по «Рейтингу Рунета 2025».
