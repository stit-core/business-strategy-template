1. **Гарнитура — из `cyrillic-display-fonts.yaml` по роли и длине заголовка**, OFL по умолчанию; платные кириллические — опция заказчика. `[данные: D]` → §2
2. **Пары, проверенные в базе**: Literata (display, opsz) + Golos Text; Commissioner на осях (FLAR, VOLM) одной семьёй; Science Gothic по ширине 58–62 % + Onest. `[проверено: J/00–03, D/02]` → §2
3. **Кегль — `clamp()` с max ≤ 2,5 × min** (WCAG 1.4.4), H1 ≤ 3 строк на 1440 и ≤ 4 на 390 (kimi T8). `[проверено]` → §5
4. **Трекинг кириллицы — не туже касания**: Golos −0,03 em (касание −0,04), Onest ≥ −0,01, Literata ≥ 0 (засечки касаются при 0). `[проверено]` → §5
5. **Висячие предлоги и союзы — `&nbsp;`** (MKT-T5), переносы только в display на узких экранах и только при `lang="ru"`. `[проверено: D; K]` → §5
6. **Метрический фолбэк обязателен, оба подмножества шрифта первого экрана (cyrillic + latin) — preload**: цифры, «», —, двоеточие берутся из latin; без предзагрузки CLS загрузки 0,15. `[проверено: F2, J/00]` → §6
7. **Кинетика одного заголовка — ось ширины по прокрутке** (Science Gothic wdth 60 → 100 %), не побуквенный split: смысл «разворачивается». `[практика; F kinetic-headline]` → §5
8. **Тильда: Zero Block + T123**, свой CSS и шрифты — файлами на своём хостинге, анимация Zero на телефоне по умолчанию выключена. `[документация: G 02 §10]` → §7
9. **Тексты — голос школы, не «инфобиза»**: без обратных отсчётов и «осталось 3 места» без факта (38-ФЗ). `[практика: text, site]` → §4

## 1. Бриф и уровень

`page_type: landing-course`, `budget_profile: landing-course@L1`, `constraints.cms: tilda` (типично для онлайн-школ рунета); трафик —

## 2. Концепция и шрифт

- **Тезис** (образец для школы редакторов): «Заголовок, который дышит смыслом: главное слово курса раскрывается по ширине, пока вы
  читаете программу — от сжатого черновика к развёрнутому тексту».
- **Выбор гарнитуры** (D): длинные русские слова («редактирование», «профессионального») → узкий или переменный по ширине display;
  Science Gothic (wdth 50–200, k 0,69 при 100 %) для кинетики; Sofia Sans Extra Condensed (k 0,349) — если заголовки длинные и без
  кинетики; антиква Literata — если школа «про текст» и нужна книжность (одно тёплое направление максимум).
- **Направления**: «Черновик → текст» (выбран: тёмно-тёплая бумага, узкий гротеск на осях), «Корректура» (белая бумага, антиква,
  красная правка), «Тетрадь» (клетка, рукописный акцент — только как отсылка).

## 6. Код (фрагменты)

```css
/* Chrome 153 · Safari 26 · Firefox 159 · без SDA — статично · 2026-09-25 · [не проверено: пример не собран; ось ширины — J/02 (Science Gothic 60 %)] */
.hero__word { font-family: "Science Gothic", "Science Gothic fallback", sans-serif; font-weight: 760; font-stretch: 100%; }
@supports ((animation-timeline: scroll()) and (animation-range: 0% 100%)) {
  @media (prefers-reduced-motion: no-preference) {
    .hero__word { animation: widen linear both; animation-timeline: scroll(root); animation-range: 0 60vh; }
  }
}
@keyframes widen { from { font-stretch: 60%; } }
```
Фолбэк Science Gothic при wdth 60: `size-adjust 99.54%; ascent-override 109.3%; descent-override 38.98%` (J/00, против Liberation Sans Bold).

## 7. Тильда — как собрать

- Hero — Zero Block: заголовок — текстовый элемент с классом `hero__word` (поле CSS class name); шрифт — файлы woff2 на своём хостинге
  и `@font-face` в T123 в head страницы (не «Шрифты» Тильды, если нужна ось ширины) `[документация: G 02 §10; не проверено на опубликованной]`.
- Кинетика — CSS из §6 в T123; Zero «On Scroll» для ширины шрифта не подходит (Move, Scale, Opacity, Rotate — без осей).
- Программа — стандартный блок Тильды + CSS SDA в T123; на телефоне Zero-анимация выключена по умолчанию — наш CSS работает везде.
- Проверка — только на опубликованной странице; вес платформенных скриптов Тильды — в воротах страницы site.

## 8. Решения о клише

| id | Приём | Решение | Почему |
|---|---|---|---|
| d-variable | `cliche:variable-axis-gimmick` | twist | ось ширины несёт смысл «черновик → текст» и работает у одного слова |
| d-caps | `cliche:caps-eyebrow` | avoid | надзаголовки обычным регистром (RU по умолчанию, токен `--type-eyebrow`) |
| d-giant | `cliche:giant-display-type` | twist | гигантский кегль у одного слова курса, не у декоративного вордмарка |

## Частые ошибки

1. Montserrat/Roboto «по умолчанию» (`cliche:overused-display-font`) — гарнитура не выбрана, а взята.
2. Трекинг −0,05 em у кириллического display — буквы слипаются (у–х касаются).
3. Только кириллическое подмножество в preload — цифры и кавычки прыгают при загрузке (CLS 0,15, F2).
4. Побуквенный split каждого заголовка — `cliche:split-text-reveal`, LCP врёт (E/01).
5. «Осталось 3 места» и таймер без факта — ложная срочность.

## Открытые вопросы и противоречия

- `font-stretch` в `@keyframes` с `scroll()` в WebKit 26.6 не проверен кадрами (ось ширины анимировалась у нас только статично).
- Платные кириллические display (type.today, ПараТайп) — лицензия на веб и ИИ-генерацию страниц — решение заказчика (вопрос 7 PLAN).
