## 6. Эффекты, стек и код

Эффекты: `effect:hero-entrance-once` (L0, 0,1 КБ), CSS-отклик; `effect:details-accordion` (F2) — без анимации высоты. Стек:
HTML + CSS, один встроенный скрипт 0,5 КБ; GSAP, Lenis, WebGL — запрет L0 (`ambition-levels.yaml`). Отметки плана — SVG: сдвиг
`translate` стоит на внешней группе, анимация `scale` — на внутренней, иначе масштаб тянет отметку из угла SVG `[проверено]`.

```css
/* Chrome 153 · WebKit 26.6 · 2026-09-25 · [проверено] появление первого экрана без JS */
@media (prefers-reduced-motion: no-preference) {
  .hero__lead, .hero__proof, .hero__actions { animation: rise var(--motion-marketing-duration-reveal) var(--motion-marketing-easing-out-expo) both; }
  .hero__proof { animation-delay: 110ms; }  .hero__actions { animation-delay: 160ms; animation-duration: 440ms; }
  .mark { animation: mark-in calc(var(--motion-marketing-duration-reveal) / 2) var(--motion-marketing-easing-out-expo) both; animation-delay: calc(80ms + var(--i) * 40ms); }
}
@keyframes rise { from { opacity: .01; transform: translateY(var(--motion-marketing-distance-shift-reveal)); } }
@keyframes mark-in { from { opacity: .01; scale: .5; } }
```

```js
/* Chrome 153 · 2026-09-25 · [проверено] липкий призыв на телефоне: прячется, пока видна кнопка первого экрана или форма */
const bar = document.querySelector('.sticky-cta'), seen = new Set();
bar.classList.add('is-off');
const io = new IntersectionObserver((es) => { es.forEach((e) => e.isIntersecting ? seen.add(e.target) : seen.delete(e.target));
  bar.classList.toggle('is-off', seen.size > 0); });
io.observe(document.querySelector('.hero__actions')); io.observe(document.querySelector('.form'));
```

## 10. Ветки

### 10.1. Ветка L1 — «Отвес» (тёплый трафик, высокий чек)

Готовая спецификация — I: `../09-ai-execution-evaluation/examples/otves-home.treatment.yaml` и `otves-home.motion-spec.yaml`
(линия-отвес в `how-it-works`, CSS scroll-driven, 0 КБ JS; станции по якорям, допуск ±24 px зондом `shoot_stations.py`

с весом первого экрана телефона как у L0 (1,5 МБ). Форма, калькулятор, цена — L0 (A `section_caps`).

### 10.2. Тильда (`constraints.cms: tilda`)

- Первый экран и секции — Zero Block; появление первого экрана — Zero «Step-by-step» с `Element on Screen` ≤ 600 мс, **на телефоне
  анимация Zero выключена по умолчанию** — включить явно или оставить без неё (L0 допускает) `[документация: G 02 §10]`.
- План с отметками — SVG в HTML-элементе Zero; отметки CSS-анимацией в блоке T123 (код §6), без JS.
- Липкий призыв — блок Тильды «кнопка внизу экрана» или T123 со скриптом §6; проверка — только на опубликованной странице.
- Вес Тильды (свои скрипты платформы) в бюджет подачи не входит, но входит в вес страницы — ворота site `[документация: G 01 §10]`.

### 10.3. 1С-Битрикс (`constraints.cms: 1c-bitrix`)

- Код подачи L0 — CSS шаблона + один встроенный скрипт; если скриптов больше — **один собранный файл** через
  `Asset::getInstance()->addString('<script type="module" src="…/dist/fx.js">')` (`addJs` не гарантирует порядок) `[документация: G 02 §10]`.
- Композитный кэш и «объединение JS» ядра — проверить, что `html.js` ставится до стилей (иначе появление без JS-ветки).

## Частые ошибки

1. Hero «ремонт под ключ»: фото прораба на весь экран под вуалью, белый текст — `cliche:hero-media-veil`, доказательство спрятано.
2. Счётчики «0 → 147» и «0 → 7 900 ₽» — движение ради движения на цифрах, которые человек сравнивает (генераторы, K3).
3. Появление каждой секции fade-up — у K3 6 из 15 работ прячут ≥ 10 % элементов (E 05/02 §2.1); на L0 — ни одного.
4. Анимация H1 из `opacity: 0` или split — LCP врёт (E/01); на телефоне LCP может стать лидом — не прятать и его.
5. `interpolate-size` для FAQ — высота = свойство раскладки: MKT-M2 и схема motion-spec v1 это ловят; проявлять ответ opacity.
6. `font:` шорткат после `font-variant-numeric` — цифры в таблице цен теряют `tabular-nums` (H12, пример J/01, два прогона).
7. Липкий призыв на телефоне с первого кадра рядом с кнопкой hero и шапки — три призыва в одном экране.
8. Отзывы и «1 200 довольных клиентов» без фактов — демо-страница без фактов обходится без отзывов (правило text: факты до текста).
9. Тильда: проверка анимации в редакторе, а не на опубликованной странице; Zero-анимация на телефоне «пропала» — выключена по умолчанию.
