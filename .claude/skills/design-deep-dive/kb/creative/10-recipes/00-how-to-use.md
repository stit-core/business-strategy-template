## Выжимка для агента

1. **Рецепт — не шаблон страницы, а маршрут решений**: бриф → уровень → концепция → мудборд → план site → treatment и motion-spec →
   эффекты → ассеты и тексты → стек → бюджет и ворота. Каждое решение — ссылкой на файл-владелец. `[практика]` → §1
2. **Выбор рецепта — по `page_type` и уровню** (таблица §2), затем по трафику и чеку: горячий мобильный — ниже уровнем. `[практика: A]` → §2
3. **Три рецепта `verified`** (01 L0, 02 L1, 03 L2) — у них есть код, прошедший ворота K (перепрогон J2: motion_check 0.1.3, ворота
   v0.2 — B 0, S 0, D 0 у всех трёх); остальные `proposed` — собрать пример и прогнать ворота до выдачи заказчику. `[проверено: J/01–05]` → §3
4. **Два рецепта подряд на одного заказчика — ≥ 4 из 8 осей отличны** (журнал H); у 10 рецептов базы — 45 пар, 0 пар < 4. `[проверено: recipe_check]` → §4
5. **«Прошёл ворота K» = 0 FAIL B и 0 FAIL S**; S снимается только `x-gate-exception {id, why, who, until}` с доказательством. `[практика: K]` → §3
6. **Смотри кадры глазами** и отвечай честно: «сильная студия» или «сделано нейросетью»; для L2 — попарно с якорями (рубрика K). `[мнение]` → §3

## 3. Проверка результата

```bash
# из корня creative-research/; утилиты берут обе блокировки браузера сами
python3 ../../scripts/creative/motion_check.py <страница> --level L1 --out <папка> --spec <motion-spec.yaml>
python3 ../../scripts/creative/marketing_audit.py <страница> --level L1 --out <папка> --name <имя>
99-raw/tools/venv-I/bin/python ../../scripts/creative/spec_check.py spec <motion-spec.yaml>
99-raw/tools/venv-J/bin/python ../../scripts/creative/recipe_check.py 10-recipes/recipes/*.recipe.yaml --ledger <out.md>
```

Ложные срабатывания K 0.1 (отчёт J §3): рендер WebGL во время прокрутки считался петлёй (EG-A11Y-16/17), станции fixed-холста мерились
по краю холста, `motion.js` переключателя в reduce считался библиотекой (EG-A11Y-11) — **исправлено K2 в 0.1.2–0.1.3** (два снимка в
паузе, станции холста кадром, скрипт переключателя исключён); спорный случай холста по-прежнему доказывается зондом
покоя (два снимка счётчика вызовов WebGL в одной паузе). Осталось в 0.1.3 (отчёт J §11.3, §11.8): станции цели внутри sticky-слоя — ложные FAIL
сверки spec (L1 «Сверка» — 9; сверять кадром станции), EG-A11Y-25 — N/A у одной кнопки `aria-pressed` «Меньше движения».

Текст над живым фоном (видео, шейдер, 3D) — `motion_check.py … --f83 "h1" --contrast "h1" ".hero__lead"` (0.1.3: EG-A11Y-26 — F83 по
буквам, EG-A11Y-27 — худший кадр живого фона; у L2 «Звено» v1 так найден H1 1,0:1 на телефоне). `page_accept.py --contrast` напрямую —
только если стили и медиа страницы лежат в её папке: иначе страница меряется без CSS (K2).

## 4. Журнал вариативности

`recipes/variation-ledger.md` — 8 осей H (бумага, стиль display, оттенок акцента, макроструктура, архитектура hero, главный приём,
подпись движения, язык углов) для 10 рецептов; пар с различием < 4 осей — 0 из 45. Для нового проекта того же заказчика: добавить
строку, запустить `recipe_check.py`; меньше 4 отличий — пересобрать направление (H 02 §3.3, «хвост, а не медиана»).

## Частые ошибки

1. Взять рецепт как вёрстку и сменить цвета — это 1 ось из 8; рецепт задаёт решения, а не внешний вид.
2. Пропустить шаг 2 (тезис словами) и начать с эффектов — получится «средний Awwwards».
3. Поднять уровень всей страницы ради одного приёма — конверсия и внутренние шаблоны остаются L0.
4. Считать зелёный `motion_check` доказательством «вау» — ворота ловят вред, эффектность — рубрика K и глаза.
