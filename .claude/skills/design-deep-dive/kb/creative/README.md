## Как пользоваться (для агента)

Единица базы: папка → `README.md` (файлы и выжимка на 10 строк) → файл → «Выжимка для агента» (15–40 правил с меткой и `→ §`) →
разделы → «Частые ошибки» → «Чек-лист» → «Открытые вопросы и противоречия» → «Источники». Обозначения: `05/01 §3.2` — папка 05,
файл 01, раздел 3.2; `X-17` — пункт `CONTRADICTIONS.md`; `effect:<id>` — запись `06-effects-catalog/effects.yaml`; `cliche:<id>` —
запись `08-uniqueness-anti-slop/cliche-registry.yaml`; `block:<id>` — блок site (`../site/04-blocks/blocks.yaml`); `EG-…`
— ворота `09-ai-execution-evaluation/effect-gates.yaml`; `MKT-…` — проверка профиля `marketing`;
`CRV-AL/CD/AD/MO/CH/PF/CL/UV/TR/MS/REF/MB/SRC-…` — пункты чек-листов файлов (префикс тройки `CRV-`); `[V:<id> mm:ss]` — дайджест
`91-videos/digests/<id>.md`; `[проверено]` — опыт `99-raw/experiments/F/04-…`. Уровни и роли секций — по словарю site
(`../site/02-site-types/vocabulary.yaml`). Одна норма — одно место: бюджеты уровней — `ambition-levels.yaml`, ворота

## Выжимка: 48 правил по этапам «уровень → концепция → референсы → язык → движение → эффекты → стек → клише → спецификация → проверка → рецепты»

В основном блоке метки не слабее `[консенсус]`, `[проверено]`, `[стандарт]`, `[документация]`, `[данные]`, `[исследование]` (у
составного правила — метка каждой части; `[не проверено]` рядом — какая часть ждёт живой фазы). `{L0–L2}` — где действует; `→` —
файл и раздел. Практика и решения заказчика — блок П1–П8 в конце.

**Уровень и бюджет**

1. **На всех уровнях — CRV-AL-01…11**: reduce-вариант, пауза петель дольше 5 с рядом с контентом, ≤ 3 вспышек в секунду, смысл и
   CTA в HTML (LCP — не canvas), фолбэк без WebGL и JS, телефонная версия, фокус ≥ 3:1, F83 на медиа, «вау» после LCP, стоп вне
   экрана, конвенции; на L2 — ещё переключатель «меньше движения». `[стандарт: WCAG 2.2]` `[практика]` {L0–L2} → `01/03` §2.3
2. **Исходы CWV одни на всех уровнях**: LCP ≤ 2,5 с, INP ≤ 200 мс, CLS ≤ 0,1 на p75 поля («плохо» — 4 с, 500 мс, 0,25); «вау»
   платит весом и TBT, а не LCP. `[документация: web.dev]` {L0–L2} → `01/03` §4.3–4.4
3. **Бюджет — два слоя, числа не копировать**: «подача» (JS эффектов 20 / 100 / 150–200 КБ br, 3D отдельно) —
   `ambition-levels.yaml`, «страница» — site `budgets.yaml`; в документе — профиль `<page_type>@L<n>` и траты с `load` (`eager` —
   только LCP). `[документация: site P]` `[проверено]` {L0–L2} → `01/03` §4.1–4.2

**Концепция и направления**

4. **Концепция — словами до эффектов**: механизм, сцена аудитории, что доказывает первый экран, тезис ≤ 240 знаков; эффект без
   строки «связь с концепцией» не выбирается; колею категории и её противоположность — назвать и исключить, буквальное прочтение
   имени — не больше одного кандидата (было в 5 из 5 брифов). `[практика]` `[мнение вендора: impeccable]`
   `[проверено: A/01 — 5 брифов]` {L0–L2} → `01/01` §1–4
5. **3–5 направлений (умолчание 4)**: пары различаются ≥ 2 осями из 4 (бумага, стиль заголовков, тон акцента, макроструктура);
   тёплая бумага или антиква — не больше чем у одного; одна рекомендация. `[документация: Anthropic]`
   `[консенсус: ui, kimi, impeccable]` `[проверено]` {L0–L2} → `01/01` §6–7; X-29

7. **Конвенции взаимодействия не ломать**: логотип слева ведёт на главную (центрированный — провал возврата в 6 раз чаще),

8. **Хвост вместо медианы**: 8 направлений с оценкой типичности → 3–5 наименее типичных; проекты подряд различаются ≥ 4 из 8 осей
   журнала вариативности (смена палитры — одна ось). `[исследование: на тексте]` `[проверено: recipe_check, 45 пар]`

## Получится ли «как Unseen»

Unseen (unseen.co, illoca.unseen.co, hubtown.co.in) в рубрике K — потолочный якорь L2 по концепции, ремеслу и движению, но не по

«Звено» (рецепт 03, three.js 0.186.1, 3D только кодом) проходит ворота K без исключений — B 0, S 0, D 0 на `motion_check.py` 0.1.3
(LoAF 0,23 %, CLS 0, один контекст, 0 вызовов в покое, LCP — постер своего рендера) — и весит 0,365 МБ за сессию, в 20–60 раз
меньше якорей `[проверено]`. После светового прохода J2 (8 приёмов за +1,5 КБ br: студия для PMREM, лак и сатин,
мягкая тень, пол-циклорама, фон со свечением, свет по сюжету) **свет и материал у кода — уровень уверенного предметного рендера**
(craft рендера 3 → 4; concept 4, motion 4, clarity 5; против Illoca — победа или ничья в 2 из 3, против hubtown — в 1 из 3)
`[мнение: J2, один судья]`. **Отстают мир вокруг продукта (окружение, туман, свечение, вода) и детализация модели** — их закрывают
ассет (CAD), запечённый свет Blender и KTX2 плюс решение «мир вокруг продукта» в `art-direction`
(`10-recipes/03-product-launch-l2.md` §9.1). **Ответ заказчику:** идею, ясность, движение и исполнение (вес, reduce, доступность)
система делает кодом уже сейчас и по исполнению обходит Unseen; «мир» и фактуру модели — только с ассетом и Blender (для L2 —

## Как обновлять

Процедуры — `PLAN.md` «Как расширять базу». Коротко: число живёт в одном машиночитаемом месте (YAML, токены, схема), тексты
ссылаются на него; `effects.yaml` правится по месту: схема `effects.schema.json` описывает поля, сверка — `../../scripts/creative/registry_check.py` и
`../../scripts/creative/spec_check.py levels --check`, схема проходит метасхему при приёмке правки (`../../scripts/maint/accept.py`); после
правок — `python3 ../../scripts/maint/check_links.py` (0 новых ERROR); скоропортящееся
— с версией и датой.
