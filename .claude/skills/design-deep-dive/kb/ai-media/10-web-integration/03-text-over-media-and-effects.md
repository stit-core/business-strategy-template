    `[проверено]`.

17. **Параллакс слоёв — `animation-timeline: scroll(root)` в `@media (prefers-reduced-motion: no-preference)` и `@supports`**:
    подложка отстаёт (≈ 40 %, W5), объект уходит быстрее; без поддержки — просто статика → §4.4 `[проверено: страница 03]`.
18. **2.5D на любом цвете секции — объект с альфой + слой тени multiply**: RGB-слой отношения «кадр / чистая подложка» —

    `[проверено]`.
19. **Движение по указателю — только `(hover: hover) and (pointer: fine)` и без reduce**; эффекты, запускаемые
    взаимодействием, отключаемы (WCAG 2.3.3, AAA) → §5 `[документация; проверено: J/06]`.
20. **Метка ИИ поверх кадра — компонент L** (иконка ЕС в правом верхнем углу, 24 px минимум, контраст 10–18 : 1) — не путать со
    скримом текста; её тоже проверять F83 → §6 (`../12-legal-provenance/02` §7.1).

## 1. Контраст на странице: F83 «по буквам» и по кадрам

### 1.1 Метод двойного снимка (`page_accept.py`, функция `f83`)

1. Прокрутить элемент в вид; снимок области элемента + 2 px — с текстом.
2. Добавить класс `color: transparent !important; text-shadow: none` — снимок того же места без текста (фон как есть: скрим,
   зерно, картинка, кадр видео).
3. Маска букв = пиксели, где снимки различаются больше 24 уровней; расширить на 1 px (сглаживание краёв).
4. Цвет текста — вычисленный (`getComputedStyle`), а при `opacity`/альфе < 1 — отрисованный (медиана 30 % «самых текстовых»
   пикселей).
5. Контраст WCAG (относительная яркость) цвета текста к **каждому** пикселю фона под маской → худший (F83 шаг 2), p1, p5;
   порог 4,5 : 1, крупный текст (≥ 24 px или ≥ 18,66 px жирный) — 3 : 1.

`[проверено: J/06 — 9 страниц × 2 режима]` Это строже Quickcheck F83 по всей полосе (F, `03` §2.3) и точнее «до вёрстки»:
учитывает реальный шрифт, переносы, брейкпоинт, скрим и зерно.

### 1.2 Видео: худший кадр

- При видео-фоне шаги 1–5 повторяются на кадрах 0 / 25 / 50 / 75 % длительности (пауза, `currentTime`, `seeked`); итог —
  минимум по кадрам; после проверки видео снова играет `[проверено]`.
- Пример (страница 02 до скрима, лид 20 px): 4,79 / 4,71 / 4,53 / **4,28** — блик ряби на кадре 4,5 с под буквами; на
  картинке-постере (страница 01) — 4,55 → **проверка на постере не заменяет проверку по кадрам** `[проверено]`.
- Четырёх кадров мало для быстрого движения (вспышки, яркие объекты в кадре): для таких петель — шаг 0,5 с (K) `[мнение]`.

### 2.2 Скримы (CSS страниц `pages/`)

```css
/* светлый скрим под колонкой тёмного текста (кадр светлый) · [проверено: pages/01, 02, 00 — F83 ≥ 6,2] */
.hero--light .hero__scrim { background: linear-gradient(90deg, rgb(243 239 231 / .46) 0%, rgb(243 239 231 / .34) 40%, rgb(243 239 231 / 0) 64%); }
@media (max-width: 699px) {           /* телефон: текст сверху — скрим сверху вниз */
  .hero--light .hero__scrim { background: linear-gradient(180deg, rgb(243 239 231 / .40) 0%, rgb(243 239 231 / .28) 55%, rgb(243 239 231 / 0) 75%); } }

/* тёмный скрим под светлым текстом (ночной кадр) · [проверено: pages/04 — кикер 13 px 5,14; H1 7,28] */
.hero__scrim { background: linear-gradient(180deg, rgb(10 12 16 / .55) 0, rgb(10 12 16 / 0) 140px),       /* под навигацию */
                          linear-gradient(90deg, rgb(10 12 16 / .62) 0%, rgb(10 12 16 / .42) 42%, rgb(10 12 16 / 0) 68%),
                          linear-gradient(0deg, var(--paper) 0, rgb(0 0 0 / 0) 120px); }                  /* в цвет секции ниже */
@media (max-width: 699px) {
  .hero__scrim { background: linear-gradient(180deg, rgb(10 12 16 / .80) 0%, rgb(10 12 16 / .68) 50%, rgb(10 12 16 / .15) 72%, rgb(10 12 16 / 0) 84%),
                            linear-gradient(0deg, var(--paper) 0, rgb(0 0 0 / 0) 96px); } }
```

- Цвет скрима — нейтраль паспорта (`post.scrim.color`, F `01` §7.3): тёмная для светлого текста, «бумага» секции для тёмного;
  серый `rgb(0 0 0 / .5)` на всё — «серая коробка» (F/02) `[проверено глазом: F; J]`.
- Положение: полная альфа — на всю ширину колонки текста, спад — к объекту; у края кадра под навигацией — отдельный
  короткий градиент сверху (140 px) `[проверено]`.
- Цвет текста выбирать по зоне: на рассветном кадре тёмный текст без скрима проходит мелкий кикер (8,5), белый — нет (F/02:
  белый текст без подложки 0/32) `[проверено: J/06; F]`.

### 2.3 Мелкий текст решает альфу

- В одной зоне кикер 13 px (порог 4,5), H1 68 px (порог 3) и лид 20 px (4,5): скрим, достаточный для H1, проваливает кикер —
  на 04 3,89 при 5,43 у H1 → альфу считать по **самому мелкому** тексту зоны; кикер капсом с разрядкой 0,14em тонок, как
  обычный текст `[проверено]`.

### 2.4 Когда скрим — не выход

- Контрастные детали под строкой (ветви, провода, блики, край холма): поднимать альфу до «проходит» — значит закрыть кадр;
  дешевле сдвинуть фокус (`object-position`, `01-…` §3.2), сузить колонку, опустить строку или взять другой кадр
  (F: «busy background — not ever», автор APCA) `[проверено: J/06; мнение APCA через F]`.
- Текст-обводка и тень (G18: ореол ≥ 1 px) — допустимы как страховка мелкого текста поверх видео, но не как основной приём
  `[документация через F]`.

## 3. Состояния и темы

- Смена состояния (ночь → рассвет) меняет и цвет текста: `.hero.is-dawn { color: #111418 }`, другой скрим (светлый) — оба
  состояния проверять F83: `page_accept.py … --click "[data-state-toggle]" --contrast …` → рассвет: H1 6,28 / лид 8,29 / кикер
  9,55 (десктоп), 14,94 / 11,64 / 10,27 (Pixel 7) `[проверено]`. Клик сразу после `load` — это ввод: LCP перестаёт
  записываться (в десктопном прогоне с кликом записей LCP нет) → вес и LCP мерить отдельным прогоном без клика.
- Тёмная тема страницы (`prefers-color-scheme: dark`) не меняет кадр hero, но меняет `--paper` (градиент в цвет секции) —
  прогон `--dark`: страница 00 — 6,23 / 7,47 / 9,50, как в светлой `[проверено]`.

### 4.4 Параллакс слоёв (страница 03)

```css

@media (prefers-reduced-motion: no-preference) {
  @supports ((animation-timeline: scroll()) and (animation-range: 0% 100%)) {
    .layer--back { animation: back linear both; animation-timeline: scroll(root); animation-range: 0 100vh; }
    .object, .shadow { animation: front linear both; animation-timeline: scroll(root); animation-range: 0 100vh; }
    @keyframes back { to { transform: translateY(24vh); } }       /* ≈ 40 % медленнее страницы (W5) */
    @keyframes front { to { transform: translateY(-12vh); } } } }
```

- Без JS, без обработчика прокрутки, в композиторе; без поддержки (`@supports`) и при reduce — статика `[проверено: Chromium
  153; документация MDN]`; параллакс за курсором (страница 07) — `transform` по `pointermove`, только `hover: hover` и без reduce.
- Глубина из картинки (Depth Anything V2 Small через Transformers.js, 19–99 МБ весов, H) для 2.5D на странице — не мерилась;
  по весу — только «по требованию», не в первом экране `[не проверено]`.

### 4.5 Объект с альфой и тень на цвете секции (2.5D, страница 07)

```css
/* pages/07 · [проверено: J/07 — Chromium multiply = расчёт, ΔE00 p99 ≤ 2,2] */
.stage2d { position: relative; isolation: isolate; background: #e9e2d6; }          /* любой цвет секции */
.stage2d .shadow { mix-blend-mode: multiply; }                                       /* слой тени AVIF 7,3 КБ (RGB) */
```

| Слой тени (эталон Blender H/00: банка и мяч, точные альфа и чистая подложка) | Восстановление на исходной подложке, ΔE00 медиана / p99 | AVIF |
|---|---|---|
| серый (среднее по каналам) | 0,50 / 11,3 (теряет красный рефлекс банки на полу) | 5,2 КБ (4:0:0) |
| **RGB** | **0,0 / 3,1** | 7,3 КБ (4:4:4) |

- Рецепт: `shadow = кадр / чистая подложка` вне объекта (под полупрозрачным краем — от ближайшего соседа снаружи),
  объект — с деконтаминацией края `(кадр − (1 − α)·подложка·тень) / α`; скрипт — `99-raw/experiments/J/07-shadow-layer/make_shadow.py`
  (ответ на вопрос H `08/01` §6) `[проверено]`.
- Нужны кадр на ровном фоне и тот же фон без объекта (рендер или правка удалением с широкой маской, H) — у генерации это «две
  картинки из одной» (W5) `[практика; не проверено генерацией]`.

## 5. Доступность эффектов

- Автодвижение > 5 с — пауза (WCAG 2.2.2, `02-…` §5); эффекты по взаимодействию (прожектор, параллакс по прокрутке и указателю)
  — отключаемы (2.3.3, AAA) → при reduce параллакс и переходы выключены, прожектор остаётся (прямое управление, без
  автодвижения) `[документация W3C; ux-research 06/03 §7]`.
- Прожектор недоступен с клавиатуры и касанием → то же содержание — кнопкой состояния (`aria-pressed`) `[проверено]`.
- Подсказка «Курсор открывает рассвет» — только при `hover: hover` `[проверено: страница 04]`.

## 6. Метка ИИ поверх кадра

- Видимая метка для дипфейков (аудитория ЕС) — иконка ЕС «AI GENERATED/MODIFIED» в правом верхнем углу кадра, кнопка с
  `popover`-пояснением, ≥ 24 px, контраст 10–18 : 1, площадь 0,35 % кадра на десктопе и 2,1 % на телефоне (L/03); код и тексты —
  `../12-legal-provenance/02-labeling-ai-act-provenance.md` §7 [L]. На шаблонах J меток нет: сюжеты — природа без людей, не
  дипфейк (L §2); при добавлении — прогнать `page_accept.py --contrast ".ai-label"` и проверить, что метка не перекрыта скримом.

## Частые ошибки

- Проверять контраст по средней яркости зоны или на постере при видео-фоне.
- Один горизонтальный скрим на все брейкпоинты (на телефоне текст уезжает на небо).
- Скрим по H1, а кикер 13 px проваливается; белый текст «по умолчанию» на светлом кадре.
- Поднимать альфу до «проходит» над ветвями и бликами вместо сдвига фокуса.
- Прожектор без кнопки для касания и клавиатуры; обе петли грузятся сразу; экран-заставка.
- Зерно в файле (съест кодек) или поверх текста; data-URI SVG в `style="…"` с двойными кавычками.
- Параллакс на `scroll`-обработчике JS без reduce; серая тень выреза у цветного объекта.
- **Ошибки нейросетей-агентов**: «ACT afw4f7 прошёл — значит контраст есть» (это необходимое условие, F); «4,499 ≈ 4,5»;
  «text-shadow решает всё»; «mix-blend-mode multiply в браузере не совпадает с Photoshop» (совпадает с sRGB-расчётом, J/07);
  «CSS-градиент бандит так же, как картинка» (Chromium дизерит CSS).

## Открытые вопросы и противоречия

- APCA (Lc) не считался: для фото метода нет ни у WCAG, ни у APCA (F); F83 по буквам — строгий, но бинарный.
- Четыре кадра на петлю — компромисс времени проверки; для быстрого движения нужна плотная выборка (K).
- Тёмная тема прогнана только на странице 00; состояние «рассвет» — на 04 (оба PASS).
- Параллакс и прожектор в Safari/Firefox (`animation-timeline`, `@property`) — не проверены; без поддержки — статика.
- Глубина в браузере (Transformers.js) — вес и LCP не мерились.
