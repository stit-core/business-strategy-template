## Выжимка на 10 строк

1. Выход модели не публиковать: AVIF по SSIMULACRA2 ≥ 80 (hero) / ≥ 70, WebP-запас через `<picture type>`; hero 1920 — 90 КБ.
2. Телефону — отдельный мастер 4:5 через `<source media width height>`, `object-position` — по фокусу формулой F.
3. Картинка, видимая часть которой = вьюпорт, не LCP (тогда LCP = H1); < 0,05 бит/px — тоже; из `opacity: 0` — тоже.
4. LCP-картинка: в HTML, без lazy (при конкуренции lazy — 21,7 с против 2 с), `fetchpriority="high"`, ≤ 150/80 КБ.
5. Видео-hero = `<picture>`-постер (кадр 0 финального AV1 через Pillow) + видео-слой после `load`; AV1 → H.264; HEVC — только альфа.
6. Видео кодировать с полными тегами BT.709 (`setparams`), иначе цвет в браузере «уезжает» на ΔE00 ≈ 8; постер не `ffmpeg … .jpg`.
7. reduce/Save-Data/2G — 0 байт видео (`data-src`, `preload="none"`); автоповтор дольше 5 с в сумме (любая бесконечная петля, даже 2 с) — кнопка паузы или стоп ≤ 5 с.
8. Тихую петлю кодек «замораживает»: `motion_keep ≥ 0,75` → AV1 CRF 24–28 (не 36), H.264 18–20.
9. Контраст — F83 по буквам на странице (десктоп, телефон, кадры видео); скрим по самому мелкому тексту и по оси текста.
10. Альфа-видео — stacked AV1/HEVC/H.264 + WebGL2 (12,5 КБ), зерно — SVG в CSS, тёмные градиенты — CSS (Chromium дизерит).
    [поправка фазы 5, 25.09.2026: «мышь ведёт видео» на живом облёте — секвенция AVIF (0 отставания, 1 250 КБ, ≈ 214 МБ кадров) или
    AV1 GOP 4 (998 КБ, отставание 2–5 кадров); петля 8 с — AV1 CRF 28 1 011 КБ, пульс стыка 0,8 → 2,4; прожектор — только на
    совмещённых кадрах; шрифт с кириллицей без пакетов — 72 КБ WOFF2 → `../14-recipes/04-capability-map.md` §2.8]
