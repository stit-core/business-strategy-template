## Выжимка на 10 строк

1. Петлю принимать по шву **и** «живости»: `seam_ratio_local` ≤ 1,5 после среза и `motion_vs_control` ≥ 0,5 к i2v того же кадра.
2. FLF [A,A] → срез последнего кадра по построению; круговой стык цепочки → оба конца; мерить на выходе модели или мезонине без потерь (`-qp 0` 4:4:4): CRF 10 превращает чистый шов 0,96 в 2,08 (X22).
3. Разрыв — кроссфейд хвоста 12 кадров (`blend` с `+0.5`); пинг-понг — только симметричное движение; RIFE — не для текста.
   [поправка фазы 5, 25.09.2026: на крупной форме кроссфейд даёт «фантом» (двоение) при шве 1,46–1,76 → RIFE-мост 8 кадров
   последний → первый: 0,69–0,84, 1080p — 0,41; пинг-понг — 0,66–0,74 → `../../../scripts/ai-media/loop_rife_bridge.py`]
4. Камера в петле стоит (`fixed_lens` Seedance 1.5 Pro или «Locked camera»); ползущую камеру маска и кроссфейд не лечат.
5. Ключ по оттенку объекта: золото и зелень — пурпурный; кеер `chromakey` по медиане фона; despill `geq` G ≤ max(R, B).
6. Альфа-видео 2 с: stacked AV1 10,5 КБ, VP9-alpha 16–30 КБ; libx265 альфу молча теряет; VP9-alpha читать libvpx.
7. Кодирование: AV1 первым `<source>` (0,32× H.264), H.264 запасом; CRF — по `motion_keep` ≥ 0,75 (AV1 24–28, H.264 18–20; X20); тёмные гладкие градиенты — CSS, не AV1 10 бит (в Chromium ступень 0,354, X21); `-an`, `+faststart`, `-r`, полные теги BT.709.
8. Постер — кадр 0 финального файла, AVIF 18–29 КБ (720p); прокрутка — GOP 8 (×3), не all-intra (×9,3).
9. Тихая петля — Seedance 1.5 Pro [A,A] + `fixed_lens`: 720p 4 с — 10,5 ₽ (черновик 480p — 5,25); премиум — GA Omni 1.1 Flash (48 ₽, 1080p, поля `*_frame_url`) и Kling 3 (50 ₽); Seedance 1.5 Pro снят у BytePlus — в polza через KIE «до поры».

   стоп-кадр) → для петли не брать; финал 1080p — Seedance 1.5 Pro 8 с 45 ₽; Seedance 2 Mini [A,A] — референсы (шов 7,21); выходы
