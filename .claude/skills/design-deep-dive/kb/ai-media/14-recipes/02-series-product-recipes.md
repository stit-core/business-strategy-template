## 1. Серия иллюстраций фич и пустых состояний (`IMG-ILLUSTR`, `IMG-SERIES`, `VEC-ILLUSTR`)

### 1.1 Цепочка

Паспорт (`illustration` + `style_blocks.illustration`) → **эталон**: 3 кандидата одного сюжета (E-11: Flare, NB2, Seedream 5 Pro,
13,8 ₽) или Recraft V4.1 Vector (G-10, 8,74 ₽ RouterAI) → голос заказчика → серия от эталона (E-12 у E, G-11/G-12 у G, сетка
M-08 у M) → проверка серии → вектор (`vtracer --palette`) или растр AVIF → доставка `<img>` (SVG > 40 КБ не inline).

### 1.2 Спецификация серии

- `series.block` — дословный блок стиля паспорта (40–80 слов видимых признаков: линия, радиусы, заливка, свет, фон), первым в
  промте; компилятор отклоняет перефразированный блок в `jobs` и ставит свою метку «Series style (keep identical)».
- `references[]` — 1–3 кадра одной серии с ролью `style` и заметкой «line weight and palette only; the subject comes from this
  prompt»; три одной роли — одной фразой «Images 1-3 are style references…» (D2b; иначе FLUX раздувается до 319 слов).
- Замены запретов — без предметов: «clean unmarked surfaces», «no one in the frame»; «an empty desk…» попадёт в каждый кадр
  (F/07). Фон генерации — «plain warm white background», не «transparent» (модели polza альфы не дают; риск нарисованной шахматки).

```text
// openai/gpt-image-2.5-flare (было gpt-image-2-5-flare — id сменён в каталоге 25.09) · polza 2026-09-24 · 2K 1:1 · сетка 2×2 одной генерацией · [не проверено: M-08]

black #1C1B18, smooth flat colour only, one light from the upper left, plain warm white background, generous empty space.
Subject: A 2 by 2 grid of four separate flat illustrations of one consistent set, equal cells with wide empty gutters. A map
```

### 1.3 Нарезка, проверка, вектор

```bash
# F/06 split_grid.py · series_metrics.py · asset_audit.py · vtracer 1.0.0a4 — [проверено: F/06, G/03; серия — M/01]

99-raw/tools/bin/vtracer-1.0.0a4/vtracer -i cells/c1.png -o c1.svg \
   --palette '#FBF8F2,#E4DCCD,#1F4D3A,#1C1B18' --simplify 1.5 --optimize 2              # палитра целиком: бренд + контур + фон
99-raw/tools/node/node_modules/.bin/svgo c1.svg -o c1.min.svg
```

- Серия прошла, если `series.verdict` = pass: оттенок ≤ 10°, ΔE палитр ≤ 0,045, σL ≤ 0,04, pHash ≥ 10 (пороги F/06 сняты на фото
  — для иллюстраций калибровать по голосам, K-07); поштучно `needs_human` — нормально: стиль смотрит человек.
- Вектор: SSIM к растру ≥ 0,9, ≤ 40 КБ на SVG; «8 самых частых цветов» теряют чёрный контур — палитру задавать полностью (G/03).

## 2. PDP «пакшот + ИИ-сцена» (`IMG-PRODUCT`, `IMG-EDIT`, `IMG-CUTOUT`)

### 2.1 Цепочка

Фото товара клиента (или рендер из CAD/Blender) → точная альфа (вырез по типу объекта, H `08/01` §1.2; для банки — любой метод,
IoU 0,97–1,00) → сцена: правка «change only the surroundings» с товаром на входе (Sunburst/NB2, 4–4,8 ₽; E-10 — 8 вариантов) →
`edit_check --protect` → вклейка настоящего товара по альфе + контактная тень слоем → грейд → поставка галереей 1:1/4:5.

### 2.1а Продукт-концепт: лист ракурсов → сцены (граф BarkBox, Rory Flynn)

Только для товара, которого ещё нет (питч, концепт, макет упаковки) — существующий товар генерацией «как есть» не делаем (L

## Частые ошибки

- Серия «по соседу» (кадр 3 от кадра 2) — дрейф копится; всегда от эталона.
- Мудборд из 8 разнородных референсов вместо 1–3 одной съёмки — модель склеивает чужие детали («collide», Recraft).
- «No X» в блоке стиля и оценочные слова (stunning, cinematic) — линт паспорта (`vlm_to_dna.py validate`) их ловит.
- Перегенерировать товар до «похожего» — 25–47 % брака у лучших моделей; товар — только композитом.
- Проверять правку только `outside_leak_frac` после `--match-color` — локальная утечка ΔE 4,4 проходит (K/02).
- Сравнивать размеры предметов на разной глубине по пикселям — перспектива (2,78 вместо 3,7 у рендера E).
- 3D-иконки с альфой на однотонной секции — вес ×2,2–4,8 без пользы.
