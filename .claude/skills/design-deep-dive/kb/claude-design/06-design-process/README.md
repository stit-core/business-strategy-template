## Выжимка

1. Бриф — значениями, не прилагательными: пустое поле отдаёт решение дом-стилю модели; заказчику — ≤ 7 вопросов одним сообщением.
2. Вход один на ДС и холст: файлы `input/` в репозитории, у каждой части — канон соседней базы; артефакты — живой редактор.
3. Токены: DTCG ui → `tokens.json` ДС и `tokens.css`; на артбордах — литералы из токенов ДС, в `kit` и коде — только `var(--…)`.
4. Итерация: слить правки заказчика → пакет ≤ 7 с «Keep» → эхо → `diffshots` → «прочитать → слить → опубликовать» → коммит.
5. Прогресс — W = 3·critical + major; стоп по числам; две итерации без прогресса — сменить стратегию, не формулировку.
6. Проверка — по постоянной просьбе заказчика; слои от дешёвых; честность — critical; судья — Opus в отдельной сессии, решает человек.
7. Дом-стиль Claude и «дефолтный вид» — поимённо с порогами (капс ≤ 2 %, ≤ 7 кеглей, кратность 4 ≥ 85 %, шапка ≤ 64 px).
8. «X лучше Y» — нижняя граница Уилсона > 0,5 и ≥ 75 % пар прогонов, иначе «неразличимы → умолчание»; стратегия — на двух брифах.
9. Метки — `../../common/evidence.md`; свои метки базы: `[практика другого исполнителя]` — показано с другой моделью, на Claude нет; `[проверено: замер]` —
   замер LLM-вёрстки 2026; `[исследование]`, `[мнение базы]`, `[решение заказчика]`.
10. Правила формата типов сюда не копируются — их отдаёт инструмент `Artifact`; версии и дрейф — `../05-design-artifacts/02`.
