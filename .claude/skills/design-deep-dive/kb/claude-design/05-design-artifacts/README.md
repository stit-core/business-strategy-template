## Выжимка

1. С 26.09 из сессии Claude Code (десктоп) доступны типы артефактов **Design** — сам редактор холста Claude Design (панель свойств, твики,
   Play, страницы, заметки, комментарии, экспорт) — и **Design System** (бренд-бук, токены по темам, компоненты с превью, обложка).
   Рисует по-прежнему модель сессии: серверного агента Claude Design нет.
2. Содержимое обоих — обычные файлы под `project/`. Исходники живут в репозитории, публикуются одним вызовом `Artifact` с `root`, правки
   заказчика на claude.ai забираются обратно чтением.
3. Порядок как у Claude Design: дизайн-система из реальных источников → холст с установленной ДС → страницы процесса: направления →
   макет и прототип.
4. Редакторы сами сохраняют версии при открытии; публикация поверх непрочитанной живой версии отклоняется → «прочитать → слить →
   опубликовать», чужие ключи не выкидывать.
5. Тип запрещает самопроверку без просьбы заказчика: проверка — явный шаг процесса; `kit` — автопроверки и запасной путь.
6. Правила формата берутся из ответа инструмента при каждом вызове и в наши скиллы не копируются; версии — в `snapshots/`, дрейф — по `02`.
7. Артборд — живая страница: в Play исполняются JavaScript, WebGL, three.js, модель из Blender и библиотеки движения; файл `.glb` холст
   не принимает — модель кладётся текстом; под живой сценой — постер (`03`).
