26.09 в десктоп-приложении `Artifact quickstart intent=design` вернул тип **Design [core]** — «Design canvas for websites, landing pages,
screens, UI mockups, wireframes…: live artboards laid out on a canvas» — и указал на тип **Design System**; дизайн-систем в аккаунте не
было. Режим `/design` в этот день не перепроверялся. `[проверено]`

(`appifact_extra_export_formats`, `design_cross_canvas_paste_confirm`, `design_vector_pen`). Тип Design System: `artifact`, `assets`,
`comments`, `db`, `downloads`, `user`. `[проверено: декларация в ответе инструмента]`

## 3. Форматы файлов (пересказ; первоисточник — справка типа)

### 3.1. Холст — тип Design

- **`project/canvas.json`** — индекс: `v: 3`; `createdOnFiles {v, at}` (маркер; прочитанный — сохранять как есть); `title`; `launch`
  (`{view: "canvas", page}` или `{view: "focused", file}`); `pages [{id, name}]` (≤ 40); `boards {<файл>: {x, y, w, h, title, page,
  is_interactive, expand, print, paper, guides, radius, frameless}}` (w, h 40–8000; 80 px между рамками в ряду, 120 — между рядами);
  `order` — сзади вперёд, первый артборд — `Main.dc.html` (вход); `notes` (`title1` — заголовок нескольких артбордов, ≥ 223 px над рядом;
  без `kind` — стикер с `w`, `maxH`, `fill`; `rect|oval|pen|line|arrow|image` — фигуры пользователя, не трогать; ≤ 200);
  `designSystems [{title, namespace, artifact, version, copiedAt}]`. Редактор добавляет свои ключи (26.09 — `attachments`).
- **`project/<Имя>.dc.html`** — артборд, самодостаточная страница: `<script src="./support.js"></script>` в `<head>` дословно; `<x-dc>`
  с `<helmet>` (база страницы, цвета `a`/`a:hover`, `<link>` Google Fonts css2, правила состояний и движения по атрибутам `[data-…]` — без классов и без смены раскладки, CSS набора движения `kb/creative/11-motion-code/` — сюда же; на холсте его движение принимают в Play `[практика]`) и разметкой; корень фиксированного размера, равного рамке
  и `$preview` (у артборда страницы — резиновый корень и `expand: fill`); блок `<script type="text/x-dc" data-dc-script data-props='…'>` с `class Component extends DCLogic { renderVals() {…} }`.
- **Синтаксис**: `{{путь}}` — только поиск по точкам, без выражений (вычислять в `renderVals`); события — `onClick="{{f}}"`, `onSubmit`,
  `onChange` (JSX camelCase); `<sc-if value hint-placeholder-val>`, `<sc-for list as hint-placeholder-count>`, `<dc-import name …>` (дочерний
  артборд); Play — `<a href="Booking.dc.html">`, оформленная кнопкой (кнопка внутри ссылки глотает клик); общее состояние нескольких
  экранов — в одном артборде (`setState` + `<sc-if>`).
- **Твики `data-props`**: редакторы `text|color|int|float|range|boolean|enum|null`, `default`, `options` (у цвета — 3–4 образца), `min`,
  `max`, `step`, `unit`, `section`; `$preview {width, height}`. JSON — в одинарных кавычках атрибута; экранирование — `&amp;`, `&#39;`, `\"`.
- **Нельзя**: `<iframe>`, `<object>`, `<embed>`; построение интерфейса скриптом (`innerHTML`, `appendChild`); сеть, кроме Google Fonts и
  загрузок `/_blob/<id>`; эмодзи вместо иконок (линейный SVG); глобальные обработчики клавиш.
- Лимиты: холст — 512 файлов и 256 MB; одна загрузка — до 20 MB. `[документация типа]`
- Справка типа `artifact-type/reference/diagrams.md` в пересказ не входит — читать у типа.

### 3.2. Дизайн-система — тип Design System

- **`project/design-system.json`** — индекс: `v: 3`, `layout: "files"`, `createdOnFiles`, `title` (имя системы), `namespace` (глобал
  бандла и имя папки при установке в холст), `libraries` (`[]` без бандла; React 18 — если есть компоненты на React), `groups`,
  `assetGroups`, `sections {}`, `blobs {}`, `docs {sections: []}` (примеры `docs` в справке типа противоречат друг другу), `lastChange {by, at, via, note}` —
  пишется при каждой правке, `meta.source` — источник пересинхронизации. Индекс пишется последним.
- **`project/tokens.json`** — списки `{name, value, usage}` по семействам: `color` (+ `themes`, значение по темам; hex, rgb, hsl, oklch или
  алиас `{токен}`; без `var()`, `color-mix()` и названий цветов), `type` (`families` → `--font-<ключ>`; `groups` со `styles` → классы
  `.<стиль>`; `fonts` — только файлы, шрифты Google — лишь в `families`), `spacing`, `radius`, `shadow` и до 12 своих семейств (в «Спице» —
  `size`, `typescale`); семейства движения нет. Значение токена — одиночное: составной токен (градиент, ритм, размер) формату не отвечает.
  Имя → `--<имя>`, имена уникальны между семействами. Карту DTCG страница не читает.
- **`project/README.md`** — бренд-бук; страница дописывает генерируемый хвост («Consuming this system» и индекс карточек).
- **Компоненты**: `components/<Comp>/README.md` (первое предложение — сводка) и `preview.html` (строка 1 — маркер
  `<!-- @dsCard group="…" height=N subtitle="…" -->`; кадр заранее грузит `tokens.css`, шрифты, `bundle.css`, библиотеки, `bundle.js`;
  на `<html>` — `data-theme`); `components/bundle.css`; по желанию `bundle.js` (`window.<namespace>`, React 18) и `index.d.ts`.
- **Обложка** `components/Cover/preview.html`: папка голая (README рядом превратит её в компонент); 960 × 240–360; 3–5 цветовых блоков +
  один паттерн + имя крупно внизу слева; вывод («derivation») комментарием над SVG; пишется последней.
- Страница генерирует сама, не писать: `tokens.css`, `api/**`, `manifest.json`. Картинки и видео — загрузки по id с записью в
  `assetGroups`: в исходниках репозитория — путь к файлу ассета, id подставляет `ds_build artifact --bind-assets`; шрифты — файлы
  в `fonts/`.
- Справка типа `artifact-type/reference/migrated-compat.md` в пересказ не входит: у перенесённых систем — режим `editing: off`.
- Лимиты: 1 008 своих файлов и 256 MiB, файл ≤ 15 MiB, вызов ≤ 16 MiB. `[документация типа]`

## 4. Дизайн-система: процесс (как сделано в «Спице»)

1. **Инвентарь из реальных источников**: токены и стили кода, бренд-файлы. В «Спице» — `tokens.css` (роли цвета светлой и тёмной темы,
   шрифты, шкала 4 px, радиусы, контролы) и `site.css` (компоненты). Нечего взять — маленькая первая система (6–10 цветов, 5–7 стилей
   текста, 4 шага отступов, 3 радиуса) и честная пометка. `[документация типа]` `[проверено: демо]` Когда строить ДС относительно
   ассетов — `../../../references/phases.md § Порядок ассетов и ДС` (сайт — ключевые ассеты до ДС, кабинет — ДС первой).
2. **Имена — как в коде**: `color-bg`, `space-4`, `radius-sm`, `control-h`, `fs-display` → скомпилированные переменные совпадают с
   переменными кода, и `site.css` стал `components/bundle.css` без правок значений. Движение (`--dur-fast`, `--ease`) задано в
   `bundle.css`: у формата токенов нет семейства движения. `[проверено: опубликовано]`
3. **`usage` у каждого токена** — где и зачем; контраст — числом; слабые пары источника не исправлять молча, а помечать (в «Спице»:
   граница поля к фону ≈ 1,4:1 — ниже 3:1 для границ контролов). `[документация типа]`
4. **README — бренд-бук**: голос и содержание, визуальные основы, иконография, компоненты, правила использования с именами токенов,
   доступность и известные проблемы (в «Спице» — `small_targets_24` на 390 из прогона `kit`), источник.
5. **Компоненты** — статические превью на `bundle.css` (бандл JS не обязателен). Компоненты на React с `bundle.js` дают на холсте
   `x-import` настоящих компонентов — в демо не делалось.
6. **Обложка** — последней: блоки `color-accent`, `color-band`, `color-text`, `color-band-muted`, паттерн — дуги обода колеса (мотив бренда).
7. **Один вызов**, индекс последним, `lastChange` заполнен. Установка в холст — §5.

## 6. Связка с репозиторием проектирования: исходники ↔ claude.ai

- **Где лежат исходники** (вывод):
  ```
  docs/projects/<проект>/design/
    design-system/project/…   исходники артефакта Design System
    canvas/project/…          исходники холста
    ARTIFACTS.md              адреса артефактов, версии, контракт, дата последней синхронизации
  ```
- **Из репозитория на claude.ai**: `publish` с `root` = папка в репозитории (под рабочей папкой сессии — без лишних подтверждений).
- **С claude.ai в репозиторий**: `read url paths=[project/…]` сохраняет файлы в scratchpad → скопировать в репозиторий → дифф → коммит.
- **Конфликты — наблюдались оба раза**: (1) редактор холста при первом открытии сам записал `project/canvas.json` (пустой индекс с ключом
  `attachments`, `title: "Design"`) и сохранил версию → публикация отклонена, пока не прочитан файл; затем отклонена ещё раз («newer
  version saved from inside the page») → `read` всего артефакта + `list scope=files` → публикация прошла; (2) страница дизайн-системы после
  открытия тоже сохранила свою версию. Правило: перед каждой публикацией — прочитать живую версию, слить, сохранить чужие ключи и
  `createdOnFiles`; ещё один отказ — остановиться и сказать заказчику. `[проверено]`
- **Чего нет в git**: загрузки (`/_blob/<id>`), комментарии, совместная правка, база артефакта. В `ARTIFACTS.md` — адреса и версии.
- **Дальше в код** (вывод): токены → CSS-переменные (ДС отдаёт скомпилированный `project/tokens.css`); `.dc.html` → HTML/компоненты
  (инлайн-стили → токены); `kit` умеет кадры и проверки на обычном HTML.

## Частые ошибки

1. **Карта DTCG в `tokens.json`** (`{"color": {"brand": {"$value": …}}}`) — страница покажет пустое семейство и потеряет записи при первой
   правке. Только списки `{name, value, usage}`.
2. **`var()`, `color-mix()`, названия цветов в токенах** — такие значения отбрасываются молча.
3. **Публикация без чтения живой версии** — отказ; `force: true` стирает правки заказчика — только по его прямой просьбе.
4. **Индекс «с нуля» поверх существующего** — пропадают ключи редактора (`attachments`, `frameless`, фигуры); сливать, а не заменять.
5. **Изменённая строка `support.js`, размер корня ≠ рамке, незакрытые теги** — артборд ломается молча.
6. **Твики для текстов** — захламляют вкладку Tweaks; тексты — литералами в разметке, их правят на месте.
7. **Дырки `{{…}}` для статичных цветов** — панель свойств их не правит; литералы, дырки — только для твиков и состояния.
8. **Кнопка внутри ссылки в Play** — клик проглатывается; оформлять кнопкой саму `<a>`.
9. **README в папке `Cover`** — обложка становится обычным компонентом, у системы нет лица.
10. **Самопроверка скриншотами без просьбы** — нарушает правило типа; спросить заказчика.
11. **Копия правил типа в своём скилле** — устареет после обновления типа; ссылаться на ответ инструмента.
12. **`DesignSync` ради макета** — это синхронизация React-ДС с claude.ai/design, макеты им не делают (README, правило 4).
