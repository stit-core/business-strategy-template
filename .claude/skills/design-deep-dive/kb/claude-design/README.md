claude.ai/design**: что Claude Design умеет, что из этого есть в Claude Code официально, что делаем сами уже сейчас, как выстроить
конвейер «бриф → направления → макет → прототип → код» и что проверить тестами. Что именно должно
получиться (UI, UX, сайт, тексты, креатив), отвечают соседние базы — здесь на них только ссылки; бриф, вход холста, цикл правок и
проверки — `06-design-process/`. Цель: агент работает с Claude Design из сессии Claude Code — типами артефактов Design и Design
System; исходники — в репозитории, claude.ai — живой редактор и канал показа, синхронизация — «прочитать → слить → опубликовать»
(`05/01` §1).

## Как работать в чате Claude Code: рабочий цикл

Макет собирает Claude Design по входу холста — `../../references/claude-design.md § Вход холста` (состав входа и каноны его частей —
`06/02` §1); порядок этапов — `../../references/phases.md`. Цикл ниже — путь `kit`: схема А (`02/01` §10), доведённая до цикла правок
(`04/01` §2); `kit` — автопроверки и запасной путь (`05/02` §5). Кто делает: **Claude** — всё, кроме вкуса и решений; **заказчик** —
ответы на вопросы, выбор направления, правки по номерам, «Keep», приёмка.

```
0 сессия      Claude Code (десктоп), модель Opus 5.5, effort xhigh на ДС и первый hi-fi; git в проекте; «Help Improve our AI models» — выкл.
1 бриф        brief.yaml (06/01 §7) + ≤ 7 вопросов одним сообщением (факты свободно; выбор 2–4 варианта с умолчанием)
2 ДС          DESIGN.md + tokens.css (06/02 §2; из репо, бренда или сайта) → артборд-образец → снимок → «Keep»
3 направления low-fi артборды по названным осям, число — по роду продукта: сайт — creative 01/01 §6, приложение — ui 11/02 §2.4
              (фон hex / акцент hex / гарнитура + мотивация и компромисс) → выбор или ремикс
4 hi-fi       артборды всех ширин приёмки (+ тёмная тема, если есть) на токенах и утверждённых текстах;
              frontend-design + нормы ui / ux / site / text
5 правки      снимок с метками → «#N: …» от заказчика → эхо Claude → правка → diffshots (0 неожиданных) → «было → стало» → Keep
              (Keep принимает и структуру, и облик)
6 ревью       ui_audit.py + 34 маркера ui 11/04 + приметы дом-стиля Claude + рубрика ui 13/02 + аудит свежим контекстом
7 экспорт     export.py: PDF (страница на артборд), PNG 2×, standalone.html, zip; артефакт claude.ai — только с разрешения
8 код         та же сессия: компоненты и тема из tokens.css в стеке → снимки сборки теми же ширинами → сверка с макетом
```

Команды (`04-claude-code-native/` §6.2; браузер — headless, при свободной памяти ≥ 2 ГБ; замок браузера `shot.py` и
`export.py` берут сами):

```bash
K=../../scripts/claude-design/kit; P=design
python3 $K/shot.py $P review/iter-01 --tiles --iteration iter-01 --min-free-gb 2                    # кадры с метками, холст, marks.json
python3 $K/shot.py $P review/iter-02 --tiles --prev review/iter-01/marks.json --min-free-gb 2
python3 $K/diffshots.py review/iter-01 review/iter-02 --expect 16,22,37,38 --strict                  # код 0 = ничего лишнего не изменилось
python3 $K/shot.py $P review/try --set "color-accent=#0B6E4F;radius-md=4px"                           # «ручки»: предпросмотр без правки файлов
python3 $K/export.py all $P export --min-free-gb 2                                                   # PDF, PNG 2×, standalone, zip
python3 $K/shot.py serve $P --port 8765                                                              # живой холст для встроенного браузера
```

**Как заказчик даёт правки из чата** (грамматика — `04/01` §2.3): `#22: высота ≥ 44 · #16: текст «Посмотреть услуги» → «Услуги и цены» ·
#37: добавить ссылку «Как добраться» перед #38 · Keep`. Широкие правки: «все кнопки: …», «токен --color-accent: …», «везде: углы 8».
Предпросмотр без правки: «покажи #29 с space-section=120». В пакете ≤ 7 пунктов; всё не названное не трогать. Номера живут между
итерациями и одинаковы на всех ширинах и темах. **Где смотреть**: встроенный браузер десктоп-приложения (`standalone.html?marks=1`
или `shot.py serve`); PNG — для точных ссылок и для глаз Claude.

    По file:// обычный `canvas.html` манифест не читает. → `04/01` §3 `[проверено частично]`
22. **Публикация артефакта — только по явному разрешению заказчика**: это выгрузка на серверы Anthropic. На Pro и Max делиться можно только
    публичной ссылкой. → `04/01` §3, дока артефактов `[документация]`

24. **Код — той же сессией, без handoff.** На этапе кода библиотека компонентов — «как визуальный референс»: механику сохранить, цвета и
    размеры подогнать под токены; одна библиотека за основу, 1–2 акцента. → ux 11/03 §2.6, creative 07/01 §6.4, X-67 `[мнение]` `[спорно]`
